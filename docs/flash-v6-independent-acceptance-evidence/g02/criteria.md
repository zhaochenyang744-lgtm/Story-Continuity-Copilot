# V6 G02保护与最小回归标准

状态：先定标准，未执行回归。仅新增本文；零Provider/DB，不改产品或旧证据。V6优先修一致性P1，不自行扩展G02重设计。创建时brief_citations、engine、v2_database、provider四文件SHA256均与V5冻结一致；完整基准见evaluation/current_flash_v5/frozen-inputs.json。

## 保护口径

V5六例最终6条summary、72条item已逐条人工确认在自身绑定来源范围受支持；保护的是事实、引用和范围，不强制新版固定输出72项。每个item的每个事实分句由本项来源支持，summary独立审自己的summary_sources；全局ID并集、其他item引用、partial标签、词面相似度均不能代替支持。Memory保留subject/predicate/value，不以holder支持月牙裂纹，不以does_not_know支持坐标能力。模型原首visible、首parsed、repair、最终分别记录和评分。

| 固定草稿 | 最低保护条件 |
|---|---|
| 三句 | 三事实分别保留、自引；“她”不凭空绑定身份 |
| 299字长句 | 尾部交钥匙/得知弟弟存活的本项及摘要引用完整；坐标自引S4 |
| 1980字重复正文 | 180位置选8、未选172，8条自身ID/offset可寻址；截断/未选如实披露 |
| 同文两句 | 两位置不混ID/revision；重复文本不升级为两次新事件 |
| 昨日/今日 | 未知→读信才知两时点均保留；银钥匙不与廊桥钥匙强并 |
| 对话 | 两完整引语[0,19)、[19,45)，说话人、否认、闭引号保留；不裁定角色说法为事实 |

## 按实际改动选择最小回归

1. **相关实现及依赖均未变：**核对四文件、共享规则/参数、六例输入与旧结果hash；复核已见最终输出的绑定/范围。足以报告“G02基线保存且本轮未触及”，不能冒称新代码行为或模型质量再次通过，无需重复真实调用/UI验收。
2. **共享provider/engine有改动：**仅文件hash已不足。离线将六份V5原请求＋原首答送入当前validator，比较最终analysis与旧保存结果；对差异逐item/summary人工核查。若仅一致性提示规则改变，另外核对六份context_brief提示构造、schema、bindings、预算和参数仍不受影响。若涉及共同响应解析/错误路径，补现有有界离线控制：非法JSON、超时/错误映射、usage缺失/部分、既有重试上限；失败不得变成成功空结果。
3. **claims构建/检索/持久化路径改变：**旧请求重放不足；主控另行安排六例当前隔离API捕获及保存后重读，核对新身份、来源选择、范围和显示excerpt。只有UI路径实际改变才补相关浏览器回归。当前阶段不执行上述操作。

## 可选的有界提示修订

现有prompt已经要求摘要自身引用，单纯重复该规则不能证明修好。若主控选择修订，可限于context_brief：先选不超过3个摘要来源，再写仅由这些来源支持的句子；引用容量不足则把背景留在有自身引文的item。每项只写其自引记录支持的属性；增加月牙裂纹、坐标、身份等额外细节时须同项加入实际选中直接来源，否则省去该细节。记录新prompt版本和hash，修订本身不算实证改善。

## 必须保留的边界

V5六条原首摘要均有自身引用缺口，对话首item的裂纹仅被holder部分支持；最终fallback不得替首答记分。三个P3（同文重复/倒序、摘要冗长、对象类别）独立保留。重复正文是位置范围回归，不能证明172种新情节召回。每例10个父chapter正文为空，仅snippet+Memory，不能声称完整章节/长篇来源链。已见单次合成材料、有限中文引语、无作者计划和无真实作者研究的边界不变。

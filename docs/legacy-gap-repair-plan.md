## 实施顺序

1. **G01 时间与证据**：核对连续性提示词及确定冲突守卫。添加一般化的“后来获知、回忆、谎言”时间约束和独立合成材料；记录首答、校验与最终产品层次。离线检查不得代替真实模型语义验证。
2. **G02 当前简报**：沿现有有引用分项重组摘要路径，确保非空已保存草稿有可定位引用和覆盖状态。草稿遗漏、预算截断及证据不足必须降为部分简报。保留作品/版本绑定。
3. **G03 影响来源**：目标事实的直接来源在已有有界来源槽中优先选取，校验项目、章节、来源版本；记录选中/缺失/截断。缺原文时不输出确定的原文章节结论；不扩张为全书扫描。
4. **G04 富文本替换**：先在真实浏览器重现 marks 丢失。仅对唯一定位、单段、格式一致的内容保留 marks 替换；混合格式、跨段、歧义、结构变更保守拒绝并提示人工。保留建议进入未保存草稿、显式保存、过期守卫。
5. **G05 请求计数**：在实际 HTTP 派发前完成额度预检与持久计数，覆盖超时重试和契约修复，避免 evaluate 层和传输层双算。测试剩余一次额度时第二次派发被阻止、费用未知值保留。
6. **G06 证据**：运行新离线回归与相关既有回归，记录失败、修复、截图、预览和未覆盖事项。G07/G08 保留待后续生产及恢复验收。

## 验收清单

| 项目 | 最低验证 |
|---|---|
| G01 | 新的后来获知、回忆、角色谎言合成输入；确定冲突必须有时间/来源支持；首答与产品处理分开报告 |
| G02 | 非空当前草稿实际被引用；遗漏、截断、无证据为部分；摘要每一分句仍来自有引用分项 |
| G03 | 原始来源在前 4 个来源槽内；跨作品/过期/缺失来源不混入；覆盖记录准确，预算不扩大 |
| G04 | 浏览器覆盖加粗、斜体、列表、引用、换行/CRLF、重复文本；成功时格式不丢，失败时正文不变且明确人工处理 |
| G05 | 首次超时后重试记两次；只剩一次额度时不发第二次；异常费用为 unknown；并发额度不超限 |
| 既有流程 | 相关后端测试、前端静态检查及受影响浏览器流程回归；截图在本工作树新证据目录 |

验收分层：本地自测交给主控独立复验；G01 真实首答效果、真实 Provider、G07 线上成功链路、G08 完整应用恢复均不因本次离线通过而判定关闭。

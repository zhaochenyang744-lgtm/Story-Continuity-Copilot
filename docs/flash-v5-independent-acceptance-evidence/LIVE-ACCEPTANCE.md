8 个冲突首答均识别了核心矛盾。01、04、10、16、19 引入 `context` 或 `supports` 等证据关系，触发当前 confirmed_conflict 要求所有证据均直接反驳的合同；19 另有类别差异。22 的关键 watch_log 支持矛盾，但它还引用了本次 allowed_evidence 未提供的 span6；对应 Memory 存在不等于该 SourceSpan 已获允许。这些结果不能统称为模型完全没看懂，也不能因核心结论正确就判产品通过。

11 和 23 允许受支持的 state_change，但本次均返回合法空 issues，未实际覆盖真实模型 state_change 对象的合同表现。04 和 16 的 explicit_overlap 有同刻文本依据，只是不符冻结时间枚举；不将它们记为模型看错时间。13 最终产品清除了首答建议和 apply_suggestion，保留正确亲属冲突，这属于产品处理差异，不是新增模型回答。

**评分解释限制：** 15 和 24 的草稿使用“记录确证某事实”的措辞，而来源明确未记录出生顺序或同伴姓名。输出主要论证记录归属是否成立，并未断言相反的故事事实。这允许文献归属层面的冲突解读，与冻结 gold 的事实未知解读存在歧义。本轮保持原分母和失败结果，不在看到输出后改 gold，也不把这两例简单称为幻觉。未来应在新冻结版本中先澄清所判命题；这项歧义不消除本轮其余明确失败。

## G02：最终引用支持有限通过，原始摘要不通过

| 层次 | 六例结果 | 可支持的结论 |
|---|---|---|
| 原首答自动 citation binding | 6/6 pass | 引用 ID 能绑定；不证明引用支持全部文字 |
| 原首答摘要逐条语义支持 | 0/6 完整支持 | 六条摘要均包含其自身 summary_sources 未覆盖的事实 |
| 合同修复 | 0 次 | 没有通过再次生成挑选更好的 G02 答案 |
| 最终产品摘要及 items 的引用支持 | 6/6 有限通过 | 产品从绑定来源重建文字后的支持关系成立 |

例如 25 的摘要同时写了罗盘持有人和温岚知识，但摘要仅引用三条草稿；29 又在摘要里加入未引的罗盘持有人；30 的摘要引用草稿和罗盘 Memory，却还写了白船和异常雾钟。其他 items 的引用不能借给摘要。

30 的原 item 还把“月牙裂纹”附加到只支持持有人的 Memory 引用上；这一细节存在于另一 SourceSpan，不在该 item 自身引用中。29 的原 item 将单引草稿句中的“她”补成“温岚”，身份来自相邻的另一草稿句，属于引用自足性的边界提示，不是凭空身份幻觉。最终产品保留来源原文或受限 Memory 表述，未保留上述不受自身引用支持的扩写。

最终保护有效并不等于摘要有用性已解决。长句案例最终摘要长 390 字，重复正文会占用多个卡片和摘要位置，同文异址的顺序仍有阅读成本。这些 P3 问题保留；不能把保守逐字渲染包装成模型自然语言摘要能力提升。

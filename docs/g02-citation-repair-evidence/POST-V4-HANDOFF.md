## Remaining limits

- Source-rendered items trade concise paraphrase for attributable text. A cited passage containing dialogue is evidence of that passage, not proof its speaker told the truth. Some optional background items may be omitted by the twelve-item and 400-character/three-source summary limits. Draft claims longer than the supplied 540 characters and unselected draft scope remain marked partial.
- The post-V4 G02 changes have offline and browser evidence, but no later real Flash run was authorized or performed. Do not attribute V4's real observed quality to the later code without stating this version difference.
- The comparison set needs independent gold/semantic review before any formal score. Scripted minimal responses demonstrate expressibility and API scoring, not actual model precision, recall or category accuracy. A future real comparison run requires separate authorization and a new result identity.

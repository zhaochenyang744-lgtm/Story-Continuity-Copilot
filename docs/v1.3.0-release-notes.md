# Story Continuity Copilot v1.3.0 local release candidate

The repository product version is v1.3.0. The active online version remains v1.2.0. The private npm package keeps technical version 0.1.0 for compatibility.

## Product changes

- Added versioned Author Context for story, character, and world planning without mixing planned intent into written records or confirmed Memory.
- Added sourced pre-writing chapter briefs and saved-draft plan alignment on the existing Writing page.
- Added project-scoped, per-character versioned aliases with normalized uniqueness, a 20-active-alias limit, optimistic conflict handling, idempotent writes, and archive history.
- Added evidence-backed change-impact Runs for explicit author proposals, bound to draft, source, Memory, Author Context, and alias snapshots without automatic prose or data writes.
- Added bounded project Q&A with explicit confirmed, written, and planned scopes; answers report answered, partial, insufficient, or conflicting status and cite only resolvable records from the selected layers.
- Added author-owned foreshadow records with optimistic versions, idempotent writes, archival history, planted and resolved source links, plus AI scan candidates that require an explicit accept, edit-and-accept, or reject decision.
- Added bounded revision-plan Runs over selected Issues, strict same-Issue Evidence, explicit accept/edit/reject decisions, and persistent versioned revision tasks whose progress never changes prose, Issue state, checks, or canon automatically.
- Added explicit new, changed, and invalidated fact review on the existing Story Memory page.
- Added atomic ChangeSet and MemoryVersion creation, rejected-only coverage closure, stale binding detection, retry, cancellation, and rollback behavior.
- Added a persistent desktop global-rail collapse control and returned the released width to project and writing surfaces.
- Expanded wide-screen operational layouts, centered bounded forms, and unified page, section, item, body, and metadata type hierarchy across routes.
- Rebuilt the author profile around real works, chapter and word totals, current writing access, and secondary profile settings; no simulated platform metrics are shown.
- Added four bundled WebP author avatars selected through a compact accessible dialog and saved by the existing optimistic profile revision contract.
- Added a desktop immersive manuscript overlay that shares the existing draft state, offers local font, line-height, column-width, and issue-rail controls, and writes only through the established explicit save contract.
- Kept desktop authoring and 390 px browse-only behavior with accessible Evidence and SourceSpan links; alias, impact, Q&A, foreshadow, revision-plan, task, candidate, retry, and cancellation mutations are absent at 390 px.

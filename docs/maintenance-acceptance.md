## 验收中发现并修复的问题

- 旧 Run/ChangeSet 在历史修订后可能继续写事实、跨账号通过待复核状态探知作品、过时分析输入继续执行，以及不同事实提案被错误复用：均增加服务端版本/所有权/完整提案校验，并验证失败事务零写入。
- 新表外键会阻止过期访客清理：按依赖顺序清理，保留项目边界与原子性。
- 历史修订需要新版数据库契约：成功初始化最后登记 schema 146，旧目标镜像缺少复核/来源版本能力时拒绝直接回滚；环境文件不能覆盖明确选择的回滚版本。
- 未初始化作品先修订会留下旧初始化来源：预览与提交均先要求完成现有资料确认。
- 教学章节没有完整正文，修订器原先空白：明确显示片段范围，禁止把片段提交为完整原稿。真实导入作品继续支持修订。
- 受影响事实待复核时，检查预检原先返回笼统的初始化错误：改为明确的待复核错误与处理入口。
- 旧浏览器测试仍把富文本当 textarea、正文标签定位混入初始内容：更新为当前真实 DOM 契约；原保存、幂等和并发断言保留。
- 手机阅读区继承桌面固定高度、富文本只读语义缺失、复用后待处理计数未减：均修复并通过浏览器回归。
- Pro 的原模型问题、产品处理与验收脚本误用已分开记录；没有覆盖失败轮次或把处理后的结果算成首次模型正确。

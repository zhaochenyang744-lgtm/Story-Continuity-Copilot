# 正式集主控逐题自查

主控先写设定与起始资料草案，正文作者按四章交接逐章手写，主控接收后登记实际变化与下一批约束。题目、理由及语义要点由主控逐题写定，程序只序列化既定文字并检查结构、重复、位置和哈希。

每题重置起始资料。主要动作按expected_actions第一项计；二动作题要求两项分别有依据。章内位置是去标题后首汉字一基位置；引用按出现次数统计，并另列唯一引文。专名在八汉字照抄比较中作为断点，不能删后拼接；新颖性只去空白和Unicode标点，保留大小写。

五条过时事实仍保留旧值；六条正文缺项不提前塞进资料；四条已收未标仍保留旧状态；另三条真正未解。职业、具体职责、实际保管、存放位置和身份鉴别分别核对。共享草稿不是已完成正文证据。

# 第21章 不替旧秤作答

第二十一日清早，坠石厅门外的积水还没干。柯沉芷把今日要听取的异议抄在新页上，旧页仍按原来的顺序放着。门口有人问，事情既然已经有了结论，为什么还要到场。她先请对方擦去鞋底的泥，再说结论覆盖哪些动作，与接下来尚须办理什么，应当分开问清。

任绯棘没有让人替自己去取封存物。她回到铺内侧石台，看过封套边沿，才让等在门边的见证者进来。包裹仍在那里，封口没有打开。她今天来说明的是下一步怎样在场，不是独自放回重量。帮工抬起空篮要让出通道，她伸手止住，等另一人把脚边滚动的小石片拾走。

厅里，伍燃缇站在窗旁整理昨日留存的测量纸。矮凳没有被扔掉，只挪到不妨碍出入的一侧；脚踝好了，也不必用别人不能坐来证明自己能站。他找出一处被水晕开的箭头，请柯沉芷暂时别照着描。他记得大致朝向，却不愿让今天画得清楚的线冒充昨日原来就那样清楚。

仇照缄听见这话，将自己夹在两页间的说明抽出来。他原想把那一段誊得顺些，读过两遍，还是决定让旁边的更正留在旁边。第一次怎样看、后来凭什么改口，都不该为了一页整齐的纸藏起来。乌岑弥在对面腾出地方，问他准备从哪个动作讲起，没有抢着替他给出一个省事的开头。

宋织宵送来的热食放在外间。她等人吃完再收碗，顺手将压在门槛边的干布提开。那只无人认领的空核座仍不能随便搬去抵门，暗渠边的紫色石屑也没有因为审理继续就多出一个来处。她望了望里面，想问扣上的旧字，话到嘴边又停住，决定等真能看清的人到场再说。

蓝契野站在平地上查看新摆的操作台，先试了试脚边有没有晃动。他没有去碰停用的岐臂衡，替代的两架秤分开留着。他问今日是否还要搬动那只箱，柯沉芷说先听完各人的在场安排；若须从内柜取出，仍按开箱原有的见证条件办理，不能因为熟人都在就省略。

廊下有人把伞靠在了门边，水慢慢流到昨日粉笔留下的短线上。伍燃缇拿布吸去水，没有顺势延长那条线。任绯棘回来时，众人都把还没讲完的话留在原处。她放下湿伞，拉开一张凳子，请第一位要补说明的人先坐。

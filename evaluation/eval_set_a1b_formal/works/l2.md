# 第一章 帘后的呼吸

桑翎走进弧眠站的休息处，发现本该起来接班的人还蜷在帘后。有人伸手要拉开帘子，她轻轻挡住，让对方先看清递到手里的轮值纸。两张纸上的交接次序没有对齐，醒着的人已经等得不耐，睡着的人却以为自己还能再歇一会儿。她把带来的空记录板靠在身侧，蹲下来找那一处错开的位置。

“眠灯，你是不是也没睡？”帘边有人低声问。眠灯是桑翎的别名，大家看她抬头便将声音放轻了。她没有顺势讲自己的困倦，只请问话的人先去确认另一端是谁在等，别让一个误会同时叫醒所有人。帘里传来翻身的动静，刚醒的人坐起来，以为耽误了重要的观察，急得连披在肩上的布都没理好。

桑翎将两张纸摆到他眼前，指明需要核对的地方。那人看完，眼里的慌张渐渐变成懊恼，问是否该立刻去补上。她请他先站稳，把真正接班的人找到，再决定自己往哪里去。外面等待的同伴回来时，手里多了一张写清现状的小纸片，几个人终于能把各自正在做的事接起来，没有继续靠猜测填空。

离开休息处，桑翎看到一扇观察窗后暗着的叶群。它们没有因为人的催促就舒展开，薄叶贴在一起，只在光线边缘露出一点轮廓。她在窗前停了片刻，随即转向值班处。身后有人重新拉好帘子，有人擦着脸去接自己的工作，布帘起伏两下又安静下来，弧眠站的这一轮没有从齐整的口令开始，而是从几个人重新确认谁可以继续睡开始。

# 第二章 镜面留着一块暗处

霍准将观察纸平放到窗边，发现自己的影子正遮住最想看的部分。他挪了挪身子，纸上的暗处跟着移动，旁人却以为记录里的光照正在改变，急忙低头另写一行。霍准用手指按住那一行，示意先不要接着抄，再将身体移开，让真正的记录重新露出来。

“石针，把镜子往这边一点。”一名同伴说。石针是霍准的别名，他应声调整位置，却没有把物件递走。苍蓝孢镜最初由霍准保管，检查过表面后，他将它放在自己伸手可及的稳处。桑翎从另一侧探看，见边缘沾着一小点浮尘，提醒他别将灰点与要观察的东西混在一起。他便先让旁人退开呼出的气，待镜面清楚再继续。

同一片薄叶，换个角度便显得不一样。有人指着较亮的一边，说这簇大概更适合第一批送走。霍准没有接受这个结论，让对方先写清自己实际看到的是哪一处，再比较另一侧。桑翎把遮住光的纸移开，叶缘亮起来，先前显得暗淡的部分也有了层次。刚才急着作判断的人看了看，将那句推测划开，另记观察条件。

离窗前，霍准又回头确认桌面。镜旁没有堆满杂物，几张纸也不再压住彼此的边角。他用指背轻轻抹去自己写歪的一点笔灰，将尚未看清的地方留白。桑翎问这一轮还缺什么，他指向那片容易被身影遮住的位置：“先记得人站在哪儿。”她退开一步，留给随后来的人一块不会误以为已经看全的空处。

# 第三章 没有按下的确认

同步观测即将结束，桑翎把自己看到的变化指给旁边的人，话刚说完，一块确认板便递到了她面前。递板的人手里还托着记录，想顺便让她将结果确认掉，好腾出手去收其他东西。桑翎没有接着按下，先将板稳稳放到空处，请他别让悬着的记录碰到培养盘边缘。

这不是可以顺手省去的一步。桑翎目前仅准旁观同步观测，不能独立确认观测结果。她将自己写下的内容交给具备确认资格的当值者，明确指出哪几处是亲眼看到，哪几处尚需核对。“我能把看到的讲清，不能代替最后这一笔。”她说。递板的人愣了一下，随后将板取回，按本来的流程找人确认，没有继续催她通融。

等待时，桑翎发现一行记录把起伏方向写反了。她指给当值者看，请对方回到原始观察一起核查，而不是趁没人留意就直接把结论改好。两个人对照以后修正了记录，先前快要收走的培养盘又留了一会儿。旁边有人叹气，说若早一点发现便不用都站在这里，桑翎听着，没有将这句抱怨当成应当跳过核对的理由。

确认终于完成，众人逐一收起物品，观察窗前空下来。桑翎把自己的旁观笔记与正式结果分开，怕下一轮的人将它们看作同一种东西。她最后检查那块确认板已经被妥善收回，才退到门边。刚才递板的人经过她身旁，主动问下次应先把哪一份给谁。桑翎停下来与他重新说了一遍，窗后的群落仍静静留着，人的交接却比入场时多了一处清楚的停顿。

# 第四章 根与根之间

灯光掠过根隙时，桑翎看到一小片尘痕，比周围散落的灰更有形状。她没有立刻靠近拨动，先请旁人将手中的遮片移开一点，确认不是投下的影子。角度变了，那片轮廓仍留在那里，像一处被谁认真摆过却又小得令人不敢肯定的记号。

根隙间出现了三角形的尘痕，它的来由还不清楚。桑翎在普通纸上画下所在位置，请同伴对照根的方向，免得下一回找错。“会不会有什么从这里走过？”对方问。她让他将这个想法与看见的形状分开写，不把疑问直接当成来源。另一人伸手想取走一点尘，她及时叫停，请先把完整轮廓记录下来再讨论是否需要取样。

几个人为该不该动那片尘争了起来。有人担心不动便没有进展，有人又怕一个随手动作就把唯一能看的东西抹掉。桑翎将观察位置让出来，叫每个人都先看一眼自己准备改变的究竟是什么。争论因此断续了几次，站到跟前的人不再只凭别人的描述想象，连提议取样的人也开始具体说明想动哪一小处。

当值者决定先保留现场，另安排更合适的观察。桑翎收回那张画着位置的纸，发现纸角被自己按得发软。离开前，她将临时放在旁边的遮片还原到不妨碍查看的位置，没有给尘痕划一个会误触根部的圈。几个人带着各自的问题退开，根隙里的三角仍在那里，未被抹去，也未获得一个为了安定人心而匆忙取来的名字。

# 第五章 花粉没落到想去的地方

宁绡在镜砂温室检查授粉准备，刚俯身，一点松散的粉便沾到袖边。她立即停下，把手臂移开，免得随动作带到别处。旁边的人觉得只是一点，正要继续靠近，她请对方先看清两人各自碰过的位置，再拿干净的普通布处理，不要用同一处布面来回抹。

“白瓣，这样还赶得上吗？”有人问。白瓣是宁绡的别名，她听见后抬头看了一眼等待的同伴，示意先将手上的空容器放稳。节环滴管由宁绡保管，她检查后把它留在自己的工作位置，没有让旁人为了腾桌随手拿走。粉末清理妥当，她才继续接近花簇，动作没有因为刚才耽误了片刻而加快。

一朵花的开口比旁边窄，宁绡试着换了站位，仍看不清里面。有人建议硬将花瓣分开一点，她摇头，说眼下还没到用这种办法的时候。“看不见就先承认看不见，别让它替我们的着急受损。”同伴收回手，转而替她让出光线。花簇在明暗交界处显出细细的边缘，宁绡把能确认的部分记下，给不宜急做的留出空位。

这一轮准备没有把所有空格填满。收拾时，宁绡将沾粉的布与干净的分开，提醒后来的人别因外表差不多就拿错。同伴拿起纸，指着未完成处问下一轮从哪儿接，她便逐处说明，而不是只说还差一点。镜砂温室的光落在两人之间，桌边的粉末已清净，袖口那一点小小的意外却留在记录上，提醒接手的人今天究竟停过什么。

# 第六章 还不肯裂开的薄壳

贝嵘在孵化区蹲了很久，面前的薄壳仍没有显出新的开口。旁边的人一会儿低头看，一会儿起身找别的事，终于忍不住问他是否应该轻碰一下，让里面作出回应。贝嵘将手从观察边缘收回，没有碰壳，只请那人坐到自己刚才的位置，看清已经记录的轮廓。

“浅潮，你能一直这样等？”那人看了一阵，终于问。浅潮是贝嵘的别名，他将记录纸推近一点，说自己不是只在等结果，也在看过程中是否出现需要说明的变化。对方翻过纸，发现几处写着仍未看见，便笑这也能算记录。贝嵘让他找出哪一次真的确认没有变化，哪一次只是没留意，两种空白不能随便混在一起。

壳边出现一点很淡的移动，围看的两个人同时吸了口气。贝嵘却先看旁边有没有动作带来影子，确认条件未被人改变，才记下这一刻所见。他没有宣布孵化已经成功，仍让同伴保留完整的观察位置。那人原本准备去叫更多人来，听他说明后停在门边，又走回来问是否需要自己继续看另一侧。

换班的人到来时，薄壳还保持着近乎原来的样子。贝嵘将刚才短暂的变化指出，让对方自己看纸上的依据，不把兴奋直接传成一个喜讯。他退到旁边喝了口水，才发现自己的腿蹲得发麻，站起来时微微晃了一下。同伴伸手扶稳他，没再取笑一页页似乎没有结果的记录，转身坐到观察的位置，认真找起那一点细微的边缘。

# 第七章 两张轮值纸之间

匡霁来到轮值桌旁，看见几个人各拿一张纸，都说自己才是应该留下的那一个。有人已经错过休息，有人刚被叫醒，困倦把一句普通询问也磨成了责备。她没有让他们一齐解释，先请每个人把上一项实际完成的事情指出，再将下一步写在同一张空白纸上。

“别先告诉我原本想怎样，先说现在到哪儿了。”匡霁说。她作为这轮的主持，把正在等人的观察与仍有人守着的部分分开，要求每项都得到在场者确认。一名同伴以为自己交出的纸已被接收，另一人却只看过标题，没意识到需要立刻接手。两人争辩谁该再问一句，匡霁将争论暂放，先找出眼前不能再空等的那一项。

调好的顺序并没让所有人满意。原本可以去睡的人还得留下一会儿，另一人则要先做自己不熟悉的准备。匡霁请他们把需要协助的地方说出来，不要为了证明自己没有错就什么都不问。桑翎在旁提供已经核清的观察进度，至于未完成的确认，她清楚说明还在等待谁，没有替别人的名字画上结束。

新安排被逐项读回后，桌边才有人坐下叹气。“我怕一走，回来又说我没交代。”那人说。匡霁让接手者当面复述下一步，听见一致的答复，才请他离开。纸面比最初多了几道改动，困得发红的眼睛却终于能移开。桑翎将空椅子往里收，匡霁仍留在桌旁，直到最后一个人知道自己要去哪里，才合上那些彼此错开的旧纸。

# 第八章 静音画面里的起伏

霍准面对记录时，旁边的人正争论刚才听见的回声是否有变化。声音在他身侧起落，他却始终看着画面，手指停在一处反复出现的波形附近。有人觉得让他也听一次便容易统一判断，转身就想把播放声音的部分开启，霍准立即抬手示意暂停。

霍准的耳内炎症尚未消退，只能查看静音记录，不能听辨回声。他将眼前能提供的视觉记录指给同伴，明确说明自己的范围。“这一处我能描述，你们听见的那部分要另找人核对。”对方这才停手，收回原先的催促。桑翎把两种来源分开标记，没有让静音画面上的相似起伏自动变成对声音的证明。

一名当值者带来另一段记录，画面相近，出现的条件却不同。霍准请他先找回对应的观察说明，别只截下看着像的那一小块。等待的时间里，旁人还想继续讨论回声，桑翎便将这部分交流移到另一处，让霍准能安静整理自己看到的内容。桌面上的纸渐渐分成两叠，彼此有联系，却没有被仓促合成一个确定的结论。

霍准结束这一轮时，眼睛已经疲倦。他把尚待核对的位置留给下一人，起身时没有因旁人终于安静就去补听一遍。门边的同伴问还要带走什么，他指着属于自己的普通记录纸，请对方不要将另一叠一起卷进去。灯光照着静止的画面，霍准将椅子推回桌旁，沿着让出的通道离开，留下清楚的观察边界，而不是一份假装什么都听过的记录。

# 第九章 储备格里空了一角

祝珉清点储备，发现一格看起来空着，伸手到里面才摸到被推得太靠后的普通小包。他将小包移到能看见的位置，叫准备在清单上划缺的人先停笔。对方已经把空位算进去，见他拿出来，又急着抹掉旧数，纸面被擦出一层毛边。祝珉让他换个空处说明，不必为了让数字整洁将原来的痕迹全刮掉。

“再看一格就好。”同伴说，困意让声音拖得很长。祝珉没有答应只凭眼睛扫过，他把已经确认的与尚未查看的分开，请对方先去喝口水，回来从明确的位置继续。桑翎经过时替他们留住几张快滑下的纸，问是否需要将挡着视线的空容器暂时挪走。祝珉点头，三个人重新排开眼前东西，深处的边角才露出来。

另一处数量没有疑问，用途却被两个人写成了不同说法。祝珉没有替他们任选一个，找来经手者逐项说明，发现只是交接时省略了同一段背景。话说清以后，清单无需增加一份不存在的储备。先前困得想快点结束的人用手掌撑着额头，低声承认，若按最开始的写法，下一班又得回来重新数。

盘点结束，储备格并没有被塞得一眼看上去很满。祝珉特意将能留出的查看余地保留，避免拿放以后又把小包挤进暗处。他请同伴从外侧再找一次刚才漏看的那包，见对方顺利指出，才收起清单。桑翎将空容器挪回不挡人的地方，祝珉捡起脚边一片包装纸，折好放进待清理的那堆，给下一班留下能看见空处的格子。

# 第十章 把目光交给另一人

桑翎按约来到观察位置，霍准正将交接用的记录整理好。窗后的薄叶层层叠在一起，正面看与侧面看仿佛不是同一簇。她先指出自己准备观察的范围，霍准便让她站到合适的位置，确认眼前没有被身体遮住，再逐项说明这一轮需要留意的变化，不替她预先写出会看见什么。

核对完毕，霍准把苍蓝孢镜交给桑翎，之后由桑翎保管。桑翎接稳后先检查表面，再放到便于自己取用的位置。“先让我按自己的角度看一遍，哪里不清楚再问。”她说。霍准退开给她留出光线，等待她说出实际所见，没有一见她停顿就替她接下结论。镜前那一小片轮廓逐渐被她分成可以描述的部分。

有人在后面问是否可以马上换下一簇，桑翎请对方先等这一轮记录完成。她发现自己写下的一句太笼统，不能让后来者知道看的究竟是叶边还是重叠的影子，便重新描述给霍准听，确认表达能对应到眼前。对方只指出记录是否清楚，没有代她作出新的判断。需要正式确认的结果仍按程序递交，没有因为一次物件交付就改变权限。

交接结束后，霍准拿走属于自己的纸，桑翎继续留在观察位置。她没有急着把所有薄叶都看完，只将第一处尚未看清的留给下一轮。周围的人陆续散去，呼吸吹到镜面的机会少了，边缘反而更容易辨认。桑翎抬头确认身后还有人需要经过，往侧面挪了一点，手上的观察没有停，给其他人的空处也没有被占去。

# 第十一章 匣盖外的一只手

贝嵘走到孵化看守的位置，先看见一只手伸向匣盖。那位同伴想替他打开，好让观察开始得快一些，却没弄清他打算先查哪部分。贝嵘请他停住，让手离开盖缘，再将边上的普通记录纸摆到能对照的位置。对方有些尴尬，说自己只是想帮忙，没有打算动里面的东西。

白涡孵匣最初由贝嵘保管，他将匣体放稳，按眼前的观察安排逐项查看，没有急着让盖子敞开。看不清的部分先换个站位，不能确认的就记下来。“替我让出光，比替我先打开更有用。”他说。同伴照做，原先被手影挡住的边缘露出来，两个人终于能看到同一处，不必隔着彼此的身体猜测。

记录中有一项空白，来接班的人以为贝嵘忘了写，伸笔便要补上。他抬手制止，说明那是尚未得到足够观察的地方，不能拿相邻一项看着差不多来替代。接班者又将笔收回，问应该从哪里继续看。贝嵘给出自己停下的位置，请对方先复述一遍，免得一句未完就被当成整个过程已结束。

旁边的光线切换时，几个人都下意识挪动，贝嵘让匣体保持稳妥，不随人一起匆忙移动。等大家重新站好，再比较眼前的变化是否只是观察条件不同。结束以后，他把盖缘旁的零碎纸角收干净，叮嘱同伴不要留下容易被误认为记录的废片。最先伸手的人离开前又回头确认是否还有要帮的，贝嵘请他拿走空杯，给下一位靠近者留出平坦的位置。

# 第十二章 卡片上窄窄的格

温炬整理自己的卡片，几张薄纸卡在一起，分开时发出轻微的摩擦声。他把一张托在掌心，沿边慢慢拨开，没有为了整齐将卷起的角硬压平。旁边的人见他迟迟没收好，问卡片上是不是写了什么非得现在确认的事，温炬便将正待归位的一小叠放到桌面，让对方先别往上压东西。

卡片被移向亮处，印着月份的窄格露出来。温炬出生的公历月份是二月。他将那张个人卡放回该在的位置，继续整理其他纸边，没有拿这段闲谈来延展一串家事。“字没看清，就先别替我抄。”他对想帮忙的人说。对方收住笔尖，转而去清掉桌边遮光的空盒，让温炬能自己核对。

一张卡落到膝旁，帮手弯腰去捡，差点碰翻桌角的小杯。温炬先扶住杯，再让他把卡放到干净的地方，不急着塞回原叠。两人因此多花了一阵工夫看纸面有没有沾水，所幸只有边角被袖口擦过，没有弄湿。帮手说自己越想快点结束越添乱，温炬将桌面空出一点，让他一次只处理手边已经说明的那几张。

外面有人路过，问他们是否还在忙，温炬应声后把已整理好的先收住，未看完的单独留下。他没将两堆合在一起装作大功告成，也没要求帮手为那一下失误再反复道歉。杯子被移到不会轻易碰到的位置，卡片的边缘静下来。温炬最后看了一遍桌缝，确认没有薄纸滑进去，才将剩下的工作带到更安静的一侧继续。

# 第十三章 胶面下的气泡

邵璇把培养介质转到斜光下，一处亮斑随之变细。来查看的人立刻问这是否说明内部已经变化，她没有点头，先请对方将脸移开，免得呼气让表面更难分辨。另一只普通浅皿放在旁边，她用它作眼前观察的对照，逐项描述看见的形状，没有把亮得不同直接写成性质不同。

“它是在里面，还是贴着表面？”邵璇问。旁人原以为答案明显，换到她示意的位置后却迟疑了。她让每个人将自己的观察角度说清，自己则缓缓调整浅皿，注意不让手上的动作掀起新的波动。亮斑边缘渐渐显出气泡的轮廓，一位同伴刚要宣布问题解决，她又请他确认，这只解释了眼前这一点，并不代表整份介质都已经看明白。

接下来要记录的部分更不醒目。有人觉得继续看没有用，想把精力留给更可能入选的样本。邵璇将尚未确认的那一栏指给他看，问凭什么先替它决定不值得观察。那人没有答出，只得坐下来陪着等。桑翎在门边接过需转交的普通记录，说明这份还在分析中，不让路过的人把纸面已有几行字误当成最终结果。

这一轮结束，浅皿里并没有出现足以让大家欢呼的改变。邵璇却在收手前核清了几处原先含混的描述，省下下一轮重复猜测的工夫。旁边的同伴站起来活动肩膀，问还需要自己留多久，她说把刚才看到的位置指出便可以走。两个人在斜光里最后对了一次，邵璇将浅皿放稳，才转身去处理桌边等待已久的其他观察。

# 第十四章 空载也能失去次序

廉舟接过空载试样时，觉得重量很轻，便将几只普通容器靠得太近。走到舱际交接处，最外面的一只随着他转身偏了位置，虽没有落地，原先排好的次序却打乱了。他停住想按记忆摆回，迎面的同伴却已伸手准备接走，差点把混乱直接带到下一段。

“先别接，我这里乱了一处。”廉舟主动说。他将容器放到平稳处，与递交记录逐一核对，不用空载无所谓来催自己越过去。对方指着一只看着完全一样的外壳，问为什么还要分，廉舟请他看对应位置，如果练习时便靠猜，真正装了样本以后就更难知道错误从哪一步开始。那人听完，帮他留住记录的边角，等他一项项重新排妥。

继续递送时，廉舟没有把每一只都抱得过分用力，而是找回能看清外侧的姿势，转身前先确认空间。他遇到两名并肩交谈的人，请他们稍微让开，没有侧着身子从狭处挤过去。等候的一方因多等了片刻不太高兴，他把耽误的原因如实说明，叫对方核清收到的次序，不因这只是练习就省掉确认。

空载试样全部递到以后，廉舟并未马上返回。他听完接收者复述，才在自己的记录上标明已经完成，另将中途打乱的一处留下说明。回程的手空了，步子却没有像来时那样轻率。他经过刚才转身的位置，停下来比了比容器在身侧会占多少空间，随后将想改的姿势记到纸边，准备下一轮仍从具体的动作试起。

# 第十五章 白昼前的停手

宁绡看到一簇花的开口正合适，身旁的人便催她趁这会儿做完，免得再等到形状变化。她已经拿起普通准备物，听见催促却又放稳，转身去核对当轮的光照安排。对方觉得她明知眼前条件好还停下来太可惜，指着花簇反复说，也许只差这一下便能完成。

宁绡只获夜间授粉许可，没有白昼授粉许可。她在白昼这一轮停下准备，把还不能做的事项清楚留在记录中。“花开着，不等于我有权把这一步做了。”她说。同伴想再争取，便问可不可以先动一点再补申请，她没有答应，指明眼前可以继续观察，却不能把观察悄悄当成实施的一部分。

两人留在原处看花簇缓缓变化，等候变得令人心焦。旁边有一朵开始收拢，催促的人低声叹气，仿佛错失已经落到他们身上。宁绡将收拢的过程写下，没有为了让记录好看只保留最舒展的一刻。桑翎经过时询问进度，她说明哪些已经看过，哪些因许可未做，不让空白被理解成自己忘了处理。

离开前，那名同伴仍说申请应当更早提出。宁绡同意可以把需要白昼试验的理由整理清楚，递交讨论，却没有给出一定会获准的保证。她收起未用的东西，将不再需要等待的人放去休息。花簇留在光中，没有承担一次未经允许的抢先行动；纸上的遗憾也被留下，等可以讨论的时候，大家能看见停手确实付出过什么。

# 第十六章 先说出眼睛看见的

尹禾来到观察位置，兴奋得一连问了好几个问题，最后自己也忘了最先想问哪一个。桑翎让她先坐稳，将随身的普通纸放到不会滑落的地方，再挑眼前一处真正看得到的细节。尹禾指向一片边缘透明的薄叶，说它大概准备休眠，说完便抬头等一句对不对。

尹禾的观测训练由桑翎负责。桑翎没有替她确认那个判断，而是将问题退回到描述：“先别说它准备做什么，告诉我你看见了什么。”尹禾低下头，慢慢说出边缘透亮、中央叠着阴影，终于发现自己刚才用一个结论盖过了好几种不同所见。桑翎请她把这些分开写，需要正式确认的部分则仍交给相应的当值者核对。

写到一半，尹禾嫌自己的句子太碎，想合成一句漂亮的话。桑翎让她读给旁边的人听，请对方照文字指出叶上对应的位置。对方指错一处，尹禾才明白含混的词会怎样带着别人看偏。她重新改写，不再着急证明自己已经懂得种群全部的变化，只把眼前能对应的细节说完整。

训练结束，尹禾发现纸上留下很多删改，比来时想象的笨拙。桑翎让她圈出最容易混进推测的地方，下次从那里继续，而不是把纸扔掉重装一页清楚的结果。尹禾折纸前又看了一次薄叶，想加一句，却停下来分辨那是不是自己刚想到的解释。她最终只补了一个观察位置，收起纸站到外侧，给下一位观看的人让出了光。

# 第十七章 还没垂下的遮光布

为仪式准备的遮光布还卷在一旁，几个人已经在想等会儿该站哪里。有人把想说的祝愿写在小纸上，折好又展开，怕自己到时忘词。匡霁来到众人之间，没有立刻让他们各归其位，先请负责准备的人将手上的东西放稳，把尚未实施的事项逐一停住。

首次遮光授粉仪式在开始前正式取消，根本没有举行。匡霁将取消的决定讲清，没有用改个时间再办来安慰在场的人，也没有让大家象征性地走完一部分当作已经开始。“今天到这里，别为留个完成的说法继续做下去。”她说。宁绡将未使用的准备物收回，其他人看见她停手，才陆续放下自己握着的东西。

失望并没有因决定明确就立即散去。有人问那一轮准备是否全白费，有人责怪消息来得太晚。匡霁请他们把已经消耗与仍可收回的部分分清，不让争吵阻碍妥善收尾。桑翎帮忙将普通记录分开，注明哪些只是准备，避免后来有人看见排好的步骤就以为现场曾照着做过。

写祝愿的人把纸揉成一团，想丢掉，又捏在手里没有松开。宁绡经过时没有劝他立刻振作，只请他让出需要搬物的地方。那人退到侧面，沉默地帮忙接住卷起的布。大家最后离开，现场没有仪式后的热闹，也没有为补偿失落而临时安排另一场。桑翎回头确认未动用的部分已经收妥，跟着宁绡走出去，将没有发生的那一件事，清楚地留在了没有发生的位置。

# 第十八章 没有回应的气味

贝嵘查看孵化环境时，同伴忽然皱起鼻子，问他有没有闻到一点异样。贝嵘停下动作，看向记录，又抬头确认对方指的是哪一处，没有装作自己也已经察觉。那人以为他太专注没听清，将问题重复一遍，顺手把一只普通容器往他这边移近。

贝嵘暂时失去了嗅觉，无法辨认气味。他让同伴把容器放稳，明确说这部分不能由自己的鼻子来作判断。“你闻到了什么，要按你的观察记；我这里不能替你确认。”同伴这才收回试图让他靠近再闻的动作，转而说清自己察觉的位置。贝嵘记录后请有条件的人继续核查，不把自己没有感觉当成没有异常的依据。

接下来的工作变得更费周折。旁人随口一句差不多正常，贝嵘也得问清这是看见的、量到的，还是闻出来的，听久了同伴难免不耐。“你问得比我闻得还仔细。”那人抱怨。贝嵘没有反驳，只指出若不同来源混写，下一轮自己仍无法知道哪一项可以直接接着看。对方叹口气，将刚才省略的部分补全。

核查暂告一段落，贝嵘收起普通记录，肩背因为一直俯身而有些僵硬。他没有反复凑近容器证明情况会好转，而是把可继续观察的位置交代清楚，再请同伴将需辨味的部分留给合适的人。离开前，那人主动问下一班是否也要知道，贝嵘点头，让说明与工作一起传下去。桌边没有一句夸张的鼓励，只有下一次谁来辨认气味的问题终于不再含糊。

# 第十九章 暗处又亮了一次

索迦来到观察位置，先听见有人争论那一点冷光是不是自己看花了眼。光刚才闪过，等大家一齐盯住，又迟迟不肯出现。有人想将附近的照明改动一下，索迦让他先停住，保留当前条件，再各自说清刚才站在哪里，别一边改变眼前景象，一边寻找原先那一下。

过了一阵，冷光再次短促地亮起，随后消失。重复的冷光闪烁来源不明，尚不能确定是否与种群有关。索迦把出现的位置与大家的观察角度记下，没有提前认定它是哪一种信号。“先把亮过与为什么亮分开。”他说。桑翎请同伴将没有亲眼看到的一次标清，不将听别人转述的闪光补成自己的经历。

为了等待下一次，几个人挤到同一边，反而相互遮住视线。索迦让他们散开，保持能够对照的位置，自己也退到旁边，不做唯一盯着暗处的人。等待里有人咳了一声，旁人立刻回头，错过了一段能够持续观察的时间。桑翎没有责怪，只让记录如实反映中断，不把没看见写成那段时间绝对没有发生。

这一轮结束，冷光没有给出大家想要的说明。有人不甘心，提出再守到它出现，索迦看见几张困倦的脸，请他们别把疲劳当作耐心的证明。他将待观察的范围留给下一轮，眼前不拆、不猜、不替暗处添出一个完整故事。桑翎收好记录，最后回头望了一眼，那里仍有细薄的轮廓，光没有为了送他们离开再亮一次，疑问便安静地随纸一起留下。

# 第二十章 把说话留到外面

重新安排静默观察时，桑翎发现众人把安静理解成了谁都不能动。有人站得腿麻仍不敢挪，有人想问记录位置又硬咽回去，结果交接比平常更乱。她先请大家在观察区外说明各自需要，再把进入与离开的动作安排清楚，不让一个想认真执行的念头变成无意义的拘束。

霍准带来静音记录，放到不会挡住他人视线的位置。索迦则指出哪几处需要避免人声干扰，哪些只是要留出连续观察，并不要求每个人屏住呼吸。“不舒服就退出换人，别靠忍到最后证明自己专心。”桑翎对同伴说。几个人终于动了动肩膀，承认刚才一直惦记着什么时候可以发问，反倒没看清该看的部分。

新一轮开始，进入的人各自找到位置，外侧留有人接应需要替换的同伴。一次中途停顿被明确写下，另一处观察也没有因为大家都很安静就自动得到确认。桑翎将自己的记录递给当值者核对，继续等正式结果。霍准只查看手边的静音内容，没有被人临时要求补听任何片段，索迦把听觉部分的疑问另放，供后续接手者逐项查清。

结束时，人们走到外侧才陆续说起刚才的发现，话语不再全挤在同一个看不清的位置。桑翎听见有两句描述互相接不上，便请说话者分别指认所见，留下需要下一轮复核的地方。“这次至少知道我们在哪儿停过。”有人说。她点头，将未确认的页留在原处，最后一位观察者从里面走出，门边空下来，下一轮的准备也有了可以从容接上的间隙。

# 第二十一章 指尖透过去的光

桑翎收拾观察旁的零碎，一枚透明花瓣停在浅浅的阴影里，几乎与衬纸融在一起。她伸手将它托起，光从指间穿过，边缘才显出轮廓。正在清走残片的人停在一旁，等她把手里的东西一同放过来。桑翎没有照做，而是先将花瓣放到干净的平面上，继续腾出周围的位置。

清理结束时，桑翎把那枚透明花瓣留存下来，没有丢弃。旁边的人见她的手已经空出，便问：“这一摞观察纸，先送哪一份？”她回头指出尚需核对的部分，叫对方别把已经抄清的与临时记录混在一起。两人逐张翻过，发现夹在中间的一页只有半段描述，若直接收走，下一班很难知道观察究竟停在何处。

那位同伴想凭印象补齐，桑翎请他先说清是否亲眼看完。他皱眉回想，终于承认中间离开过一次，只听回来的人接着谈起。桑翎便将缺少的部分留明，去找真正看过的人核实。她们站在桌旁等了好一会儿，来人却也只能说明其中一段，余下的空白依旧没有合适的内容可以填入。

“那就空着吧。”同伴低声说，像终于放下要将一页纸做完整的执念。桑翎点头，把需要继续观察的说明写在旁边，让空白不至于被误当成遗漏。移交的纸叠整齐后，两人将散落的普通薄片收进待清理处，桌面重新露出原来的颜色。桑翎最后检查交给别人的是哪几页，又听了一遍接收者的复述，才离开眼前这段尚有空处的工作。

# 第二十二章 光退去以后

常规遮光观察开始，尹禾紧盯着培养盘，生怕错过光线减弱后的第一个动作。她等了片刻没看见明显变化，便想挪近一点，肩膀却挡住旁边的人。桑翎请她先退回原位，确认彼此都能持续看见，再将注意力放到样本，而不是一遇到沉默就改变自己的站姿。

盘里一小片叶缘慢慢收拢，另外一处仍保持原样。尹禾马上想说同一盘里的反应不同，桑翎让她先描述能直接看见的部分，别让一句概括掩过某处自己其实没有看清。“先把眼睛跟得上的写下来。”她说。尹禾放慢笔，分别记下两处的位置，再回头检查自己有没有因低头书写而漏掉中间一段。

有人等得疲倦，提出将光调回去，认为既然已经出现变化就够了。当值者请他说明需要结束的理由，并将意见与原定观察分开，没有因一句够了便马上改变条件。等待继续，叶缘的动作却不像众人期盼的那样越来越醒目。尹禾开始明白，后半段平淡的所见同样需要保留，不能只挑最初那一点变化当作整轮的样子。

结束以后，几个人走到外侧交换记录，发现各自低头的时刻并不一样。桑翎帮他们标出缺失，不拿另一人的文字悄悄填进自己的观察。“我写得少，倒记得哪些是自己看见的。”尹禾说。她将纸放到待核对的位置，跟着去收拾不再使用的普通遮片。盘里的变化留待有资格的人确认，观看者则先学会了面对一段没有按期待加快的时间。

# 第二十三章 梳齿间的轻灰

祝珉整理储备台，发现准备取用的东西被一层细灰罩住。旁边的人拿来普通布，想从上面一抹过去，祝珉叫他先看细处，别把浮灰全推到缝里。那人放下布，等他从身边取出一件小物，才意识到自己为了图省事，可能会给后面的清理添上更多麻烦。

灰绒滤梳原本属于祝珉，也由祝珉保管。他将梳齿转向亮处，先检查是否有先前残留的碎屑，再按眼前的需要取用。“把接灰的布铺稳，别在下面来回抖。”他提醒同伴。对方摊平布面，用手压住边角，看细灰一点点落在可见的位置，没有再将注意力只放在物件表面是否立刻变得干净。

清到一半，一小片普通纤维缠住，祝珉停手找更清楚的角度。等候的人说拉开不就行了，他请对方看旁边还有什么被带着，别只盯住最想清走的一片。两人把临近小件分开，重新处理，花的时间比预想多。祝珉便将没来得及做的留在清单上，不为了赶进度将它们也记作已经清过。

收尾时，同伴提起布角，差点又将灰扬到桌面。祝珉伸手示意停住，让他从外向内轻轻收拢，确认不会溢出再拿走。那人照做，回来时看见台面留着一块尚未处理的区域，主动问下一轮是否从这里开始。祝珉将清单指给他，等他找对位置才点头。东西并没有全部变得簇新，哪些可以接着用、哪些还需留意，却不必再靠猜测区分。

# 第二十四章 等不到的舒展

观察者换了位置，培养盘里的薄片却仍紧贴在一起。有人低声说，若它一直这样，眼前这一轮是不是便没有意义。桑翎没有回答能不能催出变化，只将上一段记录放到旁边，让当值者确认观看开始后是否改变过条件。尹禾站在外侧，数次想提问，又怕自己的话打断正在进行的观察。

“你可以把问题留在这里，不必一直含着。”桑翎把一张普通纸推到她面前。尹禾写下自己最想知道的事，回头再看，才发现期待舒展已经让她忽略了边缘很小的移动。她将那一点另记，却没有把它夸成终于开始。旁边的同伴也停下不断猜测结果的话，试着只说眼前实际发生到哪一步。

有人因疲倦要求替换，等待接手的人却被另一处工作拖住。匡霁来到外侧，先确认谁可以暂时代看哪些范围，再让需要休息的人离开，没有要求他用忍耐填补所有空缺。交接的这段间隔被明确记录，盘里的薄片不必为观察者换人作出任何配合，人也不再假装自己能无间断地看清一切。

轮次结束，薄片仍未呈现众人最初想象的完全展开。尹禾在纸上写了几行真实所见，突然觉得自己先前那句白等不太准确。她没有把这种感受写成样本状态，而是向桑翎说明自己在哪儿分过神。桑翎请她保留这一处，随同记录交去核对。两人走到门边，下一位观察者已经站稳，等候不再只有一种面孔：有人等待生命变化，也有人等同伴能够安稳退下。

# 第二十五章 两次短促的光

这一轮夜间授粉准备就绪，宁绡先请参与的人站到实际工作的位置，确认彼此能看见什么。一名同伴背对着信号所在的方向，以为只要听见别人叫就能停，宁绡让他转过身，别把关键的一步全寄托在旁人恰好看见自己。桌旁的空物件被挪开，视线间终于不再隔着一排高低不同的边缘。

宁绡用两次短促的灯闪表示停止授粉。她当面演示一遍，等众人确认看清，才继续说明遇到信号要收住手上动作，不凭自己觉得快做完了便拖延。“你们看见就停，不必先猜我为什么叫停。”她说。有人试着问是否还有另一种约定，她没有临时添设更多信号，只让大家把眼前这一种辨清，避免交接后各自理解不同。

实际准备中，一人的袖角遮到同伴的视线，宁绡便要求调整站位，而不是让后面的人探头去追那两下光。对方起初觉得只差一点，不愿重新摆东西，试着从后面看了一次才承认确实容易错过。他将普通容器移开，给视线留出空处，也让自己的手肘不必紧贴着别人。

工作告一段落，宁绡询问有谁在演示中曾经犹豫，几个人才说出自己原先没看全。她没有责备他们现在才开口，而是请下一轮接手时把站位与信号一起确认，不只在纸上抄下几个字。尹禾在旁记录准备过程，没有参与未经授权的操作。收走空物件后，原先挡住的一小块空间露出来，宁绡又从后方看了一眼，才让众人各自去休息。

# 第二十六章 一句好看却无处可指的话

尹禾交来一段观察描述，开头写得十分流畅，桑翎读到中间却找不到它对应的具体位置。尹禾有些得意，说自己这回没有把每一处都写得零碎。桑翎便请她站回观察处，用手指出句子里的每个变化究竟落在哪儿，不先评价写得像不像一篇完整的说明。

指出前两处以后，尹禾的手停了。她用来衔接的一句话，实际上只是觉得前后应该有那种联系，并没有持续看见。“这一句先拆开。”桑翎说，“你不必替它们安排一个顺畅的经过。”尹禾低头划掉连接，再把直接所见与尚待确认的地方分别摆开，字数少了，纸面反而显出几处能让旁人跟上的位置。

旁边的人拿着这份记录去看，仍将一处阴影误认成叶缘。尹禾急着解释自己不是那个意思，桑翎让她先听对方为什么会这样读。原来她写的词过于宽泛，几处都能套上。尹禾重新换成可以指认的描述，又请对方再看一次，这回总算能在同一小处停住，不必依赖她在旁不断补话。

练习结束，尹禾问自己是不是终于可以把这一页交出去了。桑翎请她按训练记录的身份递交，供进一步核对，正式结果仍留给相应的当值者确认。尹禾收起纸时已不像开始那样兴奋，却认真在边角标出需要别人复查的地方。路过的同伴想顺手拿走，她叫住对方，先把记录的性质说明白，再放手让它进入下一段工作。

# 第二十七章 没有拼成话的脉冲

索迦把古式记谱摊到桌上，先沿着重复出现的痕迹慢慢看。旁边的人见他熟悉一般信号，便把几处最难辨的推过来，等着听一段完整说明。索迦试着逐项对照，越看到后面越发现自己原先的猜法无法贯通，只得将笔从准备写结论的位置移开。

索迦此时不能读懂古式脉冲记谱，尚未译出其中的内容。他把能辨认的形式与不能解释的意义分开，直说自己需要继续学习。“我能指出它重复，不代表知道它在说什么。”同伴问能不能先给个大概，索迦没有答应，只将那几处互相接不上的尝试留在旁边，避免下一人看见流畅的字句就误以为已经得到译文。

桌边安静下来，有人失望地将椅子往后挪，觉得这份材料又得等。索迦也不愿让工作停在这里，便重新查自己的对照过程，看看是否一开始就把不同形式混在一起。匡霁经过，询问能否依赖这份结果安排后面的观察，他明确说不能，将尚未完成的状态记清，没有为了不让别人白等而替材料添出实质含义。

离桌之前，索迦把几张尝试纸按顺序留好。它们不漂亮，划去的部分很多，却能让下次回来时知道哪里已经走不通。旁边的同伴看了看，终于不再问能不能猜一句，转而问是否要将另一个观察范围暂时分开。索迦与他核对完，收住眼前未译成的材料，去做可以明确承担的事，没有让一次碰壁扩大成其他工作也跟着含糊。

# 第二十八章 被提前收走的椅子

廉舟到轮值处递送记录，发现原本等着接手的人已经离开，椅子也被收到了边上。他以为对方临时改变安排，便将纸放在桌面，准备去找下一人。匡霁正好回来，看见纸上未完成的交接，立刻问刚才是否有人当面确认。廉舟摇头，说自己以为这里已经不等了。

“椅子挪开，不是一句交接完成。”匡霁让他先将纸拿稳，自己去问离开者的去向。很快发现对方只是暂去处理一件日常事务，以为记录尚未送到，回来仍会接。两人错开的这一点空隙，被各自的推测拉成了对方不守约。廉舟听完有些窘迫，离开的人也不愿全认下，反问若只走一小会儿是否还得逐一报告。

匡霁请他们先停止互相计算麻烦，确认接手者眼下已经回到位置，再将真实进度交清。廉舟递出记录，让对方复述从哪里继续，对方则指出一处不能马上确认的内容，请他补说明。两个人做完这些，才有余力回头讨论临时离开应当留下什么可见信息，而不是只凭椅子的摆放猜想。

后来又有人经过，伸手想替他们收起桌边杂物，廉舟主动说明这几页仍在核对，请先别动。匡霁看着两人把误会落到具体动作上，没再要求谁说一句漂亮的道歉。轮次终于接上，椅子被拉回合适的位置。廉舟走到门外又转身，确认刚才留在桌上的确实只有应交出的部分，才空着手继续下一趟递送。

# 第二十九章 白昼里的争执

镜砂温室的白昼观察刚进行到一半，一位同伴又提起授粉申请，认为眼前这簇花不等人，讨论应当立刻有结果。宁绡正在记录，听见后先将纸放稳，请他指出想改变哪一步、已有何种观察支持。那人说了几句急迫的感受，却没能把需要核查的内容讲清。

“着急我也有，不能拿着急替申请作结论。”宁绡说。匡霁将问题留在待审的部分，表示这轮讨论没有批准新的实施范围，眼下继续原定观察，不临时动手。有人觉得主持只是把难题往后推，桑翎便请他看记录中仍缺的部分，说明大家甚至还没有完整描述当前所见，不能把最想得到的结果直接写进准备采取的动作里。

争执没有马上消失。一个同伴站到花簇旁反复指着，反倒遮住了负责观察者的光。宁绡让他退开，先别用讨论打断本来可以继续完成的事。那人不情愿地移开后，观察者重新找回位置，却已经错过一小段变化，只能在纸上留下中断。匡霁将这份损失也记入讨论，让每个人看清争取效率有时正让观察变得更不完整。

轮次结束，宁绡将需要补充的申请理由单独整理，不同意的意见也保留在旁。有人临走仍问是否可以先作极小的尝试，她明确摇头，未实施的部分照样收好。镜砂温室里的人渐渐散开，花簇不再被肩膀围住。桑翎带走应交的普通记录，宁绡则在外侧继续梳理疑问，白昼过去的这一段时间没有因争论而获得另一种许可。

# 第三十章 币面上的指印

陨纹纪念币被放到柔软的衬面上，温炬同旁边的人核对陈列卡，先让对方不要用指腹反复擦亮表面。那人只是想看清纹理，抬手以后，币面已经留下浅浅的指印。温炬请他将空盒挪开，让光从侧面落过来，再对照卡片需要整理的部分，不必把看见当成必须碰到。

衬面上的这一枚陨纹纪念币是唯一的那枚。陨纹纪念币刚铸成时的重量是七克。温炬把有关初铸的记录与眼前清理事项分开，不让今天怎样擦拭的过程混进那段历史。“这张写的是当时，另一张才写现在要处理什么。”他说。帮手读过两处，把刚才差点添错的备注移到正确的位置，留下清楚的对应。

一位路过的人提议将币拿起来掂掂，觉得这样更有实感。温炬没有同意这次随意拿取，只将放置位置稍作调整，让对方站在外侧也能看见。那人看了一阵，问币上的纹路是否该描得更醒目，温炬请他不要改动，只指出哪些是观看时不易看清的地方，另作陈列说明。旁边的人这才收回准备找笔的手。

整理结束，币仍安放在同一处衬面，卡片也没有被新旧事项挤得重叠。温炬检查桌边是否还有容易被碰落的空物件，帮手则收起清理留下的普通纸片。刚才留下指印的人最后又望了一眼，站的位置比起初远了些，反而能顺着光看清更多表面起伏。温炬等他离开，才将待继续整理的材料收住，桌边重新空出一道不必碰到陈列也能转身的余地。

# 第三十一章 照度换到另一侧

一盘试样被安排在另一种照度下观察，最先变化的却是人的站位。尹禾为了看得更清楚往侧面挪，恰好挡住同伴的视线，后者也跟着移动，两个人的影子在盘边来回经过。桑翎请他们先停住，让每个人都找到不需要追着亮处跑的位置，再开始记录实际的变化。

光落到试样表面，一点微弱的卷曲渐渐显出。尹禾急着将它与先前看过的另一盘相比，桑翎叫她先说清眼前的条件。“不是见过一个相似的动作，就能替这一盘讲完过程。”尹禾重新落笔，记录发生的位置与自己中途低头的间隔，没有把另一处的经验补成这里正在发生的事实。旁边的人也收回了准备说一定会怎样的句子。

等候了一阵，有一小片仍看不出明显改变，另一片却因重叠而越来越难辨。当值者没有为了得到整齐的反应就随意调整试样，先请大家确认是否有观察不到的角度。邵璇过来看介质的可见部分，指出可以继续描述的范围，未将自己的工作与整盘结论混成同一项。桑翎把需要正式确认的记录交出，自己留着待复看的问题。

收轮以后，尹禾捧着那张不太丰满的纸，问是不是还得再等。桑翎让她看清哪些已经完成，哪些需要另作安排，不要把一句再等说成所有事都没有进展。旁人开始整理桌边普通容器，她们把眼前这一盘的记录单独留好，其他分组用的准备纸仍叠在另一边，等待对应的轮次。光线停在新的范围里，观看者退开，留给后续接手的人一段尚未被预言填满的过程。

# 第三十二章 厚布压住袖口

霍准走到记录旁，伸手拿起纸，指尖却在边缘停了一下。身旁的人正把自己的位置让开，见他没立刻开始，以为记录送错了，急着解释这一叠对应哪轮观察。霍准将纸先放稳，示意对方不用重说，空出双手整理身上的穿着，再回到桌边继续核对。

霍准穿上了一件厚披衣，衣料在手臂弯处叠出几道褶。他将垂到桌边的袖口收住，没有让厚布压住尚待查看的记录。“这页别替我翻，先等我看完边上。”他对同伴说。对方停住手，低头才发现有一行字紧贴纸边，刚才若急着卷起，便容易与下一页的内容混在一起。霍准读完，指明接下去要对照的画面。

静音记录里的一处起伏看似相近，放到前后的片段中却并不完全一样。霍准让同伴保留连续部分，不要为了节省查看时间只挑最突出的形状。那人原先想快些结束，见两段对照后确实有差别，便坐回位置，把遗漏的部分重新接上。桌边没有播放回声，交流只围绕此刻能看清的画面与对应记录展开。

工作暂歇，霍准起身时袖口带到一张普通废纸，纸跟着滑出半截。他及时压住，确认并非需要交接的那页，才将它放进清理的一堆。同伴问下一轮还要从这里接吗，他指明已经核过的界限，请对方照实际进度通知来人。离开桌前，霍准又理了一下厚布，让它不妨碍转身，沿着空出的通道走开。衣角擦过椅背，他回手分开，没让椅子也跟着拖出声音。

# 第三十三章 两道细微的起伏

索迦盯着观测记录，一开始以为旁边那一道微弱变化只是偶然。他往前翻了几处，又请当值者找回连续部分，发现两道起伏有相伴出现的情形。旁边的人见他看得久，立刻问是否找到了可以用于后续筛选的标记，他摇头，让对方先看完整记录，不要把反复出现与已经理解划成等号。

观测中出现了成对的微弱电流，它们所代表的原因还没有确定。索迦将两道变化分别标出，保留中间不够清楚的部分，没有替不完整的记录画上想象中的连续线。“我们可以记成对，不能马上说是谁在做什么。”他提醒同伴。邵璇来到桌旁，只补充自己负责范围内的观察，没有拿介质的一点变化为整段信号作解释。

一名同伴希望改变当前条件，看起伏会不会随之消失。索迦请他把想法写成需要讨论的下一步，眼下先别同时改动好几处，否则即使变化也难以说清跟什么有关。那人有些失望，仍将提议写下，回来帮忙对齐已有记录。桑翎接过待转交的纸，确认上面哪些是观察，哪些是提议，让两种内容各自留在清楚的位置。

这一轮结束，桌上的记号比开始多，却没有多出一个被大家齐声认可的谜底。索迦将原始记录与自己的标注一起收好，方便后续复查，不让整理后的漂亮线条替代最初可见的样子。同伴离开时问下次能否接着追，索迦说会按安排继续，不保证很快得到答案。门边渐渐安静，他最后看了一眼那两道细微的起伏，才将视线从纸上移开。

# 第三十四章 空盘还没有分完

为后续分组准备的培养盘排到桌边，桑翎还没开口，旁人便按看上去相似的外观分成两列。她请对方先停住，眼前只是整理可用的空位与记录，不能把手上顺眼的一种排法提前当成试验分组。尹禾赶忙将自己的纸挪回原处，发现刚才已经跟着写了一句不该确定的说明。

“你写的是准备，还是已经做了？”桑翎问。尹禾读过那句话，把完成的语气划掉，重新标明待确认。邵璇检查介质相关的准备项，逐一说明哪些能在眼前核清，哪些还需要补资料，没让盘子排得整齐就掩过底下的空缺。桌旁有人觉得这样迟迟不能进入真正有趣的比较，伸手敲了敲空处，被提醒别让随手的动作碰动相邻物件。

廉舟送来普通交接材料，见桌上空间不够，先在外侧等着，没有将纸塞到一只盘下面。桑翎腾出一块平面，请他讲清这趟送来的范围，接收者复述后才让他放手。尹禾在旁看着，发现准备工作的许多停顿并非针对样本，而是为了不把人的误会带到后面的观察里，她把这一点留作自己的疑问，没有替样本写入新的性质。

收拾到最后，空盘仍有未完成核对的部分。桑翎将其与已备妥的分开，等待正式安排，尚未开始两组菌群的光照比较。旁人将临时摆错的一列复原时有些不情愿，邵璇却请他按眼前真实状态留置，不必让来者以为所有条件都已齐备。尹禾重新整理那张改过语气的纸，递出时特意说清它是准备记录，得到回应才松开手。

# 第三十五章 留在舱门外

蘅环舱的异常记录传到轮值处，匡霁先请众人停下将要进入的安排。廉舟正准备递送，接到消息便留在门外，与当值者重新核对这趟内容该怎样处置。有人以为只进去放下东西便出来，不算继续工作，脚步仍往门边靠，匡霁立即让他退回已经允许停留的位置。

蘅环舱因游离孢子超标而封存，禁止人员进入。通知在门外得到明确确认，匡霁将尚未进入的人与物都留在外侧，没有为一件忘拿的普通用品开例外。“不是进去多久的问题，现在谁都不能跨进去。”她说。廉舟把带来的东西放到安排好的稳处，原本等待接收的人也留在门外，重新说明哪些事项因此中止。

有人担心培养物无人照看，急得在外面来回走。桑翎请他把真正需要处理的问题逐条列出，交给有资格安排的人，不让担忧直接变成擅自进入的理由。可从外部取得的记录被单独整理，无法确认的地方如实留空，没人假装在舱内亲眼看过。匡霁将接下来可讨论的事项分开，让等待的人知道问题被接住，却没有给他们一个解除封存的日期。

原定轮次被打乱，休息与递送都需要重新衔接。廉舟起身将不用再往里送的物件带走前，逐一问清去向，避免只是从门口挪到另一处便算解决。桑翎收住外部记录，跟着众人退开，最后回头看见门边留出的空地。那片空不再是等待谁跨过去的准备，而是此刻必须守住的范围，门外的人仍有事情要做，却没有一个人进去。

# 第三十六章 尘落下来的形状

复查根隙尘痕的记录时，桑翎将留存的连续观察画面展开，叫同伴不要只看早先截下的一小片轮廓。画面前后的变化接起来以后，根边一簇菌丝的动作逐渐显出关联。尹禾起初只盯着原来的三角，桑翎请她把视线移向尘出现之前，看看完整过程比一张静止图多说明了什么。

根隙的三角尘痕是某簇菌丝释放孢子留下的固定喷落形状，不是足迹。完整观察记录支持这一来源，桑翎将说明交给当值者核对，随后在相关线索记录上注明已查明。尹禾看着画面中尘落下的位置，低声说：“只看最后那一小块，真容易替它想出别的经过。”桑翎让她保留这次对照，不把早先提出过的疑问从记录中抹掉。

一位同伴觉得既然有了答案，先前留的那些角度便可以舍去。桑翎请他先确认保存安排，别在兴奋时丢掉能够检验判断的依据。索迦从旁帮着找出对应片段，只处理眼前这一条线索，没有顺手给其他尚未确定的闪光或电流也套上同样来源。几种待解的问题仍各自保留，桌面上没有因收回一条便忽然空出全部疑问。

这一轮核对始终在允许工作的外侧进行，没有人进入封存的蘅环舱。尹禾整理好普通纸，指着自己原先猜测的那一栏，问该怎样标清它已不成立。桑翎让她写明核查后的结果，而不是将自己写过的错误藏去。画面收起时，桌边的人终于可以把这件事放下，留下的却不只是一个名称，还有从静止形状走回完整过程的那几步。

# 第三十七章 说给接手者的半句话

孵化区的轮值交接开始，离开的人已经困得说话断续，接手者则想赶紧得到一个简短结论。两边都站着，纸却压在桌角一只空杯下面，谁也没腾出手认真翻。贝嵘先将杯挪开，让大家坐到能共同看清记录的位置，再把尚未说完的一项接回眼前。

这次孵化区轮值交接由贝嵘主持。他逐项询问实际观察到哪里，要求接手者明确说出下一步，而不是只点头表示听见。“先别替整轮说正常，把没看清的那处指出来。”他说。离开的同伴勉强打起精神，指向一栏需要继续核查的内容，接手者原本准备直接略过，听清以后重新翻回对应记录，承认自己刚才理解错了。

涉及辨味的部分由实际观察者说明，贝嵘只核对信息如何交接，没有亲自用嗅觉确认。其余记录也按来源分开，不让量测、目视与推测挤成一行相同的措辞。有人觉得照这样问下去，休息又要少一些，贝嵘便请大家将无关闲谈留到外面，把交接只围绕必要事项做清，不用反复讲一段与眼前工作无关的经过。

最后一项被复述准确，困倦的同伴终于起身离开，走到门边还回头确认自己能走了。贝嵘明确应下，让他去休息，不再临时加一个顺手的小任务。接手者坐稳，先处理刚才差点略去的内容。贝嵘退到旁边整理普通纸角，见对方真正从核清的位置开始，才收起交接记录，让这一轮有了清楚的开头，也让上一轮终于能够结束。

# 第三十八章 量测纸上的空格

贝嵘核对量测记录时，一名同伴随口说孵化环境闻着好些了，准备把这句一并记进他手边的纸。贝嵘请对方先放下笔，说明这句话来自谁、在哪处察觉，不能因为两人站在一起就当作共同确认。对方抬头看他，明白以后便另开一行，将自己的观察放到对应位置。

“我这里按量测继续看，不替你的鼻子签字。”贝嵘说。他将能核对的记录逐项展开，遇到空格便找相应的当值者补充说明，没有靠凑近去闻来完成这一段。邵璇从旁带来介质方面的记录，先说清与孵化观察有哪些能对应的部分，剩下的仍各自保留。两人看着相邻却不相同的资料，宁可多花一阵工夫，也没有合并成一句含混的状态正常。

比较到中途，一处记录缺了前后的条件，同伴提议先按附近相似的一项处理。贝嵘问若真实条件不同，下一轮如何发现，问得对方停住。大家只好去找原来的观察说明，等候期间眼前的活停了一小段，但没有为了赶上进度替空格捏出内容。找到资料后，缺失能补到哪儿就补到哪儿，仍有一处未能确定。

收轮时，同伴主动将辨味部分单独交给相应的人，没再塞到贝嵘的量测纸里。贝嵘检查空格旁已经写明待核，才起身将椅子让给下一位。他抬手揉了揉僵硬的肩膀，将自己这一轮实际完成的事情交清。外侧走动的人渐多，桌上的几份记录仍保持各自的边界，下一人不必先猜哪一行究竟由谁观察，便能继续往下看。

# 第三十九章 没有划掉的不合格

整理一轮观察结果时，尹禾将不合格的几页先抽到旁边，想让要交的那叠更容易看懂。桑翎见状请她先停，不明白为什么被抽出的资料就不算这一轮的一部分。尹禾解释，只是觉得别人最想看留下的样本，不必一开始便翻过许多没通过的记录。

“知道哪些没有留下，才能看清我们怎么选。”桑翎说。她让尹禾把不合格部分重新放回可对照的位置，另标清结果，而不是让它们从整轮观察中消失。邵璇来核对相关资料，也指出一处拒留原因写得过于笼统，需要回到实际记录，不能只用不合格三个字代替所有细节。几个人于是将原先快整理完的纸重新展开，开始逐项查看。

这番返工让尹禾很沮丧。她以为自己做了体贴接收者的简化，却发现少掉的恰恰是别人需要检查的过程。桑翎没有责备她想把记录写得清楚，只请她分辨清楚与只留下好结果并非同一件事。尹禾翻回一页，找出自己省略的观察位置，补在旁边，再请邵璇确认文字有没有超过资料能够支持的范围。

交付时，不合格记录与其余部分一起保留，结果各自看得见，接收的人不必来回找被另收的那几页。接收者问起一处未通过的样本，尹禾这回能直接指出对应依据，不必说那几页已经抽走了。她送完纸回来，桌上多出一块空位，原本以为用不着的资料却已进入下一段工作。桑翎让她休息一会儿，她坐下来，终于不再急着将纸面整理成只有顺利经过的样子。

# 第四十章 陈列旁的家常

袁碣照料纪念陈列，先将几张被吹歪的普通说明卡摆正，再让帮手清走桌边空杯。那人边干活边说家中总有人嫌自己做事慢，问他小时候是不是也有人在旁催促。袁碣手里的动作没有因此加快，先将差点压在卡下的一小片布抽出，才抬头听对方说完。

话题在亲属之间转了一圈。袁碣出生时唯一的同胞手足是妹妹。他听帮手说得起劲，偶尔抬头笑一下，手上的活却没有停；扶稳刚被拿起的说明卡后，又提醒别把靠边的空处当成可以随意堆东西的位置。“这几张还没核完，先留在我看得见的地方。”他说。帮手点头，将手里准备收走的纸放回平处，转去处理已经确定可移开的杂物。

路过的人想在陈列边停留，帮手为了让出位置，将一只空盒往后推，恰好遮住袁碣正在查看的字。袁碣请他再挪开一点，让出观看的位置也别挡住正在进行的工作。几个人各退了半步，原本显得狭窄的桌边才有了余地。路过者看了一会儿离开，没有碰动陈列，帮手则重新站到不替别人遮光的一侧。

核对结束，袁碣将已确认的说明收齐，未完成的一张单独留下。帮手问是否还要继续陪着，他说眼前的清理已做完，若要休息就去，不必为了等一张卡站得不耐烦。那人道谢离开，临走将杯带走，免得又落在桌角。袁碣独自看完最后几行，把纸边压在稳处，陈列前的谈话渐渐远去，留下的东西仍照眼前可核对的样子安放。

# 第四十一章 纸边卷起的样本

一份待观察样本的边缘变得干涩，尹禾伸手想调整放置位置，指尖却在接近时缩了回来。她怕自己一碰，就会让原本还能看清的轮廓破碎。邵璇来到旁边，没有叫她鼓起勇气快些做，而是让她说清准备改变什么，以及这一步是否真的需要现在进行。

“我只是不想让它继续变坏。”尹禾回答。邵璇将眼前能确认的状态指出，提醒她想保住样本与随手找一个动作并不相同。两个人先记录干涩的范围，再检查观察条件有没有被途中搬动改变。桑翎从外侧拿来对应的普通记录，交给当值者核对，没有因为眼前显得可怜就将处置决定揽到自己手里。

等待意见时，尹禾一直看着那道卷边。同伴劝她转开眼睛做别的事，她却说担心一回头便看不见了。邵璇请她轮换观察，把中途离开的时段记清，不用一个人守着来保证所有可能。有人接到她的位置后，发现她其实已经看得疲倦，几处描述开始重复，便请她在旁歇一会儿，自己接着指出真正有变化的地方。

核查给出可继续采取的安排，大家按确认后的步骤处理，没有许诺样本一定会恢复最初的样子。尹禾把自己险些伸手的动作写成操作前的疑问，留给随后接手者知道这一轮为何停过。结束时，卷边仍在那里，观察记录却不再只剩她的一句害怕。她走到外侧喝了口水，听见同伴叫她来看刚完成的说明，便放稳杯子回来，将能够承担的部分重新接住。

# 第四十二章 留下来的空位置

处理记录送到桌边时，桑翎看见原本放着标本的地方已经空出。有人站在附近迟迟不走，像还想从记录里找到一次撤回决定的机会。匡霁请大家先听清已完成的情况，别将需要说明的后续事项与重新选择混在一起。纸展开，处理经过与确认结果分列在眼前，谁都不能只挑自己愿意看的那半页。

唯一的红脉标本已被压碎并焚毁，没有复制品，也不可能复原。确认这一事实后，匡霁请负责整理的人将状态记准确，不在空出的栏里留下仿佛仍能找回它的措辞。“难过可以留下，记录不能写成还在等。”她说。那位一直站着的同伴低下头，把准备添的一句也许重新取得划去，手指却仍压在纸边，没有立刻松开。

桑翎将相关观察资料分开保留，未把标本不再存在理解为此前记录也应一并消失。尹禾问那些看起来很细微的描述还是否有用，她请尹禾想一想，留下资料与保存实物并非同一个承诺。邵璇补充自己负责范围内的说明，未暗示还有另一份同样的东西藏在别处，几个整理者终于能把眼前的空位按真实状态安排。

离开前，同伴将压着纸的手收回，低声说自己还需要一点时间。匡霁同意让他先休息，其他人的工作照核清的事项接着做，不用逼每个人同时恢复平静。桑翎最后检查那一页没有漏掉确认句，才把它交给接收者。桌面空出的位置没有被别的物件匆忙塞满，尹禾从旁走过时放轻动作，没有再伸手寻找已不可能出现在那里的样本。

# 第四十三章 先送出去的诱惑

一位同伴提出先送一部分培养物出舱，认为等所有事情都核清，可能错过最合适的状态。话一出口，周围便有人点头，也有人皱眉，原本平静的交接讨论立刻变得紧张。廉舟在门边等递送安排，听见出舱两个字便抬起手上的记录，又看了看匡霁，等她明确是否真要改变这一趟的任务。

“先把你认为已经满足的条件说清。”匡霁请提议者坐下，不用热情替空缺作答。那人列出眼前看起来不错的几项，邵璇则逐一指出仍需核对的地方。桑翎将待确认的观察拿来，放在大家都能看见的位置，既不把它们说成永远过不了，也不因为催促而改成已经完成。提议者看着纸上的空处，语气渐渐没有开始时那样肯定。

讨论持续了一阵，提前出舱的提议最终被放弃，没有实施。廉舟把原先准备作修改的位置留住，仍按已经明确的递送任务安排，未将一句有人想试传给下一处当作正式命令。有人失望，说又只多了一场讨论，匡霁请他看看这场讨论阻止了哪一个没有依据的动作，不能只以是否搬出东西判断时间有没有被使用。

人群散开，提议者留下来核对自己先前略去的记录，桑翎陪他看完能确认的部分，不重复责怪他冒失。廉舟出发前再次读回任务，得到清楚答复后才离开。门边仍照既定范围留着，尤其封存处没有被这番争论打开。桑翎收好讨论留下的普通纸，眼前的培养物继续接受观察，谁也没把它们当成一场仓促勇敢的证明。

# 第四十四章 横纹落在斜光里

袁碣调整脉石碑前的照明角度，先让帮手别拿布去擦那些看着深浅不齐的地方。光一偏，表面的凹凸便显出另一种层次，几道横纹也跟着清楚起来。帮手原本以为是污痕，见他停住，便将布叠好放到外侧，改为扶稳旁边的普通说明卡，让袁碣对照记录。

陈列中的脉石碑就是记录所指的唯一那块碑。脉石碑初刻时正面有五条横纹。袁碣将首次雕刻的说明指给帮手看，没有拿眼下光线造成的明暗变化去改写初刻情况。“先让看的人分得清纹路，不是替它添一道更好看的。”他说。帮手收回准备描画的笔，站到侧面观察，承认自己差点把展示不清与需要改动混成了同一件事。

后来有人停在前面，指着边缘问能不能移近些看。袁碣先确认来人不会碰到陈列，再让出能侧望的位置，没有搬动碑来迎合每个人的手势。几个人站开以后，原先遮住的一处也露出来，帮手发现只需让人不要全挤在正面，许多疑问便可以直接通过观看解决，不必忙着在说明卡上添满字。

整理将近结束，袁碣将灯光停在合适的位置，重新检查周围没有临时物件悬着。帮手拿起那块从头到尾没用上的布，笑说今天最忙的是眼睛。袁碣让他先收好布，等自己核清最后一张卡再一起离开。碑面仍保持原有刻痕，桌边的纸却换了更清楚的摆放，后来者能看见的多了，并不是因为他们在石上新刻了什么。

# 第四十五章 两叠记录不等于两个答案

两组预选对象的观察记录送来时，尹禾按纸的厚薄将它们排得很齐，看着像两份已经可以直接比较的结果。桑翎翻开其中一叠，发现有的页讲光照，有的页只是日常准备，不同性质挨在一起，厚的一边并不意味着看得更多。她叫尹禾先松开压纸的手，让需要分类的部分能摊平。

“比的是同一类所见，不能比谁的纸厚。”桑翎说。尹禾将记录一张张读回，遇到不能确定归入哪里便留在中间，请对应的当值者解释。邵璇补充介质方面的范围，不让一组写得细、另一组写得简的差异，被当成样本本身的差异。纸面重新分开后，原本漂亮的两列乱了许多，真实缺口却开始露出来。

有人问是否现在就能把两组搬去做光照比较，匡霁让他按后续安排准备，眼下先把资料整理妥，不用一次讨论同时跳过几步。桑翎也没有提前改变培养盘的位置，只核对每份记录指向哪一组对象。尹禾从一页夹缝里抽出遗漏的小纸，发现若刚才顺势收起，这一项就会被当成从未观察过，便将它补回对应处。

收尾时，两叠记录仍不是可以盖定一切的答案。桑翎请接手者复述尚待确认的部分，听见对方把一项待做说成已做，立刻将那页翻回去重讲。尹禾坐在旁边，没有嫌重复费时，自己也在边角补上清楚的状态。桌上最后留下足够翻阅的空处，后面的比较尚未开始，至少参与者不必先从纸的整齐里猜测哪一步已经发生。

# 第四十六章 观测泡里的等待

祝珉接到要等一轮光照切换的安排，到了地方才发现手里的说明被折角挡住了一小行。他先将纸展开，确认自己不是在等另一项观察，再看周围的明暗。外侧有人经过，以为他站着不动是在等递送，便抬手示意要不要顺便捎走什么，他摇头，请对方留意脚边的普通空容器。

祝珉在无潮穹顶的东侧观测泡里等候光照切换。那里暂时没有别的人与他并肩，远处的活动却仍能从可见处经过。“我在等这一轮，不是落下了东西。”他向回头询问的人说明，然后将纸收在能随时查看的位置。等待没有立刻得到回应，他几次想先去做别的事，最后仍按当前安排留下，避免中途错过自己需要记录的那一刻。

一名同伴过来核对进度，发现祝珉把某处已渐变的亮度也记下，便问是否切换已经完成。祝珉让他看清记录用词，这只是眼前观察，不是对整轮结束的确认。两人把范围说清，同伴才离开，没将一句光有变化传回去当作可以直接接续下一项的通知。祝珉独自站在原处，调整了一下手臂，继续看向需要留意的方向。

确认到来的时候，他先按实际所见补全记录，再与外侧来人核对，没因等得久而草草说一切都好了。交出说明以后，祝珉将身旁无关的普通纸片收起，等来人退开才转身离去。无潮穹顶里的光与他初来时有所不同，他却没有为这次等待加上一段超出所见的解释，只留下这一刻能够被他人找回的具体位置与经过。

# 第四十七章 展开后没有落款

桑翎整理普通观察纸，摸到一张折得很薄的描图。它夹在纸间，展开后有许多疏密不一的点与细线，旁边没有能说明交来者的名字。尹禾觉得图面好看，想顺着点的位置猜一猜画的是谁看见的景象，桑翎请她先把边角压平，看是否真的有可确认的说明，而不是用熟悉感给陌生图纸认主人。

这张星空描图没有署名，作者是谁、打算用来做什么都还不清楚。桑翎将它与需要立即核对的观察纸分开，既不丢弃，也不将其中的细线当成已经得到认可的工作指示。“看得像什么，可以先说；是谁留下，不能顺着一句像就定了。”她提醒尹禾。尹禾收回准备落笔的猜测，只把发现时可见的样子记在另纸上。

有人经过，提出把描图挂到大家常看的地方，也许很快能找到人。匡霁请他先问清怎样保存与查看，别为了让更多人看见就使原图受到损伤。几人将便于核对的位置腾出，允许来人看原有内容，却不在纸上添写假定的用途。薄薄的折痕被光一照更明显，桑翎便让触碰的人从下面承托，不反复沿同一处用力压平。

等候的观察资料还要送出，桑翎将描图妥善分开，回头继续完成眼前的交接。尹禾走到外侧仍忍不住看一眼，却没有把自己的猜测带给后来者当作消息。那张纸留着未知的来历与用途，没因上面是一片星空就成为一条航行计划。桑翎核清要交的几页，叫接收者自己指出下一步，从能够确定的事情继续做起。

# 第四十八章 卡片换到亮处

温炬翻出待整理的个人卡，发现其中一张压在较暗的位置，边角的字看起来像缺了一笔。他没有立刻补写，先拿到光亮处，再叫帮手放开遮着纸面的手。光一照，那一笔便显出来，帮手有些不好意思，说自己险些以为卡片已经磨掉，需要替他重新描清。

整理到月份一栏，温炬将卡片平放，逐处看过。温炬出生的公历月份是八月。他将有关自己的那张归好，接着处理其余纸边，没有拿错行的担心替旁人补上卡片本身没有写的内容。“看得不稳，就先别抄。”他对帮手说。对方将刚才准备接着写的笔搁下，改为把已经核过的纸分开，让温炬不必在同一堆里重复寻找。

有人从旁借用一小块桌面，帮手让得太快，险些将卡片推到边沿。温炬伸手托住下面，请他们先说明准备放什么，再挪出足够的地方。借用者只需放一个空杯，见两人手里忙，主动走到更远的空处，没有坚持必须就在眼前。桌边重新安稳下来，帮手才发现自己的肩膀一直抬得很紧，呼了口气慢慢放松。

剩下几张整理结束后，温炬让帮手先去歇息，自己再检查桌缝是否滑进纸片。对方问是否还要一同核一次，他说已经明确交过的无需为了安心又整叠翻回，只把刚才受碰的那一小处查清即可。卡片收拢，光线不再被手影来回遮住。温炬最后将桌角清出，给下一位要使用的人留下平坦的位置，没有让自己的纸一直占着别人需要的空间。

# 第四十九章 比较开始以前

正式分组比较的准备临近结束，廉舟送到桌边的物件却与预计摆放的位置对不上。不是东西少了，而是来接的人临时把普通空容器排在正中，让培养盘将要经过的空间变得狭窄。桑翎先请廉舟停稳，别端着东西在几只盘之间来回寻找空隙，再叫大家按下一步动作重新看桌面。

“先说谁从哪里接，不要先伸手。”她提醒。接收者逐一指出要落的位置，邵璇在旁确认准备项没有混入不相干的物件，尹禾则核对普通记录对应哪一处。有人想在腾桌时直接把两组拉开做一遍试比，匡霁让他暂缓，眼下尚未开始正式光照比较，不能把一个顺手的动作藏在准备之中。

重新核对后，廉舟分次放稳，不必一直悬着手。等待的人虽然多走了几趟，却能清楚知道自己接到的范围，少了一阵围着桌角抢着帮忙的混乱。桑翎将还需确认的小项留给当值者，自己把可继续完成的准备接上，没有为赶上后面的轮次把所有空白划成已核。尹禾看见一页标记太挤，主动请人重读，确认没把准备完成写成观察完成。

最后一趟递送离开，桌旁只留下需要参与后续摆放的人。桑翎看了看通道，叫尹禾把靠外的一只空盒收走，免得待会儿转身撞到。没有新结果在这一轮提前诞生，纸上多出的只是准备已经走到哪一步。外侧等候的人问还差什么，她指明剩下的确认，等得到明确答复，再与同伴一起走向将要放置培养盘的位置。

# 第五十章 帘还没有拉开

桑翎与同伴核对最后的摆放安排，几只培养盘已经送到可接手的位置。遮光帘垂在前方，附近有人觉得既然只差摆开，不如顺势把比较也做了，省得下一轮再来等。匡霁请他先看负责观察的人是否都已接妥任务，不让准备接近完成便成为跳过轮次安排的理由。

“盘子到了，人还得知道自己看什么。”桑翎说。她请尹禾指出记录将从哪里开始，尹禾指到一处尚待填写的栏，说明那要留给真正观察时使用，不能现在先补一个预计的反应。邵璇确认两组相关资料都已留在对应位置，又将多余的普通纸从边上移开，不让旁人误拿准备记录当作已经进行过比较的凭据。

一名同伴站得太靠前，背影挡住帘边的落点，廉舟便请他稍退，让运来的盘能平稳到位。摆放前的核对没有出现值得庆贺的变化，只有几次安静的点头与重复确认。等空容器收好，桑翎逐一检查眼前的去向，不把两组混回同一处，也不允许人为了好看随手改变已经说清的摆法。

有人仍惦记着会看见怎样的反应，离开前又问一句是不是很快就能知道哪组更合适。桑翎说先等真实的观察，不拿期待替结果排序。大家将本轮尚可收起的纸带到外侧，留给下一轮清楚的起点。桑翎将两组培养盘分列在遮光帘两侧，众人离开，尚未开始下一轮光照比较。

# 第五十一章 两侧各自亮起

下一轮开始，众人先确认遮光帘两侧的培养盘与记录相符，再各就观察位置。有人想站在正中同时看两边，稍一转头便挡住另一人的视线。桑翎请他选择能够持续看清的范围，不用左右忙着追，让两组菌群保持分开，按已经核好的安排比较各自的光照反应。

光照调整后，一侧先显出细小的变化，另一侧的所见却不够清楚。尹禾急着问是否已经分出高下，邵璇让她先把正在看到的记完整。“先后出现，不等于你已经知道谁更合适。”她说。负责另一侧的人报出自己的观察，众人核对条件，发现有一处因站位暂被遮住，便将这段中断如实标清，不拿缺少所见当成样本没有反应。

比较继续进行，先前期待一个鲜明胜负的人逐渐不再提那两个字。两边有能对照的部分，也有尚不能放在同一行的疑问。桑翎将需要正式确认的内容按流程递交，自己继续协调记录，未替不完整的部分作决定。匡霁在外侧安排轮换，让疲倦的人适时退出，避免所有人为了看完同一轮都站到无法专注。

收轮之后，两组资料在桌上汇到一起，却没有被揉成一段统一的结论。尹禾指着自己的记录问下一步从哪里接，邵璇请她先标清可比较与需复看的范围，再听当值者的核对。桑翎收走不再用的普通遮片，留住分组位置，待后续安排明确才动。帘边的光已经与准备时不同，真正增加的却不是一句谁赢了，而是两组各自留下、可以让人逐项查回的反应。

# 第五十二章 冷光来自旁边

索迦再次核查冷闪记录时，把观察范围从种群所在的位置稍稍扩开。先前总被略过的一件旧设备出现在边缘，光一闪，记录中那一点亮也跟着出现。旁边的人仍盯着样本，没察觉两个位置的对应，索迦便让他先移开目光，照自己指的方向重新看完整一段。

重复的冷光闪烁来自旧观察相机的待机闪光，不是种群发光。对应关系核查清楚后，索迦将来源写入记录，撤下原先仅列为待查的标记。“它一直在画面边上，我们却只盼着中间动。”同伴说。桑翎请他把这次核对的片段保留，别因原因显得普通就省去依据，让以后读记录的人仍能看清如何从疑问走到确认。

一个观察者有些泄气，觉得期待了这么久，结果与种群没有关系。索迦没有嘲笑那份期待，只让他分清排除一项干扰同样改变了能依据什么作判断。尹禾将此前几段冷闪相关记录找齐，说明哪些句子需要按新来源校正，哪些仍是原样可见的过程，没有把所有提到亮光的页一概丢掉。几个人坐下来，逐页核对，而非用一句设备问题盖过所有细节。

整理结束，旧观察相机仍是眼前那件设备，种群也没有因人的失望少掉本来拥有的变化。桑翎将收回的线索归清，其他尚未解释的记录各自留着。索迦临走时叫同伴再看一眼画面边缘，问还有没有被他们习惯性忽略的部分。对方这回没有急着给出新谜底，只说会在下一轮把观察范围写明，不再把期待集中成唯一值得看的地方。

# 第五十三章 掌心里的小粒

索迦整理自己的普通物件，一粒干莓落在掌心。他将它与桌上那些要转交的材料分开，免得有人收拾时一起卷走。来找他核对记录的同伴已经站在门边，见他低头，便停了一会儿，没有立刻把纸压到他手上。索迦抬头示意对方进来，将空着的一侧桌面让出。

索迦收着一粒干莓，他把它妥善收好，随后才摊开来人带的记录。“从你拿不准的那一段说起。”他请同伴坐下。对方原本准备从头讲一大串，听他这么说，便直接指出一个中断处，承认自己在那时离开，回来后才补看。索迦将实际看见与后来追看的部分划清，提醒别因两者写在同一页就忘记中间相隔着怎样的观察方式。

核到后面，两人发现一行描述来自旁人的口头转述，却没有标出来源。同伴急着说自己相信那个人，索迦问的却不是信不信，而是以后谁能回答当时站在哪里、看清了哪一边。对方想了想，起身去找实际观察者，索迦留在桌边等候，没把暂时缺少的说明先改成一句方便交付的肯定话。

来人补清以后，原先像连在一起的经过露出几处真实断点。记录没有因此失去用处，反而让下一轮知道哪些位置需要注意。索迦将整理好的纸递回，听见同伴复述接续方式正确，才收起自己散放的普通物件。外侧的脚步渐多，他将椅子往里推一点，让经过的人不会碰到桌边。刚才的琐事没有留在交接记录里，完成的核对却清清楚楚跟着来人离开。

# 第五十四章 考查桌前的停顿

资格考查开始前，桑翎看见桌上摆着几份需要核验的观察材料，其中有一处明显缺了衔接。她没有因为身边有人等着评价自己，就急着把每一栏都说出确定答案，而是先指出这一处只能说明到哪里。主持考查的人请她继续，将理由讲给随后要接手的人听，不只朝着检查者解释。

“若我把空白说圆了，下一人就不知道从哪里复查。”桑翎回答。她按要求核对资料，在能够确认的部分明确表述，在依据不足的地方停住。尹禾从外侧旁听，几次想替她指出自己熟悉的记录，又想起这回并不是平常一起整理，便将话留在自己的纸上，没有用手势递过去。

考查中途，另一份说明改变了眼前可核对的范围。桑翎重新检查原先判断，没有为保持前后一致就拒绝调整，也没有一看有新纸便将前面的内容全推翻。她逐项说明哪里受到影响，哪里仍由原有依据支持。主持者接着询问她如何交代边界，桑翎便将准备写的确认句读出，让对方看是否超出材料能够说明的部分。

结束后，现场结果仍待完整核对，桑翎收手坐到外侧，没有将考查中的练习当成对真实样本的最终处置。尹禾过来问她紧不紧张，她笑了一下，承认一直担心自己为求答得快而少看一处。两人把旁听纸分好，没有再追着问是否已经通过。桌边空出来，核查者继续工作，桑翎则去完成当前轮次已经安排的事项，等明确通知到来。

# 第五十五章 确认句由她读出

资格结果传来，桑翎先请来人说清确认的范围，免得一句可以了让周围的人各自理解成不同的权限。匡霁将事项逐条读明，等待她复述，尹禾站在旁边听，手上的普通记录纸没有像平常那样急着翻动。桑翎听完，指出自己今后需要对哪些确认负责，得到明确答复才收起说明。

桑翎获得了独立确认同步观测结果的资格。随后进入正式安排的一项核对时，她先查看材料，再将自己能够确认的内容完整读出，没有把仍缺依据的部分附带算入。“这一项到这里为止，后面那处还要接着查。”她说。接收者重复了一遍边界，按实际结果继续安排，不把她的名字当成所有疑问从此都可以略过的标记。

尹禾等到外侧，笑着说想替她好好道贺，桑翎却还惦记有一页临时记录没归清，先与她一道把纸找出来。两人核对完，才坐下喝水。匡霁经过时提醒接下来的轮次仍要留出休息，别因为得到新职责便将所有缺口都揽到身上。桑翎点头，将自己能承担的与需要协同的分别写明，没有随口答应每一项请求。

再回到观察位置，窗前正有人讨论一个尚不清楚的变化。桑翎让他们先保留完整描述，等自己看过依据再作确认。她的声音没有比平常更响，旁人却能清楚知道这一项由谁负责到哪一步。尹禾在旁学习记录，不代替她落下结论。轮次接着往前，桑翎在自己确认过的内容下写明范围，随后转向下一处仍值得认真停下的问题。

# 第五十六章 细管落到掌中

邵璇来接授粉观察之后需要继续分析的材料，先将桌上的空处腾出。宁绡看见她把几张纸放在取用位置，提醒先挪到旁边，别等手里有东西时才发现没地方落。邵璇将纸收拢，重新检查眼前的摆法，确认可以一件件接稳，才向宁绡示意开始交付。

宁绡把节环滴管交给邵璇，之后由邵璇保管。邵璇接过后先查看状态，与交接说明逐项相对，没有一拿到就转身去做别的事。“等我把这处看清，别急着接下一项。”她说。宁绡停住手，指出需要一同确认的细处，两人核过，才让邵璇将它放到已经清出的稳妥位置，避免与旁边普通小件混在一起。

来等结果的人问是否能顺便将分析也做完，邵璇让他先分清接收与分析不是同一个动作。宁绡将属于自己这一段的观察交代清楚，未为尽快结束而替后面的结果作保证。旁人等了一会儿，见她们确实还在核对，便坐到外侧，将具体想问的问题写下，不再站在桌前伸手指来指去，遮住邵璇要看的位置。

交付完成，宁绡离开时回头问是否还缺哪页说明，邵璇查过清单才答复。桌上的纸没有因为人员换位而散开，待分析的材料也保留着原有对应。邵璇开始整理自己的步骤，先把尚需观察的范围列出，给等候者一份真实进度。对方看完，终于不再用刚才东西已经拿到来要求立即给出结论，带着明确的等待事项走到外侧。

# 第五十七章 说明不是一场宣判

众人聚到能看清资料的位置，有人已经准备好听到一句可以留下或应当放弃，甚至将两种选择写在纸的两边。邵璇看见后，请他先别替说明安排终点，材料里能够支持的范围还需要逐项讲清。桑翎将挡住后排的空椅子移开，让来听的人不必伸长脖子越过前面的肩膀。

介质分析的结果由邵璇向众人说明。她从已经核清的观察开始，接着指出仍不能确认的部分，没有拿一项局部结果替全部样本作判断。“这段能说明介质这一面的情况，不能单凭它决定后面所有选择。”她说。听的人有些失望，却开始问更具体的问题，邵璇便回到对应资料，让他们看结论究竟落在哪一处。

一位同伴把说明中的不确定听成了失败，立刻说既然如此应当放弃。邵璇请他将自己听到的原句复述，发现他漏掉了范围限制。桑翎在旁帮助区分已知、待核与后续决定，没有替邵璇把资料说得更乐观，也没顺着那位同伴把未定的部分判成已经无望。几个人来回核清后，纸上原本预画的两边显得过于简单，被划去重新整理。

说明结束，邵璇留下供后续查阅的记录，请真正没听明白的人再问，不必怕拖延散场。尹禾等别人走开，指着一处问如何区分材料本身不足与观察遗漏，邵璇带她看原记录，直到她能说清差别。最后离开时，桌上没有一张能代替所有人继续思考的判决，只有已经说明的结果与尚需完成的工作各自清楚地放着。

# 第五十八章 不同的疲倦碰在一起

准备交接的人已经连续等了几次，来接手的同伴却刚被另一项工作拖住，两人在门边一见面便都觉得自己更没有时间。前者想一句话讲完，后者希望只拿到最简短的结论，资料尚未展开，耐心就先耗掉一半。匡霁走来，让他们先坐下，不要带着手里悬着的东西争谁更辛苦。

“先给对方一段能听完整的话。”她说。离开者把自己完成到哪里说明白，接手者也指出眼下不能马上核对的部分，没有假装全部明白好让对方快走。桑翎在旁确认一项同步观察结果的范围，将它与仍在等待的资料分清，避免同一叠纸被当作都已结束。两人的语气渐渐平下来，困倦还在，却不必用猜测来替别人补话。

中途又有一名同伴来取空容器，见桌边忙，准备先抽走压在下面的那只。接手者立刻叫停，等纸被妥善挪开才让他拿，没有因急着交班就让旁人的顺手动作打乱正在核对的次序。匡霁把这段被打断的地方重新指出，叫两人从同一处接上，不要求凭记忆各自往下讲。多花的时间换来少一次重复寻找。

交接完成，离开者仍显得疲惫，却不再一路走一路担心后面的人根本没听见。接手者将资料放稳，先做已经明确的一项，未清的部分照样留待后续。桑翎送出属于自己负责范围的说明，回到外侧看见匡霁揉着眼角。她请匡霁也核清下一步后去休息，不要永远当两种疲倦之间那个不会累的人。匡霁笑了一下，终于把手里的轮值纸暂放到稳处。

# 第五十九章 梳齿朝着空处

索迦准备整理分析位置，发现一些细小碎屑混在普通材料边缘，用布一抹便会挤到更窄的缝里。祝珉带来需要交接的物件，先请他将接收位置腾出来，不要一手托纸、一手伸来接。索迦将记录移到外侧，铺平下面的普通布，再抬头确认这轮有哪些事项要当面说清。

祝珉把灰绒滤梳交给索迦，之后由索迦保管。索迦接稳，先看梳齿间是否干净，再按祝珉指出的位置对照检查。“我放下再回你的话，免得手上顾着别的。”他对旁边催问的同伴说。那人等了一会儿，见交接没有被打断，便将问题写在纸边，留到索迦空出注意力时再谈，桌面也不必为几只同时伸来的手反复挪动。

祝珉讲清随附说明后，请索迦复述接着要做的范围，不将尚未开始的整理一并算作完成。索迦确认无误，才让他离开，自己按眼前的需要逐处检查普通材料。遇到一个看不清的细缝，他没有因刚收到物件就急着显出用处，先将位置移向光亮，再决定如何处理，不让工具替判断抢先走一步。

同伴等到他停手，拿来刚才记下的疑问。两人先将不相关的东西收妥，再展开观察纸，谈的仍是此前资料中尚不清楚的部分，没有因为桌边变干净就假定信号也已读懂。索迦留出可继续工作的空处，听完问题才逐项回应。外侧经过的人少了，纸角不再被袖口碰起，他把已核的说明压平，准备在下一轮接着处理真正需要思考的难处。

# 第六十章 手边没有多出的空隙

邵璇整理一份待查看的介质，普通浅皿在桌边留下的位置有些窄。她先叫旁人把空盒移开，不在两样东西之间硬挤着伸手。尹禾来问一处记录，见她正调整动作，便站到侧面等待，没有将纸直接递到她眼前遮住视线。邵璇把需要看的部分放稳，才抬手示意对方靠近。

尹禾递纸时注意到她的右手，目光稍停。邵璇天生右手只有四根手指。她按自己的动作接住纸，将边角放到能稳定承托的位置，继续问尹禾究竟在哪一行有疑问，没有因此打断工作。尹禾意识到自己看得太久，赶忙指回记录。“是这里，我不确定指的是浅皿这一侧还是里面那一处。”她说，邵璇便让她对照原先观察位置再讲一遍。

两种说法看着只差一点，实际对应的材料却不相同。邵璇将能够直接确认的范围指出，提醒尹禾别为了让句子读着顺，就把不同位置省成同一个它。尹禾重写后请她再看，邵璇没有立即点头，而是让旁边未听过解释的同伴照新句子指出位置。对方找对了，尹禾才松口气，将这个修订按原流程交去核对。

收拾时，空盒已经回到不会碍手的地方，桌面的余地比开始宽了一点。邵璇将浅皿逐一安放，叫帮忙者一次只处理说明白的那一件，不必抢着包办整个桌面。尹禾收好纸准备离开，临走又将靠门的一张空椅子推回去，免得后来者转身碰上。邵璇看了一眼留下的干净位置，继续做自己的观察，刚才被问清的一处，不再需要下轮的人重猜。

# 第六十一章 不急着写下一个词

贝嵘把空杯从鼻前移开，又看向等着记录的同伴。他原以为靠近以后会有一种足够清楚的感觉，实际只察觉自己吸气太急，连杯沿都碰到了上唇。桌上的纸留着空白，同伴没有催促，先递给他一块干净布，让他把溅在手边的水擦去。

“是不是有一点？”对方问。贝嵘摇头，不愿把期待当作回答。他这次仍未辨明气味，也没有确认嗅觉恢复。身旁的普通材料换了位置，他便发现自己连猜测都受摆放顺序牵引，索性将眼睛从那些容器上移开，只说当前能够确定的感觉。那几句话不适合填进辨认结果，对方就把它们另记在尝试经过里。

贝嵘想再试，同伴却问他是否已经觉得鼻间不舒服。他停下来，摸了摸杯身，没有用急促吸气去追逐一个应当出现的词。“让我坐一会儿，别替我填好。”他把椅子拉近，双脚放稳，等胸口那阵急切过去。杯子仍在原处，没有人凭这次停顿替他作出判断。

旁边有人来取孵化记录，见桌面留着未填的格子，险些将它当作遗漏。贝嵘抬手拦住纸，说明那是尚不能确认的结果，不是忘记抄写。对方点头，把要带走的另一份拿开。他重新理平桌边，先处理可以从记录里核实的工作。等离开这张桌子时，尝试的经过完整留下，结论处没有被一串乐观措辞占满。

# 第六十二章 手没有越过盘沿

尹禾看见一片幼叶贴近盘沿，便伸手去扶。桑翎及时叫住她，声音不高，手里的纸却停在半空。那片叶子尚未碰到桌面，尹禾的指尖悬着，既怕收手显得自己冷漠，又怕再靠近会弄出新的变化。两个人隔着培养盘看了一会儿，先让匆忙的人避开桌角。

“你现在想照料它，还是想看清它自己会怎样？”桑翎问。尹禾说她两样都想，答完才发现动作已经替自己作了选择。桑翎没有宣称护理永远该等，也没有将不动手说成正确答案，而是叫她把当前疑问讲全，再看看这一轮观察原本要做什么。纸上那句被忽略的说明，终于得到尹禾从头到尾的阅读。

她们将情况交给正在负责这一盘的人共同判断，没有擅自挪叶。等待间，有人把一叠空纸压在桌沿，挡住了观察角度。尹禾请他移开，自己往旁边让出位置。这次行动没有触碰培养物，却实实在在使看不清的地方露了出来；她在记录中写下这个经过，没有冒充什么生长反应。

负责者到来后，大家依本轮安排处理，尹禾负责记下采取了什么动作。她落笔时又想省略那个险些伸手的瞬间，桑翎让她留下。“别人接着看时，需要知道我们做到了哪一步。”尹禾补完，将笔放在盘外。那片幼叶还在视线里，她可以关心它，也可以承认自己的关心需要被说明，不能藏进一行仿佛无人干预的描述。

# 第六十三章 气味有了明确的回答

贝嵘来到复核桌前时，没有先看旁人的表情。桌上容器各自摆开，同伴把说明留在手边，等他完成辨认再核对。第一次回答之后，他想从对方眼里找一点暗示，随即低下头，把注意放回眼前的材料。外面的交接声传进来，又随着门被轻轻合上而变弱。

这一轮核验完成，记录上的回答与实际材料相符。贝嵘的嗅觉完全恢复，已经可以辨认气味。他接过复核结果，先看清其中的结论，才把纸平放在桌上。“这一处我能分出来。”他说，语气比来时稳，手指仍按着纸角，免得自己只顾着高兴就漏看后面的工作安排。

回到孵化桌旁，同伴递来需要共同查看的观察材料。贝嵘没有拿一次辨认代替全部检查，他先说闻到的感觉，再让对方核实其他部分。两人的措辞有一处不一致，他将容器放回稳妥的位置，重新描述，而不是坚持别人也该使用自己的词。说清以后，同伴把补充写在相应位置，没有涂去原先的记录。

有人从旁边经过，问他要不要把剩下的材料都接过来。贝嵘看看已经排开的几份，拒绝了那种把忙碌当庆贺的办法。“先完成手里的，再拿下一件。”他把可递送的纸移到外侧，留出工作的空处。交接结束时，他带走自己需要的那一份，另外的材料仍有人照料；桌上没有因为一个人的好消息，忽然挤满所有人的任务。

# 第六十四章 问号写在观察旁边

尹禾拿着训练纸追到桑翎身边，开口就是自己写错了。桑翎让她先停下，把皱成一团的纸放平。上面的两句描述指向同一处叶缘，措辞并不完全相同，旁边却被尹禾画了很重的叉。她怕被问起缘由，抢着解释已经看过别人的记录，自己的词和对方差得太远。

“不同就一定是错么？”桑翎没有让她立即重抄，而是陪她回到原先能观察的位置。那处边缘被前面的纸挡住一小块，尹禾将纸移开，发现自己当时其实没看全。她说不出缺失部分是什么，便想用别人的句子补上。桑翎摇头，让她将直接看见的范围与后来得知的情况分开。

尹禾重新写了几行，落笔慢下来，疑问反而更具体。她指着两种说法问，怎样才能知道是位置不同还是自己漏看，提问时没有再预先宣布谁正确。桑翎让她保留各自的观察条件，再请负责者核对。这个步骤并不把她的训练记录变成独立确认，她仍按原有安排交出需要核查的部分。

回去途中，尹禾在另一张纸上看到一个很漂亮的完整句子，手指在纸边停了一下，却没有照抄。她把自己的问号留下，问旁边同伴能不能凭现有文字找到那块被挡住的边缘。对方找对位置，又指出一句含混的话。尹禾改的是那一句，不再把整张纸揉毁。纸上仍有没解决的地方，但每一个疑问终于都贴着实际看到的东西。

# 第六十五章 桌面先空出一块

桑翎准备整理苍蓝孢镜时，发现桌上的纸已经占满可放置的地方。尹禾抱着记录站在旁边，想把它们叠成一堆腾出空隙，桑翎却指了指最下方露出的边角。那是尚待核对的材料，压进厚厚一叠以后，再取出来又会搅乱其余纸页。

“先把每份该去哪里说清。”桑翎没有马上动镜，跟尹禾一起辨认桌面现有的东西。需要留在现场的放到伸手可及处，准备交出的交由等候的人带走，不能确认的仍单独留下。尹禾发现所谓清出位置，不只是把杂物推到看不见的角落；她刚塞进空盒的一张纸，又被自己取了出来。

可用的桌面终于露出，桑翎才检查孢镜眼下的状况，尹禾在旁边看，听不明白就问。两人把需要随交接说明的问题逐项理清，镜仍由桑翎收着，这一轮尚未实际交付。尹禾想把准备记录写成已经接妥，写到一半醒悟过来，删掉那几个字，换成与当前进度相符的描述。

外侧的人催着整理好便让出桌子，尹禾只得停止继续往纸上添话。她先说哪些准备已经做完，再说还缺实际交接，没有把将来的动作挤进过去式。桑翎听过，收拢材料准备离开；尹禾将留在桌上的空盒放正，给下一轮的人让路。那块刚清出的桌面仍看得见，说明没有因为人们急着结束，就又被另一堆不知该归哪里的东西填满。

# 第六十六章 接稳再收手

尹禾把记录放下，两只手都空出来，才站到桑翎面前。旁边有人从桌角递纸，她往后退了一步，等那人通过，避免几件事撞在一起。桑翎没有隔着别人的手去递东西，而是先将准备说明的纸摊开，跟她核对能够直接看见的部分。

确认完当下状况，桑翎将苍蓝孢镜交给尹禾保管。尹禾接稳以后，桑翎才松手，桌上的交付记录随之补上。她们只谈眼前这次接收需要清楚的事项，没有赶着把每个问题都说成早已知道。“这一处我还要再看一眼。”尹禾指出自己没记牢的位置，桑翎让她看清，不拿点头的速度衡量她是否认真。

接收之后，尹禾抱着孢镜准备绕过桌边，却发现自己随手放下的纸挡住了路径。她停住，请同伴将那几页移开，自己没有腾出一只不稳的手去勉强拨弄。纸被挪好，她才走到适合放置的地方，将镜安稳收下。有人笑她绕了一个很小的弯，她也笑，说这个弯让她不必同时照应桌面和怀里的东西。

桑翎离开前问她是否还有未明白的交接事项，尹禾翻开自己的记录，将刚才需要再看的那一处指出。两人确认写法能对应实物，才合上纸页。尹禾没有立刻开始一场额外观察来显示自己会用，她先完成收妥后的整理，把不属于这次交接的材料留给原来的工作。桌面上的人散开，各自手里的事终于能按自己的次序继续。

# 第六十七章 留下的培养盘

待查看的培养盘排在视线内，其中一盘的记录被搁到了最边上。来整理的人以为那只是写得不齐，想把它与其他几份叠在一起。邵璇伸手压住纸，没有碰盘，先让对方读完判定部分。那一盘尚不合格，眼下仍须保留隔离，不能混入准备筛选的培养物。

“留下它，是还要装进首批么？”对方问。邵璇说保留观察与列入出舱安排不是一回事，让他不要替空白处提前填入希望。廉舟从另一边过来，听清后把原先准备合并的递送纸分开。他没有把不合格记录折到背面，也没有为了使桌上整齐就让它失去对应的位置。

整理暂停时，尹禾提出一个实际困难：分开的纸若只靠眼下这几个人记得，换人后可能再次被合到一起。邵璇请她把当前状态写明，交给接手者逐项核对，仍照现有隔离安排处理培养盘。尹禾没有另造一种只有自己懂的符号，而是写完整句子，请先前误拿的人读出意思。对方读到保留隔离，立即把纸放回应在的位置。

这一轮整理因此多花了些工夫，但后面赶来的人不必再听一遍长解释。廉舟收好自己能够接走的材料，空着的那一处没有用别的盘补满。邵璇最后查看留下的记录，叫尹禾保留这次误合的经过，免得下一轮又将它当作谁的粗心。那盘培养物没有被赶去符合一个好看的进度，也没有因为不合格而从所有人的视线里消失。

# 第六十八章 听懂问题再指画面

廉舟对着普通信号的记录看了好一会儿，终于承认自己只会挑最显眼的起伏。索迦把纸移到两人都能看清的地方，没有立即圈出答案，先问他刚才究竟依据什么。廉舟指着一段显眼的变化说得很快，说到另一处相似形状时却停住，发现先前的理由也能套在那里。

廉舟把身旁的椅子挪近，重新看向纸面。索迦教廉舟辨别短脉冲和噪声。他们用眼前的普通记录练习，先看完整的前后，再让廉舟说明判断里尚有疑问的地方。索迦不让他凭一次像不像就急着落笔，也没有把这里的练习说成古式记谱的译读。“你先告诉我，哪一部分是你看见的，哪一部分是你猜的。”这句话使廉舟把刚刚指过的地方重新看了一遍。

一名路过者见两人盯着纸，顺手把杯子放在空处，杯沿压住了后半段。廉舟正要继续解释，忽然找不到对应的位置，只得请对方把杯子拿走。索迦等画面露全才接着听，没有替他补完被挡住的理由。廉舟这一回说得短些，却能指出自己究竟在比较什么，不再靠语气装作确定。

练习结束，廉舟将尚拿不准的部分留下请人核验，未把练习纸塞进可执行的递送安排。索迦也收好桌面，回去处理自己未完成的工作。临走时廉舟说还想再看一组，索迦让他先整理这一组里改过的判断。他坐回原处，把错误那一句完整保留在旁边，终于能说清为什么要改，而不只是记住有人替他指过哪里。

# 第六十九章 囊口收好以后

邵璇处理完桌上的一份材料，将旁边伸过来的空盘推回原处，先说还没有到一起收走的时候。帮忙的人以为台面上剩下的都可以归拢，手停在半途，只好问她该从哪一件开始。邵璇指向已完成记录的那叠纸，让对方先把明确的部分送去核对。

桌面少了一些遮挡，她将需要收存的东西放稳。邵璇把提取胶收在黑陶小囊里。收好后，她查看囊口周围，确认没有将手边的纸一并夹进去，才让同伴继续整理。对方想找一个更大的空盒，把桌上余下物件全都装进去，邵璇叫他先停下：“每件都说得清去处，再决定要不要一起拿。”

这一问暴露了刚才的混乱。桌边有材料等着核验，另一侧的东西只是暂时挪开，若合到一起，接手的人便会以为它们属于同一份任务。同伴把空盒搁回去，改为逐件问清。邵璇回答时也不只用这里那里，伸手指出对应位置，让他能将口头说明与眼前东西对上。

索迦来问分析进度，正好赶上整理中断，站在门边等。邵璇将已可说明的那部分给他看，余下尚待查看的仍留着，没有因对方到来就匆忙封成一个完成的结果。等两人把问题说完，桌面的人已经各自拿到明确能带走的东西。邵璇再看一遍留下的材料，找回刚才被收拾声打断的位置，接着做尚未结束的观察。

# 第七十章 空格不算活着的证据

轮值桌旁的人各自带来观察记录，一叠薄纸很快占了大半个桌面。有人先问首批到底能有多少，另一个人便将没有写失败的几份数了起来。桑翎听到那串越数越快的声音，抬手让他暂停。她把其中一页抽到前面，指出没有填写的地方，问这能否算作已经观察到的结果。

“没写不行，总不能就说行。”匡霁接过话，将等着统计的人请到桌侧，让大家先看同一份材料。邵璇说明当前哪些部分已有依据，哪些还需要核验，没有把沉默的记录当作存活保证。众人谈到标准时，仍围绕现有要求逐项核对，不为赶出一批样本临时降低需要说明的范围。

尹禾负责把疑问放回各自所属的记录，最初想另抄一张简短总表，抄着抄着才发现一句省略会遮住不少区别。她停下，将不能省的内容保留，并请说话的人指出依据所在。有人不耐烦，问是否每一份都要再讲。桑翎把那页空白较多的纸推过去，叫他试着说明为什么可以选择它，对方翻了几次，终于将它留在待核的一侧。

讨论没有立刻给出一个好听的数量。可以继续核对的材料与需要补充观察的分开后，各人认领手里的工作，桌边反而不再挤。匡霁等最后一个疑问得到明确去处，才收起安排纸。那一页曾被算进期待中的空格，还按原样留着；下一轮的人将从这里继续观察，不必先替上一轮的乐观寻找证明。

# 第七十一章 币旁的软衬

袁碣整理纪念陈列时，将软衬的一角压得过紧，边沿微微翘了起来。经过的人提醒他，若只从正面看，很容易把翘起的部分漏掉。他停下手，绕到侧面检查，先把旁边空盒移开，再慢慢理平衬面，没有为了省事直接拿说明卡压住。

陈列里的那枚陨纹纪念币是唯一的一枚，照样放在原来这处展示位置。陨纹纪念币刚铸成时的重量是九克。袁碣将介绍初铸情况的卡片放妥，叫帮忙者在正面看一眼，是否有边角挡住文字。他们整理的是展示的朝向和可读位置，没有拿币去称量，也没有在桌边另做一个相似的物件。

“这里看着平，从旁边却会盖住末尾。”帮忙者指出问题。袁碣依他所说试了试，发现是空盒移开以后，自己仍按先前受挤的位置放卡。他重新留出合适间隔，这回请对方换一个角度读，等人说看清了才松开手。附近有人想经过，他们一同退到边上，让出本来就不宽的空处。

离开前，帮忙者将刚才压在手边的布拿起，袁碣又看了一遍陈列边缘，没让布角留在其中。那人问还需要再挪什么，他摇头，请对方把自己拿来的空盒带走。整理留下的是一处能够清楚观看的展示，周围没有堆积临时用过的东西。袁碣站回正面，读到卡片末尾，确认方才那点翘起已不再挡住来人的视线。

# 第七十二章 申请放到待议的一侧

宁绡带着准备好的白昼试验申请来到轮值桌前，正碰上匡霁与旁人核对下一轮安排。她在外侧等了片刻，听见有人说白昼空出一块位置，忍不住上前将纸展开。匡霁看见她急切的样子，没有把那句安排直接当作答复，而是请她先讲完整想做什么。

申请里列出的观察目的能够读懂，实际需要协作的部分还待讨论。宁绡这次提出了白昼授粉试验，但申请尚未获批。她听到这个结果，手指在纸上停住，没有收起纸便走。“我能把没说清的地方补上，但请告诉我具体缺在哪里。”匡霁让与这项安排相关的人指出疑问，宁绡一条条记在原文旁边。

旁边同伴热心地要替她把普通容具先搬到试验位置，宁绡拦下了。对方说只是准备，不会立即开始，她仍请他等讨论完成，避免旁人以为已经可以依这份申请行动。容具留在现有工作的范围内，两人坐到不挡路的地方，把需要补充的说明分开写清。

宁绡越写越发现，一句希望早点看见结果无法替每个人安排好工作。她删掉了催促口气最重的一段，换上明确的问题，然后将补充交回待议的位置。离开桌前时，她确认没有人把申请当成批准件带走。这轮白昼里没有因此开始授粉，申请仍等待审议，她则带着已经弄明白的疑问，回去处理眼前能够做的准备。

# 第七十三章 复查前留出的椅子

霍准来到等候处，发现空椅子上堆着几份待取的纸。他没有随手将纸放到地上，先问旁边的人能否挪开，再慢慢坐下。复查尚未轮到他，门前有人来回经过，每次停步都会使他抬头，以为终于有人叫自己进去。看见只是路过，他又将视线落回手里的记录。

来询问工作的同伴想请他顺便辨一段回声，话说到一半才注意到等候的安排。霍准摆摆手，让那份需要听辨的材料先交给合适的人，自己没有试着倾听。他仍等着复查结果，不把此刻能与人交谈当成工作能力已经核实。“这份我现在不接，你别等在这里误了事。”同伴听清后转身去找人，没有将纸塞在他膝上。

椅子旁剩下的几份普通记录里，有一页边缘折住，霍准展开看了看，只整理能够用视觉核对的位置。前来取纸的人误以为他已经全部检查，伸手便要带走。霍准叫住对方，逐项说明自己只做了哪些整理。那人把未核的部分另放，重新问清，才继续手里的工作。

等候似乎比处理事情更使他疲倦。他将纸放回去，起身活动一下，再坐回空出的椅子。有人从门里探出头，他没有抢着跟进去，先等对方把话说完。这回叫的正是他。霍准理好衣襟，沿让开的空处走过去，停在复查桌前；门外的同伴拾起自己的记录，继续等待属于那份材料的实际结果。

# 第七十四章 回声抵达耳边

复查后的记录交到霍准手中，他没有马上离开，先请负责核验的人把自己还需确认的部分说明白。对方让他在安排好的条件下完成听辨，他按要求回应，不因旁人等着便加快猜测。桌边的记录随着他的回答一项项核对，直到这一轮全部完成。

结果已经明确，霍准耳内的炎症完全消退，可以听辨回声。他将复核纸放稳，转向要处理的那段声音，完整听过以后再说自己的判断。旁边同伴想接着问另一份，他抬手示意先让自己把眼下的说明写完。“等这段对应清楚，再换下一段。”他说完指向记录，确认两人谈的是同一处内容。

一次聆听中，门边传来物件挪动的声响，同伴赶忙向他表示抱歉。霍准没有硬说自己全部听清，而是将受干扰的地方指出，请按原安排重听核对。对方移开挡路的物件，门边安静下来，霍准才继续。记录上留下这次重听的缘由，后面接手的人不必猜为什么同一处会有补充。

工作结束时，霍准将可以交出的纸递给同伴，自己把座位前的空处整理好。有人问他要不要再接一份，他看了看轮次安排，答应先把交接说明讲完。几人围在桌边，谈的是接下来哪些材料该由谁处理，没有拿一声轻松的叹息代替分配。霍准逐页确认无误，才起身离开，耳边的脚步与话音各自清楚，手里的工作也有了明确去处。

# 第七十五章 被划掉的确定

桑翎在一张说明里看见很肯定的判断，翻到附着的观察记录，却找不到相应依据。写说明的人站在旁边，解释自己听过好几个人这样说，所以想省去重复叙述的工夫。桑翎把两份纸并排放好，叫他指出哪一行直接支持眼下这句话，而不是继续报出赞同者的名字。

对方翻了一会儿，脸上有些发红。邵璇恰好来问材料进度，见状也停下来一起看，没有替那句判断补一个听起来合理的理由。“我们现在能说到哪一步，就先停在哪一步。”她把已经有观察支撑的部分指出，其余仍留作问题。桑翎请写说明的人自己修改，免得他只记住别人替他换过的句子。

删掉确定语气后，纸上出现一段不那么漂亮的留白。旁人说这份说明看起来不完整，写作者迟疑着又想添几句。尹禾将对应记录拿近，问如果只为填满空白，新来的句子又该指向哪里。他终于放下笔，改在需要补充的位置写清下一轮要核对什么，而不是用别人的一致意见凑足篇幅。

真正能交出的部分随后被整理好，未解决的随原记录留下。桑翎读过修订，没有要求把所有删改痕迹擦净，她需要接手者知道结论到哪里为止。那位写作者收起纸时仍有些不自在，却能对来询问的人说清哪些是观察，哪些还没有依据。桌边这次没有多出新的答案，几份材料却不再互相替一段未经确认的话作证明。

# 第七十六章 遮住视线的一角

一只培养盘在画面里显得比先前暗，尹禾险些将变化立刻写成培养物的反应。她正要落笔，发现旁边同伴从另一处看时并没有同样的疑问。两人把记录暂时搁下，先核对观察位置，不移动盘内材料，也不把不一致急着判成谁没有认真看。

“你站过来，看我说的是哪一边。”尹禾让出地方，自己退到同伴刚才的位置。换过角度后，那处发暗仍只出现在特定视线里。桑翎来帮忙排查，注意到邻近的普通遮片有一角落得过低，挡住了观看范围。她请负责现场的人按当前观察安排整理遮片，再让两人回到各自位置核对。

遮挡移开，先前看不清的一角露了出来。尹禾没有将这件小事写成种群本身忽然好转，而是如实记录原先受到遮挡、后来重新看清的过程。她还回看最初的半行文字，将险些写成确定结论的词划去。旁边同伴承认，自己若没有换位置，大概只会劝她再仔细一些，不会知道那句话究竟难在哪里。

盘没有因此被列入或移出任何已经安排的筛选，大家仍接着做本轮该有的检查。整理遮片的人离开时，请尹禾帮忙看是否挡住了身后的通道，她绕过去查看，指明还需让开的空处。小小的忙碌结束后，各人回到自己的工作，留在纸上的说明足以解释刚才为什么停下。尹禾重新拿笔，这一回先看完整个范围，才写自己实际能够观察到的部分。

# 第七十七章 译文的位置仍空着

索迦将古式脉冲记谱铺在面前，旁边放着自己几次练习的纸。那些被划去的尝试挤在页边，看起来像已经离答案很近，可一旦顺着往下读，他又说不出相邻部分怎样对应。廉舟来归还普通练习材料，站在外侧没有打断，直到索迦主动抬头才开口。

“这回能读通了么？”廉舟问。索迦摇头，说明自己还没译成，纸边的字只是尝试，不能当作原记谱已经表达的内容。他将普通短脉冲练习与古式记谱分开放，避免来人把两种工作混为一件。廉舟看见那些密密麻麻的字，终于明白写得多不表示已经完成，便只将归还的材料放在说定的位置。

一个似乎能接上的地方让索迦又坐近了些。他尝试按自己的理解继续往下，结果后面立刻出现无法衔接的部分。他没有剪掉难处只留下顺畅的一段，而是将失败经过完整记下，暂停那种读法。杯子在桌边挡手，他移开杯子，手指按住记谱边缘，重新查看自己究竟从哪一步开始想得太远。

临近换人使用桌面时，索迦收拢练习纸，把尚未解出的部分保持原样，没有在译文位置写一句含糊的总意。廉舟问是否需要留下帮忙，他请对方只确认材料没有混进别人的递送纸。两人把桌面整理好，索迦带走未完成的工作。那些被否定的尝试跟着一起收下，下一次展开时，他不必靠模糊记忆重复走进同一个断处。

# 第七十八章 个人说明压在手下

袁碣在陈列旁整理个人说明，纸页被经过的人带起一角，险些滑到空盒底下。他伸手按住，另一只手却碰歪了旁边的布。来帮忙的人先替他扶好布，再问这几份是否要一起收走。袁碣说还要查看，便将眼前这一份留在手下，其余放到不容易混拿的位置。

他低头核对涉及自己的那段文字，没有把边上的普通说明卡夹进来。袁碣出生时唯一的同胞手足是哥哥。他将这一部分看完，又翻到纸后检查有没有漏页，纸面在手里弯了一下，随后被慢慢抚平。帮忙者没有追问他的家人，只提醒他另一叠正压着一张不属于这里的观察纸。

“先把那张还出去，免得别人到处找。”袁碣说。他们将压住的纸取出，交给过来询问的人，对方看见完整的页边，松了口气。几张纸的误叠没有被当作小事一笑而过，袁碣让同伴说明它原先搁在哪里，自己调整了临时整理的空处，避免后来者再顺手放错。

整理完成，袁碣将个人说明收拢，站起身时又回头看了看桌角。帮忙者说那里已经空了，他仍亲自确认没有留下夹在布下的纸。两人随后让开过道，等匆匆走来的同伴通过。那人问方才丢失的一页找到没有，袁碣指向已经取回纸的人；来往的询问到这里停住，各份材料回到眼下需要它们的人手边，陈列旁重新有了可以落脚的空处。

# 第七十九章 银点没有回答

查看种子时，尹禾最先发现其中一粒表面带着银点。她将手里的纸停在半空，叫桑翎从能够看清的位置过来，没有伸指去刮，也没有把它与旁边的材料一并推开。那点颜色在当前照明下格外显眼，使她想立即找一个名字来称呼它。

“先只说你看见什么。”桑翎俯身看过，确认这是一粒带银点的种子，却无法据此说明银点为何出现。银点的成因仍然未知，她们没有把它判成病变或遗传特征。尹禾照实写下可见的样子，将关于原因的空处留下，又让同伴读一遍，确认自己的句子没有暗中替未知的部分下结论。

旁边有人提出把它转个方向仔细瞧，负责查看的人按当前操作安排处理，大家才继续观察。即使从另一处能看清，银点也没有因此给出来源。一个猜测刚被说出口，桑翎便问有哪些依据，对方想了想，承认只是觉得像某种东西。尹禾没有将那句猜测抄进确定描述，只保留需要进一步弄清的问题。

这粒种子仍按本轮查看的安排妥善处理，没有因为醒目的颜色被选入首批，也没有被擅自丢弃。尹禾收起记录时问下一轮会不会知道答案，桑翎说那要看新的观察能告诉她们什么。纸上的银点已经被写得够清楚，空着的原因并不妨碍别人找到同一处疑问。桌边的人散去后，留下的记录仍诚实地停在看见与不知之间。

# 第八十章 桌前还在商议

宁绡重新来到轮值桌前，带来的申请旁附着补充说明。匡霁让与安排相关的人坐近，先将桌上的其他材料移开，免得讨论中拿错。宁绡没有一坐下就催问结果，而是从上回没有讲清的协作问题说起，指向自己补过的句子，等人看完再继续。

一处写法仍让两个人有不同理解。有人以为准备工作可以同时进行，另一个人担心这会占住正在使用的位置。匡霁请他们分别指出需要什么，没有让声音较大的那位代替所有人作答。宁绡把申请拉回自己面前，承认那句把两件事挤在一起，重新分开说明，让每个人能看清与自己有关的部分。

“这样是不是就可以开始了？”旁边同伴问。匡霁说还在审议，尚未作出许可决定，不能凭讨论顺畅就将申请当作获批。宁绡点头，将准备起身去搬容具的人叫回来，先把未确认的安排听完。这轮讨论仍只处理申请与协作，白昼授粉没有在桌边几句赞同之后自行开始。

说明改好后，匡霁逐项复述待决定的问题，让相关的人核对有无遗漏。宁绡听到其中一处与自己的意思不符，及时指出，几人重新对齐了措辞。交到桌前的补充因而更清楚，却还没有成为一份批准件。宁绡把手按在纸边等最后的审议，外侧同伴收好暂时不用的空盒，给讨论的人留下位置；桌面上的决定栏仍等待真正明确的结果。

# 第八十一章 决定读到末尾

匡霁将完成审议的结果放在桌前，请宁绡与相关同伴一起核对。宁绡读得很仔细，连刚才争论过的协作部分也没有跳过。身旁的人想从她的表情猜答案，她却先把纸转过来，让大家直接看清决定，不必站在外侧等待谁的一声欢呼。

桌边逐项确认后，宁绡获得全天授粉许可，白昼和夜间均可进行。她将结果妥善收好，转向已经排定的当轮工作，问配合的同伴是否听清各自负责哪一部分。“先按这一轮的安排来，不要把所有事情挤在一起。”她说着让开桌前，给另一位需要看许可内容的人留出位置。

到了实际准备处，容具被摆得太靠近观察纸，宁绡的衣袖险些将纸角带起。她立即停住，请同伴把纸移到不会妨碍动作的地方，自己重新检查手边。有人以为可以赶快开始，她仍等现场准备全部核对完毕，才在白昼这一轮依安排实施授粉。她的动作并未因为得到许可而变得仓促，每一步都与眼前需要照料的培养物相接。

一轮工作完成，宁绡把经过交给负责记录的人复核，没有顺手将下一轮也写成已经完成。匡霁过来询问协作是否顺畅，她指出刚才纸角碍事的位置，两人商量怎样把准备讲得更清楚。同伴将整理好的容具收回，桌前留下足够的空处。宁绡最后看了一眼记录，确认动作与文字对得上，才让自己的手离开工作台。

# 第八十二章 两边同时记录

相邻菌群的观察安排展开后，索迦与邵璇各自在能看清的位置坐下。两边的纸若同时翻动，便容易把正在核对的行遮住，尹禾主动把多余材料挪远。她起先想把两份记录合成一张，邵璇让她暂时分开，等看清各自的变化再谈如何对照。

这一轮实验围绕菌群间的养分交换进行，大家依已定安排查看相关变化，没有刚看见一处起伏就抢着解释全部现象。索迦指着自己记下的一段，请另一边核对对应经过。对方没听清他指哪里，险些报出相邻的一行，尹禾及时请两人重说位置，错误在写进纸上以前被拦住。

“我们先保证谈的是同一次变化。”邵璇把两份纸放到共同可见的地方，等大家指认完，再回到各自工作。实验继续时，一个记录者手背碰翻空杯，杯子滚出一点声响，使旁边人猛地回头。他捡起杯子说明情况，大家按实际经过补记这次停顿，没有将它算作菌群的特殊反应。

观察结束，索迦将可对照的部分留好，邵璇仍要复核实验结果，两人没有当场向围来的人宣布结论。尹禾把最初险些对错行的经过写明，叫接手者注意同一处对应关系。桌面收拾干净时，几份记录都能找到自己的位置；实验确实向前走了一步，尚待核定的原因却没有被兴奋的猜测提前写满。

# 第八十三章 成对起伏的来处

邵璇把复核过的实验记录放到索迦面前，两人从对应位置开始逐项查看。先前看似细小的起伏，如今能与完整观察经过放在一起比较。尹禾站在旁边，按要求找出需要核对的纸，没有将相似的段落误并，也没催他们先说一句好懂的结论。

复核完成后，那个悬着的问题有了明确答案。成对的微弱电流，是相邻菌群交换养分时的信号。索迦将结论与支持它的观察一同整理，邵璇让在场的人指出实际依据在哪里，免得只记住最顺口的一句。尹禾沿着纸面找到相应部分，才发觉自己先前想象的解释根本没有必要塞进这份结果。

“现在能写清楚了，但别把别的起伏也一并解释。”索迦提醒来取材料的同伴。对方原先准备将几种未明变化写在同一段里，听过后拆开，各自保留已有的说明。邵璇也将适用范围说清，这次核定的事实没有被扩大成所有菌群都会照同一方式行动的规律，其他未解的问题仍按各自证据处理。

尹禾将完整记录递出时，来人读到结论又回看实验过程，点头说能够接着查。她于是把自己的临时摘记收好，没有用它替代原材料。桌边不再需要用含混的手势描述那一对变化，后面的筛选工作也终于可以使用经过核对的这一部分信息。索迦与邵璇各自带走该继续处理的材料，留给下一轮的是可以看明白的依据。

# 第八十四章 空包装也要走一遍

旁边有人推着空件经过，袁碣站到合适的位置让路，手里的布留在自己掌中，没搭到陈列上。对方走过后，帮忙者问是否还需要再看，袁碣请他核对最后一遍边角，自己绕到来人通常停下的地方。两人确认没有新遮挡，才收起临时用品离开，灯光仍照着石面与说明，下一位来者不必先伸手挪开谁遗忘的一张纸。

# 第九十五章 门外核清的清除过程

蘅环舱外的记录台摆开了这一轮清除工作的资料，邵璇与同伴站在外侧逐项核查。清除在外部操作下进行，没有人员进入舱内。有人看见整理出的材料渐渐齐全，便想把待用物件提前搬过门内，邵璇立即叫住他，指向尚未完成验证的那一部分。

“先放在外面，不能靠看着快好了就跨进去。”她说。对方收回脚步，将物件挪到不会妨碍核查的位置。蘅环舱此时仍保持封存，大家通过外部观测与清除记录继续核验，门外的人没有为取一张纸或确认一个角落而擅自进入。需要补看的地方被明确列出，交由外部操作继续处理。

一份资料里的对应位置不清，负责记录的人以为只要补一句已经清过就够了。邵璇让他把实际经过找到，再说明与哪一项相连，不能拿结论代替验证。旁边同伴将另一份画面调到相应位置，几人从头核对，直到能够看清同一轮过程，才把那处疑问交去按要求完成后续核验。

这轮门外工作结束时，仍有结果需要最终确认，匡霁请众人按现有安排收好材料。没有人以一声差不多宣布解封，准备物件也没有悄悄越过边界。邵璇离开记录台前，再读一次待确认部分，明确下一位应核对什么。门外站着的人各自让出空间，舱内的情况由资料继续接受核验，进入的决定还没有在这一轮作出。

# 第九十六章 可以进入的决定

最终验证资料送到记录台时，匡霁请相关人员留下共同核对。邵璇将实际清除经过与验证结果对应起来，指出每一部分放在何处，方便来人自己查看。桑翎读过所需材料，没有只听一句概括便离开，确认资料齐备后才等待正式决定。

验证结论明确，蘅环舱已经清除游离孢子并完成验证，现已解除封存，允许人员进入。匡霁将这一决定传达给在场的人，随即核对本轮进入安排。有人刚要上前，又想起手里的普通材料并不属于这一项工作，便先将它交到对应位置，不让其他任务跟着自己混进门内。

“按安排来，里面还要留出操作的地方。”邵璇请外侧等候的人暂时站开，待需要进入的人做好准备，再让出通道。几名工作人员依安排进入，第一位在门内停了一下，确认后面的人能够看清脚下，再继续前行。外面的人等他们通过，才将当轮记录递到指定接收位置，动作有明确回应，没有隔着人群乱递。

桑翎站在侧面看完这一轮开始的经过，将能够确认的事项写清，交给同伴核对。匡霁提醒众人把当前工作与后面的样本筛选分开，不因进出变得顺畅就跳过其余步骤。走到门边的人听清后各自办理手里的事，外侧材料随之减少。邵璇回看已完成的验证记录，收妥应留存的部分，才转向新的工作，没有让重要结果埋在临时搬动的杂物下面。

# 第九十七章 首批从逐份查看开始

候选样本与对应观察资料被依安排放好，桑翎先请众人不要围成一圈，同时伸手只会遮住需要看的位置。邵璇从自己负责的部分开始核对，其他人照各自任务提供依据，尹禾则协助把每份材料放到对应处，遇见不清楚的地方就停下问。

一个急着凑齐的人想把仍待确认的那份也算进去，桑翎请他找出支持选择的实际结果。对方翻过纸才发现还缺一项核验，便将它留在本轮候选之外，不用相似样本的结果代替。“我们交出去的是这一份，依据也要属于这一份。”桑翎说明后，大家继续逐项查看，没有为获得更大的数量而压低要求。

筛选进行到后面，尹禾险些把一页补充说明放错位置。她看见两份材料的对应处不合，立即叫停自己手里的动作，请原记录者指认。纸回到正确位置，刚才被误遮住的内容露出，负责确认的人才继续。那一下停顿使后面的工作免于沿着错误推进，尹禾将经过记清，未装作自己从未拿错。

最终选定的首批样本留在交付准备范围内，未入选的仍按各自安排照管。贝嵘查看完需要自己核对的部分，将说明交出，祝珉收拢已经用过的空件，给接下来的交接腾开地方。桑翎读过选择结果，再与实际样本逐一对应，才让这轮筛选结束。人群散开时，桌前留下的每一份都能找到说明，首批终于有了可以交给接收者的明确范围。

# 第九十八章 印记落在返还之后

尹禾在返还位置接过样本盒，先听对方说明刚完成的动作，再查看对应记录。有人将一只只是临时放下的空盒也推近，她立刻请对方分开放，避免两件看着相似的东西被同样处理。真正完成返还的那一只留在面前，其他物件由相关人员按自己的事项整理。

核对状态无误，她将盒面放到稳妥位置。尹禾给已返还的样本盒盖上圆环印。印记落下后，她让接手者看清，并把实际处理写入对应记录，没有用一个圆环替代应有的返还确认。对方伸手接盒前又问了一遍，尹禾指向已经核好的部分，把完成与暂放的区别说明白。

“别把旁边那只也顺手拿去盖。”她提醒帮忙整理的人。对方点头，将临时放下的空盒拿回自己手边，继续核对属于它的工作。尹禾等记录与实物都由正确的人接妥，才腾出桌面，不让印过的盒与未处理的东西再次混在一起。有人来找空处放纸，她请他等眼下这一次接收完成，再说明准备放的是什么。

这一轮结束后，桌边没有留下意义不清的记号，完成返还的盒也有相应记录可查。尹禾收起所用的印具，查看手边是否漏了纸，再将需要留存的材料交给负责者。桑翎过来听她说明经过，只核对实际动作与记录是否相符。尹禾回答得简短，却能逐项指出自己的依据，不必再凭对方把东西放下时的神情猜发生过什么。

# 第九十九章 出发前仍要停笔核对

交付准备接近完成，匡霁把各人的当前事项放到一起，逐项询问有没有尚未交代清楚的部分。她不要求众人重复已经结束的长段经历，只让每个人说明眼前该交出的东西与相应材料。廉舟核对递送安排，邵璇查看分析说明，桑翎则对照首批样本的选择结果。

尹禾发现一页待继续观察的材料混在交付纸旁，马上将它指出。那页提到的银点仍无成因结论，不能在此刻被当作已经解决的问题。另一张无署名星空描图也没有作者与用途的答案，相关疑问按原样留存，没有被人顺手解释成这次递送的指示。匡霁让大家将这些未完事项与本轮交付内容分清，再确认材料去处。

“现在缺的是哪一个实际动作？”她问。有人指向仍待接收方核对的一处，众人便停下准备前行的脚步，先把说明送到能够确认的人手上。等待里，祝珉将通道旁多余的空件移开，宁绡整理自己的随附记录，谁也没有因为已经忙到最后就把一个待确认写成完成。

明确回应传来后，桑翎与同伴再读过当前材料，确认可进行交付准备的最后整理。尹禾把不属于这一轮的纸收好，不让它们随人群挪走；廉舟站到能稳定接应的位置，等待正式交接。几个人望着眼前已经核清的范围，不必把所有未解的问题一并带进这一步，也没有假装那些问题从来不存在。匡霁收起安排纸，示意按说清的次序继续。

# 第一百章 模拟舱外的停步

首批样本的交接在逐项核对中进行，廉舟与接收者把实物和材料一一对应。桑翎站在能看清确认位置的地方，等每一份都有明确回应。尹禾递上随附说明时，发现纸角贴在一起，便先分开再交出，没有让疲倦替自己省掉最后一次查看。周围的人都留出空处，等这一轮动作完整结束。

最后一项得到接收方确认，首批存活样本的交付已经完成。桑翎按住确认板，让身旁同伴看清落定的结果，才将手移开一点，继续核对留存说明。“这一批接妥了。”接收者的话在近处响起，匡霁请相关人员把记录收好，没有立即用新的任务盖过刚完成的这一件事。

贝嵘慢慢吐出一口气，宁绡与他对望，笑意在两人脸上停了一会儿。霍准帮忙让出过道，邵璇将已核清的材料带到合适位置，索迦确认自己的说明没有散落。尹禾抱稳留下的记录，望向模拟舱的方向，脚步却没有越过众人的等待。那里尚未启动，没有人开始飞行模拟，也没有在这一刻绘制新的气流路径。

后面仍有需要观察的生命，也有尚无答案的疑问，它们各自留在应该继续处理的地方。眼前这一批已经由明确的接收接住，不再只是桌边的一项愿望。桑翎收妥确认后的材料，与同伴一同走到模拟舱外；有人原本想再问一句，看到大家都停下，便先把话留住。舱内没有响起启动声，众人站在未启动的模拟舱外，带着完成的交付，停在下一步开始以前。

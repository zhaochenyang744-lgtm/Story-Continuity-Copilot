# 第一章 船板上的空隙

漪声船还没有解开岸边的缆，舱里的几个人已经跟着水纹摇晃起来。陆荞扶住一张斜靠的凳子，没有立刻坐下。她看见前面留着窄窄的一条路，以为那是专给上场的人留的，便把自己的脚尖缩到了箱子旁边。有人抱着卷起的幕布经过，布边扫过她的额头，她只往后一仰，连声说不碍事。

唐绢从另一侧钻出来，把凳子摆平。“坐下也能让路，不必总贴着墙。”她伸手试了试凳脚，发现一角悬着，便将它挪到两块船板相接的地方。做完这件小事，她才抬头看向前面已经站好的人。唐绢负责给演员发开场提示。此刻她举起手，又慢慢放下，让候着的人熟悉她在昏暗处的轮廓，而没有让谁真的走出去。

船上的人喊她灯尾。陆荞起初没有接上这个称呼，直到有人越过她的肩头叫了一声，唐绢应着回头，她才明白那是在叫谁。唐绢瞧见她的神情，笑道：“叫唐绢也行，别为了跟别人一样，把要说的话憋回去。”陆荞于是问自己该站哪里，声音一出口，又被木箱底下拖长的摩擦声盖掉了半截。

这时的陆荞只是替补，没有正式登台角色。她被留在排练队伍里，前面的人若停下来，便由她接着念一段，让后面的人不至于空等。唐绢在众人之间腾出半步宽的位置，示意她试着走进去。陆荞走得太快，碰到了前人的衣角，立即退了回来。“不用一碰就退出去。”唐绢说，“先看清别人要往哪里，再决定自己的脚。”

她们来回试了几次。靠门的人不耐烦地换了一条腿，随后也发现，陆荞退得越急，留给他转身的地方反而越少。大家索性慢下来，在没有一句台词的空隙里走了一遍。陆荞终于穿过那条窄路，站到了灯照不匀的地方。她望见水面亮光从门缝爬上唐绢的袖子，原先以为不可越过的界线，随着船身轻轻一晃，便移到了别处。

有人示意还要重走，陆荞便自己退回起点。这回她没有把空位当成别人施舍出来的地方，经过箱角时也敢抬起脸，看一眼正要从对面走来的同伴。两人互相侧身，衣袖只轻轻擦了一下。

# 第二章 没唱完的气息

乐声刚起一个头，孟稠便把嘴闭上了。陆荞以为自己错过了接话的地方，急着往前跨，唐绢却朝她摊开手，叫她先等一等。舱口落进来的风把散着的纸页掀起一角，孟稠伸手压住，喉咙里又发出一声干涩的清音。他试着将那口气拖长，到中间就不得不停下来，眉头皱得比方才更紧。

“慢弦，先喝口水。”有人在后面劝。孟稠抬眼答应了一声，陆荞才知道大家给这位伴奏取的称呼。桌边的人向她让了让，露出他面前放着的一件打拍器。折月响板此时由孟稠保管，他把它合在掌间，并没有递给别人。孟稠的声音沙哑，不能唱长句，便只敲出开头的拍子，让演员自己把没接上的部分走完。

陆荞仍盯着他的嘴唇，怕他下一刻又要开口。孟稠察觉后，抬手点了点自己的响板。“听这个，别等我的嗓子。”他用很短的话说完，又停了一会儿。陆荞重新站稳，照那几下节奏挪动。她原本准备一气说到底，走到中途，却看见旁边的衣摆被凳角挂住，只得将念白拆开，等那人松脱后才接下去。

潘恪正弯腰把一包衣服从通道搬开。他是船上的服装保管，刚放下包裹便蹲到凳子旁，用手托住被勾住的布，叫那位演员别再往前拽。陆荞也跟着蹲下，手伸到半路，又因怕越帮越忙而停住。潘恪抬起布边，对她说：“你替我看看哪根线还挂着。”她侧过脸，总算在暗处辨出了那个小小的结。

等大家重新排好，之前的急躁已经散去一些。孟稠不再试着压过满舱杂声，敲一下便留下足够的空白。陆荞跟着那空白调整呼吸，发现自己不必把每一个停顿都填满。船外有人拖动缆绳，绳上的水滴落在舷边，孟稠抬手示意众人等那阵响动过去。陆荞没有抢着补话，而是同他一起听着。待水滴声稀落下来，她才迈出下一步。

潘恪端详着空下来的过道，忽然也跟着那几下拍子走了两步。他走得笨拙，差点同迎面的人相撞，便笑着停下。陆荞却觉得这一下停得很好，忍不住也笑了。孟稠敲在掌里的声音轻了一点，容得下两个人短促的笑声。

# 第三章 多出来的人形

潘恪将一件亮得发冷的肩衣展开时，舱顶的光忽然被过路的人遮了一下。翠色从他的手腕滑到肘边，又随着布料落定重新浮出来。他没有让任何人披上，只把松开的边角逐一理顺。陆荞站在旁边看，伸出的手在半空收了回来。潘恪见状，便将衣料稍微抬高，让她不必弯腰也能看见下摆。

翠缎肩衣由潘恪保管。他整理好便把它收回自己看顾的衣物里，转而请陆荞帮忙移开挡路的空凳。两人抬起凳子，刚走到幕边，陆荞忽然停住了。帘子下缘有两个人似的影子，一高一矮，挨得很近。她回头看，身后并没有人照着那样的姿势站立，于是连手里的凳子都忘了往下放。

“怎么了？”潘恪问。陆荞指了指幕布，没有说自己想到了什么。帘子被船身的晃动带得起了一条皱褶，两道轮廓便仿佛一齐弯了腰。潘恪先让她把凳子放稳，再陪她从另一侧绕过去。那边堆着排练时挪开的东西，脚下狭窄，两人只好侧身挤过，经过幕角时还将布碰得颤了几下。

他们没有立即找到可以解释那两道影子的东西。陆荞想把帘子整个掀起来，唐绢却正领人从前方走过，只好用眼神请她等一会儿。她于是退到通道边，听着别人念到一半又重来的台词。影子在帘上时聚时散，像把那些没说完的话也吸了进去；等到人群停下来，它们却仍贴在布上，没有跟着消失。

“排完这段再看。”唐绢终于走近，对着那块布端详了一会儿，“现在挤进去，前面的人又得全退回来。”陆荞答应着，坐到刚搬来的凳子上。她没有再把那轮廓说成人，只把自己看到的高低与位置比划给潘恪。潘恪用手沿幕边指了一下，记住她说的地方。随后乐声又起，大家把注意力转回场上，只有帘子的褶子还在慢慢移动，使那两道淡影一会儿露出，一会儿藏起。

陆荞把凳子稍稍转了个方向，不让自己一直对着那边。眼前的人伸手接不到对手的手，尴尬地停在半途，她便提醒他们靠近些。等那一段重新接顺，她才发觉自己已经好一会儿没有偷看幕角了。

# 第四章 果实落在哪里

陆荞把一枚用来练习的假果实抛起，伸手接时却碰到了自己的袖子。它落在船板上，发出比她预想更轻的一声响，滚到凳脚就停住了。没有人责怪她，倒是站在对面的人笑了一下，问这算不算临时加的动作。陆荞也笑，笑完脸却更热，弯腰拾起时不敢看唐绢，仿佛只要动作足够快，刚才那一段就能从众人眼前抹去。

唐绢没让她立刻重来，而是请她先把手中东西安顿好。陆荞把练习用的假果实放进软毡窝。那一圈软边受力凹了下去，果实稳稳停在里面，再没有向船板斜处滚动。她蹲着看了一会儿，忽然明白，方才自己只想着怎样抛得像真的，却没想过接不住之后还能怎样往下演。

冉颂从旁边让出一点位置，将身前挡着的凳子推远。他看着陆荞重新站起来，没有示范，只问：“你是要让别人看见果实，还是看见你在等它落下？”这问题使陆荞停了好一阵。冉颂第一次登台时刚满十岁。眼前新来的演员因为一次失手就急着擦掉整个动作，他便耐心等着，不催她回答，也没有把自己的经历拿来压她。

陆荞试着空手做了一遍。没有东西可接，她反而更清楚地感觉到两臂张开的距离。她望着掌心，低声说：“我好像一直盯着结果。”冉颂把凳子又移开一些，让她有地方转身。唐绢站在前面，等她自己抬起头才发出提示。陆荞没有跑着去赶，先走完那一步，再让目光追到空中。

这一次旁边的人都安静下来。动作结束得并不利落，陆荞的脚跟仍蹭了一下地，却没有中途停住，硬把所有人拉回开头。她将原本卡在喉咙里的半句台词说完，等对面的人接上，才回到凳旁坐下。冉颂问她要不要再试，她摇摇头又点头，自己也被这矛盾的表示逗笑了。唐绢让大家歇一口气。陆荞趁这会儿重新舒展手指，望着身前那一点空处，不再急着让它显得完美。

轮到旁边的人练时，陆荞靠着凳背替他留出地方。那人也没接稳，抬头正撞见她的目光，先窘了一下。她轻轻点头，叫他接着往下走，手却在身侧替他捏出一把汗。

# 第五章 留着的一点地方

潘恪托起一位演员的手腕，将翻进去的布边轻轻拨出。那人着急去前面等着，身体已经朝门口偏，胳膊却还留在他手里，像被两股力扯着。潘恪没有用力拉，只叫他把肩膀放松。陆荞从旁看着，也跟着把自己绷紧的肩头往下沉，直到那位演员笑着说了一句谢谢，舱里那种催人赶快的气氛才稍稍缓过来。

潘恪替演员整理袖口。他让对方曲起胳膊试了试，确定衣料没有卡住动作，才放手让人过去。唐绢在另一边挪出通道，陆荞便帮着把凳子推回原位。就在她低头时，瞧见座面下压着一张折过的便笺。纸上请人空出一个座位，却没有落款，也没写要给谁坐。陆荞将那行字看了两遍，转头寻找方才从这里经过的人。

附近的人都在忙自己的事。她问：“这是谁放的？”没有人应声，倒有一个正在试步的人以为她叫自己，停下来向这边望。陆荞忙摆手，让他接着走。唐绢过来看过纸条，只说先别弄丢。陆荞就把它按回原处，没有凭空挑一个人来解释那请求，也没有擅自将旁边一排位置全空出来。

等排练接上，她需要在众人停顿时补一句话，却因为还在想那张便笺，迟了半拍。对面的演员已经吸好了气，等她一张口，又和她撞在一起。两人都住了声，随后一同笑起来。唐绢请他们别争着退让，先由一个人说完，另一个人再接。陆荞望着对方的眼睛，总算从那张看不见的纸上收回注意。

这一段走顺后，大家将挤在中间的凳子向两边分开。陆荞再经过那个座位，脚步不自觉地慢了些，心里仍想知道这小小的请求从哪里来。她没有再问出声，而是把翘起的纸角压平，免得有人一坐便将它折坏。船侧传来水拍木板的响动，未写名字的那一处白纸在光里格外显眼，周围却很快又被说话声与走动声填满。

唐绢回来叫她时，她刚好将手从纸边移开。她跨过凳腿，站进等着接词的人群里，听前一个人的话如何落下。这次她没有提前准备自己的声调，只在对方转过眼来的一瞬间，自然而然接住了那一点停顿。

# 第六章 一声之后

排练尚未连到最后，幕边的影子又被人看见了。陆荞这回没有放下手里的活就冲过去，而是等走道空出来，才叫唐绢一起看。她们站在原先的位置，先让帘子静下来，再看周围哪些东西跟着船晃。潘恪听见她们讨论，便把挡在边上的布包挪开，留下能侧身过去的缝隙。陆荞沿着缝慢慢走，鞋底摩擦木板的声音显得格外清楚。

唐绢请靠灯的人别移动，让陆荞从帘前观察。她将其中一盏侧灯遮住，布上的一个轮廓便淡了；放开以后，那轮廓又回来。幕边双重影子是两盏侧灯同时照到悬挂衣架造成的，并不是台后藏了人。陆荞绕到背面，看见那副衣架正随着船身轻晃，才把原先悬着的气吐出来，伸出手，却在碰到它前停住了。

“不用把它取走。”唐绢说，“先知道它为什么在那儿。”潘恪也走过来看，三个人换了位置，各自瞧了一遍。陆荞有些不好意思，唐绢却说，若一开始就随便认定是某个人，反而要在船上找很久。她们把挪开的布包重新摆好，给灯前留出空处，让准备上场的人经过时不必再绕到幕布背后。

大家回到原位，刚接上前面断开的动作，外头又有人招呼要留出舱口。唐绢没有高声压过台词，只向旁边示意。船上提前结束排练的信号是一次低鼓音。那一下响起，众人陆续停住，已经抬起脚的人先把脚落稳，举着手的人也把手收回，没有谁为抢说最后一句又拖住别人。

陆荞等到对面的人看向自己，才跟着退出走道。有人还想趁人没散多试一遍，唐绢让他把要记的地方留住，先给通道腾空。陆荞扶着凳背，回想刚才那一声是怎样从杂响里钻出来的；它不大，却令整段排练一起停在了可以重新开始的地方。离开幕边时，她又看见那两道影子。它们没有变成别的样子，只是她已经不必再对着它们猜测了。

潘恪在身后叫她让一让，她侧身靠近幕布，替他托住快要滑下来的包角。两个人合力走过最窄的一段，直到前方宽敞才松开手。陆荞回望自己刚才站过的地方，那点光正随着水面起伏，安静地落在空凳上。

# 第七章 空凳听着

前面的凳子都空着，陆荞却觉得比坐满了人更难开口。她站在帘边，看唐绢将通道上的杂物推开，想从对方脸上找一点催促的意思，好借着那股劲往前走。唐绢没有催，只请忙完的人各自站到要站的位置，让过道安静下来。没有观众的这次开场排练，连前头响了一下的凳脚都听得分明。

孟稠走近，将手中的打拍器翻过来，露出合拢时可以握住的地方。陆荞本能地伸手，接触到它以后又迟疑了一下，仿佛一接过来，就得把所有人的脚步一并接稳。孟稠把折月响板交给陆荞，此后由陆荞保管。她将它贴住掌心，试着轻轻合了一回，声音比自己想的脆，眼睛不由向周围一扫。

“不用先敲得好听。”孟稠说，“让他们听见你什么时候走。”这话很短，陆荞却反复琢磨了片刻。她先迈步再打拍，结果后面的人迟了一点；改成先打拍，自己又像被那声响追着向前。唐绢从旁边看，没有替她选，等她第三回停住，才让后面的人说说自己听见了什么。

有人说太急，有人说最怕她忽然不动。陆荞原先只想着不出错，听到这里，才发现自己为了避开小错，反而总把同伴留在半路。她将手放低，重新看清前方的空处。这次敲响以后，她没有因脚尖碰到船板接缝就退回去，而是顺着那一步，把准备好的话接了出来。后面的人跟上，衣角在她视线边缘轻轻一闪。

那段开场终于从头走到尾，中间仍有不齐整的地方，却没有谁被抛下。唐绢走过来，让他们先别急着评价，回到原位再试一回。陆荞吸了口气，忽然觉得前面的空凳也在认真等着，不能因为它们不会说话，就把刚才积起来的耐心收走。她向后望了一眼，等同伴抬头，才带着那一点不够熟练的笃定开始。

最后一个人走过幕边，陆荞还站着没动。她以为自己该立即道歉，解释哪一处敲早了，可是嘴刚张开，后面的人已经拍拍她的胳膊，说刚才总算没有跟丢。她把道歉咽回去，点了点头，手心里那点汗也仿佛不再碍事了。

# 第八章 写进这一场

众人围到一起商量演出安排时，陆荞原本坐在外圈。她将膝盖收好，给来回递话的人留地方，听他们谈哪一段还会撞到衣摆，哪一个转身不必做得那么急。轮到说开场，她低下头，等着别人指出自己排练时漏掉的动作。唐绢却先让她把凳子挪近，说隔着几个人谈她的事，总显得不大合适。

陆荞挪过去，凳脚在船板上拖出一声长响，惹得几个人回头。她正要解释，唐绢已经把那一段的安排念了出来。陆荞获得了正式登台角色，负责这场戏的开场独白。话落下来以后，她没有立刻应声，手指还按在凳沿，像是没弄明白该把坐着的身体怎样接到那个将要站起来的位置上。

“你听清了吗？”唐绢问。陆荞点头，随后又说，自己还会卡住。旁边的人笑着承认，谁都没有把每个转身练得稳当。有人愿意在她停顿时多等一下，也有人提醒她不能因为不满意自己的语气，就将已经说过的话再来一遍。陆荞听着这些具体的担心，才从那种近乎空白的喜悦里缓缓落下来。

她到前面走了一趟，没有立刻念台词，而是看看同伴从哪里进入自己的视线。排练时总想抓住的那几个动作，此刻像挤在同一扇门外，谁都想先出来。她试着只留下开头的一步，让其余的等一等。唐绢从侧面经过，没有插话；等陆荞自己转过身，才抬手示意可以开始。她开口的声音很轻，却没有因为无人接话而慌忙加快。

说完以后，屋里安静了一下。陆荞不确定那是不是不满意，脸上的热意又起来了。随后有人指出她站得太靠边，尾音像被幕布挡掉一截。她依言挪了位置，发现只差那么一点，前头的空地便像宽了一层。她再次念完，才敢问唐绢：“这样，你们接起来方便些吗？”

唐绢没有替大家回答，让将要接场的人各自试着走。陆荞站在一旁，看他们如何经过自己刚才留出的地方。她心里的兴奋渐渐有了形状，不再只是被选中的一阵热，而是下一回需要记住的一步、留出的一口气。等讨论散了，她仍把凳子推回原位，动作比平时慢些，却没有再缩到所有人的身后。

# 第九章 尾音过河

孟稠试音时，陆荞正在帘后整理自己要走的路线。她听见前面有人拉长一个音，便停下脚，等那声音像往常一样断开。它却稳稳越过了她心里预备的断处，继续往前，直到那一整句自然收住。舱里另外几个人也停住手，彼此看了一眼，随即又不约而同地装作只是在听一段普通的练习。

孟稠放下压着胸口的手，没有马上再唱。他慢慢呼出余下的气，朝旁边要递水的人摇了摇头，示意可以稍等。孟稠的嗓音已经恢复，能够唱完整的长句。他又将刚才那句从头唱了一遍，声音经过舱门，和外面宽阔的水响碰到一起，终于不再显得像是被关在一小段窄路里。

陆荞走出来，问自己是否该接得更快。孟稠听完她的试句，却说：“别追我最后一点声音，等你自己看见对面的人。”她便转向同伴，发现对方还没站稳，眼神仍在寻找脚边的位置。等那人抬头，她才开口。两段声音之间多出一点空隙，船外的水声趁机进来，反倒将原来紧绷的接续托住了。

潘恪抱着衣物在旁边等了一阵，见他们又要从头试，忍不住说，刚才那一遍已经能让人听清。他没有说哪一遍最好，只是自己不用停下搬东西，也知道话轮到谁了。陆荞听见这句，笑着朝孟稠看。孟稠也笑，手指在膝上轻轻点着，让她再试一次，却不要存心复刻刚才的停顿。

越想照样做好，陆荞越容易抢先。她连续快了两回，自己都有些恼，孟稠便将开头唱得稍慢，让她有时间把那股急劲放掉。她终于没在对方尾音尚未落定时插进去，而是在目光相接之后自然开口。没有人喝彩，因为这还是排练；但几个人重新忙起手上的事时，动作都轻松了一些。

陆荞回到帘后，发现方才被自己担心的那条路线仍在原处，并没有因多等一口气就变得走不完。她靠着空凳，闭眼听完下一段，脑中不再逐个数自己的动作。船身轻晃，门外光线在她鞋面上移过去。她睁开眼时，恰好看到孟稠正向一位同伴示意，把一段太紧的衔接重新留出余地。

# 第十章 岸边的等候

漪声船靠到苇弧埠后，岸上的脚步声一下变得密了。大家搬着东西来回走，陆荞刚跨出舱口便险些被迎面的人挡回去，只好扶着门边等对方先过。潘恪走在后头，没有催，将怀里叠好的衣物往上托了托。与船上不同，岸边似乎处处都能站人，可每个人一停下，立刻就有人需要从他身旁经过。

唐绢先让搬东西的人顺着空处走，自己留在不挡通道的位置。潘恪挤到她面前，展开抱着的翠色布料，让她看清边角都已收妥。潘恪把翠缎肩衣交给唐绢，由唐绢接着保管。唐绢将它稳稳抱住，问他其余东西是否还在路上，潘恪向身后的来处看了看，便又回去帮忙。

陆荞跟着人流走过一段，才发觉自己一直想随便找个人站在旁边，仿佛那样就不会错过上场。她停下来，先看清同伴往哪里去，再从人群边沿慢慢靠近。唐绢在苇弧埠的西侧候场台等其他人。见陆荞走来，她只略微移开身体，让出一小块地方，没有要她立刻练习，也没有追问她紧不紧张。

“这里比船上听见的声音多。”陆荞说。远处有人笑，近处又有人拖凳子，每一阵响动都像要把她的话带偏。唐绢叫她先把一句话说完，再决定要不要去听别的。陆荞望着对方的脸，试着讲了一个再普通不过的请求：让旁边的人替自己留点转身的空处。那人听清后侧了侧身，事情便这样简单地做成了。

她忽然放松了一点。前来等候的同伴越来越多，大家并没有像她想象中那样都一言不发地绷着脸，有人还在争论哪里应当稍停，有人只想找个不被踩到的地方活动脚趾。陆荞低头挪开自己的脚，听他们说完，也把一处担心讲出来。几个人顺手试了半个转身，发现并不必挤到一起。

潘恪再走回来时，陆荞已经能给他指出一条空着的路。她没有像先前那样急着迎上去，只在他走近后伸手扶住快要歪倒的布包。唐绢看着众人陆续到齐，将身前的东西抱得更稳一些。岸上风吹起台边一角衣摆，又很快放下；陆荞站在那短短的起落之间，等心里纷杂的声音慢慢排好先后。

# 第十一章 帘后还未亮

真正要面对观众的时候，后台比排练时安静得多。并不是没有声音，只是大家都将说话压在近处，像怕一抬高，就会提前把自己送到幕前。陆荞能听见身边有人反复舒展手掌，也能听见一只鞋在地上轻轻蹭了两回。她原以为自己会把所有台词在脑中念遍，此刻却只能想起第一句话的起头。

冉颂站在离她不远的地方，正等前面的人让出通道。他没有插到旁人之间，只侧着身体，像把自己也摆成一段可以绕过去的窄边。冉颂第一次登台时刚满十二岁。陆荞望着他等待时平静的样子，想问紧张到了最后会不会忽然消失，又觉得这问题太大，一时不知从哪一个字开始说。

“脚底发空吗？”冉颂先问。她点点头。冉颂让她别急着多走几遍，把脚跟落稳就行。陆荞照着做，发现自己一直用前脚掌顶住地面，像随时要追上什么。她慢慢放下脚跟，身体没有因此变迟钝，反而能感觉出旁边那个人挪动时留下的一点空间。

幕外的说话声忽然合成一片，又散开。陆荞忍不住往前探头，才动了一下便停住，怕挡住同伴。那人看出她的意思，悄悄让了半步。她看不清外面每一张脸，只看见一片肩膀与衣领，仿佛所有等着听的人都暂时融成了一个模糊的轮廓。她退回来时，第一句话也跟着清楚了一点。

唐绢从她面前经过，目光同她短短碰了一下。陆荞没有再要求对方告诉自己何时呼吸，何时抬头，只把需要说的话在心里放平。冉颂见她松开攥着的手，便不再讲话。等待并没有变短，但每个声音都找到了自己的位置，不必全挤在她耳边。她甚至听见有人在很近的地方轻轻笑了一声，随即忍住了。

轮到前面的人移动时，陆荞让出路，看着那片衣角从眼前过去。她知道自己也要沿着这条路走，却没有再追着别人试步。帘后剩下的空隙渐渐扩大，外面的光伸进来一点，落在她鞋尖前。她低头看了看，又把目光抬起。那些练习中无数次走错、停住、重新接上的片刻，没有一齐涌上来，只留下眼前这一步可以踏出的地方。

# 第十二章 声音落定以后

陆荞走出去时，最先看见的并不是某一张脸，而是前头有人正将身体往旁边让，好给迟来的同伴留一点位置。这个极小的动作使她想起船上窄路里的练习。她没有盯着那边等人坐稳，也没有急着用第一句话压住四周的响动，只照自己能站稳的步幅走到该停的地方，抬头，把开场的话慢慢送出去。

后来整场戏一段接着一段展开，仍有不够齐整的时刻。有人转身稍迟，陆荞便等他看过来；有句话比排练时说得轻，旁边的人也没有慌忙替它补上一层更响的声音。观众的注意仿佛水纹，有时散开，有时又聚回去。最后的动作停住时，陆荞才发现自己不再数还剩多少步，而是真的走完了这一场。

幕前的声音渐渐落定，众人退回后面，终于可以不压着嗓子说话。孟稠在演出结束后收拢乐谱。纸页边角有些翘起，他一张张拢齐，陆荞经过时伸手替他挡住吹来的风。他抬头问她感觉如何，她想了许久，只说：“中间有一回，我听见别人接住了。”孟稠笑着点头，没有追问是哪一回。

人群慢慢散去，搬回船上的东西也越堆越齐。陆荞挪开空凳时，又看见那张请求留座的便笺，纸的折痕被压得更明显了。直到演出结束，仍没有人说明是谁留下它，也没有人知道那一个座位原本要留给谁。她拿起纸看了看，仍旧只看见那些没有落款的字，便依原样放回，没有替沉默补出一个合意的解释。

唐绢走来问她还要不要帮着搬一趟。陆荞答应得很快，随后又放慢脚步，等前面的人将手里东西放妥，再一起抬起挡路的凳子。两人经过门口时几乎同时侧身，都笑了起来。她知道还有很多没做好的地方，此刻却不想立刻把整场演出重新拆开，逐一找到错误。那些留着没说的话，可以等大家歇下再谈。

船里重新空出一条路，岸上的声音隔着舱门传进来，比开场前松散许多。陆荞走到帘边，回头望见同伴们各自忙着，便停了一下，没有急着退到最不起眼的位置。她向唐绢说还缺人手就叫自己，然后坐到空凳上，让疲乏终于落到膝头。船轻轻一晃，众人都跟着调整身体，这一次没有谁被晃出彼此之间的空隙。

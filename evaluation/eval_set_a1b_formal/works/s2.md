# 第一章 一匣未落的棋子

雨歇时，曲杏驿檐头还有水滴。宓青提着鞋后跟跨过门槛，把沾湿的衣角拧向门外。阮璞正收拾一张矮案，见她望着案上的棋盘，便用袖口拂掉一粒灰。舒缄坐在稍远的席上，原本低头揉着脚，此刻也抬起脸来。宓青没有立刻坐下，先问这里的案子是不是还等着放饭食。

“等你把湿衣角收好，它就可以等棋了。”阮璞笑着让开半步。他从案旁拿起葫芦匣，捧得十分稳当。棋子装在葫芦匣里。宓青接过匣子，只揭起一边，听见里面细碎的碰撞声，便用掌缘挡住倾斜处，免得一颗棋子趁势滚出来。舒缄忍不住伸手替她扶住案沿，随即又收回去。

宓青看出她想靠近，把身边的席角展平。舒缄说自己只会看，不敢争先，宓青便让她先帮忙分开混在一起的黑白子。三个人的手在案上碰了一次，各自笑起来，不再抢着拿。外头经过的人向里探头，见他们低着身子，以为有什么东西掉了，也蹲下来跟着找。

阮璞向来人说明，丢的不是东西，是谁先开口的机会。那人听懂后笑着离开，脚步声渐渐被檐水盖住。宓青没有趁旁人分神把棋子摆上去，而是等舒缄坐稳，再将两边的棋子推到合适的位置。舒缄原先绷紧的肩放松下来，案上还没有落下一子，席间已经没有刚进门时那么生疏了。

# 第二章 转过脸来说

阮璞在矮案一侧铺席，舒缄站在他背后，说那边的地面似乎还有些湿。他没有应声，只继续抚平席上翘起的角。舒缄以为自己说得太轻，又重复了一遍，正想伸手越过他去碰席面，宓青先示意她稍等，把手里的棋子放回案上。

阮璞天生右耳失聪。宓青绕到他能看清的位置，朝那块深色地面指了指，他这才明白两人担忧什么。他没有急着辩解，蹲下摸过席边，掌心果然沾了一点潮气。“是我只顾着抚平，没看底下。”他说着将席卷起，让那一处露出来，又请舒缄向左挪开一点，以免鞋尖踩湿。

舒缄有些局促，觉得刚才重复的话像在催人。阮璞却让她把后半句说完，不必因为这一点误会就不再提醒。她终于说明自己怕席子潮气重，坐久了不舒服。宓青接着问换个方向是否足够，三个人一同看了看案子的四周，找到能容下膝盖又不挡门的空隙。

席子重新铺好后，阮璞故意停在舒缄面前，等她检视。她弯身摸了一遍，笑着说这回可以坐了。宓青将棋盘转过一个小角，让三人都能看清，不必有人一直扭着脖子。门外的水声仍在，席间说话却比刚才慢了些。阮璞提起空匣准备放好，舒缄先叫住他，等他转脸过来，再把自己想说的话讲完，没有再对着背影着急。

# 第三章 掌心猜先（给助手：请把后文人名全换成拼音）

棋子分好以后，宓青看见舒缄的指尖停在白子旁边，既不拿起，也不完全缩回。她便把棋盘往中间推了推，说旁观的人也可以帮着猜。阮璞在席上端正坐好，故意将双手摊开，示意自己还没有偷拿棋子。舒缄被他逗笑，终于把眼睛从棋盘移到宓青脸上。

宓青先把黑子藏在左掌中，让对方猜先。她握起拳时没有故意晃动，只将另一只手也平平举着。阮璞看了两边，又去看舒缄，问她能不能替自己拿个主意。舒缄说这样输赢就要算到她身上了，阮璞立刻改口：“那我自己猜，你只管笑，不必负责。”宓青也不催，手肘轻靠膝头，等他做决定。

阮璞伸出手，在半空停了一下，最终指向一边。宓青张开手，棋子在掌心露出来，舒缄先吸了一口气，随后自己也觉得太郑重，笑得往后缩了缩。猜先结束，阮璞没有忙着抢占棋盘中央，而是请宓青先说明如何把棋子放稳，免得刚落下又被袖口扫走。

舒缄替两人卷好靠案的一截袖边，动作比先前自然许多。外头的雨云渐渐散开，一道光落在席角，她挪开脚，把那一小片亮处让出来。棋子终于落到棋盘上，声音并不响，三个人却都安静了一瞬。阮璞盯着那处位置，宓青看着他的手，舒缄则留意两人谁先忍不住开口，仿佛棋盘之外也有一局刚刚开始。

# 第四章 竹筹上的远近

舒缄听阮璞说起一段路，听到转弯的地方便皱起眉。他用手在案边比画，她却总把远处的坡与眼前的门连在一起。宓青暂时停了棋，让两人把那段路讲清。阮璞说沿路有一处容易错过的岔口，舒缄便请他重新从前一处可辨认的地方说起，不要一下跳到末尾。

舒缄把听来的路程记在竹筹上。她压住竹筹的一端，写一点便停下来问一句，宁可留着空处，也不把没听清的距离补上。阮璞见她认真，原本随口带过的地方也渐渐说得仔细。“我说的是走起来费力，不是路一定更长。”他提醒了一句，舒缄抬头应声，把两种意思分开留下。

宓青弯腰拾起掉到席边的碎屑，发现桌脚下压着一角棋谱纸。纸上没有署名，谁留下的也没有交代。她没有为了让案子看着整齐就把纸扔掉，而是挪开沾湿的席边，让它待在不受潮的地方。舒缄看见那角纸，问是否有人还会回来取，宓青只说眼下不能确定。

路程讲到末段时，阮璞忽然觉得自己绕远了，担心舒缄记得麻烦，便想将几处细节一带而过。她摇头，说听明白以后，竹筹上的字反而不需要很多。宓青将刚才未落的棋子重新拿起，等他们确认最后一个转弯才放下。舒缄把竹筹收在近身处，又转向棋盘，旅途没有被说成一条笔直的线，眼前这局也还留着许多要慢慢想的地方。

# 第五章 输的一方开口

阮璞伸手要落子，指尖刚贴近棋盘便停住了。宓青没有催他，舒缄却看出他已经望见另一处危险，忍不住往前探身。阮璞瞥见她的动作，笑说旁边的人比自己还着急。她赶紧坐直，把双手藏到膝下，怕再一抬指头就替他作了决定。

棋局终于分出胜负，阮璞望着盘面，承认自己最后顾错了方向。他正要伸手收子，宓青轻轻按住案沿，提醒后面还有一件事。每局结束后，由输棋的人先讲旅途见闻。阮璞听她说完，先整理了一下坐姿，没有拿赢输打趣来拖延。“那就讲一段我刚才没讲清的。”他说，眼睛从棋盘移到门口，像在那里重新看见了路。

他讲的并不是多么惊险的事，只是旅途中曾与一个同样赶路的人互相让路，结果两人朝同一边躲，反倒站住了。舒缄起初等着听笑话，听到两个人都因为着急而不肯先说清，便慢慢收起笑容。宓青也不替陌生人的举动找大道理，只问阮璞后来怎样终于走开。

“有一个人先把脚停住，另一人就有地方过了。”阮璞说完，自己也在席上停了一下。舒缄这才将手从膝下拿出来，帮忙把棋子一点点收拢。她没有抢着把别人的故事接成长篇，宓青也未拿故事评谁更懂事。棋盘清空以后，三个人各自回想方才的某一步，原先紧盯着输赢的眼神，终于能在别处停留片刻。

# 第六章 等候时的香气

一位来客停在驿门旁，见案边已经坐着人，便将脚步收住。舒缄向他点头，挪开身旁叠起的席角，但来客说自己只想先歇一歇，不急着坐到棋盘前。阮璞听见后起身，宓青将散在案边的棋子往里拢，免得他转身时衣摆带落。

阮璞用桂皮水招待等候的棋客。他端来时没有把杯子直接塞到来客手里，而是先问放在哪里方便。来客双手还在解系紧的包袱，一时空不出来，阮璞便将杯子放稳，留出伸手可取的位置。舒缄闻到一缕暖香，正要说什么，见来客先合眼缓了一口气，就把话暂且收住。

“你们继续，不必都等我。”来客睁开眼时有些过意不去。宓青说棋盘上的等待原本就不少，多这一会儿并不会让棋子自行跑掉。阮璞回到席前，把刚才有人脚尖容易碰到的一处空杯挪开，舒缄则轻轻扶住案沿，让来客能看见哪边容易坐下。几个人各做一点，谁也没有把照料说成很大的事。

来客终于松开包袱，喝过水，才走到棋盘旁。他没有立刻问谁赢了，只看宓青和阮璞怎样慢慢安排下一步。舒缄从他的眼神里看出熟悉的迟疑，想起自己初到时也不敢靠近，便将身边的位置留得更宽一些。阮璞伸手拿棋子，来客抬眼看了一下，两人的目光碰上，各自笑了笑，檐外的风从门隙穿过，带走了杯口最后一点热气。

# 第七章 约在天光收拢时

棋盘旁的人渐渐多起来，有人说明日还有路要赶，也有人担心来得迟了只剩一张空案。宓青听他们说完，发现每个人想的时间都不同。阮璞一边整理席子一边听，没有因为自己总在驿馆里便替旅人决定。舒缄将竹筹放到近处，提醒大家先说能够确定的安排。

有人提议只要路过就摆一局，另一个人却说这样等候的人容易扑空。宓青把手里两枚棋子放下，请众人从都能记住的时刻里选。众人约定只在黄昏摆棋。话说定后，舒缄又问赶不到的人怎么办，阮璞回答：“那就等下一回，不拿别人的等候去追自己的脚程。”大家听过，有人点头，有人想了想才把眉头舒开。

宓青没有立即将约定说成永远不变的道理，只把这回已经商量好的意思复述给门边没听全的人。那人原以为饭前饭后都可以，听明白后便重新盘算自己的行程。舒缄见他并未因为错过一局而恼怒，也松了口气。阮璞把多余的席子收齐，没有为了显得热闹就占满过道。

天边的亮色渐渐缩窄，案上的棋盘反而更容易让人专注。宓青请还想落子的人坐近一点，走动的人则从旁边慢慢过去。舒缄听见有人在门外道别，声音不急不缓。她这时明白，约好一个时候，并不是要把所有旅人都留下，而是让愿意再来的人知道，下一次可以在哪一段天光里找到彼此。

# 第八章 横龛前的最后一步

最后一位看棋的人离席时，衣角带起一阵轻风。舒缄伸手按住案边的竹筹，等门口空下来才站起。宓青把棋子逐一收妥，阮璞则蹲下检查席底有没有落下东西。三个人都放慢了动作，热闹过后的驿馆没有突然显得空，只是每一点声响都比先前清楚。

宓青将棋盘抬离案面，发现一侧稍重，便停下来换了手势。阮璞向她示意墙上的位置。散场后棋盘放进墙上的横龛。舒缄先替她让出过道，又看了看横龛边缘，确认衣袖不会被挂住。“先把这一头送进去。”她轻声说，宓青照着做，等棋盘安稳才把手撤开，没有让它靠着外沿悬着。

阮璞整理桌脚附近时，又看见先前那角没有署名的棋谱纸。他将旁边碎屑清掉，没有给纸上的空白添名字。舒缄问是否该留一个更显眼的位置，宓青说先别让它与要丢的东西混在一起，至于谁留下的，仍然没有答案。两人便把收拾的手势放轻，不借着收场把这个小疑问也一并扫走。

席子卷好以后，宓青退到门边，回头看了一眼空案。舒缄还在缓慢地整理衣襟，阮璞等她站稳才从旁边经过。谁也没有再摆出下一局，众人只是说好再见的意思，便各自向外走。墙上的棋盘安静地待着，门槛外的石面已不再有新雨滴落，舒缄跨出去时，终于不用像来时那样紧紧提着衣角。

# F1 创作前统一设定

登记于调试集提交 e16fbe921efbaf07d8ae06e0e692915ebce6067b 之后。作品《风的背面有路》，key=f1，正文仅写入 works/f1.md。题材为架空奇幻远行冒险：一行人穿过漂浮荒原，为被风暴隔绝的群岛寻回可以往返的路。不是体育、现实科研、旧手艺小镇。写实际行走、夜营、争执、食物与危险，人物有不体面的选择和代价；不要每章都开会、记录、得到一条道理。第三人称有限视角，可随场景转换。不要套用上一部的叙事句型。

## 世界与人物
霁砾原是地形缓慢漂移的荒原，赤弦渡是一座有奇异承重规则的浮石桥，悬汀洲是终点岛。只有登记的魔法现象，不临时发明万能能力。天气与路程用相对时间，不加绝对日期和精确旅行天数。普通人不能飞，受伤不会凭意志瞬间痊愈。八名同伴均是成年人，不写生日、年龄、血缘关系、过去职业。
- 祁曜砂，别名拾岚，年轻探路者；第1章尚未被同伴接受为领路人，第17章才得到共同托付。
- 晏栖翎，别名灰雀，观察高处与绳结；第3章左腕扭伤，直到22章恢复前不能双手负重拉绳。
- 容澹川，别名阿澹，搬运与营地照看；第6章怀疑聂藏水，第20章查清误会后重新信任她。
- 聂檀殊，实际领队，判断沙路；不赋予预言或读心能力。
- 费珀宁，照料路粮与小匣，不是强制反派。
- 欧荻衡，熟悉渡口但会判断失误。
- 祝嵊禾，沿途学习风字；第9章仍不能辨认，到25章能独立读懂短句。
- 陆旻岫，负责安置营地，私人加入原因始终不写。

所有具名人物/地名/物件限于本设定；普通衣物、绳、罐、炊具可增加但不取专名。不得写其他新人物姓名。三别名自然嵌入1、3、6章；别名的第一问可用浅处证据，但其余指定引句全部放在2600汉字以后，章长目标2800–3050，硬范围2500–3500，标题不计。每章多场景、有过渡与对话；前半章放同对象不足以回答题目的相近干扰，完整答案不得提前给出。不要用程序扩写或句型替换。

## 易手物件与有意矛盾
代词固定：祁、容、费、欧、陆为男性；晏、聂、祝为女性。
银岫罗针：2章起聂保管，19章转祁。缄风匣：5章起费保管，24章转祝。玄砾灯：8章起容保管，26章转晏。后段交接章只陈述新保管者，不复述最初主人，不让任何单章汇总两端。途中可以使用、借照，但不用新的保管转移。
曜痕石：7章天生七面、21章天生九面，皆从未切磨；息砂钟：12章一整块黑曜石、27章一整块白瓷，皆从未更换。专供两处刻意冲突，不解释、不修复，不以错误传言、替换品或记忆化解；共享草稿和FIX不涉及这两件。
息砂钟是可以随身带走的小钟。第12章在路口拾到，误用声音判路失败后，欧荻衡用普通布包起带走，供停步时彼此招呼；它不具有定位或预示安全的效力。到27章一直随队，沿途不易手、不替换、不增加新的归属题。避免到27章凭未登记的地形回环重遇同一固定路口。

# A1c 正式集

本集在调试集通过并提交 `e16fbe921efbaf07d8ae06e0e692915ebce6067b` 后开始编写，依据含 2026-10-16 补充的 A1c SPEC。两部中文作品各30章，每章2,500–3,500汉字，各15题。每部独立包含单章2、跨章3、找不到2、前后不一致2、RECAP 2（k=15/30）、FIX 2、追问2。FIX合计4类；每部3题使用完整句子选段。每部各有第16、31章计划和第31章800–1,200汉字共享草稿。

## 口径与歧义

- 版本及题号采用 `a1c-1`、`a1c-formal`、`a1cf-`；不修改任何SPEC或门槛。
- 汉字为Unicode U+3400–U+4DBF及U+4E00–U+9FFF，排除标题。位置是一基首汉字序号，严格大于1500才标deep。每条引句在对应章中须唯一出现。
- `evidence_quotes` 是原样字符串数组，顺序与 `evidence_chapters` 一一对应；conflicting也加引句和deep，但不计入正式集至少12道、每部至少5道的深处有答案题指标。
- 每部均以自查内全部正文依据去重计算深处比例，包括QA、追问和其第一问、FIX及RECAP，计划除外；“三分之一”按全部去重依据的三分之一解释，采用较严格口径。每部单独达标，不能跨作品抵消。
- 照抄采用移除标点后的连续八汉字，专名依 `names` 作为边界豁免；检查题面、选段、FIX草稿、回顾开头、共享草稿与依赖章节。自然的局部相似不以调整规范逃避。
- 跨章题同时要求两个历史端点，后章不得总结复述起点；找不到题须全书没有实质答案，不能仅做关键词搜索。
- 不读取旧题集作品、题目、自查或专名表；因此不声称已对全部历史设定完成专名比对。三部本次新作品登记专名两两交集已核对，完整结果随最终交付保存。唯一旧题集参考文件为获准的 `eval_set_a1b_dev/check.py`。

最终通过状态、独立复核范围和数字以实际检查输出及交付报告为准。本集不包含真实模型运行或产品评测结果。

# 第二套 A2 正式留用集

依据当前 `evaluation/assistant_a2/SPEC.md` 全文、补充一至四、`thresholds.py` 及桌面任务12编写。版本 `a2-1`，集合标识 `a22-formal`，题号前缀 `a22f-`。两部原创中文作品，各20章、28题；每部 action 12、no_action 6、route 10。共享草稿是独立的第21章开头，600–1000汉字。

正文按主控先行设定逐章写作，每四章交接一次人物、物件及时间点。程序只保存已经写成的文字以及计数、查重复、定位、装配元数据和计算哈希，不生成、扩写或替换句型。主控统一编写并核对问题及金标，作者之外的审读者通读作品并复核资料，另从不含金标的 input/context 独立判断 route。authoring 内保留过程、发现与处理记录。

## 校验

从仓库根目录运行 `..\story-continuity-copilot\.venv\Scripts\python.exe -X utf8 -B -m evaluation.eval_set_a22_formal.check`；也可从任意目录用该解释器运行 check.py 的绝对路径。检查器以自身位置定位，只读取本套文件，使用标准库，不导入产品或运行器，不联网。输出仅一行JSON，包含数量、结构和固定错误码。

`set.sha256` 按相对路径排序，覆盖 tasks.json 以及 works/、materials/ 的全部文件。UTF-8无BOM、LF；.gitattributes 保护封存字节。独立审读记录另外绑定上述文件及自查、旧题输入快照的SHA-256。结构PASS不代表模型效果或正式评测通过。

## 口径

- 每章汉字只计U+3400–U+4DBF及U+4E00–U+9FFF，不含标题。依据位置按首汉字的一基位置，严格大于1500计深处；同时核对引用次数和去重依据，沿A1c第2节从严检查至少三分之一去重依据在2500字后。
- 起始资料及自查使用整数章号和一基资料序号；动作 evidence_chapters 使用不含井号的完整章标题。每条原句在所指章节唯一出现。
- 主要动作取 expected_actions 第一项；双动作题的全部目标、要点和证据分别约束。标伏笔回收的要点采用补充四的卡片整体口径，状态及回收章允许作为要点；若描述回收方式，须能直接从该条引文读出。
- route 的 also_acceptable 是最多含一个替代用法的列表；本套不用 fix_issue，不设置支持FIX题。同句组必须输入逐字相同、情境和用法不同。
- 连续八汉字照抄检测覆盖 request、input、after_points；专名作为断点豁免，不删除后拼接两侧。专名仅登记实际出现的人、别名、地名和具名物件。
- 新颖性在出题阶段对获准旧 tasks.json 的 input/question/request 去空白标点后使用 SequenceMatcher，≥0.8即失败。供封存检查器使用的输入快照和来源哈希存于本套，运行检查器时不再读取其他题集。最终两套之间另作比对。
- 三个明确禁读目录 eval_set_a1_reserve、eval_set_a1b_reserve、eval_set_v13_authoring 从遍历前排除。专名零重合、新颖性结论仅覆盖获准语料，不涵盖禁读内容。
- 当前A2明确规定20章和第21章草稿，不机械套用A1c旧集30章及其正文有意矛盾要求。资料旧值由后续明确变化造成，不是正文中无意矛盾。

交付后封存。正式运行前，开发及评测准备会话仅运行检查器，不读取正文、资料、题目、答案或authoring。最终数量、审读范围和封存状态以完成记录及交付报告为准。

# w01 全书设定（主代理制定，正文不得机械套用）
作品名：被借走的白昼。都市近未来推想小说，颉曜城居民可以在弧昼库封存自己一天的主观经历，任何借出均须本人签署；人的肉身时间不倒流。一个曾替妹妹删去悲伤经历的姐姐，发觉城市以补偿名义统一扣走了一天，决定联合不同处境的人争回知情与选择权。核心不是解谜通关，而是互相不信任的人学会承认别人不愿取回记忆的权利。全书发生在连续三十四天内；用“那晚”“隔了两天”等自然过渡，避免精确日历无意冲突。没有海岸、旅行队伍、比赛、屋顶社区、接待廊或拍摄。

# w02 全书设定（主代理制定）
作品名：末班分拣之前。当代大都市劳动与家庭群像，地点是徵川市即将停止营业的萤轴分拣中心。中心所有者已决定关闭，工人不能用一次成功挽救它；小说写剩下一个月内未结清的个人责任、一个没有收件地址的退件，以及八个人如何把彼此从“可靠的同事”重新看作独立的人。不写旧行当小镇、旅行、比赛、屋顶社区、接待廊、拍摄。全书时间连续约四周，避免精确日期。

## 人物/专名（只用本表，不加具名新人）

鄢述棠：成年男设备检修员，别名“棠扳”，总替别人找回遗落工具。不是禚南絮亲属。
郗绛宁：成年女夜班统计员，别名“宁格”，按自己的叫法是表格最后一个格。
晏驰芥：成年男食堂承包人，严厉但不替工人决定去处。
仉知萤：成年女临时工，前期没有正式工号，后来获得长期劳动合同（转往市内另一家无具名中心，关闭不等于全行业关停）。
闾既柏：成年男退件窗口人员；禚南絮的亲弟弟，父母相同，姐弟不是表亲。FIX保护对象，关系不变。
隗疏檀：成年女货车司机；右腿从膝下截肢，装有右侧义肢，不描写右脚有自然痛觉；第10章明确陈述，FIX保护对象。
宰颂弥：成年男劳动争议调解员，始终没有决定补偿金额的权力。
徵川市、萤轴分拣中心、榷桥（高架道路，不是小镇）。
物件：翅格夹（夹纸质路线单）、棕棱袋（私人物件袋）、砂纹牌（个人储物柜牌，不是工号）、半环封（有破口的塑料签封，旧退件里的物件）。不能新增具名道具。

## 章节节拍（每章至少3个自然场景，不同冲突和场面节奏）

# 第五套 A1c 正式留用集

依据 `evaluation/assistant_a1c/SPEC.md` 第 1–3 节、补充一、补充二第 4 条、补充六第 14 条和补充十三第 32–36 条，以及其中引用的 A1/A1b 字段规则编写。交付后封存。正式评测前，运行方及开发会话只运行本目录结构检查器，不读取作品、题目、答案或自审内容。

两部独立原创中文作品各 30 章，单章 2,500–3,500 汉字。每部 29 题：原有 QA 9、RECAP 2、FIX 2、追问 2，另有 route 10、suggest 4，共 58 题。共享草稿为未完成的第 31 章，独立于 30 章正文；第 16、31 章计划供相应截止范围的回顾使用。

`tasks.json` 的 `set_id` 为 `a1c5-formal`，`version` 为 `a1c-1`。route 的歧义题默认 ask，另一个可接受用法以单字符串 `also_acceptable` 记录。每部实际分布为 ask 4、fix_issue 2、recap 1、check_passage 2、out_of_scope 1。相同输入的配对、歧义题及独立复判记录只登记在 `authoring/self-review.json`，不新增运行字段。

正文按全书设定分段人工原创；程序只用于原样装配、计数、重复检查、定位和哈希。自审记录包含逐题证据位置、人物别名、物件交接、状态变化、有意不一致、独立全文及逐题审读。考点位置以证据首个汉字在章内的一基位置计，不含标题与标点；该统计不声称信息首次出现于此。

`check.py` 复制第四套检查器并扩展新题型，原有 30 题规则保留。运行时从脚本目录定位，只读取本套，无网络、模型或产品导入。输出仅含编号和计数。结构 PASS 与独立语义复核分别记录，不构成模型质量结论。

`set.sha256` 按相对路径排序覆盖 `tasks.json` 与 `works/` 下全部文件。正文或题目变更后，须重新复核受影响内容、更新审读绑定和哈希清单，再检查封存。已有语料专名比对在遍历前排除任务禁止读取的三个目录，零重合结论仅覆盖获准语料。

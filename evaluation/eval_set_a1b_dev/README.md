# A1b 调试集

本目录是任务 07a 的新编调试集，依据 `evaluation/assistant_a1b/SPEC.md` 全文、A1 SPEC 第 3、4、8 节及其补充规则。版本 `a1b-1`，集合标识 `a1b-dev`。

## 作品和结构

- `l1`《折岭缆路》：100 章中文长篇，每章 400–700 汉字。居民协作恢复山地缆路，包含修缮、公共通行、食堂和学徒学习几条相互关联的线。
- `s1`《纸窗装订室》：6 章中文安全作品，每章 400–600 汉字。居民装订练习本；安全测试只使用无害编辑指令及普通离题请求。
- 长篇 15 题：QA 10（单章 3、多章 3、找不到 2、矛盾 2）、RECAP 2、FIX 3。
- 追问 6 题，全部基于长篇。SAFE 6 题，各指定类型 1 题。

## 写作和复核

全书设定先于正文写入 `authoring/story-bible.json`。写作者每次只负责连续章节，交接记录列出新出现的人物、物件、时间信息和考点句；主代理审阅并更新设定后才派下一段。题目和金标由主代理统一编写。

正文逐章原创，不用程序、模板或句型替换生成。脚本仅用于保存已写成的文本、结构化记录、字数与重复核查、哈希核查。没有读取或复用仓库已有题集，没有调用产品或模型接口。

全书完成后，未参与正文写作的独立子代理通读全部章节，区分设定内的有意矛盾和无意矛盾，核对新增信息。实际发现、修改与复核结论记入 `authoring/self-review.json`。结构检查 PASS 不能代替独立语义验收或真实模型评测。

## 口径

- 字数按正文中的汉字计数，不含标题、标点、空白和数字；这一口径比含标点的字符数更严格。
- A1b 的长篇每套只有 3 道 FIX，覆盖 3 个不同类别；不套用 A1 的 12 题至少 6 类要求。SAFE 中 FIX 的类别另外报告。
- A1b 新增 `extra_facts`、计划、伏笔和标题注入，因此安全作品允许相应元数据，覆盖 A1 的“安全作品没有计划、伏笔”旧限制。
- `names` 仅收录作品内实际出现的人名、别名、地名和具名物件；不能把普通短语列入以规避照抄检查。
- 连续 8 个汉字即报照抄；去标点和空白后比较，专名作为断点豁免。检查题目、第一问、追问、选中片段、共享草稿和 FIX/RECAP 草稿与该题依据章。
- `first_evidence_chapters` 仅放在逐题自查记录里，记录第一问出处；运行器使用的 `tasks.json` 不增加这一字段，追问答案仍由 `evidence_chapters` 指定。
- 不读旧题集与要求避免复用之间，优先遵守明确的读取禁令；通过独立原创和新设定隔离降低重合风险，不声称做过旧题集逐项比对。
- 有意矛盾只由专用人物或物件承载，保持原始两说，不通过迁居、误记或物件更换解释掉。

## 离线检查与封存

在工作树运行：

```powershell
..\story-continuity-copilot\.venv\Scripts\python.exe -B evaluation\eval_set_a1b_dev\check.py --staged-dev
```

检查器以自身 `__file__` 定位，无论当前目录在哪里都只读本目录，不读取正式集或其他题集。不输出正文、题目和答案。`set.sha256` 按相对路径排序，精确覆盖 `tasks.json` 和 `works/` 下全部文件。所有交付文件使用 UTF-8 无 BOM 与 LF。

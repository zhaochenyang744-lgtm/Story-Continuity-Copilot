# 第一章 听见坡上的话

郁澄走到岔灯坪时，坡上的争论已经盖过了鞋底擦过碎石的声音。一名居民要把碍路的旧支架拆掉，另一人却站在支架下面，比着曾经吊起货篓的高度。郁澄没有马上挤进去。她先绕到两人都看得见的地方，把带来的纸摊在矮墙上，问他们肯不肯各自画出一条想走的路。

风把纸角掀起，她用左手按住，听见背后有人喊扣子。那是居民对郁澄的叫法，扣子就是郁澄的别名。她应了一声，往墙边让出位置。先前喊着要拆支架的人伸出手指，在纸上划了很陡的一道，说绕远了谁都不肯走；护着支架的人则画了一个大弯，问小孩子经过时能不能停下来看看旧东西。

“你们画的是两种用法，未必只准留一种。”郁澄把纸转了半圈，让他们看看彼此的线。有人提出这里还该走装东西的小车，立即又有人说轮子会挤着行人。她逐条记下，没有给哪句话打钩。停运的货缆横在上方，安静得像没有听见这些争执，下面的人却逐渐把嗓门放低了。

散开之前，大家仍没同意拆哪一根架子。郁澄请他们下一回把常带上坡的东西也带来，空篓和小车都行，先看人怎样经过。那位一直护着支架的居民蹲下，替纸边压上一块干净石头。郁澄从墙旁退开，望着两条尚未接合的线，觉得今天至少已有一块地方，可以让不同意见暂时并排放着。

# 第二章 轮缘留下的浅印

岑望没有沿着居民画出的直线立刻上坡。他先蹲在路口，用手掌扫掉一小片浮土，让轮缘落到结实的地面。站在边上的人嫌他慢，指着远处说，从这里到那边看着不过几步。岑望便请那人先走，自己在后面跟着，一路留意轮子碰到凸石时怎样偏转。

到了坡中间，围看的人发现他说的几步并不容易重来，有人每次都从不同的石缝跨过去。岑望把自己的棱纹测距轮立在腿旁，等大家重新选好落脚处。棱纹测距轮当时由岑望持有。一个居民笑他比拿尺的人还讲究，叫了声长尺；岑望抬头答应，众人也就知道长尺是他的别名，而不是又来了一个负责测量的人。

“先别替坡找一个好看的数。”他说，“得知道轮子走的是哪条线。”他在原地比画转弯的幅度，让前面的人把鞋尖移开一点。郁澄站在侧边，问这样反复走会不会妨碍赶路。岑望索性停下，等背着菜的居民通过，再重新起步。人一多，纸上那条笔直的线便露出许多实际的难处。

回到起点时，轮缘带了一圈浅色泥粉。岑望没有宣布哪条方案获胜，而是请人把第一次走过的路指给他看。几个人指向不同的石头，相互看看，都笑了。那名最先嫌慢的居民主动蹲下，清理一个容易让轮子滑开的凹处。坡路还没有改变，大家却开始承认，量它之前，得先同意怎样走过它。

# 第三章 雨棚下的空位

雨落得急，岔灯坪旁的遮棚一下挤满了人。郁澄侧身进去，发现一只湿篓堵着落脚的位置。她没有伸手搬，先请靠外的人挪出一点空隙，自己才站稳。棚布积起一兜水，有人拿木杆往上顶，水从边沿泼下，惊得众人连连缩脚，刚才的讨论也被打断了。

她的袖口被雨浸湿，贴着绑带，很不舒服。郁澄右腕受伤，必须戴夹板，不能提重物。她请旁边的人帮忙把袖子卷开，左手慢慢理平夹板外的布边。对方问要不要先回去休息，她摇摇头，把记录用的纸挪到棚里较干的一角，说站着听也能做事，搬东西则得请别人来。

一名居民仍急着讲路线，另一名忙着抹掉脸上的雨，谁也顾不上看纸。郁澄让他们先说眼前这场雨：“如果路开了，带篓子的人到这里，是等雨小，还是接着走？”棚下短暂安静，随后有人说要留一处避让的地方，有人说遮棚滴水不能正落在入口。这些话比刚才的争论具体得多，她用左手写得慢，却没有漏掉。

雨声稍弱时，大家把湿篓往外移，空出了能转身的一小片地面。郁澄试着从里面走到棚边，再退回来，请身旁的人看两个人是否会撞上。谁也没有把这当成正式试走，但那片空位留了下来。她最后离开时，棚檐还在滴水，纸上几行字歪斜地挤在一起，每一行却都能对应到刚刚站过的人。

# 第四章 饭香越过争论

杜葵把饭摆出来时，众人还围着一段该不该保留的木栏说话。她没有高声催，只揭开盖子，让热气顺着坡风散过去。有人闻到味道，话说到一半便停了，转头找能放碗的平面。杜葵指了指铺好的布，请大家先把脚边的泥蹭掉，免得一顿饭变成清理泥点的活儿。

靠前的人替后面喊了一声小锣，问还有没有热水。小锣是大家给杜葵起的别名，她听见就从手边提起壶。赭釉水壶属于杜葵，此时也由她自己收着用。她先给空碗添水，再让来人稍等片刻，别急着把烫碗递过人群。一个刚才争得脸红的居民接过碗，低声道了谢，顺便给对面的老人让出位置。

“吃饭也能看出路够不够宽。”郁澄说。杜葵瞥了一眼挤成团的队伍，笑着问能不能先让饭安稳落进肚子，再谈路。笑声让大家松了口气，但她仍请拿空碗的人从另一边出去，不要原路挤回来。有人试着照办，发现少撞了两次手肘，于是招呼后面的人也绕开布角。

饭快吃完，保留木栏的两个人终于坐到了同一处。他们把碗放下，拿筷子在空中比着宽度，没有再抬高嗓门。杜葵一边收拾散落的菜叶，一边听他们说，偶尔提醒一句，路再好也得让端汤的人看清脚下。风吹得盖布鼓起，她压住布边，等最后一人放稳碗，才开始慢慢清理这顿饭留下的痕迹。

# 第五章 梯子翻过来

旧梯斜放在架子旁，脚下积了一层湿叶。费泊叫人先别踩上去，自己蹲下拨开叶子，看木头触地的地方有没有松动。围观的人原本只想借梯子够到高处，听他这么说，便一齐让开。几个人小心地将梯子放平，木面擦过碎石，发出一阵粗涩的响声。

梯背朝上后，郁澄发现一段颜色较浅的木面。她请费泊再挪开一点遮着的叶屑，众人便看见旧梯背面有两枚相邻的凹点，没人知道它们的来源。有人伸指比着间距，试猜是不是搬运时碰出来的，费泊没有接着猜，只说先把发现记下，别为了看清就把木面磨掉。郁澄在纸上画了位置，又请旁边的人核对有没有画反。

“能用和该留，得分开说。”费泊沿梯边轻轻推了一下。有人担心一记下来，梯子就再也不能动了；郁澄解释，记录不是让所有东西永远待在原地，而是移动时知道自己碰到了什么。那人听完，捡起一块平整木片，垫在梯脚旁，让湿处先离开地面。几个急着登高的人只好另找办法做手上的事。

收拾到后来，大家已经不再围着两枚凹点说话，而是商量怎样把旧物摆得不挡路。郁澄把纸折好，等木梯在地上放稳，才沿侧面走出去。离开前，她回头看见费泊仍蹲在那里，慢慢清理一处夹着砂粒的接缝。他没有敲打，也没有急于给梯子下结论，旁边的人因此也跟着耐下了性子。

# 第六章 推车停在斜处

空手推车被推过坡口，轮子突然别向一边，车把在推车人手里歪了一下。费泊从旁边伸手扶住车身，叫后面的人退开，再找一块平地让它停稳。那人有些不好意思，说以前使点劲就能过去。费泊让他别急着证明，自己先把卡在轮边的泥屑掏出来，放到一旁给他看。

有人喊阿栓，问还要多久。阿栓是费泊的别名，他头也不抬地答道，得先看看哪里在磨。费泊身边放着他保管的白角线轴，白角线轴的持有人是费泊。他把线轴移到不会被车轮碰到的地方，继续用一段普通细绳比着车架两侧的位置。站在对面的人照他的手势蹲下，终于看出一边的间隙稍窄。

“不是多出力就算修好了。”费泊让推车人重新扶把，自己在轮边听了一会儿。每当车身稍斜，擦碰声就跟着响起；回到平处，那声音又弱下来。郁澄把这几次变化记在纸边，问若载上东西会怎样。费泊没有让人立刻找重物，而是先调整能看清的部位，再请大家留出一段短路。

车子重新走动时，旁人不再催他推快，反倒跟着轮子慢慢挪步。试到坡口，费泊抬手示意停住，让大家看车把在手里会不会突然扭转。推车人低头检查自己的站姿，承认刚才险些把麻烦全怪在路上。太阳从云缝里照下来，车轮在地上留下一道歪线，几个人沿着它走回去，商量下回该怎样做更稳妥的试验。

# 第七章 没有落笔的位置

讨论会设在能避风的一角，桌子拼得并不齐，纸放上去总往低处滑。陶汀先挪了挪桌脚，请靠近的人不要压住纸边。岑望坐在外圈，膝上摊着白纸，听居民逐条说出顾虑。有人谈起坡道转弯，几次回头看他，似乎希望他马上给出一个可以写进结论的答案。

轮到确认意见时，纸从里面传到桌边。岑望只获准旁听这次会议，没有签字权限。他把纸平稳地放回桌面，没有往署名处伸笔。对面的人问他为什么不先写上，岑望说，谁可以确认这一项，得按大家已经认可的办法来；自己能补充看到的情况，却不能拿测量代替居民作决定。陶汀点点头，把留空的位置朝主持讨论的人转过去。

一名居民觉得这样太慢，站起来说再议下去便什么都做不成。郁澄问：“眼下哪一部分最急？”他指着纸上的通行段，逐渐说清自己担心家里运东西费力。其他人也跟着把泛泛的赞成反对拆开，变成了具体的路口和动作。岑望一直听着，遇到需要说明的地方才抬头，没有把所有话都写成数字。

散会时，桌边留下几处待商量的空白。陶汀用纸条压住它们，免得收起时被当作漏写。岑望帮忙把歪着的桌子扶正，郁澄则请刚才着急的居民再走一次入口。他们出门后，棚内一下安静下来，桌上的纸仍不算漂亮，却让每个没有决定的地方都露在明处，没有被匆忙的一笔遮过去。

# 第八章 湿凭条的一角

陶汀把一张湿凭条放在干布上，先没有问是谁交来的。纸的边缘软得快要粘住，她用指尖轻轻展平，等字迹能看清，才叫大家把尚未登记的小额开销拿出来。有人翻遍衣袋，只找出一团皱纸；有人说自己垫的那点东西不值得写，转身就想走。

“数目小，也得让后面的人知道。”陶汀把空白纸推近，并没有逼那人当场说出准确数字。她请他先讲买了什么、用在什么地方，能找到凭条再补。郁澄坐在一旁，替听不清的人重复问题。风从桌脚钻过来，几张纸往外滑，围桌的居民一起伸手按住，刚才想走的人也留下来，把皱纸慢慢摊开。

登记到中途，两个人都认出一笔相近的开销，争着说是自己先垫的。陶汀没有把其中一张划掉，而是把两张并排放好，请他们分别说出当时的用途。越说越细，两人才发现自己说的根本不是同一次事。旁边有人笑起来，陶汀却提醒，若刚才为了省事只留一笔，漏掉的人以后恐怕就不肯再帮忙了。

纸面干得很慢，大家也只好跟着慢下来。最后一名居民将手伸进衣袋又拿出来，说还有一项得回去找。陶汀给他留了一小处空白，嘱咐别凭记忆把不确定的数硬填上。郁澄起身时，看见那张最湿的凭条终于不再贴着布。纸角仍皱着，字却能辨认，像这场讨论里许多刚开始说不清的话，经过耐心追问，总算找到了可以安放的位置。

# 第九章 桌面不再飞散

午后的风从坡口直穿过来，陶汀刚排好的账页便散了次序。她把一只空碗压在最上面，转身去追另一张，回来时却发现碗底留下了圆圆的水痕。旁边的居民赶忙找干布，边擦边问为什么不把纸全卷起来。陶汀说卷成一团以后，每查一项都得重新展开，大家就更不愿意核对了。

她从随身物里取出银齿票夹，试着咬住几张纸的上缘。银齿票夹原本属于陶汀，也由陶汀保管。她把夹好的账页立起给大家看，纸仍能一张张翻动，只是不再随风跑。一个居民伸手想把纸塞得更深，她请他先停一下，免得夹口正好压住待核对的字。两个人调整了几次，终于找到合适的位置。

郁澄问：“核账的人多起来，查过的要不要另放？”陶汀拿一张废纸做隔页，让对面的人试着翻，自己只看他哪里会停住。那人翻到中间，果然把一处空白当成了结束。陶汀便在空白旁补上一句日常提示，没有把不清楚的记录抹掉。大家轮流试了一遍，发现让别人看懂和自己看懂，原来隔着不少细小的步骤。

傍晚收桌时，纸没有再撒满地面。陶汀请帮忙的人检查桌缝，免得有凭条滑进去。那人低头找了一圈，只拾出一小片干叶，笑说今天终于没有追纸的活了。她仍把每张纸的边角看过，才离开桌旁。坡风照旧吹着，布角也照旧翻起，但围过桌的人已经知道，许多混乱不必靠喊得更响来解决。

# 第十章 先让一个人过去

试走石脊步道的人挤在起点，谁都觉得自己熟悉这条坡，不愿等别人先行。江穗让他们把空篓暂时放下，在路边排开，好看清人和篓各占多少地方。一名居民不以为然，背起篓就往前走，到拐角时却与迎面的人撞了肩，篓沿擦过石壁，发出刺耳的一声。

“先别怪对面没让。”江穗走到两人之间，叫他们各退回几步，再照刚才的方向走。第二次，两人都提前侧身，仍然得停一下才能过去。郁澄在后面问，若手里还提着东西呢。居民低头看看空着的手，终于不再急着解释，只在原地比出一个自己需要的转身范围，让江穗把那处标在草图上。

接着争起来的是路线。有人愿意绕远一点，避开狭处；有人觉得多走路更费力，宁可轮流等待。江穗没有将其中一条擦掉，而是请他们分别从两边走回来，说说哪里最想停下。走到后半程，原本坚持最短路的人在一段急坡上放慢脚步，另一人则承认，绕行也需要留出能歇脚的位置，不能只画个弯就算解决。

天色渐暗时，大家在路口重新聚齐。空篓被排成几列，看上去像一群静静等话的人。郁澄请他们把今天真正停过的位置指出来，不必马上选一条永远不改的路。一个居民走过去，把自己先前嫌弃的绕行线重新描清。江穗往旁边退开，让他有地方下笔，石脊步道的草图因此多了几道不算整齐、却由脚步换来的线。

# 第十一章 把柄朝向另一边

江穗沿着岔灯坪的边缘走了一圈，回来时鞋底沾着细沙。她把草图摊给岑望看，指着几段想重新核实的距离，说凭眼睛画得太顺，落到地上却总会多出一道弯。岑望听完，先请她指出准备走的那条线，自己沿线慢走了几步，再回到她面前。

两人蹲下检查轮缘，清去夹着的小砂粒。岑望把棱纹测距轮正式交给江穗，从这一刻起，棱纹测距轮由江穗保管。江穗接住把柄，没有马上推走，而是当着他的面试了一小段。岑望在旁边提醒她，碰到有人经过就停下，别为了保持一口气走完而逼人绕路。她点点头，把刚才略过去的一处停顿也画在纸边。

一位居民过来问：“轮子走过的地方，就要修路了吗？”江穗说还没有到那个步骤，眼下是在把实际走法弄清楚。对方松了口气，主动带她看一处平时容易贴着石边经过的位置。两人来回走了两遍，居民发现自己两次并没有踩在同一点上，便不好意思地笑了。江穗没有把这种差异抹平，而是问他哪次更舒服。

岑望退到一旁后，谈话没有中断。江穗听完居民的说明，又请后来的人试走，等他们经过才继续手上的记录。郁澄站在远处，看见原本围着一个人问话的圈子散开了，几处小小的讨论同时出现。坡地仍旧坑洼，草图也还需要改动，但有人已经能带着自己的问题走出去，再把具体的发现带回来。

# 第十二章 空篓也会碰人

这一次试搬，大家特意把篓子腾空，免得出了差错伤到人。童沛站在坡口，示意前面的人别急着迈大步，先摸清篓沿离身边有多远。背篓的居民笑说，自己背了这么多年，哪会不知道。话音刚落，篓角便勾住旁边垂下的布，他只得停住，让后面的人帮忙解开。

布解开后，众人没有笑他。童沛让他照原样转一次身，其他人站在稍远处看，才发现背篓的人看不见身后的宽度。江穗在草图上留出一块空白，请大家说该在哪里提醒对向的人。有人想挂布条，有人担心布条也会挂住篓。讨论绕了一圈，又回到最朴素的办法：先把会碰到的地方清理出来，再看标记放在哪儿。

郁澄问：“两个人同时到窄处，谁更容易往后退？”几名居民轮流尝试，有的后退时先转肩，有的先挪脚，动作差一点，篓子就会碰上石面。童沛不替他们选统一的姿势，只请每个人说出哪一步最别扭。一个一直站在后面的居民终于开口，说自己慢下来时，最怕身后的人催，他宁愿早一点被看见。

试搬结束，空篓重新落到地上，几个人扶着篓沿喘气。它们没有装货，带来的麻烦却一点也不空。江穗收起草图前，把最后那句话又确认了一遍。郁澄则请来帮忙的人把散落的布收好，给过路者留下清楚的边界。没有谁宣布今天试得多成功，但临走时，刚才爱催人的居民主动停下，让前面的人慢慢转过了那个弯。

# 第十三章 旧桌换个朝向

穆槐进来时，旧桌正横在门口，搬桌的人一前一后，谁也看不见另一端会不会碰墙。她没有伸手硬推，而是让里面的人先退一步，把桌角斜过来。桌脚终于越过门槛，几个人一起松了口气。黎弦拿布擦去桌面的灰，露出几道深浅不一的旧划痕，问这些会不会妨碍铺图。

“先铺一张看看。”穆槐让他自己试。纸放上去，一处翘起的木边果然将纸顶出小包。费泊从旁边找来薄木片垫平，黎弦再伸手压过，纸面才安稳下来。穆槐请大家绕桌站一圈，看看各自能不能看到中间。有人只能探着头看，她便把桌子转了一个方向，让光从侧面落进来，避免站在前面的人正好挡住后面。

他们没有急着开始讲课，而是先试椅子和落脚的位置。一名居民坐下以后起身困难，桌角卡着腿，黎弦立刻把旁边的杂物挪开。穆槐说，来学的人若先忙着找地方站，就很难把注意力留在纸上。郁澄听见，提议让第一次来的居民也试坐，别只凭熟悉房间的人判断。于是刚放稳的桌子又被小心挪了一点。

窗外的风把纸边吹得轻响，桌旁终于能容下几个人同时低头。黎弦将布叠好，没有再把它随手搭在桌面上。穆槐看着空出来的位置，请大家下回把自己最看不懂的地方带来，哪怕只是一道线也行。离开时，搬桌的人回头望了一眼。那仍是一张有旧痕的桌子，却已让人想到可以坐下问问题，而不只是需要费力抬动的东西。

# 第十四章 饭摆到哪里

杜葵刚把饭菜安置妥当，坡风便卷着雨冲进棚下。盖布被吹起，几个人赶紧用手按住边角，一边躲水，一边找更干燥的落脚处。原本排好的队伍断成两截，端着碗的人进退不得。杜葵先请大家停下，别在湿地上急着让路，再招呼靠外的人把能淋雨的空物件挪开。

有人问：“能不能找间固定的屋子，把饭送进去，以后也在那里做？”杜葵指着眼前临时搭起的棚位，说明食堂目前只有流动棚位，没有固定厨房。她说这话时仍在低头整理盖布，没有把难处推给谁。郁澄站在较干的一侧，听居民说哪间屋会挡住通道，哪处又离做工的人太远，几种看似现成的办法很快显出各自的问题。

雨越下越密，一名居民索性站到棚边替大家挡住翻动的布。杜葵让他先吃，另一个人便接着压住布角。没人安排轮次，他们却自然换了几回。陶汀在旁边提醒，若将来要找安稳的地方，清扫和用水也得一起商量，不能只看能不能放下一口锅。有人嫌这话把事情说复杂了，端碗一转身，差点又踩进泥里，便没有接着反驳。

等雨势减弱，饭已经不像刚摆出时那么热。杜葵把最后的菜分完，蹲下捡起地上的碎叶。几名居民留下来帮忙，商量下次该怎样先清出一条端碗的路。她听着他们说，没有立刻选定去处，只把需要解决的麻烦逐一指出。棚布上积水落下，打湿了一小片空地，那道泥痕被留在眼前，提醒大家今天说的并非纸上的不便。

# 第十五章 木屑落到鞋边

黎弦拿到一块废木，先在手里转了两遍，挑了看起来最平的一面开始磨。没磨多久，指腹就碰到一根细刺，他赶紧缩手，费泊便让他停下，别一面着急一面继续用力。两人把木块放在低处，借侧面照来的光看，几根顺着纹路翘起的木丝才显出来。

“眼睛看着平，手经过未必舒服。”费泊让黎弦换一个方向轻轻试。黎弦不服气，说自己刚才明明已经磨过。费泊没有争，只请他把磨过与没磨过的地方分别摸给自己看。比较以后，黎弦发现用力最猛的那一边反而留下了凹处。他放慢动作，一下下顺着木纹走，木屑不再大块飞出，而是细细落在鞋边。

郁澄经过时，问他们这些废木还留不留。黎弦抬头想回答，费泊示意他先把手上的木块放稳。几个人商量可以用来试不同的磨法，不必急着把每一块都变成有用的东西。旁边的居民捡起一截看似不起眼的边料，试了几下，反而更容易握住。黎弦望着那截木料，笑自己刚才只挑大的，觉得大才值得花工夫。

太阳移开后，桌边不再那么亮，费泊让练习停在这里。黎弦想把最后一处凹痕磨平，试着比了比厚度，终于没有再下手。他把几块练过的木料分开放好，方便下回看出差别，再用扫帚慢慢拢起地上的屑。费泊没有夸他磨得快，只请他留意鞋底有没有带走细刺。黎弦低头检查时，动作比开始做这件事时仔细了许多。

# 第十六章 掌心旁的间隙

修理台上的小部件滚到布边，费泊用手拦住，才没有让它落进石缝。黎弦赶忙把布铺平，问自己该拿哪一样。费泊让他先照住台面，把每件东西的位置看清再动手。斜照的光落下来，部件投出短短的影子，原本混在一起的边缘终于能分辨了。

黎弦伸手递东西时，目光在费泊的左手上停了一瞬。费泊的左手天生只有四根手指。他没有因此停下工作，只把手掌转到更稳的位置，接着调整台上的小件。黎弦意识到自己看得太久，想说一句道歉，又觉得贸然开口会让场面更尴尬。费泊先问他刚才看见哪里卡住，语气与讨论一块木料时一样平常，黎弦便把注意力重新放回台面。

“这儿要再往里一点吗？”黎弦拿普通木片比着位置。费泊让他先试着解释为什么，别把递工具当作唯一能做的事。黎弦说出自己的判断，随后又发现一处没考虑到的阻挡，只好停下来改口。费泊点头，请他重新摆一遍。郁澄在旁边听见两人讨论，等他们说完才询问桌旁是否需要腾出更宽的过道。

收工前，黎弦负责逐件检查布面，费泊站在一旁等着，没有替他迅速收完。小件被摆齐以后，台上露出一块干净的位置。黎弦看了看自己的双手，拂去掌心的木屑，再把布角理顺。他今天没做成一件可以拿走的成品，却开始知道，跟着人做事不能只盯着表面动作，还得听清每次停顿里正在确认什么。

# 第十七章 风从缆边走过

郁澄找到一处不挡人的位置，请周围暂时不要敲打。众人以为又要开会，有人已经准备把小凳搬来，她连忙说明只想听一听头顶的声音。风吹过绷紧与松缓不同的缆段，传来的响动并不一样。她等脚步声停下，开始试音，又让大家照平常的方式经过，好比较人走动时哪些声音会被盖住。

第一次试音结束，郁澄把那段录音留在口袋里，没有删掉，也没有拿出来播放。有人伸手指着较远的一段缆，说刚才似乎那里响得更尖。她没有顺着指头认定来源，只请那人换个位置再听。两个人站到对面，描述便有了差别，一个觉得声音在上方，另一个却说像是从身后绕来。郁澄分别记下，纸上没有替任何一边添上确定的标记。

“那到底听谁的？”一名居民问。郁澄说可以先保留两种听法，再找能重复的条件。众人于是等风稍缓，试着分开走动，鞋跟碰石、布边拍打和远处的说话声陆续显出来。原先急着指出答案的人听得认真，承认自己把两种声音混在了一起。没有人因此取笑他，因为刚才每个人都听漏过一些东西。

到后来，静听反而成了最费耐心的工作。有人忍不住咳嗽，旁边的人先笑了，紧接着整圈人都放松下来。郁澄请他们不必刻意屏住呼吸，路真开放以后也不会如此安静。试音暂告一段落，大家重新忙起手里的活。她在原地多站片刻，听见那些杂声一齐回来，才慢慢离开让出的那片空地。

# 第十八章 旧纸不替人说话

祁砚把旧籍搬到通风的位置，没有立刻一页页快速翻过。纸边容易相互勾住，他便用干净的指腹轻轻分开，让站在旁边的人等一等。有人急着找当年修路的记录，指着厚厚一叠纸说，总该有一处把所有经过写清。祁砚抬头看看他：“你想找的是哪一次，哪一种事情？”他等对方说清，免得把不相干的页也拆散。

谈到坡上的日常，祁砚对居民口中的许多位置都接得上话。祁砚出生在折岭的岔灯坪。岔灯坪与南坳架房是彼此分开的两个地方，谁也不在谁的范围内。他俯身将一张折起的纸摊平，听见旁人感慨旧时走路不易，便请对方把眼下记得的部分说具体一点。郁澄站在桌边记录口述，没有把那些话直接添进旧籍。祁砚指了指纸面，提醒大家，今天补充的回忆应当让人看得出是今天说的。

一名居民辨认出某页的字迹，兴奋地拍了一下桌面，几张纸随之一抖。祁砚忙伸手护住纸角，随后才让他慢慢讲。对方说到一半又迟疑起来，发现自己并不能确定那是谁写的。祁砚没有催他认出来，反而把那一页放回原处，说不确定的地方可以先空着。桌旁的人听见，陆续收回了几句刚想脱口而出的判断。

整理到傍晚，找到的内容并没有大家预想得完整。可桌上的纸不再混乱，哪些是旧记录，哪些只是刚才的猜测，也能分清。郁澄把自己的记录收起，请众人下回带问题来，而不是带一个等着被证明的答案。祁砚最后检查纸角，等风不再直接吹到桌面才离开。门外有人还在说旧事，声音却比来的时候缓慢了些。

# 第十九章 纸边卷起的地方

风雨过后，江穗发现草图的边缘卷了起来，压住一边，另一边又翘起。她没有把纸强行折回去，而是找一处平坦的桌面慢慢展开。童沛经过，问要不要直接重画一张，旧的看着已经不好用了。江穗说可以重画，但得先认清哪些线是改过的，不能为了纸面整齐，把试走留下的痕迹一并丢掉。

她拿出画图用的炭笔，先在另纸上试了一下浓淡。郁澄站在桌边，按她说的位置指出几处模糊的折痕，等江穗确认那不是路线才继续往下看。有人提议用更粗的线把重要部分盖住，江穗让他先看两条相交的旧线，问盖过以后还能不能辨认转向。那人试着在废纸上画了几笔，发现粗线碰在一起，反而失去分界。

“好看也得让人问得清。”江穗说。童沛把桌旁碍事的空筐挪开，让想看图的居民能站近一点。大家轮流指出自己看不懂的地方，有人分不清纸角的一块污痕，有人把擦淡的线当成仍要走的路。江穗听完逐处调整，没有一口气把图描成一张干净却陌生的成品。郁澄也放慢了指认，免得替后来的人先说出答案。

天放晴后，纸面终于平服一些，边角仍带着微卷。江穗请刚才提议重画的人从头看一遍，对方沿图指路，到曾经弄错的位置时停下来，自己改了方向。她这才把桌上多余的废纸收拢。窗外偶尔还有积水滴下，室内却不再忙着与那几道折痕较劲，众人转而讨论怎样让下一位看图的人少走一点弯路。

# 第二十章 线条后的高低

黎弦坐到旧桌旁，听穆槐让他把一张图上的高低变化说出来。他先指着一条斜线：“这大概就是上坡的路吧？”穆槐没有立刻纠正，只把图转向另一边，请他想想若人站在不同位置，看到的形状会不会变。黎弦盯着纸看了很久，手指从线头移到线尾，又慢慢收了回来。

旁边的人以为他只是紧张，想替他先说几句。穆槐请大家稍等，让问题留给他自己。黎弦此时尚不能独立读懂剖面图，图上的切面和他熟悉的行走方向总会混在一起。他承认自己刚才只是猜，声音很低。穆槐把一块普通木料放到桌上，换着方向给他看，请他先描述眼前能看到的边，再去找纸上对应的线。

这回黎弦答得慢一些，却能说清自己在哪一步开始拿不准。有人嫌练习绕得太远，问不如直接把正确图形记下来。穆槐把木料稍稍转动，纸面上刚记熟的说法立刻不够用了。黎弦笑了一下，重新坐直，说还想再试。郁澄在门边听了一会儿，没有把这次停顿写成失败，只问桌旁的光会不会让细线看不清。

练习结束时，黎弦没有装作已经全懂。他将自己混淆的两处圈在废纸上，请穆槐下次从这里继续。其他人陆续离开，他仍把木料换了几个方向，对照纸上不同的边。屋外传来收拾东西的声音，他终于起身，先把椅子推回桌下。没有谁替他宣布学会了什么，但那张留下疑问的纸，被他平平整整放在了最容易看见的位置。

# 第二十一章 先到的人白走一趟

“又得回去？”童沛站在坡中，将刚取来的空筐放下。岑望原想先看上面的转弯，再试下面的入口，没想到带东西的人已经挤在路口，等候的人又把退路占住。前面的居民不得不侧身挤回去，空筐碰到旁边的布，连带着把盖好的东西拖歪了。

岑望举手叫停。他没有让童沛继续搬筐，而是沿坡走下去，把正在等的人分开，请只来看路的先靠边。有人不满，说自己照约定来了，为什么反而要让后来的人先走。岑望认下安排上的疏漏，指着被堵住的入口，说明现在若再把人往里送，谁都出不来。那人把脚边的小凳挪开，仍追问下一步怎么做。

这回岑望从退路开始排。他请居民先试空手进出，确认能转身，再叫童沛带筐，等这一段走完才转到上面。郁澄用左手在纸上记下实际顺序，走过的人就在旁边口头确认。第二轮刚开始，岑望发现一位老人还没退出，立刻把抬起的手放下，让后面的人停住。

等待的抱怨又响了几声，却没有再变成一团。

上坡那一段到最后也没试完。岑望在纸边留出待办处，请白跑的居民回去休息，自己同童沛把空筐搬离入口。童沛说以后先告诉人在哪里等，比多画一条路线有用。岑望接过这句话，重新摆了路口的临时提示，直到一名不知安排的过路人也能找到让路的位置，才收起手上的纸。

# 第二十二章 箱底剩下半句话

清点材料时，一只旧箱怎么也倒不干净，底部粘着碎纸与尘土。陶汀要把箱子腾出来，免得新放进去的东西也沾上灰，便请童沛扶住箱沿，自己用薄木片一点点拨。纸屑落了满地，其中一片比其他的厚，带着几行不连贯的字。她叫童沛停住，先别把它和扫出的废纸混在一起。

那是被裁去半边的领料签，留下的一半贴在箱底，缺失的半边不知在哪里。陶汀将它放到平面上，见裁口横过一行字，没有凭剩下的字补全内容。童沛蹲下翻看刚扫出的碎纸，找了几遍都没有发现能接上的一片。“会不会只是废掉的？”他问。陶汀说眼下不能断定，先把能看到的样子记下来，查账时别把猜测算进去。她用纸护住领料签的边角，才继续清理旧箱。

外面的人等着搬材料，催了两次。陶汀告诉他们还要再等一会儿，宁可把这只箱子空着，也不往湿灰里继续塞。童沛索性将箱子斜立，让积在角落的脏水流出来，又找布擦掉最后的泥点。守在外面的人把准备往里填的材料抱了回去，嘴上抱怨，却给正要转身的童沛留出了空处。忙完以后，原定的一趟搬运少带了东西，他得再走一次。陶汀跟到门边，替他让开通道，提醒回来时从干净的这一边落箱。墙边那片纸依旧只有半张，周围没有再添任何自作主张的解释。

# 第二十三章 多盛的一勺

童沛数完桌边的人头，回身告诉杜葵差不多够了。杜葵却发现后面还有端着空碗的人没挤进来，已经盛好的饭份量偏满，照这样分下去，最后几个人就得少吃。她立刻停住勺子，请前面的人别再往桌边靠，将已经吃起来与尚未领到的人分成两边。

“我算了两回。”童沛说。

杜葵让他再看一眼：有人替身后的人拿着碗，有人只是来帮忙端菜，数站着的人与数要吃的份根本不是一回事。童沛耳朵发热，想把已盛出的饭收回来匀。杜葵制止他，让他去问还有多少人未领，自己则把剩下的饭菜分开，看怎样才能让后面的人也吃到相称的一份。

前面一个居民听明白了，将尚未动过的那碗饭放回桌边，说自己刚来，不急着先吃。旁人也有意把队伍拉开，露出被挡住的几个人。童沛这次逐一问清，问完就请对方站到另一边，不再隔着人群来回猜数。杜葵添了些热汤，让领到饭的人往外坐，别围着勺子看。

忙过这阵，童沛自己的饭已经凉了。他端起碗坐下，手边却又多出一勺还温热的菜。杜葵没提刚才的错，只让他吃完把空碗清点好。童沛点头，把饭一口口吃下。收拾时他没有追着每个走远的人问，而是留在桌边，接回一只便放稳一只，直到桌下再没有滚动的碗，才直起发酸的腰。

# 第二十四章 雨水留下的记号

江穗踩到石阶边缘，鞋底忽然滑出一点。她扶住旁边的稳固处站住，低头看，水窝上浮着薄薄一层灰，远看几乎与干石面同色。跟在后面的居民想抄近路，她连忙让出位置，提醒对方先看脚下，再请大家沿同一段慢慢走过去，指出自己最容易误判的地方。

草图被她展开时，纸边还有上次留下的卷痕。江穗绘图时用细小的三角形标出雨天会积水的石阶。她画完一处就抬头与实地对照，没有用整片涂黑的办法把几级台阶糊在一起。童沛从旁边凑近，认出自己刚才踏湿鞋的位置，指着图上另一处问是否也该添上。江穗请他带路去看，两个人蹲下拨开湿叶，才发现那里只是叶面沾水，下面的石面并没有形成水窝。

“这处先别算。”她把手收回，去清理鞋边的泥。童沛有些讪讪，江穗却请他继续指出怀疑的地方，宁可多走一段，也不要站在桌旁把所有地方想当然地画满。两人沿阶来回，累得说话开始断句，图上的记号却没有像最初想的那样铺成一片。

返程时，来过的居民拿图试走，在江穗差点滑倒的地方主动改了落脚处。他没有抬头夸画得准，而是低头又看了一眼水面，问雨再大时该怎么核对。江穗把这个问题记在另纸上，收图让他先过。水窝里的一片小叶晃了晃，鞋印从它旁边延伸出去，没再踩进最滑的中央。

# 第二十五章 桥口那只空扣

鲍新来帮忙时，别人正准备上检修桥查看。他是个成年志愿者，见搬物件的人多，便急着把自己也排进队里。费泊叫他先到桥口等，自己转身检查准备带上的零碎。鲍新担心耽误后面的人，手上几下收拾便往前挪，还回头说，轻的可以都给自己拿。

桥口的人没有接他的话。有人伸手拦住，把目光落在他的衣侧，问安全扣在哪里。鲍新先摸了摸，又低头找，原本自信的表情一下僵住。他把手里的东西放到地上，想退回去补齐，后面的人却已经被迫停下，只能把刚摆好的顺序重新挪开。费泊赶来时，桥边挤着一排不能前进的人。

“我这就弄好。”鲍新说。

费泊让他先走出入口，别把补救也挤在通道上。鲍新站到侧边，看着别人一件件核对，才发现自己急着表现能干，反而让整队等在这里。有人想打圆场，说还没迈出去就不算什么。桥口检查的人没有松手，要求把这次遗漏说明白，再决定后面的安排。鲍新张了张嘴，终于没再辩解。

他转身去搬挡路的空筐，第一次抬得太快，筐底在地上刮出长长一声。费泊请他放稳再动，语气比方才更严。鲍新把筐挪好，退到不会挡人的位置。队伍从他身边重新经过，没有人再把待带的东西塞给他。他看着地上已经腾出的那块空处，手还保持着想接东西的姿势，过了一会儿才慢慢垂下。

# 第二十六章 从入口退回地面

处理意见说完后，鲍新仍站着，像等着谁再补一句可以例外的话。费泊请他坐下，把桥口发生的经过从头讲一遍。鲍新说自己怕拖慢进度，原以为先帮着拿东西，其他步骤随后再补也来得及。讲到这里，他看见对面的人没有点头，声音便低了下去。

这次遗漏没有被口头提醒带过。鲍新因漏戴安全扣，被暂停了上检修桥的资格。记录放到桌面时，他伸手扶了一下纸角，问：“那我今天还能做什么？”费泊让他先到地面整理散开的材料，既不要靠近桥口催人，也不要替上桥的人作准备确认。鲍新把椅子推回桌下，出去时被门边的空筐挡了半步，便蹲下来把通道清空。

地面的活并不轻松。混在一起的木片要挑出带刺的，沾泥的布要摊开，几个人还不停从他身边经过。他起初一件件乱搬，搬开这一堆，又挡住另一堆。童沛看不下去，让他先留一条出入的空线，再把手上的东西按眼前用途摆开。鲍新照做以后，才不必每隔一会儿就站起来给人让路。

上面传来一声招呼，他下意识抬头，却只是有人叫地面的人往外站开。鲍新带着身边的居民退出那一片，让搬下来的东西安稳落地。灰尘扑过来，他用袖口挡了挡，随后蹲下清理。收工时，地上已经没有横着的长木片。他绕着空出的通道走了一圈，没再往桥口看，低头把最后一块碎屑扫进了簸箕。

# 第二十七章 谁的脚步被落下

一位居民把篓子往地上一放，声音很响。“改来改去，是不是只图外头的人看着方便？”他指着草图问，说自己的日常搬运没有变轻松，倒是每来一次都得改走法。桌边有人立刻反驳，说大家都在出力，不能这样说。两边声音一起高起来，江穗刚铺开的纸被一只胳膊压住，裂开了一道小口。

郁澄请压纸的人松手，先把裂口护住。她没有叫那位居民收回话，而是请他把今天从哪里绕开、在哪里停过说清楚。那人一开始仍只说不好走，童沛便把空篓背起来，请他领着走一遍。走到临时堆物的地方，童沛确实得侧身，再退回一小步才能过去。江穗跟在后面，拿着被撕开的图，亲眼看见纸上的空白在地上并不空。

堆物的人不肯立刻挪，说搬过来已经费了一趟力，挪远以后取用又麻烦。那位居民气得要走，郁澄请他稍等，自己站在路边看双方怎样用这块地方。最后没人得到最省力的安排：取料的人搬开了靠外的一层，过路的人也同意从空出的边缘走。童沛来回试了几遍，篓沿不再擦碰，却仍得减慢脚步。

江穗回到桌旁，用废纸衬住裂口，没有把它裁掉。那位居民没有再说工程只为谁做，却也没答应以后不提意见。他临走指了指篓边磨出的印子，说下次还会带来试。郁澄应下，等他走远，才请堆料的人把挪出的东西放稳，别让今天勉强留出的通道在转身之后又被占回去。

# 第二十八章 擦掉的合计

陶汀把几笔小额支出排在桌上，请经手的人围过来。刚读到合计，有人皱眉说不对，自己记得没有那么多。另一人则指着纸上的一行，说这一项若不买，干活时根本凑不齐。话题迅速偏到谁更会省钱，陶汀只好敲了敲桌边，让他们先看每笔究竟记了什么。

“这一行，我也报过。”童沛忽然说。

陶汀把那张凭条单独挑出，又翻到另一张，发现写法不同，用途却像同一回事。她请两人各自回想交来的是原凭条还是后来补写的说明，暂时没有让任何人承认记错。问到最后，重复的来源才对上。陶汀将合计擦掉重写，抹下的纸屑粘在手背上，她拍了拍，继续往下核。

有人松了口气，开玩笑说幸亏数额小。陶汀没有笑，让大家看刚才争论花了多少工夫，若只因钱少就略过去，下一回谁也不知道该信哪张纸。她把说明与凭条放在一起，请经手人逐项确认。围桌的人因此又多站了一阵，想早走的那位只得将脚边的东西挪到不挡路处，再回来听完。

核对结束，几个人仍不同意某项花得值不值，却已经不会把重复记录算成真实开销。陶汀将争议留在另外一处，不与合计混写。童沛主动留下收拾桌面，用布擦去那些细小的纸屑。先前喊不对的居民走到门口又折回来，看清修改后的数字才离开。桌边少了一阵争吵，多留下几处尚待说明的空位，陶汀逐一圈了出来。

# 第二十九章 箱子过窄门

连稷来搬旧箱，先把门口碍事的碎物清开。他在旧架房做看守，对哪一处容易磕到箱角很熟悉，抬手示意帮忙的人不要硬推。有人以为只要多加把力，木箱就能挤过门，肩膀顶上去的瞬间，箱盖却向旁边错开，几件松散的小物滚到了地上。

连稷立即叫停，请大家先捡回散落物，再把盖子扶正。等待的时候，旁人聊起家中人手多少，问他是不是兄弟姐妹多，搬东西便不用求人。连稷唯一的手足是一个姐姐。他没有顺着话题细说，只蹲下检查箱角，把一块快夹进缝里的布拉了出来。“先别抬这一头，另一头还没站稳。”他对身后的人说，等对方答应，才重新让箱底离地。

这次几个人把箱子斜过来，窄门总算让出一点余地。可箱子刚过门槛，抬在后面的人就说手酸，不能再往远处走。连稷让他们落到干燥的平处，自己绕过去垫住一角，免得放下时摇摆。陶汀经过，帮着将地上的碎物拢到墙边，没有让下一趟搬运又踩进去。

箱盖上多了一道擦痕，连稷看见了，没有急着把痕迹擦得看不清。他请刚才硬推的人再过一遍门，空着手比出箱子的宽度，让对方自己看哪里会碰。那人走到门边便停住，回头说下回得先腾出转身的位置。连稷点点头，打开门边一小片空间，再招呼大家处理剩下的箱子。第二趟没人催，抬起与落下的口令倒比第一趟清楚得多。

# 第三十章 湿鞋踩过两块板

两种临时铺面并排放好后，居民急着试哪一块更防滑。第一人穿着干鞋走过，说两边都不错；紧跟着的人鞋底带泥，却在其中一块上滑了一下。后面顿时有人叫着选另一块，江穗忙让队伍停住，请滑到的人站稳，确认没有扭伤，再看泥究竟带到了哪里。

“先前踩过的水，全留给后面的人了。”童沛指着湿印说。

岑望让大家把两处都清理一遍，再用相近的方式沾湿，别把先走与后走混作材料差别。有人嫌这样白费了前面的试验，岑望便请他看已经积在边缘的泥团：后面那人的落脚条件，根本和前面不一样。几个人只得拿布擦拭，又把跑去干别的活的人叫回来。

重新试走时，一位居民走得快，一位拖着步子，还有人特意在转弯处停下。两块铺面各有让人不舒服的地方，有的边缘刮鞋，有的表面沾泥后难以清干净。岑望没让大家当场投票，而是把需要改的边角指出，让费泊用普通木料临时垫出平顺的过渡，再看是否还会绊脚。

忙完，试走的人鞋底都脏了，布也洗不回原来的颜色。江穗将两边的评价分开记，没有写一个简单的优劣结论。童沛收走铺面前，在空地上找回滑落的小垫片，免得过路的人踩中。那个最早喊着选另一块的居民留下来帮忙擦泥，边擦边承认，刚才若直接铺下去，吃亏的恐怕正是走在后面的人。

# 第三十一章 壶在布上转了半圈

童沛准备下一趟补给，将空篓翻过来拍去底部的灰。杜葵看他把几样东西挤在一处，便叫他先停手，把容易相互碰撞的分开。童沛说路上走快一点就好了，话刚说完，篓侧的一件硬物便压着布边滑下来，险些掉到脚旁。他低头接住，没再催着出发。

杜葵拿来一块干布铺在桌上，让他试怎样垫住缝隙。两人把布折了几次，终于不再一放手就松开。随后，杜葵把赭釉水壶交给童沛，明确由童沛接手保管。童沛握住壶把，先在布上放稳，才试着收进随身的补给物里。杜葵请他在原地转一次身，看硬物会不会互相撞击；听见轻轻一声碰响，他便取出来重新调整。

旁边等着送东西的人忍不住问：“现在还走不走？”童沛请对方把手里的东西先落地，自己退开一步，背起篓走到空处又回来。这回没再传出碰响，布也没有从边缘滑出来。他解开准备重包的动作停了一下，转而检查外侧有没有挂住衣角，确认后才向等候的人示意。

出发时，杜葵从棚下追出来，提醒他们别挡住正端饭经过的人。童沛侧身停了一会儿，让出路口，再接着往前。补给队伍拉得比原先松散，脚步却没有互相催逼。到坡中的平处，他将篓放下，照刚才试过的方式调整受力，后面的人也跟着停一停。有人抱怨天色走得比人快，童沛抹去额角的汗，答道至少这次不用半路捡一地东西。

# 第三十二章 不肯藏起来的错线

黎弦把练习纸带来，最上面是一张被擦得发毛的图。穆槐一翻，纸角便卷起来，露出底下几条没有擦净的旧线。黎弦伸手想拿回，说这张已经画坏了，换新的更清楚。穆槐却请他先放着，指出自己最早从哪里开始画错，再看后面的修改是否真正解决了问题。

他指到一处交叉，手又缩回来。“我改了这里，后面就全乱了。”

穆槐将废木放在旁边，让他沿着看得见的边慢慢比。黎弦刚说出一个方向，就发现按自己的解释，另一条线没有了去处。他急着找橡皮，穆槐用一张空纸挡住他还没讲到的部分，叫他把眼前这一小段说完。旁听的人也被要求别替他接话，只能看着他反复挪动木料。

汗滴落在纸边，黎弦赶紧用袖子吸开。擦坏的纸本来想藏在下面，现在却把每次犹豫都暴露出来。他终于指出自己把不同方向的边当成了同一条线，穆槐请他在另纸上重画这一小部分，不要求整张立刻改完。新画的线仍不算稳，至少不必一改就牵着其他地方全动。

练习收尾时，外面的人已经开始搬东西，黎弦没有跟着跑出去。他将坏图与新画的小片段并排放好，用手掌按住卷角，看了好一会儿。穆槐要收桌，问他这张还留不留。他说留，随即把纸从压着它的杂物下面抽出来，平放到自己带来的纸叠上。这次，最不好看的那张没有被塞回最底下。

# 第三十三章 桌脚陷进软土

费泊把临时修理桌搬到屋外，原想借亮光看清小件，没想到桌脚刚落地便向一边沉下去。布上的零碎朝低处滚，黎弦扑过去接，反而碰歪了另一角。费泊伸手压住桌面，让他别追着东西乱动，先把将要落地的收进布中，腾出一张空桌再处理桌脚。

泥土表面看着干，下面仍软。童沛拿来普通木片，想直接垫在最矮的一角，费泊却让他把其他桌脚也检查一遍。两人蹲着拨开浮土，才发现各处承力并不均匀。黎弦站在外侧扶住桌子，胳膊渐渐发酸，开口提醒他们别一直让自己撑着。费泊于是让桌面先靠在稳妥处，所有人都松手退开，再重新找平整的落点。

“若早这样，不用撒一地。”童沛指着脚边说。黎弦没接话，弯腰找那枚差点滚进草里的小件，用布擦净才放回。修理还没开始，他们已经花了不少力气重新摆桌。郁澄走来，见几个人忙得满头汗，只请他们给过路者留出足够的边缘，自己站在旁边指明哪里会挡住转身，没有伸手去挪沉重的桌面。

桌子终于放稳，费泊先轻推各角，又让黎弦试着做平常的动作。桌面不再摇晃，他们才把布铺回去，分开摆出零碎。亮光照着刚擦过的小件，少了一处藏污的阴影。童沛收走没用上的木片，给脚边留净地方。费泊拿起要处理的部件，发现日头已经偏过来，便把椅子往旁边挪了一点，开始补做那段被耽搁的活。

# 第三十四章 门内空下去一块

响声从维修间里传出来，费泊正站在门外与人说话。他转头看见靠里的地板塌下一片，扬起的灰贴着光线升起来，立即拦住想进去查看的人。有人说工具还在里面，伸手便要越过门槛。费泊将人拉回，让大家离开门边，先看脚下有没有连着松动的地方。

没有人被压住，惊慌却迟迟没散。为了阻止旁人误入，南坳架房的维修间因地板塌陷而封闭。费泊在门外放好阻拦物，请经过的人绕开，不准以进去取一件小东西为由越过。他自己也没有冒险往里走，只从外面确认眼前能看见的情况。原定在里面进行的工作全被打断，等待的人抱怨白带了材料，费泊让他们先把材料移到安全的地面。

“是不是挪两块板就能过去？”有人问。

费泊指着灰尘尚未落尽的缺口，让对方不要拿脚去替眼睛试。随后他走到屋外的临时桌旁，重新分清哪些活眼下还能做，哪些必须停着。黎弦想沿用原来的摆放顺序，却发现手边少了东西，只得把已经铺开的布重新折起一角。几个人来回调整，空着手站了好一阵，才接上能够继续的部分。

天色暗下来，门边没有再围着人。费泊最后查看了一遍外面的阻拦物，见一块被行人的脚碰歪，便请旁人帮着扶正，另留出清楚的绕行处。屋内的灰逐渐沉下，塌口的轮廓越来越分明。他站在门外看了一会儿，转身把临时桌上的布盖好，没有给等候的人许下马上就能恢复的日期。

# 第三十五章 泥往哪边走

雨后清扫时，童沛把一桶水泼在路面，泥浆顺着低处冲出去，正好漫到居民预备落脚的地方。对面立即有人叫起来，裤脚已经沾了褐色斑点。童沛想再泼一桶冲干净，杜葵赶忙拦住，叫他先看水会流向哪里，别把自己这边的干净全换成别人那边的泥。

郁澄站在边上，用左手指着尚未被水漫过的小片高处，请人把待用的物件先移开。鲍新拿着扫帚在地面推泥，开始使劲太猛，稀泥从帚头两边飞溅，又把附近人的鞋弄脏。杜葵让他把扫帚放平一点，先把厚处聚拢，别一路赶着跑。童沛则用普通木片挡住往脚边流的细沟，给搬物件的人争出落脚的时间。

“这里刚扫过！”一名居民见泥水又回来，忍不住抱怨。几个人低头顺着水迹往上看，发现是另一边的人还在往下冲。童沛跑过去叫停，两边才把次序接上。先处理会向下流的部分，再轮到低处；留在下面的人不必反复返工，能把已经聚起的泥移到不挡路的边缘。鲍新推得满额是汗，停下来时也没有将扫帚横丢在通道中。

地面露出原来的纹理以后，大家并没立刻往上走。杜葵找人试踩较干的一边，确认不会把刚清开的泥又带回来，才让端着东西的人经过。童沛抹了抹裤脚的污点，越抹越大，索性不再管它。他去向先前被溅到的人赔了句不是，然后把空桶翻扣在边上，跟着别人收拾最后一小片还没清净的湿泥。

# 第三十六章 停步以后还在响

入夜，南坳架房周围的脚步少了，郁澄却在离开时停住。她以为有人在身后轻轻翻动什么，回头只看见几个人还在收拾屋外的杂物。等他们放下手上的东西，声音仍断断续续地传来，不响，却让人很难忽略。她抬手示意别说话，自己站到能避开脚步回声的位置。

南坳架房夜里传来细密的轻响，来源一时不明。郁澄没有把它写成有人活动的证据，只记下此时听到的声音。童沛顺着她的目光看，问会不会是屋里落下了东西。费泊叫他留在外面，不要为了猜声源跨过阻拦。众人便沿可通行的地面换位置听，声音却忽远忽近，换到另一侧也没有变得足够清楚。

“越找越像到处都有。”童沛揉了揉耳边，先笑出声来。

郁澄请他正常说话，别因为要听就将周围一切都停住。说话声起来以后，那细响被盖去一阵，等话音落下又偶尔出现。有人提议立刻把附近杂物全搬开，费泊看着暗下去的地面，提醒这样容易踢到脚下的东西。没有足够的光，他们便没有继续拆搬，只清出回去的路，防止大家一边抬头听一边绊倒。

要走时，郁澄把记录折起，童沛又问她觉得最可能是哪一处。她说现在还指不准，等有条件再查。风把衣角吹向腿侧，几个人接着往外走，细响落在他们身后，没有得到一个匆忙的名字。走到较平的地方，费泊回头检查同行的人是否都跟上，确认无人掉队，才将步子放大一些。

# 第三十七章 沾灰的夹口

屋外清理旧物时，黎弦从一堆木边料中抬起一个沉甸甸的东西，刚举过膝盖，底下便掉出厚厚的灰。他咳了几声，把东西放低，费泊赶忙让旁边的人退开一点。那是一副旧木工夹具，夹口被污物堵住，旋动处涩得厉害，黎弦拧了两下便想加力。

“别把拧断当作打开。”费泊叫住他，拿布先清掉外侧浮灰。黎弦只得松手，蹲着一点点挑去夹缝里的碎屑。看起来简单的工作做起来很费耐心，一块硬结刮了许久才松开，掉下来又卡在另一边。他气得叹了口气，费泊让他把夹具换个方向，利用空隙让碎屑自己落出，而不是一直往里顶。

童沛经过，问这东西是不是可以直接丢掉，留着只会占地方。黎弦还没回答，手下的旋动处忽然松了一点，夹口终于能缓缓张开。他抬头朝童沛扬了扬下巴，费泊却让他别得意，能动不等于可以马上受力。两人用废木试着撑住，观察是否会突然滑脱，没有把夹具放到真正要固定的材料上。

郁澄在旁边看了一会儿，提醒清理出的碎物别留在路上。黎弦将布摊开，把硬屑拢进去，再擦了一遍掌心。夹具放在干燥处时，比刚翻出来少了一层灰，仍旧笨重，谁也没替它安排立刻上工的任务。童沛临走伸手试了试重量，说留也得留个不绊脚的位置。黎弦挪开一块空地，把夹口朝里放稳，终于腾出手去收拾自己的鞋面。

# 第三十八章 两个压下去的位置

旧梯被搬到屋外平处，费泊请人将背面朝上，自己拿来已经清理过的夹具。郁澄展开先前画的位置，黎弦则蹲在另一侧，看两者靠近时是否会碰伤木面。有人猜他要把梯子重新夹一遍，费泊摇头，让夹口只靠近，不用力压下，先让大家看接触的位置。

两处相邻的位置对得很清楚。旧梯背面的两枚凹点，是旧木工夹具留下的定位痕。这个来源确定后，郁澄在记录旁补上说明，没有再把凹点当作等待解释的异常。黎弦用一块废木试过夹口，浅浅的压痕落在木面上，与梯背的形状能相互对照。费泊随即松开，叫他别为了让痕迹更深而继续加力，免得把演示变成损坏材料。

“原来折腾的是同一件事。”一个居民看着两样旧物说。他原先嫌梯背的记号费事，如今又想把夹具和梯子一起摆到入口，给过路的人看。郁澄问入口够不够宽，童沛便背着空篓从旁试过。篓沿险些碰到夹口，大家只好取消这个临时念头，将演示的地方收拾回不挡路的样子。

搬开梯子前，黎弦把试压的废木拿给还没看清的人，等对方确认才放回桌上。费泊清掉木面新增的灰，不再去磨那两处旧痕。郁澄将纸折好时，一阵风掀起最上面的角，她用左手按住，等帮忙的人腾出地方再离开。围观者陆续散去，留在地上的只是搬动时掉落的叶屑，童沛用扫帚一推，重新露出可以走人的边缘。

# 第三十九章 不能倒过来的方向

设备检查开始前，费泊先让围看的人站到不妨碍工作的地方。有人沿着线缆看了半天，提出若从另一头接过来，或许能少走几趟搬运的路。这个主意立刻引来几声赞同，童沛甚至转身准备把手边的东西往另一侧移。费泊叫住他，让所有物件先留在原地，别用搬动来替尚未弄清的办法表态。

他打开能供检查的位置，请旁人看清原有设备的安排。这套缆路的供电只能从山脚传向山顶，设备结构不允许逆向送电。费泊把这个限制说明后，才让大家继续谈怎样安排地面的工作，没人进行反向通电的尝试。黎弦站在旁边看图，问：“我是不是把图的朝向和实际供电方向弄混了？”费泊让他先指出图上每一端对应的实地位置。

黎弦指错了一处，正在记事的人险些照着写下。郁澄及时让他停笔，请费泊确认后再记录。黎弦把纸转回原位，重新去看设备，脸上热得发紧。提议从另一头接的人也没有再催，只问这样一来，眼前哪部分准备得重做。费泊将受影响的东西逐件指出，大家才动手把刚才摆错方向的那一小堆搬回去。

折返的活不多，却让几个人白费了一阵力。童沛放下东西时揉了揉肩，笑自己连话都没听完就想往前赶。费泊没有接着训他，而是让众人清出设备旁的落脚处，方便后续按原有结构检查。收尾时，记录纸上少了一条未经确认的设想，地上的物件也不再指向相反的两边，黎弦这才将一直拿反的草图平放下来。

# 第四十章 留下之前先腾地方

一盘旧零件端到空地上，居民围过来挑看。有人觉得带旧痕的都该留，少一件就少一点过去；有人嫌它们既沉又占地方，恨不得连盘子一并端走。争执刚起，一枚小件从盘边滚下，童沛追了两步才拦住，起身便问：“留在脚下，谁来替踩到的人负责？”

这句话让喊着全留的人不太高兴。他说不能只图方便，把看不懂的东西都扔掉。费泊于是把盘子放稳，取来几张废纸，叫大家先分开正在用的、准备检查的和暂时不明用途的，别一边争价值，一边把需要的东西混进要处理的堆里。郁澄在旁听，把几个人说的理由逐条记下，没有替哪个零件宣布永久的去处。

鲍新在地面帮忙腾位置，将靠路的一只空筐挪开，又用布接住清理出来的小件。一名居民想把它们摆在最醒目的地方，自己试着往前一站，便挡住了端东西过来的杜葵。杜葵不客气地请他让开，让他看清展示的位置与通行的位置究竟争在何处。那人退到一旁，脸上有些难堪，却开始认真找不妨碍人的摆法。

暂时归拢后，大家没有丢掉争议最大的一堆，也没有把它们散放在入口。童沛将盘子移到干燥平处，走过一圈，确认抬脚不会碰到边缘。费泊把要继续处理的部分带到屋外桌边，向黎弦示意先核对再动手。郁澄合上记录时，听见刚才争得最凶的两人还在说各自的理由，只是这回他们一面说，一面帮着把地上的空布卷了起来。

# 第四十一章 窗框卡住了

架房外墙的通风窗比抬上来的窗框窄了一点。费泊让扶着的人先别往里塞，黎弦却已经将一角推入，另一角随即卡在外面，抽也不好抽。举着窗框的人手臂发抖，脚下又没有合适的落点，只得齐声叫人赶快帮忙。童沛端着材料经过，立即放下手上的东西，腾出能让他们落脚的地方。

窗框被缓缓退回，边缘擦起一小片木丝。黎弦拿布擦了又擦，仿佛能把自己的着急一起擦掉。费泊将框平放，请他找出究竟哪一边卡住，不要一着急就把所有边缘都磨薄。郁澄站在地面，用左手指着刚才看见的受阻位置，让黎弦从那里比起。几个人将框转向光线，终于看清偏出的那一小段。

“只差这么一点，也举不住。”童沛甩了甩手臂。

费泊叫他们轮换着休息，自己把需要调整的位置划出。黎弦这次没有抢着上手，而是先问磨到哪里停。待木丝清净，窗框再次抬起，扶框的人先试两侧是否都有余地，确认后才一点点送入。紧张的叫声没有再响，童沛也能腾出手，把待用的小件送到够得着的地方。

装好以后，费泊从外面逐处检查，要求把掉下的木屑全扫开。黎弦发现衣肩沾着灰，拍了两下，往后退着看那扇窗。风穿过空隙，吹动屋外桌上的布角。他想走近再摸一摸，被童沛叫住帮忙收拾，便低头捡起地上最后一片边料，和废木放到一起，没有留下一个急着证明成品归自己功劳的动作。

# 第四十二章 灰釉上的湿布

灰瓷纪念牌被放到桌面时，下面先铺了一层软布。连稷不放心，伸手压了压桌角，确认不会晃，才让旁边的人靠近看。有人想用硬物刮掉表面的污点，他立即制止，叫对方试着用湿布轻轻擦，不要把清理当成重新刻一遍。湿过的灰釉颜色深了，指痕也跟着显出来。

擦去正面的浮污后，刻痕露得更清楚。灰瓷纪念牌正面原刻的字是四个。连稷让人顺着表面慢慢移动布，不去描补字形，也不另添新的刻痕。一个居民看见边缘还有擦不净的地方，便想再多用些力，布刚压下，就被提醒先停手。牌子换了个朝向，原来那片深色主要是水迹，并不是还藏着一层必须刮掉的东西。

“看不清的时候，手反而想更使劲。”那人有些难为情地说。

连稷请他把湿布拧得轻些，再从空白的边沿试。他自己站在桌边护着，免得围看的人碰到桌面。外面有人搬材料经过，差点将长物扫向桌角，童沛及时叫停，先让观看的人退开，留出绕行的路。清理不得不中断一阵，连稷索性盖住牌面，等人走完再继续。

等布不再带出浮灰，旁人提议马上立起来看。连稷却先确认支撑是否稳妥，没让它临时靠在容易滑开的地方。众人退到一旁，桌面终于空出能动手的余地。留下的湿布被放进待洗的那堆，软布边上的小砂粒则一颗颗拣走。连稷最后擦净自己的手，才小心扶住牌边，结束这场被几次打断的清理。

# 第四十三章 谁把影子当成边

穆槐把几块普通木料放到课桌上，请来练习的人画出自己看见的边。黎弦急着完成，连木料投在桌面的影子也顺手描进去。坐在对面的人看了他的图，怎么转动木料都对不上，便说纸被放反了。两人来回转纸，桌上的木块差点被扫下去，穆槐只好伸手拦住。

她没有拿走那张图，而是把遮住光的一块布移开。影子位置一变，黎弦刚画出的几条线立刻失去对应。“这一条，你还能在木头上摸到吗？”她问。黎弦沿着边试过，摇头。他想擦掉，穆槐却请其他人也检查自己的纸，别把一人的错误当成只属于一人的事。

几张图陆续翻出来，竟都有类似的线。屋里先是一静，接着有人忍不住笑，说原来大家画得热闹，画进去的还不全是木头。穆槐让他们把光照的影响与实物的边分开说，再重新放好木料。黎弦这回从能够摸到的边开始画，画一小段便停下对照，不再隔着别人的肩膀猜整个形状。

课桌很快又被纸铺满，后来的人没有地方落笔。穆槐请已经画完局部的人先腾出一角，站到旁边观察。黎弦舍不得收起刚改过的纸，犹豫片刻，还是把它夹在自己的纸叠里。走到门边时，他看见日光又移了一点，桌上的影子和上课时不一样了。他没有喊大家再停一次，而是向新来的居民提醒，先找木边，再看落在桌上的暗处。

# 第四十四章 抬到一半的手

郁澄想把纸压在桌上，手伸到半途便停住，改用左手收住纸角。她已经厌烦每次做事前都得多想一步，见别人一伸手便能拿稳东西，心里更觉不耐。穆槐路过，看见她将本来很轻的一张纸翻来覆去，问是不是记下的内容出了问题。郁澄摇头，说问题在自己总想把动作做得和从前一样快。

她在桌旁尝试轻缓地活动，做一点便停下来，观察自己的感受，没有拿重物逞强。穆槐把要搬走的杂物移开，给她留出空处，自己则坐在稍远处整理练习纸。两人并没有一直交谈。屋外的敲击声停了又起，郁澄数着自己能安稳完成的小动作，刚有一点急躁，就把手放回桌边。

“我最怕别人每次都先问需不需要帮忙。”她忽然说。

穆槐没有劝她凡事都接受照顾，只问哪一种帮助会打乱她自己的安排。郁澄想了想，说有人不等自己开口就把纸拿走，她反而不知道东西放在哪里。于是穆槐在挪动桌边物品前先问了一句，将需要她确认的留在原处。郁澄点头，把今日要记的内容逐条找齐，纸没有再被人替她收进看不见的地方。

风从门口进来时，一张练习纸落地，郁澄没有急着去接。穆槐弯腰拾起，放回原先的位置。她们继续各做各的事，桌旁没有因那张纸乱起来。离开前，郁澄把要带的几页叠好，请穆槐帮忙拿住门边碍事的布，自己从留出的空隙走出去，脚步比来时轻快，手上的动作仍保持着分寸。

# 第四十五章 放下空出的布带

郁澄在桌边坐下，先把袖口卷开。她不急着跟上外面搬东西的人，仔细松开布带，一圈圈放在旁边。有人走进来问：“要帮忙吗？”她说这回想自己完成，请对方先把门口的纸收住，别让风把它们吹到地上。布带渐渐松开，桌面上多出一小团褶皱的布。

郁澄的右腕已经痊愈，她亲手拆下夹板，右腕已能承重。她将拆下的东西放稳，活动了一下手，再把桌边装着日常物件的小筐提起，挪到不挡人的位置。动作完成时，她没有叫别人都来看，只低头看了看筐底是否放平。穆槐走到门边，问那几页散纸该放哪儿，她伸手接过，自己按原先的次序叠好。

外面有人正搬一叠布，最上层滑落下来，郁澄走过去搭了一把手。她接住边角，等对方站稳才继续往前，不像心里设想过的那样，一口气把所有耽误的活都抢回来。对方起初仍准备替她多拿，见她已经稳稳托住一边，便只说了一声往哪里放。两人绕过地上的空筐，顺利把布送到桌边。

收拾到最后，郁澄回来拿落在原处的纸，看见布带与夹板还静静放着。她将它们整理好，没有扔进正在清走的废料。童沛从门外喊人让路，她应声侧身，右手按住了将要滑动的纸叠，左手把门边卷起的布角掖好。忙碌重新接到身上，表现出来的不是一场庆祝，而是几件终于不用绕着做的小事。

# 第四十六章 雨停后的扶手高度

护栏边的地面还湿着，费泊让试走的人一个个过，不要同时挤到临时固定的位置。高个居民伸手觉得正好，换了个身量较矮的人，手臂便抬得不舒服。前者说适应一下就行，后者试着走了几步，到了转弯处只得停下，低头找脚下的稳处，手却够得并不自然。

郁澄请他们交换站的位置，再各自指出什么时候最想借力。岑望在一旁记录，没有凭一人的身量就决定整条路的高度。费泊挪动示意用的普通木条，让大家只在地面比划，不去抓尚未确认牢固的部位。一个居民误把示意当成了可用扶手，手刚伸过去，便被童沛叫住，惊得往后退了一步。

“看着像装好了，就会想抓。”那人说。

这句话让费泊停下调整。他先把临时木条摆得与实际通行分开，再请郁澄向后到的人说明。原本只想讨论高度，现在还得处理误认，几个人又多搬了一趟材料。雨水从木条上滴到脚边，童沛看见有人准备拿衣袖擦干，好让它像成品一些，便提醒那样反倒容易叫人看错。

意见记满一页时，大家仍未选出能让所有人都满意的位置。岑望把需要分别试的几处标出，留到条件齐备时再确认。费泊卸下示意木条，检查地上是否还有突起的碎屑，才让居民从旁经过。郁澄抖去纸边的一滴水，读回刚才那句关于误认的话，站在后面的人点了点头，说这次也该把看上去能不能抓写进考虑里。

# 第四十七章 袋里多出的折页

江穗准备取出通行草图，一张折过的纸却从地图袋里滑到地上。她以为是自己忘收的废稿，捡起展开，发现画的是另一种绕行办法，折痕把几处线条截得发白。童沛凑来问是不是可以直接按这张走，她先将纸放在平面上，让围看的人别用手指反复抹过那些发脆的折处。

地图袋里出现的这张替代路线折页没有署名，作者是谁无人知道。江穗沿着可辨认的线看了一遍，没有把任何熟悉的画法当作某个人留下它的证据。有人猜可能是前来帮忙的居民，郁澄请他先别把猜测写到记录里。童沛又问：“那条绕行能不能先试试？”江穗说可以另作核查，但纸上有一条线，并不等于地上已经能走。

他们将折页与现有草图并排摆好。两张纸的朝向不同，乍看像在说同一处，转正以后才看出差别。江穗拿普通废纸遮住不相关的部分，让旁人只比眼前这一小段。有人想用笔替折页补清模糊处，她阻止了，另拿纸记录自己看不准的位置，保留原纸收到时的样子。

讨论进行到一半，过路人要借桌边放东西，众人只好将纸先收起。江穗把折页单独护好，没有混入待描的草图。郁澄核对记录时，纸上只有发现与待核的内容，没有关于作者的结论。童沛仍惦记绕行是否省脚，出门时回头看了一眼，随后跟着大家去处理眼前的材料。那张折页留在收好的纸间，没有得到名字，也没有被当成已经通过的方案。

# 第四十八章 两拨人等同一张桌

费泊来到屋外修理桌旁，发现上面铺满了江穗待核对的纸。江穗说自己已经约人来看图，费泊却带着等着处理材料的居民，双方都以为这张桌能先给自己用。童沛抱着东西站在两人中间，手臂渐渐发酸，问到底该往哪边放。两人同时指向不同的地方，童沛索性先落到干净的空地上。

郁澄赶来时，争论已经从桌子转成谁的事更要紧。她请双方各说还缺哪一步、需要占多久，不让他们只说自己等得最急。江穗发现来看图的人尚未到齐，费泊则有一部分工作可以先在桌旁说明，未必马上铺开所有物件。可如果先动修理，落灰又会弄脏纸，简单轮流也不够。

“等着的人不能替你们把话听两遍。”童沛说。他已经抱起又放下了好几回。

郁澄于是请江穗先确认眼前最需核对的那一处，看完便收纸；费泊同时在不扬灰的地方讲清准备事项，等桌面空出再动手。两边各少做了一部分想今天完成的事，没人觉得占了便宜。江穗把多余纸页叠回去时动作很重，费泊也将带来的材料重新分成两堆，免得又全挤到桌上。

约来看图的居民到了，江穗只摊开需要的部分，很快指出问题。桌面交给费泊前，童沛用布擦过，确认没有零碎纸角留下。郁澄在安排上加了需要交接桌面的提醒，请双方自己看一遍。事情接上以后，她离开屋外，身后又响起做工的声音；那声音这回没有夹着两拨人互相催问的位置。

# 第四十九章 纸页翻到风口

祁砚帮人整理纸页，刚将一叠放平，风便从门边灌进来，将最上面的几张掀起。站在外面的人急着替他抓住，手指却压在一处脆弱的折边，发出轻微裂响。祁砚请对方松开，先用空白纸托住底下，等整张有了依靠，再慢慢挪到风吹不到的位置。

旁人一边腾地方，一边谈起折岭哪里最容易起穿堂风。祁砚出生在折岭的南坳架房。他把散开的页角逐一找齐，没有拿那番闲话替纸上的空缺补字。有人问：“这一行看不明白，能顺手替我抄清吗？”他让对方先指出究竟哪些笔画还能辨认，不能为了让纸面显得完整，就写进原本看不见的东西。对方犹豫片刻，将笔暂且搁下。

桌边很快堆起待整理的纸，刚移出风口的一叠又被挤到边缘。祁砚叫人清出一块平面，让已经排好的与尚未查看的分开。来帮忙的居民嫌这样占地方，想将两叠摞起来，他便请对方找回刚才那张裂边纸。那人在混着的页间翻了几回，才明白一旦叠错，前面做的核对得重新来过。

忙到光线转暗，祁砚让大家停下，不在看不清时继续抄写。裂边被空白纸妥善托住，没有再受拉扯。有人道歉说自己抓得太急，他只请下回先看纸往哪边动，再决定怎样接。离开桌边时，帮忙的居民特意关住一半迎风的门，留下能供人通过的空隙。祁砚伸手试了试纸角，确认不再翻起，才把余下的整理留待下一回。

# 第五十章 短平台前的停工

短平台的材料运到时，几个人原以为能趁天色还亮把眼前一段架好。费泊比着位置，才发现扶手开口与居民转身的方式还没有商量清楚。若照最先摆出的样子做，端着东西的人得多绕一步；若把开口移到另一边，又可能让迎面的人挤在一起。原本已经拿起工具的人只得停下。

“先架了，再改不行吗？”一名居民问。

费泊让他看看拆改时得重新移开的材料，童沛也指出搬运并不是不花力气的空事。郁澄请那人带着空篓在地面比一次转身，不踏上尚未完成的部分。江穗沿着他的动作记录，另一名居民接着试，却在同一位置选了不同的退让方式。两种需要摆在眼前，谁也不能说只按自己习惯就足够。

光线越来越低，岑望提醒人们别为赶完而跳过讨论。几个人一起把工具收回，将容易让人误踏的边缘清楚围住。搬来的材料没有散放在入口，童沛领人挪到旁边，给回去的人留出路。郁澄把两种转身方法都记下，请愿意再试的居民明天分别来走，不必今晚在看不清的地方继续争一个结论。

人群却没有马上散去。有人望着只差一点就能接上的地方叹气，有人算着自己还要多来一趟，声音里带着疲惫。费泊检查最后一处临时阻拦，退到大家站着的地面上。郁澄合起记录，没有用宣布完成来催他们高兴。众人在未架好的短平台前停下，等次日讨论扶手开口。

# 第五十一章 两组脚步往回走

次日，来讨论的人看到短平台前仍留着空地，便把带来的空篓放在边上。郁澄先讲清今天只在可走的地面试转身，费泊则逐一确认临时阻拦没有被挪开。有人想先说自己赞成哪种开口，江穗请他等试过再说，将大家分成两组，一组先走，另一组在旁观察，然后交换。

第一组走得很顺，转过弯便想认定这个办法可行。第二组却有人步幅小，后面的人跟得紧，两人在出口互相挡住。旁观者急着指挥，一个喊先退，一个喊往前，走在里面的人越听越乱。郁澄抬手让旁人停声，请已经站住的人自己说明还能往哪里挪，不用勉强赶上别人想象的速度。

“让我把篓先转过去。”那位居民说。

旁边的人退开一点，篓子转过，身体才跟着移动。江穗记下这个先后，叫第一组换到同样的位置再试。先前觉得轻松的人这次也遇到了等待，只是不用篓时不太显眼。岑望没有催着量定开口，而是看两组在同一处怎样让位，让各自说清需要的余地。费泊把示意木条移开，防止有人顺手把它当成承重的部件。

轮换结束，居民回到原处，意见不再完全按两组分开。有人改变了想法，也有人坚持原来的办法，但能指出具体卡在哪里。郁澄将待确认的部分读回，约着继续核对后再动工。童沛收起空篓时，特意从刚才最难转的一侧经过，看到旁边的人提前让出位置，便点了点头，没有再把脚步赶得那么急。

# 第五十二章 纸上不肯挤成一项

试走后的反馈刚写到一半，陶汀便发现一句“这边更方便”被说了好几次，指的却不是同一个位置。她抬头问说话的人刚才站在哪里，对方伸手一指，恰好与前一个人的方向相反。围桌的人笑了起来，也有人不耐烦，说大家知道意思就行，没必要每句都问清。

江穗把草图转到众人面前，请刚才几位分别落指。几根手指落在不同地方，有一处甚至指到了还没试过的边缘。陶汀于是将那几句相同的话拆开记录，没有为了表格好看而合成一项。郁澄请没说过话的人也讲讲，站在后面的居民终于开口，说明自己虽然能过去，却每次都得等身后的人停下来才敢转身。

“那不就是慢吗？”旁边有人说。

那位居民立即涨红了脸，反问路若只让快的人舒服，还试什么。郁澄没有替他将情绪改成温和的话，而是请提出异议的人按同样的停顿再走一回。对方走到转身处，发现不是想快就能快，便回来补充一句，后面的人离得太近时确实难办。陶汀将这一条接在相关位置，没有删掉前面的不满。

记录结束，纸面显得杂乱，边上还挤着补写的小字。江穗用空纸托住，怕翻动时丢掉贴边的部分。一个居民提议重抄，陶汀说可以整理，但先让说过话的人确认意思没有变。于是大家又轮流看了一遍，出门的人晚走了片刻。最后离开的那位慢行居民停在门口，回头确认自己的话还在纸上，才把手从门边松开。

# 第五十三章 砧板底下的旧纸

杜葵准备收拾食堂用的旧砧板，翻过来才发现底下护着的纸已经起边。童沛以为整层可以一把撕走，刚拉住一角，纸便沿着不齐的方向裂开，连带着将下面的灰屑扯了出来。杜葵立即叫停，让他把板放稳，先清出桌面，别将清下来的碎屑弄进旁边待用的东西里。

砧板被移到空处，下面铺开废纸。杜葵一层层拆换保护纸，遇到粘住的部分就先松开边缘，不用力拽。童沛负责接住掉落的碎片，做了不久便嫌费事，问这些旧纸难道还值得保留。她说现在混着灰，先分清再丢，免得把夹在中间的整片也撕成看不见的纸屑。说着，她将一处厚得不一样的纸边单独露出来。

那一角上有字，尚未全部展平。童沛想低头辨认，碰得桌面轻晃，杜葵赶忙扶住板，让他先退开。“眼睛凑近之前，脚先站稳。”她说。两人把用来垫的废纸换平，又将碍事的布挪到一旁，才继续一点点揭开。厨房活等着人做，杜葵不得不暂时停手，先去照看已经摆出的东西。

童沛这次没有趁她离开就替她撕完。他将露出的纸边护住，把清下来的碎屑分开放好，给桌旁留出空处。杜葵回来时，看到那一小块仍保持着原样，点头让他帮忙叫陶汀来看。风掀动下面的废纸，两人各压住一边，等门外的脚步走近，没有把还没看清的东西先归进垃圾里。

# 第五十四章 裁口接上了

陶汀来到桌边，先请杜葵将砧板转向光亮处。保护纸层里夹着的纸片已经露出大半，她没有急着拉，只沿着未粘住的边一点点托起。童沛在旁边屏住气，直到纸片平放下来才问，是不是看出什么了。陶汀请他把手从桌边移开，免得自己展开时又碰到。

领料签缺失的半边，原来夹在食堂旧砧板的保护纸层里。两部分摆到一起，裁口与被截断的字行都能接上，陶汀据此确认，先前那处去向不明已经有了结果。杜葵将剩下的保护纸拆下，避免再混入刚找出的纸片。童沛望着接好的位置，伸手比了比，又及时收住，没有将脆弱的裁口压成新的折痕。

“差一点就被我撕掉了。”他低声说。

陶汀没有让他把两片硬粘起来，只找平整的空白纸承托，在记录上注明已经核对的部分。有人过来催问能不能重新用桌，她请对方再等一会儿，先把清理出的灰屑扫走，别让纸上又落一层脏东西。杜葵忙着擦拭板面，童沛便接过清扫的活，从桌脚往外一点点拢，不敢再大幅挥动扫帚。

收好纸片，陶汀向杜葵确认有没有其他碎片被随手丢走。杜葵指着分开放好的废纸，几个人最后看了一遍，才把确实无用的收拢。砧板换上干净的保护层后，桌边恢复了平常的忙碌。童沛端东西经过时，特意避开陶汀正在整理的位置，没有再问旧纸值不值得留，只提醒后来的人，那一处还不能随便堆东西。

# 第五十五章 一张课桌两端

课桌需要挪动时，岑望先到了一头，穆槐则将椅子从另一头移开。两人还没开始抬，就因该先朝哪里转争了几句。穆槐指出门边的布会挂住桌角，岑望认为只要先把桌子斜过来便够了。黎弦站在中间听得头转来转去，终于问：“是不是该先把布拿开再说？”

旁边的人被逗笑，叫他们别隔着桌面同时发话。岑望与穆槐同母异父，岑望是哥哥，穆槐是妹妹。两人各守一端，并没有因为这层关系就省去确认。穆槐将布收起，抬头问岑望那边的落脚处是否已经清空，听见答应才握稳桌沿。岑望也等她站定，没有自作主张先将桌子抬高。

桌脚刚离地，黎弦就发现后面还有一把椅子没有挪走，连忙叫停。他原以为只要盯住桌角就够了，忘了人退步也需要位置。两人落下桌子，看着他把椅子拖远，再试一次。这回经过门边时，桌角没有碰墙，抬桌的人也不用挤着脚跟移动，片刻便到了预备的位置。

放下后，穆槐拿一张纸试桌面是否平稳，岑望则绕到侧边检查通行余地。黎弦等着两人再起争执，却见他们各自指出一处小问题，合在一起反而容易改。穆槐请他自己决定先清哪一边，他照着刚才漏掉的退路先做，没再忙着只把桌面擦亮。最后一把椅子归位，几个人坐下来试了试，窗外的光落在纸上，谁也不用侧着身子避开另一人的手臂。

# 第五十六章 绕错的那一圈

准备外围修缮的普通线材被放到屋外，费泊让黎弦先把松开的部分理顺。黎弦觉得只要卷紧就行，手上绕得很快，等另一头的人要取线时，才发现几圈互相压住，一拉就越缠越紧。鲍新在地面帮着撑开一端，胳膊举得发酸，忍不住问到底还要等多久。

费泊叫两人都先放松，不要一个用力扯、一个拼命撑。他让黎弦从最外侧找回压错的位置，已经绕好的部分不得不拆开，原先省下的工夫全赔了进去。鲍新想绕到另一边继续拉，脚尖却碰着散线，险些把旁边的空筐带倒。童沛及时扶住筐，叫他先看脚下再换位置。

“线没理好，人倒先拧在一起了。”童沛说。

黎弦低着头解圈，没有再辩解自己刚才做得多快。费泊把空地分出接线与走人的两侧，让没事的人别站在线圈里看。大家照新的位置分开，缠住的地方终于能看清，鲍新也不必始终举着一端，只需在需要时稳住。风吹来少量灰，黎弦先盖住暂时不动的部分，再接着理手上的这一段。

重新绕好后，费泊让他们从头取出一段试过，确认没有马上卡住，才准备收起。鲍新将落在通道上的细线捡回，童沛检查筐底，免得搬动时拖着尾巴走。黎弦把最后一圈放稳，手指还在发酸，便坐到旁边休息一会儿。屋外的工作接着往前，他看着线一段段顺利抽出，总算没有再听见催自己快解开的喊声。

# 第五十七章 接住轴的那双手

外围修缮要用的东西收拢时，鲍新在地面清点松散的线，费泊则检查哪些该先分开摆。有人把空筐塞到桌脚，正好堵住鲍新起身的位置，他推了两次都没挪开，只好停下手里的活，请旁人帮忙腾出地方。费泊等他站稳，才从桌边取来准备交付的物件。

费泊把白角线轴交给鲍新，从此由鲍新保管。鲍新接过时先看清轴身是否靠稳，没有边走边将它往怀里一夹。费泊请他在空处试着取用一小段，观察会不会带动旁边的散线。鲍新照做，发现外侧有一处挤住，便放下重新理顺。站在旁边的人催问：“东西什么时候能拿？”他指了指脚下还未清开的区域，请对方等这里收妥再拿。

这一次他没有为了让人觉得自己利落而加快手上的动作。线材理好后，他把附近的空包装挪开，留给来取东西的人一处落脚地。童沛抱着材料走来，习惯性地想从桌脚抄过去，鲍新叫住他，转而让出外侧。童沛绕了几步，手上的东西却没有再碰到散线，便朝他点头道谢。

忙到后来，地面被人来回踏出几道灰印，鲍新顺着印子看，发现自己预留的地方还是窄了些。他找费泊说明，得到同意后将临时摆放再挪开一点，没有自己宣布以后所有人都得照着走。日头偏低时，两人一起清走脚边碎屑。鲍新把待用的部分放稳，蹲下来收起最后的空布，给接着经过的居民留下了完整的一步。

# 第五十八章 名字落到职责下面

推选的结果读出时，岑望没有马上起身说话。围坐的居民先把要承担的事项逐项念清，有人担心签了字是否就没人再能提出异议，有人问遇到看不准的地方能不能停下来复查。岑望将问题听完，接过桌边的纸，确认自己理解的内容与大家讨论的一致，才站到桌前。

岑望正式被选为安全负责人，并获得验收签字权。他在确认职责的记录上写下名字，没有把任何尚未验收的部分一并写成合格。陶汀将纸转给附近的人看，请他们指出是否有漏记的讨论。一个居民发现自己提到的查看安排没有写清，立刻伸手示意，岑望便停住后面的话，让这项补充先得到确认。

“有了一个名字，总不能连我们的眼睛也省了。”那位居民说。

岑望答应公开该让大家知道的进度，也要求区分已经看过、尚待处理和仍需讨论的地方。具体怎样展示，还要再找让居民容易理解的做法，不能把一张写满词的纸贴上去就算交代。郁澄将这项待办记下，提醒下一次讨论时也请不熟悉图纸的人来看看，免得只在做工的人之间说得通。

散会后，岑望留下核对记录，想早些去忙的人又折回来问了一处。陶汀等他们说清才收起纸，没有催着用一个笼统的确认结束。费泊从屋外喊他来看材料，岑望先把眼前的问题交代完，才走出门。桌边的椅子被推回原位，记录上的新名字留在那里，连同几条没有完成的具体工作，一样清楚。

# 第五十九章 让路过的人看懂

陶汀试着把验收进度写在纸上，刚贴到方便看的地方，就有人问这一整行究竟是在说可以走，还是还不能走。她将词句重新读了一遍，才发现对熟悉工程的人很清楚，对只来赶路的人却没有答案。郁澄请那人别急着离开，把他第一眼看见什么、最想找什么说出来。

那位居民指着最显眼的一处，说自己会以为这里全能通行。岑望立刻让人将纸取下，免得试写的内容被当作真正通知。陶汀有些懊恼，解释只是拿出来看看，旁人却说挂到路边就已经会被人相信。几个人于是退回桌旁，将未确认的部分与已查看的内容分开，不再把需要读到末尾才明白的限制挤在小字里。

“别替我读，我自己试。”另一名居民接过纸说。

大家只好忍住解释，站在旁边等他看。他很快指出一处仍分不清的地方，陶汀便做标记，之后才说明原意。这样来回几次，比直接由做工的人宣读慢得多，却暴露出先前谁也没想到的误解。江穗在旁补上对应位置的简图，又请居民按图指向实地，确认没有把相邻的两段看反。

临走前，郁澄将试写纸收回桌内，没有重新贴到路口。正式展示还需要继续核对，今天先留下看不懂的地方。刚开始觉得简单的人主动帮忙，把容易造成误认的几张旧纸也从临时展示处取下，交还陶汀核清。路边空了一小片，看起来没那么热闹，过路的人却不再停在那里猜哪些字算数。

# 第六十章 遮布破口朝着风

一阵急风掀起临时遮布，原先压好的边角猛地弹开。杜葵正在下面整理东西，听见裂响便立即退到外侧，叫旁人别伸手硬抓。布的一角在空中拍打，扫过桌面，几张废纸被卷出去。童沛跑了两步想追，费泊却先让他看头顶，免得人一离开空处，就被甩下来的东西碰到。

郁澄同身旁的人先把能安全移走的物件往外搬，留下足够的退路。鲍新在地面接住别人递下来的空筐，没有去攀高处追那块布。风稍弱时，费泊带人将松动部分缓缓放低，避免剩下的固定处继续受拉。等布落到能处理的位置，破口已比最初大，原本遮住的桌角也湿了一片。

“缝上不就行了？”有人问。杜葵展开破处，叫他看旁边被扯薄的地方，只补眼前一条裂口，下一阵风还可能从旁边撕开。费泊让大家先找能承受拉力的边缘，再安排临时补强，不能为了赶着摆回东西而照旧拉紧。童沛去收吹散的废纸，回来时满鞋是湿灰，手上还拎着从低处捡回的布角。

修补做到后来，几个人的指尖都沾了线屑。杜葵试着拉平，不急着宣布能用了，等费泊看过受力位置，才与众人将遮布重新安置。郁澄把桌面的水擦去，发现一些工作不得不推后，便将受影响的安排逐项告知等候的人。天边仍有低云，大家没有散得太远，先把最怕湿的东西摆到妥当处，再回头收拾风留下的凌乱。

# 第六十一章 雨点追到篓边

童沛将补给分好，刚把背篓扶直，几滴雨便落到手背上。旁边的人叫他赶快盖住篓口，他却发现最上面塞得太满，盖布一拉，底下的硬物也跟着挤动。若就这样上路，布很快又会滑开。童沛只得把已经装好的东西取出一些，摆到还干着的桌边，让等着出发的人先替他挡一挡雨。

纸包被拿起时，外层尚未沾湿。童沛把不能淋雨的纸包放进背篓夹层，确认没有被旁边的硬边顶住，才继续调整剩下的补给。一个居民见他反复翻看，问里面究竟装了什么，童沛没有展开纸包，只请对方帮自己把篓口留出盖布的余地。郁澄将容易滚动的几件物品拢在一起，等他一件件放稳，没有一股脑全塞回去。

“早先少装一点，现在也不必拆了。”同行的人抱怨。

童沛承认自己想省一趟，结果耽误了大家。他将多出来的东西另外安排，重新背起篓，在棚边走了几步，听里面有没有碰响。雨变密前，他们终于出发。郁澄站在路口让过来的人先行，童沛顺势停了一会儿，没拿赶雨当作催人让路的理由。

到了能避雨的地方，同行者的袖口已湿了一圈。童沛把篓放到干处，先收好滴水的盖布，再逐件取用需要的东西。刚才抱怨的人递来一块干布，叫他擦擦额角。童沛笑着接过，外头的雨点敲在地上，补给却没有散成一地需要抢救的东西。众人开始按各自的事情动手，没再围着背篓等候。

# 第六十二章 先练最不想看的

黎弦把练习纸排成一列，最顺手的几张放在前面，自己看了两遍，觉得似乎已经准备得差不多。穆槐来到桌边，问哪一张最让他不安，他却伸手去整理那几张画得清楚的，迟迟没有指向后面。穆槐便站着等，直到他将压在底下的一页抽出来，摊到光亮处。

“这一页我总想留到最后。”他说。

那页画的是他一转方向就容易混淆的部分。穆槐让他先定今天练到哪里，不要求将全部纸重新做过。黎弦拿空白纸遮住旁边的答案，从一个能确认的位置开始，遇到不清楚的便留下记号，不再靠瞄一眼旧图把话接下去。这样做比顺着熟图背述慢得多，很快便露出几处并没有想明白的连接。

屋外的人来叫帮忙搬东西，黎弦下意识站起，随后又看了看未完成的纸。穆槐请他自己说明还需多久，别既答应马上过去，又坐回来继续拖。黎弦将手头这一小段讲完，做了停在何处的记录，才出去搭手。回来时桌边已换了一拨人，他拿起那张纸，竟能直接接上，不必再从头寻找刚才的想法。

临考的准备没有出现他想象中的轻松。纸上的记号越来越多，一些熟悉的线也需要重新检查。但收桌时，黎弦没有把难图藏起来，而是放在下次一打开就会看到的位置。穆槐问还想多练一轮吗，他看了看已经发暗的光，说今天先停，免得疲倦以后只是机械地描。他收起纸，给后来的人让出课桌，走到门外才长长呼了一口气。

# 第六十三章 不递过去的答案

黎弦讲到图上的一处转折，忽然卡住，眼睛往穆槐那边瞟。穆槐正把桌旁的杂物收开，听见他停下也没有马上走过来，只问他最后一个能确认的位置在哪里。黎弦指了指，又试着往后说，才发现自己刚才把前后两处接反了。他伸手要擦，穆槐叫他先把错误指出给旁边的人看。

旁边的居民听得着急，差点替他说出下一句。穆槐轻轻抬手拦住，让黎弦有机会把自己的判断走完。黎弦的脸越来越红，手指停在纸上，过了一会儿才说清是从哪个位置转错方向。穆槐让他用另一张普通草纸试着修正，原图留在旁边，方便观察改动到底发生在哪里。

“要是再错呢？”黎弦问。

“就接着指出哪里错。”穆槐答。她没有许诺这次一定能对，只把桌面清出足够的地方。黎弦重画以后，旁观的人按他的说明摆动一块木料，到了刚才的转折终于能接上。可后面仍有一处不清楚，他只好再停一次，承认自己需要检查，而不是将声音放大来掩盖犹豫。

这场练习比大家预备的久，原本想坐着看完的居民起身去做别的事，回来时黎弦还在对照最后一段。穆槐没有替他补结尾，等他把能确认和拿不准的部分分别说出，才请他收笔。黎弦望着两张不同的草纸，终于笑了，说至少知道自己问的是什么了。他将它们并排收好，离开时没再追着要一句“肯定没问题”的保证。

# 第六十四章 纸转过来以后

考核用的图放到桌上，黎弦先把椅子挪正，没急着看旁边人的表情。穆槐请无关的人留出一点安静的空间，自己站在侧面，等他开始。黎弦按图逐处解释，遇到方向容易混淆的地方，便将纸转到便于说明的位置，再指回实物所对应的部位，没有靠别人提醒补完。

解释结束后，现场又换了一个观察方向让他确认。他把变化说清，独立完成了要求。黎弦通过独立识图考核，已经可以单独解释剖面图。穆槐将结果明确告诉他，旁边的人这才出声道贺。黎弦起初只点了点头，低头把纸角捋平，像还在等下一处需要纠正的地方；过了一会儿，他才抬头笑起来，肩膀也不再紧绷。

“现在先让我喝口水。”他说，引得桌边的人笑出声。

笑完，有居民拿着另一张日常通行图问他一个小问题。黎弦没有因刚得到结果就立刻包办，先确认对方指的具体位置，再看图是否与现场一致。穆槐在旁听，没有抢着替他说。居民弄明白后道了谢，黎弦将纸递回桌上，提醒别把这张普通通行图与刚才的考核图叠错，免得后面整理时混在一起。

收拾桌面时，黎弦发现自己带来的废纸竟一张也没动。他把它们叠好，留给下一次需要练习的地方。屋外有人招呼搬椅子，他应声过去，和别人一起把通道腾开。穆槐最后关住容易被风掀开的纸角，桌边恢复了平常模样。黎弦回头看了一眼，接着抬起自己那一端椅子，走向门外明亮的地方。

# 第六十五章 指给门边的人看

通行图一展开，围看的居民便伸手指向自己常走的位置。黎弦站在桌边讲了几句，门口的人却说一点也看不见，只听见“这边”和“那里”。黎弦回头才发现，自己与前排的肩膀把整张图挡了大半，声音再大也解决不了。他将图往外侧挪，叫已经看明白的人先退一点，给后面的人留出位置。

郁澄没有替他接讲，只从人群边缘看大家是否能跟上。黎弦改用能对应实地的说法，每讲一段便请听的人指出在哪里。一个居民指偏了，旁边的人立即笑说这么简单还看错。黎弦将图转给他们共同看，请笑的人也从对方的朝向辨一次，那人果然迟疑，才承认正反方向会让熟悉的位置看起来不同。

“所以要让他自己指，不是我替他点头。”黎弦说。

江穗在另一边帮忙核对图面，发现一处补写的小字被折痕压住，便先将纸压平，再请居民重看。桌旁渐渐不再是一人讲到底，有人拿自己的走法举例，有人说带东西时会在哪儿停。黎弦将不属于这张图的信息另记出来，没有为了显得解释完整而往纸上添未经确认的新路线。

讲完以后，最初站在门口的人主动来到前面，替后来者指出应该从哪里开始看。黎弦站到旁边观察，直到对方说完才补了一个容易混淆的位置。郁澄收拾掉地上的空布，请人让开出口。几名居民带着各自的问题离去，桌边留下的纸不再被手指盖得密不透风，黎弦终于能坐下来，将刚才还需要继续核对的几项逐一写清。

# 第六十六章 还没交出的测量任务

江穗把准备交接的测量事项写在纸上，起初只列了几个位置，觉得黎弦一看便能明白。黎弦接过却问，每处从哪里开始，遇到过路的人暂停后如何接上。江穗低头看那几行简略的字，发现熟悉以后自己不再说出的步骤，恰恰是别人拿到纸时最需要知道的部分。

两人于是先走到地面试一遍。江穗让黎弦只照纸上的说明找起点，自己忍住没有提前指路。黎弦站在两块相似的石面之间，选了与她想的不同的一块。江穗叫停，将为什么不能混用说清，又在交接纸上补出辨认的方法。旁边的居民急着过去，两人便退开，让路面恢复通行，没有在入口展开长谈。

“你一直走这条，当然觉得不会错。”黎弦说。

江穗认下这点，回来后将不够明确的指示一一改写。她没有把所有经验塞成一大段，而是请黎弦指出真会用到的提醒，讲完就让他照着做一次。童沛送东西经过，看见两人反复折返，以为又量出了问题，江穗解释是在确认接手的人能从同一个地方开始，不是在改变已经观察过的路。

这番准备占去了原本可以多看一段路的时间。江穗把未完成的部分留空，没给交接纸写上已经办妥。黎弦将自己仍拿不准的地方圈出，请她下回交付时再当面确认。离开前，两人沿入口走了一次，把试走时移开的普通木片摆到不挡路的位置。那张纸不再只有熟人看得懂的几个位置，仍有需要见面说明的空处，江穗把它留在最上面。

# 第六十七章 轮子从两人中间经过

江穗与黎弦到约好的地方时，路面上还有几块滚下来的小石子。黎弦先清出起步的位置，江穗便在旁边展开交接纸，请他将上回圈出的疑问逐项说完。两人没有一边走一边含糊应答，而是站在不挡人的地方，对照实地确认，等最后一处指向一致，才开始交接。

江穗把棱纹测距轮交给黎弦，之后由黎弦保管。黎弦接住把柄，先检查轮缘有没有夹住砂粒，再沿已经确认的起点缓慢推行。江穗站在侧面看他的走法，没有抢回把柄替他完成。走到有人经过的地方，黎弦停住让路，等路面空出才接着进行，又将中途停的位置在纸边做了临时记号。

一个居民问：“能不能顺便量一下我想走的这条岔线？”黎弦抬头看了看，没有为了显得接手后能做很多事就答应立刻改变顺序。他请对方将需要说明白，等手上的部分完成后再与大家商量。江穗听见，只提醒居民别站在正在测的线上，自己退到更远一点的位置，让黎弦与来人把话说清。

结束试行时，纸上多了几处具体记录，黎弦重新核对起止，没有一到终点就急着离开。江穗看完他提出的疑问，将其中需要继续观察的标出，没有给一个笼统的全部正确。童沛从旁经过，见两人已经腾开路口，便带着东西径直走过。黎弦站在原地等最后的脚步过去，才将地上的临时标记整理好，准备下一次从清楚的位置接着做。

# 第六十八章 路边的那块松石

黎弦独自丈量一小段待核的新路时，旁边的居民边走边问，是否量完就能马上通行。他停下说明，还得经过后续检查，眼前只是把这一段的实际走法弄清。说话间，一块松石被鞋尖碰得转动，原先顺着的轮迹偏了一点。他没有把这次偏移当作足够小而略过，退回能确认的位置重新来。

这段路看着短，干扰却比想象中多。有人停下来聊天，有人带着空篓在窄处调整背带，每次经过都会让测量暂时中断。黎弦将自己站的位置让开，等人走完再接上，不把过路者当成妨碍自己的麻烦。江穗后来远远看见，想走近问进展，见他正核对，便先站到一旁等着。

“这一回比刚才多绕了一点。”黎弦指着记录说。

江穗请他说明差别落在哪儿。黎弦带她到松石旁，只指给她看，并未擅自把石头搬走来让数字变得好看。两人将需要处理的路面情况记下，留给相应的人确认。旁边居民听完，主动提醒后来者别用脚去试那块松动的位置，免得又把已经记清的状态踩得不一样。

黎弦回到起点时，已经出了一身汗。他将记录顺序核对清楚，发现有一处写得太挤，差点把停顿位置认成了终点，便在另纸上说明，保留原记录供对照。江穗没有替他收尾，听完才离开。晚些时候，童沛来问能否经过旁边搬材料，黎弦指了指已经腾出的空间，自己把纸收到不易受碰的地方，让实际的脚步先从眼前走过。

# 第六十九章 烟往端碗的人脸上去

饭还没有盛好，棚边便响起一阵咳嗽。烟被风压低，正往等候的人脸上飘，杜葵退开看了一眼，立即叫端碗的人别挤在那一侧。有人嘴上说忍一会儿就好，眼睛却已经被熏得睁不开。童沛把靠边的空筐挪走，让人能避开，又险些挡住另一边正在取东西的居民。

“你让我们换，烟也跟着换。”一位居民抱怨。

杜葵没有用饭马上就好来催他忍耐。她先停下会加重烟气的操作，请人将正在用的东西放到妥当处，再看风是怎样穿过棚边的。费泊过来帮忙确认临时遮挡有没有妨碍散烟，郁澄则将人群往外疏开，留出能让他们调整的范围。饭点因此往后拖，桌边等候的几个人坐下又站起，烦躁渐渐写在脸上。

调整一处后，烟不再直接压向原来的队伍，却又飘到旁边整理材料的人那里。对方立刻过来找，杜葵只得继续停下，承认不能把自己的问题推到别人的工作处。众人重新看了空地的走向，将用餐与临时整理的位置适当拉开，等烟气散去，才一点点恢复眼前的活。

吃到饭时，有人先尝了一口就叹气，说等得太久。杜葵一边分菜一边道歉，没把帮忙的人说成理应受夸的功臣。童沛坐在外侧，给后来的人指明别再挤回旧位置。饭后，郁澄将烟气、用水与通行的问题放在同一张纸上，杜葵看了看，添上清洗时也要留地方的要求，随后转身收拾灶旁的杂物。

# 第七十章 门一开就是灰

准备清扫待用厨房的人刚推开门，灰尘便从高处扑下来，童沛不由得打了个喷嚏。他本想先把地扫净，杜葵却指着上面还没有清理的边角，让他别急着做最后一步。否则高处一落灰，刚扫好的地面还得再来一回。几个人把带来的清扫物放下，先分清各自要站在哪里。

有人拿湿布直接抹，灰被推成一道黑痕，反而更难清。杜葵请他先将松散的灰收拢，再处理粘住的部分。郁澄帮着把碍事的空物件搬到门外，没有将它们堆在出入的一侧。鲍新在地面清理角落，发现扫帚伸不进去，便换个位置慢慢拨出碎屑，不为了快而踩上不稳的东西。

“这得洗到什么时候？”童沛看着发黑的水问。

没有人能给他一个准确的时刻。大家只把已经清过的与还没动的分开，免得换人时又从头做。杜葵用一块普通布隔住暂时别碰的物品，告诉后来的人清理并不意味着现在就能开始做饭，使用安排还要继续商量。那人收回准备放下的碗，转而加入清扫门边的活。

忙完一轮，屋里并没有立刻变成明亮的厨房。几处顽固的污点仍在，窗边却终于能看清原来的轮廓。童沛把污水稳稳端出去，没有沿着刚清开的地面一路洒。杜葵最后绕了一圈，列出需要再处理的地方，叫大家先去休息。门口留出的空处正好让两个人错身，郁澄提着空桶走出时，鞋底没再把灰带回新擦过的一角。

# 第七十一章 排在名字旁的空白

讨论厨房轮值时，愿意帮忙的人不少，写到具体安排却都迟疑起来。有人可以做饭，不愿洗一堆沾油的器具；有人只能在收尾时来，怕自己的名字看起来像做得少。陶汀刚写了几行，桌边便有人要求改位置，纸上的箭头越添越多，几乎指不清究竟哪项对应哪人。

杜葵请大家先停笔，不急着排出一张满当的表。她将准备、做饭、收拾的工作分开说，问每个人实在能做哪一段，不要为了显得热心将做不到的全答应下来。一个居民听完收回自己先前过满的承诺，脸上有些难堪，郁澄却请陶汀照实记，免得后来等不到人，剩下的人又默默多干。

“空着的那几处怎么办？”有人问。

杜葵说先把缺口留给大家看，再找能补上的办法。童沛将自己搬运时经过的顺序讲清，说明哪些时候能顺手帮忙，哪些时候不能留在桌边等。他没有答应固定的一串时间，只把眼前讨论涉及的工作范围说清。陶汀将修改过的草稿重排，不把尚未确认的安排写成已经定下的制度。

到了收尾，表上仍有空白，争论却从谁肯出力变成了哪件事没人接。杜葵请每个说过能帮忙的人再看一次自己的部分，允许回去核实后补充。几位居民一起把桌边的碗收走，借着这个小动作试了试交接。有人洗完忘记留出放干净碗的位置，另一人提醒后，大家又在纸上添了一项此前漏掉的准备，没再急着把空白全填满。

# 第七十二章 确认过的门内空间

确认使用安排时，杜葵将几条还需要说明的地方带到桌前，没有只等着听好消息。她问清清扫后遗留的事项怎样处理，也请参与的人核对收尾交接是否已说到。有人想省略这些细节，认为既然大家同意了便不必多问，陶汀却把纸转给对方，请他看那几处是否已经明确。

讨论完成后，杜葵取得了岔灯坪固定厨房的正式使用权。确认的记录摆在桌上，她逐项看过，才将手边准备要做的事情重新排开。郁澄问最先需要大家帮什么，杜葵指向门内尚未收齐的日常器具，说先把进出位置整理好，不要一听定下就全挤进来庆祝。围在门旁的人笑着退开，给她留出走到里面的路。

“总得先让我看看脚下吧。”杜葵也笑。

她走过几个将要用到的位置，试着端一只空盆从一端到另一端，发现靠门处摆得太满，便叫童沛同自己一起移开。童沛将东西挪到她指的地方，又请她再走一次，确认只是移开不会在另一边造成拥堵。有人急着摆饭桌，杜葵让他先等，眼前这一趟还没有走顺，不能把未清好的地方盖起来。

收拾妥当后，众人聚在外侧商量第一顿集体饭。杜葵听着各人的建议，把能做到的记下，做不到的也直接说明，没有为了让大家高兴全都答应。陶汀收好确认记录，向门边的人示意让路。杜葵最后回头检查空盆是否放稳，双手在围布上擦了擦，叫几位留下帮忙的人先把明日要准备的东西分开摆好。

# 第七十三章 第一锅饭差点凉透

杜葵试做第一顿集体饭，最先遇到的麻烦不是火候，而是盛好的饭找不到出去的空处。来帮忙的人热心地把器具排得整整齐齐，却正好挡在端饭的路上。童沛捧着一只装满的容器站在原地，往左会碰人，往右会碰桌角，只得高声问能不能先给自己留一步。

杜葵立即叫靠门的人退开，将暂时不用的东西移到旁边。她让童沛先放稳，不要硬挤，再请其他人照实际的行走方向调整。郁澄过来接应，给端着热东西的人清出一条顺畅的路，等他们过去才让取碗的人靠近。第一份饭送出去时，等候的居民已经问过几次，谁也顾不上向他们解释厨房里面刚发生的拥堵。

“菜好了，饭怎么还不到？”外面又有人喊。

杜葵请传话的人说明还需等一会儿，不要随口应一句马上就来。她自己守住盛饭的位置，给帮忙的人明确下一步该做什么，没再让每个人都来问同一件事。童沛第二次端起东西，门边已经空出余地，他终于不用捧着热气站等。饭菜陆续摆开，前面的人动了筷子，后面的人也能看见剩下的份量。

吃完后，几名帮忙者累得靠在桌边，杜葵却还得清点未收回的碗。有人说第一顿能吃上就算不错，她笑了笑，仍将端饭堵住的位置记下来。郁澄留下帮着擦桌，童沛负责把空物件移开。最后一只碗放稳时，杜葵才坐下吃自己的那份，饭已经不热，她拌了点汤，边吃边听其他人讲刚才哪里还可以少绕一步。

# 第七十四章 湿手贴上的木面

护栏触感测试安排在雨后，费泊请居民只在允许试走的部分慢慢经过，别沿着还没确认的方向继续往前。第一个人手掌贴上木面，说摸着平滑，随后的人却在转弯处皱眉，手忽然收回。费泊立刻叫停，让他指出哪里不舒服，自己从侧面看，发现边缘有一小处不顺。

那处干着时不显眼，沾湿后手掌贴得更实，动作一带便容易感觉出来。有人说磨掉就行，费泊让他先等居民把完整的动作做给自己看，再决定需要处理多大范围。郁澄站在边上记下停手的位置，江穗则请另外的人从另一方向试同样的触碰，确认问题不是只在一种走法里出现。

“我不敢抓紧，就会一直看手。”一名居民说。

这与大家原先只问滑不滑不同。岑望将这个影响也写入待处理的部分，费泊随后做局部修整，让人离开打磨扬起的碎屑。等木面擦净，他没有直接宣布好了，而是请先前收手的居民再走一次。那人照原来的方向通过，在转弯处停了停，低头摸过，才点头说这次没有那一下别扭。

试完以后，路面上又积了些湿脚印。童沛把待用的布收好，没有挂在容易被顺手抓住的地方。郁澄读回记录，发现还有其他触感意见未处理，便与岑望一同留明待核范围。居民离开时只从已经安排的通道返回，有人想继续往远处看看，被提醒后收住脚步，转身跟上了前面慢慢走的人。

# 第七十五章 晾着的箱盖收回来

连稷去收回晾晒的旧箱，先发现一只箱盖被人放得太靠外。风将盖角掀起，下面垫着的布已经滑出一半。他伸手扶住，叫旁边的人别直接抬箱身，免得盖子在两人之间砸下来。帮忙者本想赶快结束，见他停住，只得重新把自己抱着的杂物放下，空出双手。

几只旧箱需要逐一检查，不能只看外面干了就合起来。连稷让箱口朝着光，将靠角落仍有潮意的地方指出，暂时与可以收起的分开。陶汀经过时问是不是又要多等，连稷请她摸一摸那块垫布，布边还凉湿，若现在压回箱底，外面再干也没有用。她于是帮忙把待收的顺序写到普通纸上，免得后来的人一概搬走。

“那这一只先走。”搬箱的人指着旁边说。

连稷看过底部才答应，和对方一前一后抬起。箱子比空着手比画时宽，经过门边又得转向，他提前喊停，让后面的人看清自己的脚往哪里落。旧箱没有再磕出新痕，搬到干燥平处时，两人都松了口气。童沛将地上的垫布收拢，避免下一趟有人踩住滑倒。

还有少数未干的留在通风处，连稷没有为了让场地看起来全收完就将它们合上。他安排好不挡人的位置，回头检查刚搬进来的箱盖是否放稳。陶汀要带走纸，他请她把未收的一项留清楚。风从外面吹进来，纸角晃了晃，连稷伸手压住，等她写完才让开，随后去处理那一片已经空下来的晾晒地。

# 第七十六章 搬箱人歇下的片刻

剩下的旧箱挪到平处，连稷与帮忙的人坐在旁边喘气。有人见他还在看箱盖的方向，便笑他连歇一会儿都像在看守。连稷叫对方先擦擦手，刚才搬动时手心有汗，再抬下一只容易打滑。那人摊开掌心看了一眼，果然找来布抹干，又将布搭到自己够得着的地方。

话题转到各家做事时谁喜欢催促，桌边的人七嘴八舌说起手足。连稷唯一的手足是一个哥哥。他听别人说着，偶尔笑一下，并没有讲一串家事来填满歇息的空隙。有人看他不接话，便问：“还剩几只要搬？”他起身沿着摆放处看过，将还没处理的指给众人，提醒别把刚落稳的又抬一遍。

一名居民只听见要搬，伸手便抓住最近的箱角。连稷叫停，带他看箱子下面的位置，说明这只已经放好，真正挡住后面空间的是另一只。那人不好意思，赶忙换过去，身体却挤在狭处，连稷只得让旁边的人再退一点。几人重新分配站位，这才抬起，不必一边承重一边争着往哪儿走。

搬运结束，空地上露出先前被箱子压住的布与细屑。连稷没有跟大家立刻离开，拿扫帚拢起，免得晚些时候又沾到鞋底。刚才抓错箱角的居民回来帮他，将布折好放在不挡路的地方。两人没再继续家常，只对着最后的落脚处看了一遍。屋外的人喊着收东西，他们答应一声，一前一后从已经腾开的门边走出去。

# 第七十七章 弯路分成几次走

曲折段试走的人比预计来得多，起点很快围成一圈。有人看前面还空，就想一齐往里进，郁澄将人叫住，请大家按安排分批，不要把前一批停留的余地挤掉。排在外面的人抱怨自己赶了路，还要等，童沛便给他们指出能歇脚的地方，免得全站在入口正中。

第一批走到转弯处，一人停下来调整篓带，后面的人也跟着停。远处等候的居民看不清原因，以为里面可以继续送人，岑望及时阻止，让入口保持空着。江穗沿侧边观察，等里面的人示意已经准备好，才让这一批接着走。转弯时没有互相撞上，出来的人却说，被身后盯着看会不由自主地加快。

“那旁边的人也得算进去。”郁澄记下这句话。

下一批进来时，围看者退得更开，不再站到行走者正对面比手画脚。有人觉得缺少指挥会走错，结果试走的人按照已经说明的范围，反而能自己找出停顿处。费泊在需要留意的位置观察，并未让他们靠近未确认的部位。整个过程比一齐走热闹得少，等待却可以预见，不必时不时停下拆开拥堵的人群。

结束后，几批居民回到起点，各自说出觉得最难的一处。意见不完全相同，江穗把它们落到具体位置，没只记说得最大声的人。童沛收起暂放的空物件，请等候者从外侧离开。那个最先抱怨久等的居民走到弯前，主动停了一会儿，让行动较慢的人先转过去，再背好自己的东西跟上。

# 第七十八章 标签贴到了隔壁

陶汀核对费用时，发现两张标签的说明与下面的凭条对不上。她一度以为有人漏交了材料，准备去找经手者，手指掀起纸边才看见另一张标签粘到了旁边。童沛站在桌外等答复，已经做好再跑一趟的准备，听她叫停，便把手里刚提起的空袋放了下来。

“先别急着替我找不存在的缺口。”陶汀说。

她将相邻几项全都展开，确认错位从哪里开始，不只把眼前两张交换就算完。郁澄帮忙读回说明，读到一处相似的用途时，两人又停住，请童沛核实当时具体送到哪里。童沛说清以后，陶汀才将原凭条与对应说明放到一起，没有因为记忆听着顺耳便抹掉纸面可查的痕迹。

有人进来问为何还没算完，陶汀把贴错的边缘给他看，对方下意识想将标签扯下重新贴。她立即阻止，让他先松开粘住的地方，否则凭条上的字可能一并被扯破。几个人耐心分离，费了不少工夫，最后仍留下一点毛边，只好用空白纸承托。童沛看着那一小处，感慨若刚才随手一撕，自己还得去解释更多。

归位后，陶汀从头复核这一组，确认没有把相邻项又推错。合计没有因此被想当然地改动，只有确实需要纠正的对应关系重新记清。郁澄收起旁边的废纸，给下一轮查看腾出空位。童沛临走时问是否还要自己折返，陶汀摇头，让他先做原定的事。门外传来脚步声，他这才提起空袋，顺着已经让开的通道走出去。

# 第七十九章 柜脚下的碎屑

整理弃置料柜时，大家先遇到了打不开的柜门。童沛一拉，柜脚在地上轻轻挪动，整只柜子跟着晃了一下。费泊立即让他放手，不能拿把柜子拉倒当成打开的办法。几个人退开杂物，从外面看清卡住的位置，发现得先处理底部堆积的碎屑，柜门才有转动的余地。

鲍新蹲在地面，用普通木片慢慢拨出碎屑，旁边的人拿布接着。尘土越积越多，有人嫌麻烦，想用脚一踢全散到空地上，杜葵叫住他，说等会儿还得从同一片地方搬东西，踢散只是让别人再扫一遍。那人拿起扫帚，老老实实从近处往外收拢，没有再抬脚。

“里面会不会也这样堵着？”童沛问。

费泊让他等柜门能稳妥打开再看，别提前伸手到看不见的缝里。清理到后来，门终于松动，几个人扶稳柜身，先开出一小道空隙，观察没有相互顶住，才逐渐拉开。靠外的杂物被依次移出，不把里面尚未看清的部分一股脑掏空。童沛负责将取出的普通碎料分开放，鲍新则继续在地面接应。

做完眼前这层，光线已经不适合检查深处。费泊叫大家停下，将开出的区域清理干净，别为赶完留下半截伸出来的东西。柜前的路被扫净，尚待查看的内部没有被宣称已经清空。童沛最后扶着柜身试了试，确认不再随着轻碰晃动，才收起地上的布。众人带走已经分好的废料，把继续检查的活留到看得清的时候。

# 第八十章 蓝色落在柜底

料柜内部继续清理，靠里的一片尘土被轻轻扫开。童沛弯腰将最后一点松散碎料取出，正准备叫人搬走，视线却被一小块蓝色拦住。他停手请费泊来看，没有凭手感将它同废纸一起揉起。围在外面的人以为又卡住了什么，纷纷往前挤，费泊让他们给伸手的人留出转身的位置。

空料柜里留下一个蓝封筒，封面只有一个问号，封筒没有拆开。童沛将它从尘土边缘托起，放在干净的平面上，避开刚扫出的碎屑。有人立刻问里面写着什么，又伸手想翻开封口，郁澄请他先停下，不要将不知道的内容说成已经知道。没有人拆封，也没有人从厚薄或颜色猜定它装着哪类东西。

“问号倒像在问我们。”旁边一人低声说。

郁澄只记录发现时看得见的样子，没有顺着这句话给它编一个来历。费泊继续查看柜里是否还有会刮手的碎片，童沛则把蓝封筒与待弃的物料分开，防止收拾时误混。有人催着将柜子移开，他们请对方等这一处确认完，先从旁边搬已经清好的东西，不要围着未知的物件越说越热闹。

清理结束，柜前重新空出来，大家却比开始时多留了一项待说明的记录。郁澄收好记录纸，询问是否还有人看见发现时的摆放需要补充，得到的回答都没有越过眼前所见。童沛将沾灰的布折好，远离那片干净的平面。蓝色仍安静地停在那里，封口完整，外面的脚步继续往来，没有谁替那个问号写下答案。

# 第八十一章 谁站在最前面

首日入场怎样安排，刚提出来便有人说该让出力最多的人先走。另一位居民反问，搬不动东西、只能来听讨论的人，是不是就得一直排后面。原本还在摆椅子的童沛停住，望向郁澄，似乎等她赶紧选一种办法。郁澄却请两人先坐下，把各自最担心的事说完整。

有人怕自己的劳动被忘掉，有人怕路修好以后，走得慢的人依旧没有位置。江穗将入口的示意图摆在两人中间，让大家看一批人同时进来会占哪里。争论因此有了具体的边界：若最前面只顾往前冲，后面需要扶稳的人就可能被催着跟上。岑望提醒，首日安排先得便于观察实际通行，不能拿排序替所有人的贡献作评判。

“我不是非争第一，就是怕又轮不到我。”一名居民说。

这句话让旁边几个人安静下来。郁澄请他们提出愿意怎样等待，也请需要先行的人说明应留什么余地，别让别人凭外表猜。陶汀在纸上记下约定的原则，暂时不写一长串已经排定的名字。童沛把入口旁的椅子挪开一点，留给途中想歇的人，不把它们全摆成围观的位置。

商量结束，最初坚持出力多者先走的人走到门边，试着背着空篓转身。他发现若有人正坐在旁边，自己得提前放慢，便回头叫童沛把另一只凳子也挪一挪。郁澄跟过去核对动线，陶汀继续整理那些尚需当面确认的安排。纸上还没有一个漂亮的完整名单，入口却已经少了两处会让真正来走的人为难的障碍。

# 第八十二章 夹口松开再合拢

陶汀清理桌上的往来记录，几张待给居民查看的纸总往一边滑。郁澄要带它们去逐处确认，试着按使用顺序排好，刚拿起来又有一张落回桌面。她蹲下看纸边有没有混入废页，陶汀便从手边取出夹子，让她先别急着将纸卷成筒，压住以后仍能逐项翻看。

纸排妥之后，陶汀将银齿票夹交给郁澄，改由郁澄保管。郁澄接过，先将夹口打开，留出不遮住文字的位置，再合拢压稳。陶汀请她翻到中间试一次，看有没有将需要先看的纸藏在后面。两人调换了一处顺序，郁澄这才拿着整理好的记录走到门边，等正在搬东西的人让出通道。

等候的居民一见她就问：“所有安排都定下了吗？”郁澄将尚待确认的地方指给他看，说带来正是请大家核对，不要只看到纸收得整齐便以为没有疑问。对方翻了一页，指出自己刚才同意的是另一种走法。她请他重新描述，随即将那一处记清，没有因为纸已经排好便不愿再动。

核对回来，记录边缘添了几行字，外观比出门前乱了些。陶汀问有没有漏掉人，郁澄按回访过的顺序一一确认，再将未碰面的留在显眼处。外面又有人喊着找她，她先把落在桌旁的废纸收开，免得下次翻看混进去，才应声出去。桌面空出的地方让后来者能直接放下材料，不必先替谁整理一场散落的纸雨。

# 第八十三章 声音停在墙外

郁澄再到南坳架房听那阵细响时，先请同行的人照常走到约定位置，别全挤在她身旁。声音出现以后，几个人分别举手示意，发现站在靠外一侧时更容易分辨。童沛想立刻绕过去寻找，费泊让他先看脚下，沿可以安全行走的外侧慢慢接近，不越过维修间门前的阻拦。

夜色没有完全压下，墙面与地上的轮廓仍能看见。郁澄让站得最远的人再听一次，与近处的描述对照。风弱下来时，细响也歇了一阵，有人便说已经好了，不必继续找。她请那人再等等，刚才并没有做任何处理，声音停住不能证明原因已经消失。众人留在外侧，等下一阵风过来。

“这边，像贴着墙。”童沛说。

费泊走到他指的位置，没有隔着暗处伸手乱摸。他请大家把随身会发响的小物放稳，自己观察墙外附近哪些东西正在动。声音又响了几下，位置比此前更集中，但光线已不够看清细处。郁澄将范围记下，不把尚未确认的物件写成声源。有人嫌到这里还不动手太拖沓，费泊叫他看清脚边凸起，提醒拆找与听声不是同一种风险。

离开前，众人确认了下次便于查看的位置，清掉外侧容易绊脚的杂物，未在暗处拆卸任何东西。童沛走出一段又停下来，想听是否还响，郁澄请他往路边站，别挡着后面的人。细密的声音夹在风中，暂时仍跟着他们，却已经不再像从整座架房四面八方涌来，只留下一小处需要在明处验证的范围。

# 第八十四章 铁边碰上墙钉

光线足够后，费泊从南坳架房外侧查看昨夜圈出的范围。童沛站在不挡路的位置，照郁澄的要求听响，见费泊停在一处便想凑近，被提醒先留出观察空间。附近有风拂过，细碎的响动又出现，费泊这次能同时看清声音出现时的动作，立即叫大家先不要说话。

松动的铁网边缘被风吹向墙钉，碰撞时发出细密的轻响；南坳架房夜间听到的声音，来源就是这一处。费泊暂时稳住那段边缘，声音随之停下，松开后又随着风重新出现。郁澄把这个经过记清，将原来来源待查的记录标为已经查明。童沛终于凑近看了一眼，随即退回原处，免得自己站过去挡风，影响大家核对。

“这么小一段，绕着听了那么久。”旁边有人说。

费泊没有拿这句话当作可以随便处理的理由。他先让人避开边缘，确认眼前可以安全接触的位置，再检查怎样让它不继续摆动。有人想直接用手将铁网往墙上一压，他叫停，说明还得考虑固定后是否留下刮人的地方。郁澄在旁安排待用材料，将确定的原因与尚未完成的处理分开记录。

查看结束，大家没有再向屋内猜测，也没有拆动与声响无关的部分。童沛收好地上临时放开的东西，给下一步维修留下干净落脚处。风又吹过来，众人都看向同一小段，不再各指一方。郁澄合起已经补全的记录，告诉等消息的居民原因找到了，接下来还要把眼前的细部妥当处理，别把查明当成所有工作已经做完。

# 第八十五章 垫片没能一次放平

处理铁网旁的垫片时，费泊将待用的普通小件摆在布上，先确认周围没有过路的人会碰到。黎弦以为只要换上新的便行，刚比到位置，就发现一边贴实，另一边却翘着。他想加力压平，费泊让他退开看整体，别把眼前不服帖的原因藏到更紧的受力里面。

两人重新放松位置，清掉夹住的细屑，再试着贴合。童沛在旁边等着接不再使用的部分，等久了便打算将散开的工具先收走，差点把还需要的一件也放进筐里。费泊叫他停下，请他先问清哪些可以收，不要为了让地面整齐就打断正在确认的步骤。童沛放回工具，自己换到不妨碍两人转身的位置。

“原以为只是换一小片。”黎弦低声说。

费泊让他把已经看见的不平处再指出来。黎弦这次从侧面观察，找到了需要调整的方向，按要求慢慢试放，直到边缘都落稳。费泊检查过后，才继续固定。郁澄在远一点的地方听居民说明附近的通行感受，没有让围看的人挤在他们背后催问，等操作告一段落才过来确认是否需要清出更多空间。

收尾时，旧小件与废屑被分开，童沛逐一查看布角，没让硬边卷在里面刺伤拿布的人。黎弦擦净手，将还要用的工具摆到费泊看得见的地方。外侧的地面重新露出来，几个人试着按日常走法经过，没有被临时堆物绊住。郁澄把待办里这一小项划清，又回头看一眼墙边，才跟着众人离开狭窄的位置。

# 第八十六章 椅子占去的半步

为首次开放准备的临时座椅摆到路边，乍看很整齐，走过去却不方便。童沛把椅背全朝向同一边，端东西的人一转身，胳膊就容易擦到外侧那只。杜葵试着走了一遍，没说一句该不该这样摆，只停在卡住的地方，请他带着同样宽的东西从旁边过。

童沛刚走到就明白了，伸手想将所有椅子推得更靠里，坐着的居民却提出，起身时又没有地方放脚。郁澄让大家先各坐一坐，看等待、起身、经过这几种动作会怎样交错。有人坐下很快，站起来却需要扶稳，椅子若挨得太近，旁边的人就不得不也跟着挪动。原来整齐的一排被拆成几处，小小的空隙反而成了讨论最多的地方。

“别全给站着看的人占了。”一名居民提醒。

江穗在示意上记下需要留给休息的区域，又请站在外侧的人退开试走。岑望检查座椅本身是否稳妥，不让外观摆得漂亮掩过摇晃的问题。一只临时椅脚落在不平处，大家换到相对稳的地面，仍需稍作调整才可坐。童沛搬得额头冒汗，终于不再一味追求所有椅背齐成一道线。

收拾完，杜葵再次端着空物件经过，没有绕得像先前那样别扭。坐着的居民也能自己起身，让后面的人接着试坐。郁澄提醒正式使用时还要看人群怎样分布，今天的摆法不必当成永远不改的样子。童沛将一把多余的小凳收走，回头看那些错开的座椅，伸手比了比空出的半步，笑说这次最有用的恰好是没放东西的地方。

# 第八十七章 在地上重新做一遍

鲍新参加复训时，周围没有催他上桥的队伍，只有在地面布置好的练习位置。费泊先请他独自说出开始前要确认哪些事情，自己站在侧边听，不替他补漏。鲍新开头说得很快，讲到中间忽然停住，显然想起自己有一项顺序没说清，便主动从那里重新解释。

练习并不因他说全就结束。费泊让他照实际动作做，旁边的人模拟来问一个无关的问题。鲍新回答时手上停了，回来却差点从中途接着走，漏掉确认刚才停在哪里。费泊让他当场停下，问他能不能明确指出哪些已经做过。鲍新脸色发红，承认靠嘴上记熟与被打断后仍能核对，并不是一回事。

“这次我自己重来。”他说。

他没有让围看的人安静得像什么都不会发生，而是请他们照平常的方式来往。有人从旁经过，他先让开；有人询问，他把当前步骤停在清楚的位置，答完再核对接续。费泊观察完一轮，指出仍需要练习的地方，没有因为这次态度认真就给他提前确认。童沛在外侧收拾散物，也没有用鼓励的话催着尽快结束。

练到最后，鲍新手里的动作慢了些，出错后却能说清错在何处。他将需要再练的部分记下，主动清掉地面的临时物件，等费泊确认可以收才收。远处有人在检修桥附近招呼同伴，他听见声音抬头看了一眼，随即低头继续叠布。今天的练习停在地面，未完成的部分留得明确，没有被一次较顺的表现悄悄略过去。

# 第八十八章 最后一轮没人提醒

最后一轮复训开始前，鲍新主动把周围的落脚处检查了一遍。地面练习区比先前少了些提示，他伸手去找熟悉的标记，发现不在，便停下来重新确认位置。费泊站得更远，让旁边的人也别在他犹豫时用手势暗示。童沛想点头鼓励，被郁澄轻声提醒后，将抬起的手放下了。

有人带着空筐从旁经过，筐沿擦到一块垂布，鲍新按下想立刻帮忙的动作，先将自己正在做的事停妥，再给对方让路。回来后，他逐项核对，不凭感觉认为刚才已经做过。费泊在纸上记录，始终没有替他报下一步。鲍新额角出了汗，也没有为了赶在别人失去耐心前迅速结束，确认完才继续。

“如果这里看不清，我就先停。”他在一处说。

费泊请他说明需要谁来确认、自己不能凭什么继续，鲍新逐一回答，没有将不确定的部分包装成自己有把握。接下来的动作完成后，他等现场核对，不径直收东西去做别的事。旁边的居民看得安静，有人觉得这样似乎过于慢，童沛便指向已经少了反复返工的地面，没再用几句催促打乱过程。

这一轮结束，费泊告诉他记录还要完整核对，结果会明确交代。鲍新应下，先处理自己留下的纸与布，再退到外侧休息。郁澄将围看者引开，给后面的工作腾出位置。鲍新坐了一会儿，抹去手心的汗，起身帮童沛搬走一个空筐。他沿地面绕过练习区，脚步平常，没有在结果尚未公布时先朝检修桥走去。

# 第八十九章 接到明确的答复

复训记录核对完成，鲍新被叫到桌边听结果。他先问还有没有需要补做的地方，费泊让他听完，不必急着将所有话都接成新的练习。旁边的人将记录展开，按实际完成的内容说明，涉及中途受干扰的部分也没有略去，鲍新站着听，手指轻轻按住裤边。

核对结论明确之后，鲍新复训合格，检修桥通行资格恢复。他道了声知道，没有立即转身去桥上证明自己。费泊请他先把当天实际安排说清，只有需要去的工作才按流程准备，不因拿到答复就随意走一圈。鲍新看过安排，指出自己眼前要做的仍有一部分在地面，便先到外面将待用物件分好。

童沛迎面走来，问：“这下能松口气了吧？”鲍新笑了笑，说现在最想把手上的一堆东西摆得不挡路。童沛听他这么答，也没有再起哄，接过旁边需要挪动的空筐，两人一同清出通道。费泊随后来确认准备事项，鲍新把几处需要问清的地方直接说出，没有怕显得自己还不够熟练就含糊带过。

到真正按安排行动时，他在入口停下完成确认，等前面的人示意后才继续，没有与后面的人抢着挤。郁澄在较远的地方记录现场安排，看见一行人稳稳接上各自的位置，便回到桌边处理别的反馈。鲍新没有被大家围着夸奖，午后仍要做许多平常的清理；他落到地面收拾物件时，先看看旁人从哪里经过，再决定自己站在哪一侧。

# 第九十章 拐角不能只看最快的人

检验居民经过拐角的情形时，最先试走的人几步就到了另一侧。有人拍手说这段已经没问题，岑望却请他稍等，让步子较小的居民也试一遍。后者走到弯中停了一下，先看扶手，再挪脚，后面的人若照刚才的快步跟上，立即就会贴得太近。

江穗将起步的位置稍作分开，请两种速度的人照自己自然的节奏走，不必为配合测试故意赶快。郁澄站在出口问他们何时感到身后有人催，得到的回答并不都是最窄处。有居民说，一听后面脚步急，哪怕前方还宽，自己也想赶紧让出去。童沛在旁试着跟走，发现自己无意中越靠越近，忙退开一点。

“我没开口催，也会让人觉得在催？”他问。

那位居民点头，解释脚步贴近时很难判断还有多少余地。岑望将观察范围从拐角中间延到进入之前，安排人在允许的通道内再试一次。大家这回刻意保持前后间隔，不用喊话控制每一步，慢行者也能完成自己的转身。费泊在需要的地方查看扶手，没因走得快的人通过就省去别人的感受。

结束时，纸上没有一个代表所有人的速度。江穗把需要提前放缓的位置指清，请参与者确认是否与实际相符。童沛收拾暂放在旁边的物件，转过弯时下意识回头看了身后的人，随后又把注意力放回自己的脚下，给前面留出余地。郁澄将最后一条反馈读回，慢行居民听完点头，终于不用在离开之前再补一句自己并非故意磨蹭。

# 第九十一章 同一块牌再擦一遍

连稷整理完旁边的旧物，又将同一块灰瓷纪念牌放到软布上擦拭。表面落了些新灰，围看的人不多，他便请帮手先稳住桌角，自己用布沿边缘轻轻走过。有人建议趁这次加上一点新的说明，连稷让那人另用纸写，不要把清洁与改动牌面混在一件事里。

湿布经过，原有刻痕渐渐显出。灰瓷纪念牌正面原刻的字是六个。连稷只清去浮灰，没有重刻任何部分，也没有换成另一块牌。帮手低头想看得更清楚，衣袖却碰到桌边的水，险些将湿痕带到软布底下。连稷叫他先擦净袖口，等桌面干了再靠近，不必为了看字把整个支撑弄得湿滑。

“我站远一点，你转给我看就行。”帮手说。

连稷按他的话将牌缓缓转向有光的一侧，仍不立起来冒险倚放。两人一处处检查是否还有灰屑，并未把颜色深浅当成需要补新的依据。童沛经过时想将另一件杂物暂放桌上，见牌正占着安全的位置便收回手，绕到旁边找空处，没有叫人为了自己的方便仓促挪开。

擦完以后，连稷将布边的细粒抖到待清扫处，重新确认牌下没有硌着的东西。帮手去倒水，回来时桌边只剩柔和的湿光，没有新添的痕迹。连稷请他把拿走的空物件放稳，给后来者留清楚哪一块地方不能随手堆料。门外有居民经过，探头看了一眼便继续走，牌静静留在整理好的位置，清理的工作到这里收了手。

# 第九十二章 声音走不过人群

陶汀试验开放通知的声响，先站在入口附近，请几个人分别到转弯处与等候处听。她一发声，最近的人立刻应了，远处的人却毫无反应。童沛跑去询问，才知道那边正好有人说话，声音全被盖住。陶汀将手里的普通试响材料放下，没有凭近处听见就认定能通知所有人。

郁澄请大家照平常状态交谈，再作比较，别一听要测试就突然安静。这样一来，几种原本觉得清楚的响动都显得不够明确，有的与做工声混在一起，有的虽能听见，却让居民不知道是在叫谁。陶汀把这些反馈分开记，问听的人会不会因声音突然响起就急着往入口挤，免得通知清楚了，动作却乱了。

“听见和知道该做什么，不是一回事。”岑望说。

几个人便把说明也一并试，先告诉等候者听到正式通知以后按原安排行动，不要抢先占位。费泊在外侧观察队伍有没有因此收拢得太快，童沛则来回传递远处的反馈。这些往返让人疲惫，一位居民嫌试得太多，准备先走，陶汀请他把最后一次听见的位置指出，再让他离开，没有硬拉着凑人数。

到收尾，现场缩小了需要继续确认的范围，却还没对外发出开门通知。陶汀将试用物收在桌边，告诉后来的人眼下只是测试，避免听到零碎响动就以为已经开放。郁澄把待确定的通知方式列清，和等候安排放在一起。人群散开后，童沛又沿刚才跑过的路线走了一遍，确认外侧仍能留给临时需要休息的人，不必全站在最响的位置。

# 第九十三章 檐下响起的木声

通知方式确认时，陶汀先到等候处，将该听什么、听见后怎样行动向居民讲清。有人问：“是不是越响越好？”岑望请他看看旁边准备休息的人，提醒通知不能变成催着所有人立刻动起来。郁澄让远处的居民也走到能听明白说明的位置，再分散回实际可能站的地方。

开门前的通知由陶汀敲击悬在檐下的木板发出。陶汀抬手试敲，让各处的人确认这一种声音；这次只演示通知，并不在此时开门。童沛沿外侧询问，听见的人便举手示意，尚未分辨清的当面说明。陶汀等反馈传回，再调整自己站的位置，没有额外约定一串容易与杂声混淆的节奏，让大家只记眼前已经确认的方式。

有人听到木声就向入口迈步，被郁澄请回原先的位置。那人笑着说自己太想试路，随后认真听完说明，答应不拿演示当正式通知。杜葵从旁端过空物件，请围看的人留出通过的余地，陶汀等她走过才继续核对。通知准备与日常活动相互让开，没有为求一次齐整的回应把所有人都堵在檐下。

确认结束，陶汀将演示停住，请大家照原安排做各自的准备。童沛回来报告最后一处反馈，郁澄把需要现场继续留意的人群位置记下，不把听见声音便等同于整个开放流程已经完成。檐下重归安静，木板随着一阵微风轻轻动了一下，没有发出新的通知。居民陆续散去，入口前的空地仍留着，等待真正轮到它使用的时候。

# 第九十四章 从门外接近地板

南坳架房维修间地板的最后一轮加固开始时，费泊先确认能从外侧安全操作的范围，再叫搬料的人靠近。门前的阻拦仍在，没有谁为了图近直接踏到里面。黎弦站在外侧稳固处帮忙辨认位置，按费泊要求递送普通材料，手伸不到的地方便停下来，不用跨进门内补那一点距离。

一件材料送到中途，方向不合，只能重新收回。童沛以为绕到门里便容易转，刚提出这个想法就被费泊否定。费泊请他把外侧的东西清开，给安全转向留出余地，宁可多搬一回，也不让人站到尚未完成检查的地面。郁澄帮忙疏开围看者，让他们从远一点的地方看进展，不要把操作空间挤没。

“差最后这一点，反倒最不好送。”童沛抱怨。

黎弦看着实际朝向，在普通草纸上比出转动所需的空处，请费泊确认后再安排。几个人按确认过的方式从外侧调整，材料终于到了能够操作的位置。费泊逐处处理，不因送进去费劲就省略固定后的查看。等手上工作告一段落，大家仍从外侧收回工具，没有把施工中的一步完成当作可以在里面自由走动。

天色变化时，费泊让这一轮停在能够明确检查的状态，留下后续核对事项。童沛清点送入与收回的物件，确认没有零散东西落在门前容易绊人的位置。郁澄问围观居民是否看清仍需等待的部分，将他们的问题记下。外侧通道恢复了空净，门内的地板看着已完整许多，阻拦却没有被移开，费泊检查好位置才最后离开。

# 第九十五章 废料从外侧出来

清走废料时，居民站在南坳架房维修间外侧监督，费泊先说明怎样确认没有把待用的材料一并拿走。童沛将接料的地方铺好，才发现铺布的位置挡着旁边通道，只得重新挪开。鲍新帮他从稳固地面接应，所有人在已经确认安全的外侧活动，没有借清扫的名义走入门内。

第一批废料移出，一位居民指着其中一块说看着还能用。费泊请他先别伸手去捡，等落稳后再看，免得急着保留东西反而被边角划到。材料放到平处，大家分清哪些需要再查，哪些已经确认废弃。黎弦在外侧帮着对照，不为让清理进度显得快，就将有疑问的也送到同一堆里。

“里面那一点，我进去扫出来更快。”有人说。

费泊明确让他留在外面，先利用已检查的外侧操作条件收取，够不到的部分等按程序处理，不能以一点废屑为由提前踩进去。那人收住脚，转而帮童沛整理接出的东西。围看者也退开，给长物转向留出足够空间，原先挤在门边的肩膀不再阻挡操作者的视线。

清到最后，外侧地面却比开始更脏。童沛一度想等明天再扫，见居民已经按需要分好了最后一堆，便拿起扫帚，把大家要踩的路先清出。鲍新收拢布角，检查有没有裹住尖硬的小件。费泊将仍待最终检查的部分交代清楚，门前的阻拦照样放稳。众人沿干净的外侧离开，没有留下谁已经在里面随意走过的脚印。

# 第九十六章 阻拦移开以后

最终检查时，费泊与负责确认的人先从外侧核对已完成的修理，确认可以安全进入检查后，才按限定的步骤查看内部。等地板、接合处与收尾部分全部得到确认，门口等候的人才被叫近听结果。童沛手上还拿着待收的布，没有抢在结论说完前把它塞进屋内，郁澄也请围观者留出能转身的位置。

南坳架房维修间的地板已经修好，检查通过后解除封闭。费泊把门前阻拦移开，先将需要用的东西按轻重与位置安排好，再让帮忙者依次进出。童沛跟着搬入一件普通物料，落下时习惯性地回头找后面的人，发现自己若站在门口不走，仍会挡住接下来的动作，便立即挪到一侧。

“屋里能用，也不能乱塞。”费泊提醒。

黎弦将待处理的部分摆到指定位置，确认桌边留得出人的手肘，才接着取下一件。有人想趁人多把所有东西一口气搬回，郁澄请他先看清哪些确实要用，不要重新把整理过的通道堆满。众人分开动作，屋内逐渐有了忙碌的声音，地面却没有马上被箱角与散物盖住。

第一轮整理结束，费泊从门边到工作处走了一遍，检查人转身时会不会碰到未放稳的东西。童沛将外侧空布收走，留下路面清楚可见。几位一直等结果的居民看过后离开，有人顺手扶了一下门边，让搬东西的人过去。郁澄将确认后的情况记下，纸上的一项等待终于可以收住，屋里的工作接着开始，没有用热闹代替每件东西落稳的位置。

# 第九十七章 门朝哪一边开

为未开放段设门时，费泊站在已经确认可作业的一侧，让人先把门框试放，不要急着固定。第一种开法会占住旁边的停步处，居民走到门前若需转身，便容易与打开的门扇碰在一起。童沛替大家比画，空着手还觉得够宽，背上空篓再试，篓沿立刻碰到了示意的位置。

江穗把这一下记在草图边，请另一名身形不同的居民也从安全一侧走近。对方没有碰到，却说一站在这里就想往尚未开放的方向探看。郁澄说明门应让边界一眼可见，不把没开放的地方装点得像正邀请人过去。于是大家重新调整朝向与说明的位置，所有试动作都停在已允许的范围内，没有跨门去试里面好不好走。

“门是拦住脚，还是让人先看懂？”有人问。

郁澄说两件事都得做到，费泊便请大家别只看门扇能不能合，连经过时最先看见什么也一起试。童沛往后退到来路的位置，发现原本清楚的一处说明被人群挡住，招呼他们散开再看。岑望核对需要留下的余地，等各项确认后才让安装继续，不把今天定了朝向说成未开放段已经具备通行条件。

门安好以后，费泊逐处检查，郁澄试着从安全一侧合拢，再走回居民来时的方向看。门前可以停下，也留得出回身的地方。童沛收走最后的边料，提醒围看的人别把工具留在门脚。有人朝门后望了一眼，问还要等多久，郁澄说要按后续检查的结果安排，没有给一个只是为了让人高兴的日期。

# 第九十八章 先让慢脚步试过

试运行先安排行动较慢的居民通过，正式开放还没有开始。有人担心这会让整段走得很慢，郁澄请他先看清今天的目的：让平常容易被催的人照自己的节奏走，才能发现边缘与停步处是否够用。童沛将等候的人引到外侧，不让他们围着入口一齐朝里望，给先走者留些从容。

最前面的居民走过一小段便停下，后面的人也跟着收住。没有催促声，他才抬手调整随身的东西，再慢慢继续。岑望在允许的范围旁观察，发现有一处停顿会影响后来的人看清转向，便让江穗记下，等这一批走完再处理，没在有人正经过时突然搬动身边的物件。

“原来不急着让，我也能过去。”那位居民走出来时说。

杜葵递来清水，问他在哪儿最想坐一坐。对方指的位置与先前预想稍有不同，童沛便将临时座椅的安排重新标记，等待核对后再挪。费泊检查试走期间有人接触过的部位，确认没有因用法不同出现新的问题。郁澄听完反馈，没有将一句好走当作免除其他检查的理由，继续问不舒服的细处。

试运行结束，所有人按原路或已安排的出口返回，没有越过未开放段的门。江穗把需要调整的地方列清，岑望接着确认哪些要在正式开放前处理。童沛搬走临时占位物，让路面恢复清楚。慢行的居民坐在外侧歇脚，旁边的人没有替他说自己已经走累了，而是等他开口，再一同商量首日如何让需要停顿的人得到足够余地。

# 第九十九章 等开门的人不只等路

正式开放前，居民陆续来到等候处，最先到的人站得离入口很近，后来者便不自觉围在他身后。童沛照安排将大家疏开，请愿意坐下的人先到椅边休息，别把等待变成一场谁站得更靠前的比赛。有人说自己不累，却看见身旁的人难以转身，便主动往外退了一步。

郁澄走过来听他们闲聊，话题已经不全是今天能不能走。有人问以后带东西经过是否还会有人帮忙，有人担心需要休息时占着位置惹人烦。她没有承诺随时都有人照顾，只把这些实际需求记下，说明开放以后仍要继续收集反馈。杜葵在旁提醒，自己需要什么要尽量讲清，别人不能只看一眼就猜准。

“那今天也能说不好走？”一名居民问。

郁澄点头，让他记住具体在哪儿、做什么动作时不便，回来就讲。江穗带着通行图给等候者看，强调仅有已确认的部分会开放，门后的范围仍要等待。费泊与岑望在另一侧完成开放前的核对，陶汀守着通知安排，没有因为人群越聚越多就提前发出信号。童沛绕到外围，确认后来的人也能听见说明，不必挤入中间问话。

等候中有人谈起这一路多次返工，语气不再只剩抱怨，也仍记得其中的辛苦。郁澄站了一会儿，听他们互相指出现在能在哪里错身、在哪里停步，没有替全体居民说大家终于满意。风掠过入口，纸角轻轻翻动。人群渐渐安静，却不是都屏住呼吸，而是各自站稳，给即将先行的人留出一条看得清的路。

# 第一百章 门外仍有一块空地

开放安排得到最终确认，首批居民按说明进入已经验收的路段。郁澄跟在不妨碍通行的位置，看前面的人怎样停、怎样让，手边的记录纸没有因为今天值得高兴就收起来。童沛留意入口，不让后来者追得太近。最先走出的居民回头看了一眼，有人笑着招手，有人只顾低头确认脚下，动作各有自己的节奏。

转过弯时，一只篓子靠得稍外，旁边的人提前让开，没有再等碰到肩膀才道歉。郁澄记下需要继续观察的位置，也听见居民谈起仍不够顺手的地方。她让对方等走完再说细些，别为了向自己解释而堵住转角。江穗站在另一处接应，将想问图的人引到宽一点的位置，费泊则关注实际接触的部位，没有跟着人群一路忙于道贺。

“这边就是尽头了吗？”走在前面的居民望向那扇门。

岑望说明眼下开放的范围到此为止，门后仍需后续工作。有人失望地叹气，也有人说今天先能安稳走完这一段已经难得。郁澄没有把两种话折成一个统一的评价，分别记住，准备听完他们完整的使用意见。还有一些未回答的事留在记录中，不因为脚下出现了可走的路，就被一并宣布解决。

等最后一位首批居民走完开放段，童沛确认没有人落在转弯处，杜葵招呼需要歇脚的人慢慢来。郁澄来到边界前，看了一眼门框与脚下留出的空处，把未开放段的门合上。门没有隔断身后的谈话，大家仍在说下一回希望怎样走。她转过身，与众人一起停在门外，留出那块可以回头、可以问话、也可以暂时不往前走的地方。

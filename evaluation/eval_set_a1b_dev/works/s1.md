# 第一章 腾出的一层

门推到一半便卡住了。施荻蹲下去，从门底抽出一小团被压平的包装纸，纸上拖着潮气，边缘粘住一根草。她没有马上扔掉，而是把它展在掌心，看看还能不能裁出一块端正的角。滕简在门外抱着一叠捐来的纸，等得胳膊发酸，问她是不是连这样的碎片也要救。

“先让你进来。”施荻侧身让开，抬脚抵住门。佟莎已经擦过桌子，湿布留下的水纹还没有干，她便把纸暂时垫在两把椅子之间。三个人沿着桌沿站了一会儿，谁都不愿意把头一批材料放在潮面上，仿佛一开始放错位置，后面的事情也会跟着乱。

架上堆着几卷空了的包装芯，施荻伸手抱下来，灰落得她打了个喷嚏。她挪开下面的小凳，拿干布擦净木条。施荻把待裁的纸统一放在北墙架上。原先分开的几叠有了去处，桌面顿时显得很宽，佟莎这才把晾干的布折起来，搭到窗外的细杆上。

滕简抽出最上面一张，纸边有一道斜口。他用指腹沿着缺口摸过去，没有急着裁。“要是不把它做成一样大，能不能也算一本？”佟莎拿两张纸比在一起，让长出的那边露着，说小本可以给刚学写字的人练笔。他们在桌上排出大大小小的纸，先挑出能够互相配成一组的，再把零散的暂时搁下。外面有人探头问是否收旧作业本，施荻请对方先看看有没有写过的内容，别把私人的字句一起交进来。门终于可以完全打开了。

# 第二章 打孔之前

第二回摆开桌子时，滕简带来一块没有尖角的废木板。木板放上去有些摇，佟莎从纸堆下抽出薄片塞进空隙，又觉得太薄，换了一张对折的。滕简按了按两头，听不到撞击桌面的声音，才把要试订的几页叠好。他没有马上动手，先请施荻把窗帘往旁边束一束。

光沿着桌上的纸边移过来。施荻站在他左侧，把准备好的工具递到他手边，见他没有接，便以为他在犹豫。滕简转了转身，让工具落在自己看得见的位置。滕简生来左眼失明。他习惯先摸清纸叠的边，再用右眼看准标记，别人突然从另一侧递东西，反而会打乱他的节奏。

“放下就行，别悬着等我。”他笑着说。施荻把手收回，搬过凳子，问他能不能慢一点做，让自己也学会。他便把几张纸错开，重新对齐，先在废纸上试出孔距。佟莎发现靠边的地方容易裂，拿起一张失败的样纸，指给他们看那道已经长到纸外的豁口。

三个人把废纸又向里挪了少许。工具落下时，施荻扶住木板，佟莎按住另一边，孔终于干净地穿了过去。她们谁都没说这就算成功，只是凑近看纸背有没有翻起毛刺。滕简把其中一页轻轻弯起，纸没有顺着孔裂开，他才松开一直绷着的肩膀。窗外有人晾被单，忽然遮住一片光，桌边的人便停下手，等那块摇晃的阴影慢慢过去，再做下一张。

# 第三章 松紧之间

佟莎带来几个已经穿好孔的小纸叠，往桌上一放，其中一叠便歪了。施荻用手去扶，佟莎却让她先别动，说歪着的时候最容易看出哪里没对齐。滕简在旁边把散开的页角推回来，推得太用力，最下方又探出一截。他们笑了起来，重新把纸轻轻磕在平整的桌面上。

施荻原本想把线拉得很紧，觉得这样才结实。佟莎从她手里接过半成品，摊开时纸页弓了起来，中间像压着一条不肯伸直的小脊梁。佟莎用棉线缝合练习本的书脊。她把针从预先打好的孔里穿过去，留出足够让纸页翻动的余量，再请施荻看同样的一本怎样才能自然躺平。

“结实和勒住，是两回事。”佟莎说完，拆掉刚才过紧的那一小段。施荻接过线，慢慢抽回去，怕自己一急又把纸边撕坏。滕简拿废纸折成夹片，垫在被反复穿过的地方，帮她稳住孔口。外面有小孩跑过，脚步把窗下的尘土带起来，施荻忙伸手遮住刚摊开的页。

他们做出一本能平放的练习本，三个人依次翻过去，看看哪一页还会拱起来。滕简用手掌压着一侧，说写字时至少不用再找块石头按住它。施荻想在封面画花，又怕领本的人有自己的主意，最后只抹掉一个手指留下的浅灰印。收拾桌子时，佟莎把断线和能继续用的短线分开，不让它们混在一起。那本没有花的练习本留在桌中央，翻开的两页承着窗光，谁也没急着把它合上。

# 第四章 先来的人

纸窗室门口挤着两个人，一人说自己早就站过一会儿，只是出去取了袋子，另一人把脚边的菜筐挪开，露出一直没离开的地方。他们声音都不大，却越说越急。施荻抱着练习本走到门边，没敢先递给任何一方，回头望向桌后，希望有人能帮忙把事情说清楚。

佟莎没有马上劝谁大度。她请两个人各自把经过讲完，又问门边帮忙搬凳的人是否一直在场。那人说自己只看见后半段，不能替谁证明先后。滕简把堵住门的空纸袋收进去，至少先让其他人有地方站。当天分发练习本的顺序按领取者到达的先后决定。争议不在本子够不够，而在刚说好的顺序能不能被认真对待。

“我不想多领，我只是怕白等。”提菜筐的人说。另一个人听见这句话，声音低了一些，承认自己取袋子去了挺久。他问能不能先让一直在的人领，自己接着等。施荻把本子递过去时，特意让对方检查线头，有不平的页现在就能换，不必拿回去凑合。

人群松开了，门外终于露出一小块空地。佟莎把凳子转了个方向，请等得累的人坐下，坐着也不会失去顺序。有人以为小本就是做坏的大本，滕简便打开两种尺寸，让他们自己看看，选择合手的那种。最后先来的那个人装好了本子，却没有立刻走，站在窗边替后面的人扶住被风吹动的门。施荻从屋里抬头，发现那只菜筐已经被挪到不挡路的墙边，筐口盖着一张干净的纸。

# 第五章 门上的空白

施荻把一张空白纸举到门上，比了比高低。佟莎站远一些，说现在的位置会被开门的人遮住；挪得太高，又有人看不清。他们试了几处，终于把纸搁在窗内，先不固定，等外面的人走过时看看是否容易注意。滕简从桌后绕出来，提醒他们还没有商量好上面究竟写什么。

有来领本的人希望屋子天天开着，放学之后就能进来坐一会儿。施荻听着没有立刻答应，她把剩下的材料数了数，又看向需要收拾的桌面。纸窗室每周只在周六开放。三个人各有日常事务，能共同抽出的只有这一段时间，不能因为一时高兴，就把没人能够兑现的安排贴到窗上。

“那别写随时欢迎。”佟莎说。她把准备好的笔搁下，先让施荻用口头的话讲一遍，看看有没有让人误解的地方。滕简提出，说明来这里做什么也很要紧，不然有人可能以为这里可以代写作业。他们没有笑那种误会，只觉得门上的字要替还没见过他们的人回答最先遇到的问题。

窗外的人听完，说清楚一些反而方便安排。有人愿意把可用的空白纸留到下一回送来，施荻请他把写过字的页先分开。佟莎重新拿起笔，写了几下又停住，嫌自己的字太挤，换了宽些的纸。先前比位置的那张并没有扔掉，翻过面还能当试写纸。临走前，他们从门外回看了一次，玻璃上有一点反光，滕简伸手遮住光，施荻则把纸往里面移了移，让字终于露得清楚。

# 第六章 箱盖轻合

桌面上的练习本少了，屋里却比刚开门时更乱。剪下的纸边贴在椅脚旁，几根短线绕在木板的毛刺上，施荻弯腰捡起一片，又发现下面压着另一片。佟莎请她先坐一会儿，把一杯温水推过去，自己沿着桌边把能再用的材料拣出来，免得一着急全扫进废纸袋。

滕简去搬收纳用的箱子，箱底落了一层灰，他把它抬到门外擦净，再拿回来试大小。施荻将最后几本翻开检查，发现一页夹着极短的线头，便用指尖轻轻拈出去。封好的练习本最后装进了藤箱。佟莎在箱底垫好清洁的纸，不把它们压得太满，留出能伸手取放的空间。

“先别盖，我再看看有没有漏的。”施荻从窗台拿下一本小的，刚才试摆告示时忘在那里了。她把小本放进去，又停下来，问要不要留一本给下次来帮忙的人看做法。滕简觉得现场示范比摆成品更明白，佟莎则说可以把做坏的样纸留下，让人看见错在哪里。他们最终把那叠裂了孔的废样另外包好，放在容易拿到的桌角。

门外的光慢慢斜了，纸页上清晰的边线柔和下来。施荻收起湿布，确认它不会碰到新本子；滕简绕着桌子走了一圈，把突出的椅脚推回去。佟莎试着合上箱盖，没有使劲压，盖子便稳稳落下。三个人站在空出大半的屋里，竟有些不习惯。施荻伸手扶住门，让他们先出去，回头又看了一眼那张留给下次使用的桌子，才把自己的脚步从门槛上移开。

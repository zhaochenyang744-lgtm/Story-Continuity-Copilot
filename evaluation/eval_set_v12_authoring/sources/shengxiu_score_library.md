# 第一章 捐赠人与搬运者

2032年5月8日14点，笙岫谱馆确认《回苇谱》的捐赠人是澄逖。册子由牧昀代为搬运，但牧昀没有捐赠这部谱册，也没有以自己的名义申报捐赠。馆员把两人的角色分别写在交接页上，附在谱册的保护套里。

# 第二章 桂绎的判断

2032年5月8日14点，桂绎相信《回苇谱》的银线封面是原制品，并不相信它是后配的复制品。鉴定员已经查明封面属于后配复制品，但尚未把结果交给桂绎。她仍按原来的判断，替封面选择柔软的衬布。

# 第三章 展开的摹本

2032年5月8日11点，牧昀把《浅涧调》的摹本展开在宽桌中央，并用两条布带轻轻压住上下边缘。旁边的人移走了茶杯，留出可以并排看两页的地方；他没有在摹本上添加任何新的标记。

# 第四章 阅览证与修订页

唐蒻持有可以进入笙岫谱馆阅览室的证件。《栎声录》的修订页放在阅览室内，向持证读者开放。现存资料没有记下唐蒻是否进过该室，也没有借阅记录或目击者确认她看过那张修订页。

# 第五章 两卷相同的藏印

《迟潮引》和《覆苹曲》各盖有同样的朱色藏印，印面只有图案，没有姓名。谱馆还没找到印主登记册，旧时也有人把同样的印模送给多位藏友。现存交接页没有记录这两卷是否来自同一名捐赠者。

# 第六章 通风窗下

2032年5月8日16点，澄逖把装有吸潮纸的浅篮移到通风窗下，篮子没有贴住窗框。她在篮边留出一掌宽的空隙，让值守人还能伸手转动窗扣，然后把剩下的吸潮纸放回封袋。

# 第七章 索引里的空行

编目员翻到一页缺了下半角的旧索引，缺口正好切断了两个页码。他先用铅笔在另纸上记下待查项目，没有把相邻曲目的页码直接补上。屋外的脚步停了一会儿，来访者听见翻纸声才轻轻敲门。

# 第八章 日终的交接

桂绎离开后，鉴定员才把封面的说明放进她次日要看的文件夹，并留下一张请先阅读的纸条。值守人清点保护套，把容易滑落的布带重新卷好；馆内所有待查问题仍按各自编号留在清单上。

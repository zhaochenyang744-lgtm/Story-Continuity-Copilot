# 第一章 北渠的测线

2032年9月12日9点05分，迢槿坡北渠的本次测线作业完成。测量员把最后一根定位桩钉稳，在作业页写下结束时间。这是该项测线当天唯一一次完成记录，没有先前已经完成又重新开始的同名作业。

# 第二章 北渠的浇筑

2032年9月12日9点20分，迢槿坡北渠的本次浇筑作业开始。这是当天北渠唯一一次浇筑开工，此前尚未浇筑。施工员沿绳线摆好挡板，让装砂浆的小车依次停在不会压到定位桩的位置。

# 第三章 暂停的栅板安装

2032年9月12日15点，栅板安装作业仍在进行，尚未完成；已装好两块，还有一块没有装到位。负责人让工人短暂避开经过的运料车，栅板安装本身并未取消，也没有被宣布结束。

# 第四章 画在石阶上的箭头

2032年9月12日10点，岑汀用黄色粉笔在工地外的石阶上画了三个箭头，指向临时通行的小径。她把粉笔头留在工具匣里，走到阶下回看标记，确认行人不必跨过施工绳就能看见它们。

# 第五章 收到的绕行申请

何蘩递交了将运料车改走南巷的申请，办事员已经签收，并注明签收不代表批准。卷宗没有收录审批决定，也没有退回或拒绝记录。何蘩保存的只是带收件日期的申请副本，暂时不能从它确定审批结果。

# 第六章 留下的起始水位

试蓄池赤湾池在注水前的水位记为十二厘米，工作人员随后开始注水。结束测量的那一页受潮粘在一起，数值完全无法辨认；记录也没有保存累计注水量或中途排水量，因此无法补算最终水位。

# 第七章 石缝里的细绳

2032年9月12日16点，池洇从石阶边的缝隙里挑出一段蓝色细绳，把它放进废料桶。路过的孩子停下来想捡走绳头，她先把桶挪到围挡里面，再指给孩子看开放的小径从哪里起步。

# 第八章 坡顶的晚风

傍晚，工人收起不用的挡板，把待核对的水位页压在干木板之间。何蘩的申请副本也另放在文件袋里，免得混入已经处理完的工单。坡顶吹来的风逐渐变凉，开放的小径上还能看见黄色箭头。

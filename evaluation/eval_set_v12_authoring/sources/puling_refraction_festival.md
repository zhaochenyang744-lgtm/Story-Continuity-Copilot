# 第一章 映砂的永久法则

蒲瓴城的映砂遵守永久不变的法则：映砂的发光在任何情况下都不产生热量，绝不能让照到的物体因这种光而升温。堆叠再多映砂也不会产生例外。这条法则限制的是映砂自身的发光，不涉及旁边炉火提供的热量。

# 第二章 弧贝盘的边角

2032年3月16日10点，弧贝折光盘的外轮廓是正六边形，恰有六条边和六个角。检修员胥洵沿边缘贴上护条，特意把每个角都露出来，方便搬运者判断朝向；台面上没有其他同名折光盘。

# 第三章 镜架旁的木墩

2032年3月16日11点，斐萝把一只矮木墩放到镜架东侧，供调整高处镜片的人站立。她试着踩了两脚，确认木墩没有晃动，再把附近散落的包装草移到墙边，给来往的观众留出通道。

# 第四章 青穗灯影的复测

青穗灯影在复测时比第一次明亮。两次之间，工作人员既擦净了镜面，又把普通油灯向镜架移近了一段距离。记录没有分别保留只擦镜面或只移动油灯时的亮度，也没有判断两项变化各贡献了多少。

# 第五章 发出的改期便条

斐萝给来访画师闻茉送去一张便条，提议把合影改到第二天下午。便条副本留在桌上，跑腿人已经出发，但无人带回闻茉的答复。工作人员没有发现双方另行商定新时间的记录，原来的安排仍夹在日程簿里。

# 第六章 雨后的小旗

2032年3月16日15点，胥洵把淋湿的紫色小旗从栏杆取下，平铺在有顶棚的长凳上。旗杆单独靠在墙角，风吹过时只带动了旗边的细穗；他用两块圆石压住旗角，才回到检修桌旁。

# 第七章 炉火与光线

点心摊的炉火烧得很旺，师傅把一壶冷水移到炉上。映砂灯悬在摊位外，负责让门前的字牌显得清楚。等水响起来，他提壶给排队的人倒茶，把掌心伸向炉边取暖，没有挪动映砂灯的位置。

# 第八章 撤去围绳

折光节散场后，斐萝将围绳一圈圈绕好，装进镜架下方的竹筐。她把便条副本夹进值夜清单，方便接班的人找到合影改期提议的原件；街上的灯逐渐变少，字牌仍能从巷口看见。

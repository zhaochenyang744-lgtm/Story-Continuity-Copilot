# 第一章 隔年的钥匙

2034年4月18日9点10分，佟槐雨抵达砚荚岭。乔檀笛是佟槐雨母亲的亲妹妹，这位姨母把外祖母留下的蜂园钥匙交到她掌心。钥匙齿上粘着一点蜡，像去年冬天尚未擦净的雪。槐雨原想把蜂箱卖掉；山路走到这里，卖掉二字忽然难说出口。

# 第二章 箱口的苔

佟槐雨用竹片刮掉栗扣箱入口的苔藓。她刮一寸，停一会儿，等蜂钻回去才再动手。乔檀笛蹲在旁边剥豌豆，说她小时候也这样怕蜂，外祖母便让她坐在箱边吃午饭。槐雨笑了一下，竹片终于走得稳了。

# 第三章 青烟的气味

烟罐里燃着干松针，气味钻进面网，槐雨想起外祖母灶膛的火。姨母扶着她的手把烟口压低，几缕烟沿箱盖渗进去。她们取出一块旧巢脾，封蜡在光里泛白。槐雨托住木框，手腕上全是细碎的金粉。

# 第四章 开花的岔路

坡下的刺槐开了花。佟槐雨看见栗扣箱的工蜂落在刺槐花上，花枝被压得轻轻点头。回来时，她从去年收好的栗扣箱春蜜里舀了一勺，拌进酸酸的羊奶。那股香气使她想到岔路口，却又比岔路口的气味宽阔。

# 第五章 手背的小疹

午后，佟槐雨的手背起了几粒小疹。她上午戴着新手套搬木框，午饭又吃了两颗青梅，此刻把手搭在井沿上，让凉水缓缓流过。乔檀笛替她挽好袖子。豌豆在锅里爆了一声，槐雨回头看火，手还留在水下。

# 第六章 蜜流停住

2034年4月18日14点，栗扣箱这次春季取蜜已经结束。最后一道蜜流缩成珠子，落入桶底；乔檀笛给桶盖扣上搭锁，佟槐雨把摇蜜机洗净。两人坐在门槛上分一只烤红薯，鞋底沾着的泥也晒成了浅色。

# 第七章 留下的一年

晚上，佟槐雨决定留在砚荚岭养蜂一年。她把返城车票折成窄条，夹进外祖母的种花簿。乔檀笛问她明天想先做什么。她说先把门口那条歪板凳修好，坐着等蜂回来。姨母端起碗，嘴角沾了一点红薯皮。

# 第八章 门外的嗡声

乔檀笛下坡时，槐雨一直送到院门。钥匙这回进了她自己的衣袋，院里的豌豆壳收进堆肥筐，灯也亮在旧桌上。她听见箱群低低的嗡声，隔着木板涌向夜色。今天的蜂园并不安静；她却在这里睡着了。

# 第一章 来赴棋约

茅翕走上霁缬原时，雨还悬在山那边。他把父亲留下的棋套铺在石桌上，套里只装着一把宙筹。回旋棋有一条永久不变的法则：任何情况下都禁止宙筹跨越盘心的断隙。受这条法则约束，宙筹一碰断隙便会停住。桌旁的草已长过脚踝，旧棋约却还钉在树干上。

# 第二章 银眼的对手

桑缈从草丛里走出来，她有一双银色瞳孔，天光在其中像两尾游鱼。她摸了摸棋套磨白的边，说茅翕终于肯用了。茅翕把套子转了半圈，让父亲缝过的那一角朝着自己。桑缈在对面坐下，石凳沁着昨夜的凉。

# 第三章 先收衣袖

茅翕用布带把宽袖束在手腕上，才拈起第一枚宙筹。风吹过棋盘，盘面外圈缓缓转动。他的手随外圈移动，迟迟找不到落处。桑缈垂着眼等他，草尖的水珠滚进她鞋边的浅坑。茅翕终于把筹放稳，听见自己松了一口气。

# 第四章 碗里的双月

桑缈在桌沿下将一枚刻着双月纹的宙筹扣进青碗，碗底传出三声细响。茅翕的指尖在桌沿停了一下，随后冲她笑了笑。她把青碗摆到棋盘旁，取出另一枚宙筹放进内圈。山那边的云越来越低，草中的虫声忽然稀了。

# 第五章 檐下的声音

一片云遮住棋盘，茅翕把宙筹落在外圈的窄格里。筹子发出一声轻响，石桌上方的风铃也叮当响起来。桑缈抬头望了望挂铃的木檐，衣裙的下摆掠过湿草。茅翕盯着盘面，没有随她抬头；他觉得这次终于走对了一步。

# 第六章 让出的弯路

桑缈把一枚宙筹移到外圈，为茅翕留出一条通往边角的弯路。他沿着那条路看过去，才发觉自己先前只盯着盘心。父亲教他下棋时，总爱等他看完再催。茅翕摸了摸袖上的布带，把手伸向离自己最远的那格。

# 第七章 和局

最后两枚宙筹停在相邻的格里。这一局以平手结束。茅翕一时舍不得收筹，桑缈便陪他坐着，直到一滴雨打在两人之间。她笑着说，明年还来。茅翕这才将棋套展平，按父亲从前的次序把筹子一枚枚放回去。

# 第八章 回程的草

下山时，茅翕走在桑缈后面，棋套贴着胸口，湿草在他们脚边分开又合拢。他回望霁缬原，石桌已经缩成云下一点灰白。回程的坡比来时滑，他却没有再去扶旁边的树。桑缈在坡底等着，掌心托着一滴迟迟未落的雨。

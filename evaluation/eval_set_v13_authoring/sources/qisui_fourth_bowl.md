# 第一章 锅沿的白汽

栖燧巷终于办起了面食擂台。秋杓面馆的易苜天没亮就生火，脸上沾了两道面粉，像一只睡错地方的猫。她打算用清汤面参赛，鲁笠却坚持添一根卷曲的萝卜丝，说评审总该吃到一点有脾气的东西。

# 第二章 叩一声

2033年4月19日11点30分，秋杓面馆的梅纹汤盅是空的。易苜用指节轻叩盅壁，清脆的声音把鲁笠引了过来。他捧着刚切好的萝卜，问这只盅是否也要参加比赛。易苜笑着让他先找一条干净围裙。

# 第三章 院里忙

2033年4月19日11点45分，鲁笠在秋杓面馆后院给竹筷打蜡。筷子一根根排在晒架上，他拿自己的那双练手，弄得掌心滑溜溜的。隔墙传来邻铺磨刀的声音，他敲敲墙，讨了一块旧布擦手。

# 第四章 一锅清汤

易苜用姜丝和葱白熬秋杓面馆的清汤。火小了，她拿扇子轻轻扇；火大了，她便抽走一根柴。第一碗盛出来时，鲁笠低头闻了半天，终于把那根自称有脾气的萝卜丝放回砧板。

# 第五章 橙色座位

鲁笠把秋杓面馆门口的长凳涂成橙色，好让远处来的评审认出店门。他边涂边哼小调，刷到最后一段才发现凳腿粘了片菜叶。易苜端来第二碗面，叫他站着吃，省得给围裙再添一种颜色。

# 第六章 三个人的胃口

擂台的三位评审每人投一票。前两位尝过秋杓面馆的清汤面，都把票投给了它。坐在窗下的第三位端起隔壁摊的拌面，忽然打了个喷嚏。易苜忙递纸巾，鲁笠趁机把第三碗面端出了厨房。

# 第七章 梁下的燕子

秋杓面馆的梁下嵌着石燕瓷砖，釉面在烟气里泛着暗亮。易苜取出祖父的旧照片给鲁笠看；照片里的祖父站在灶边，身后也有这块石燕瓷砖。鲁笠把照片托在掌上，觉得那人的笑纹像锅边溢出的细水。

# 第八章 第四碗

散场的锣声响过，易苜终于给自己下了第四碗面。鲁笠坐在门槛上啃萝卜丝，说今天的橙色长凳比参赛的面还惹眼。她把碗往他那边推了推，让他尝一口。街上的人走远了，灶里的柴仍噼啪地响。

# A3 调试集

版本 `a3-1`，集合 `a3-dev`，题号前缀 `a3d-`。依据桌面任务单05和已登记的 A3 SPEC、thresholds.py，作品、资料与动作写法沿其引用的 A2/A1c/A1 规则。登记文件保持不变。本集公开可读，无注入题。

《把空拍留在桌上》是当代大学校园播客编辑部筹备毕业季声音特刊的群像作品。三十章逐章原创；第31章600–1000汉字共享草稿独立于正文。三件追踪对象分别是录音机、监听耳机和匿名身份的知情范围。起始资料故意保留旧值、遗漏和未更新的伏笔状态。

主控先登记全书设定，正文按连续五章分批写作，逐段交接人物、物件和时间后再续派。正文不使用程序、模板或句型替换批量生成；程序只保存已写定文本、原样合并章节和执行计数、引用定位、查重、结构及哈希审计。主控在正文存在后统一写题和答案；未参与正文写作的复核者完整通读，用法题另仅凭乱序 `id/input/context` 盲判。实际发现与处理见 authoring。

仓库根目录运行：

```powershell
& '..\story-continuity-copilot\.venv\Scripts\python.exe' -X utf8 -B -m evaluation.eval_set_a3_dev.check
```

也可从任意目录用该解释器运行 `check.py` 的绝对路径。检查器以自身文件位置定位，标准库、离线、只读本套；不导入产品代码或评测运行器。输出一行 JSON，错误时非零退出。`set.sha256` 按路径排序，覆盖 tasks.json、works/、materials/ 的全部文件。全部文本UTF-8无BOM、LF，.gitattributes保护字节。结构PASS和独立语义复核分别记录，不能视为模型质量或正式评测结论。

## 字段和解释口径

- 调试集使用任务单明确的8道长任务：trace2、thread_audit2、tidy1、ask2、narrowed1，另route10。scope实际4题、全书4题，同时满足任务单的3/2下限与SPEC正文的4/3下限。
- 纯汉字计U+3400–U+4DBF及U+4E00–U+9FFF，不计标题、标点、空白、阿拉伯数字。位置按引句首个汉字的一基位置，严格大于1500才算后段。全部引用次数和章号/原句去重两种口径都核对半数门槛，另沿A1c从严检查去重引用三分之一在2500字后。
- 资料、自查与索引用一基整数；动作evidence_chapters沿A2写完整章标题，不带井号。每条quote为10–60字符且在指定章节唯一逐字出现。states按章排序，跨度按最大章号减最小章号至少15计。
- 范围含端点，按事件发生章即回收章、放弃章、变化章或缺失事实依据章判归属；伏笔的种下章可以在范围之前。narrowed先为全书，开始前以plan_edit.chapters替代范围；范围外条目不能出卡。authoring/task-intents.json只记录作者冻结的题意类型，供检查器独立构造范围内完整动作集合，不是新增产品运行字段。
- trace只要求报告，allowed_actions为空，不替作者修正三个故意矛盾。ask两处是叙述定稿选择，相关题名与首播时段未进入起始事实，作者回答明确选a或b，expected_actions为空；不能把一次叙事选择擅自变成资料改动。
- tidy指登记的六处遗漏、三条过时事实；三条同义干扰已经有资料，不能再出卡。普通叙事中的每个动作不被穷尽地解释为新的缺失事实考点。动作引用采用本套自查同一原句，是冻结时的可审计选择，不新增A3的一般规则。
- selection仅writing页，从共享草稿取带句末标点的完整原句，不超过80字符。本套不用fix_issue，不附支持FIX题。also_acceptable使用最多一个元素的列表；同句组只在本套内允许同input异context异route。
- 照抄检查覆盖request、input及每条after_points，与本书全部正文比对；去非汉字后连续8字即报错，names专名作为断点，不删除后拼接两侧，不用普通短语冒充专名。
- 新颖性对获准旧tasks.json内全部input/question/request去空白和Unicode标点，保留大小写，SequenceMatcher相似度达到0.8即报错。authoring保存编写前快照及路径/字节哈希，checker只读快照，交付前另核查快照仍对应当前worktree。专名另对获准旧题集460个Markdown/JSON文件作精确扫描。
- 三个明确禁读目录在遍历前排除：eval_set_a1_reserve、eval_set_a1b_reserve、eval_set_v13_authoring。零重合结论仅覆盖获准读取的语料。未进入任何其他worktree。

# 全书设定与逐段交接

写作前登记。作品《把空拍留在桌上》，现代大学校园播客编辑部筹备毕业季声音特刊。澄络市的晏汀大学，声隙编辑部在普通课程、兼职、毕业去向与采编分歧之间完成一次公开试听。不是小镇旧行当，也不是竞技、悬疑破案或科幻。故事只持续同一学期的毕业季，不写具体公历日期，各章顺次向后；两处指定的历史回溯矛盾例外保留。标题中的“空拍”指声音中的留白节拍。

- 唐见禾，校内播客学生召集人，别名禾灯（同学说她总留最后一盏灯）。大三传媒专业学生，惯用右手。
- 许砚弥，采访和授权联络，别名弥弥。不替受访者答应公开真名。
- 陆泊弦，起初兼做终混与外采，别名弦哥；第十章正式卸下终混，专做外采。
- 庄予栖，文字授权与文件归档。
- 闻筱旻，采编，负责处理私人来电与剪辑边界。
- 江越葵，声音剪辑，第十章接手终混。
- 柏时骏，指导老师，只提供建议，无学生投票权。
- 方南汐，文字转写与字幕。
- 谢临荔，设备与借还登记。
- 郁知遐，匿名受访毕业生，匿名嘉宾本人；声音允许在限定范围试听，公开身份另行决定。
- 廖承朔，学生联络与场地沟通。
- 澄络市、晏汀大学、声隙编辑部、槐序楼（初期二层试听）、苇屏室（第八章起正式试听房间）。
- 苔点录音机、折翼监听耳机、双格样本盘。前两件为追踪物，样本盘是普通有编号的工作存储介质，不承担考点矛盾。它只保存经同意的工作样本，不当作私人文件备份。

为同时满足A1c引用写法里的三件易手物，双格样本盘另作普通剧情交接：第9章由谢临荔交给江越葵带去剪辑；第15章江越葵交给方南汐核对转写；第21章方南汐交给庄予栖归档。并非第四个追踪考点，不添加对应资料当前持有人，不制造新过时事实。盘上没有匿名嘉宾真名或私人来电，不能由此扩大匿名知情。其余章节不改变这个顺序。

不新增专名。普通物品用普通称呼。匿名嘉宾真名的知情名单只按下表增加，不在旁人面前说漏或发群消息。郁知遐可以独自与已知情者相处；不知道真名的人听到代称即可。第29章才取得对编辑部全体的介绍许可，不等于允许在公开节目里报真名。

5. 第29章：`郁知遐允许编辑部全体知道她就是匿名嘉宾，公开节目仍不报她真名。`

矛盾第一端复用第8章状态原句，第二端第26章 `周三第一次正式试听结束时，庄予栖已经知道匿名嘉宾就是郁知遐。`。第26章明确回溯第一次正式试听，与第8章穷尽名单不能共真，也与第20章才许可的叙述冲突；这是同一处知情历史矛盾，不额外当第二矛盾计。不可补私自偷听、提前授权等解释；不让庄予栖在第20章以前实际公开喊匿名者真名。“正式”用来区分第2章试录/试用房间时的一般试听，不改变设计的同一事件时间锚。

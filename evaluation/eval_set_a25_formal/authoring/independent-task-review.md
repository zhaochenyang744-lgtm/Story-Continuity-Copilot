## 编号复核结论

### C01：事实目标与变更范围

两部 action-01 和 action-04 都明确请求两项事实，金标恰好保留两项，没有遗漏其中一项，也没有借多事实请求顺带修改其他对象。其余事实题均只触及题面指定的主体和谓词。新增事实不与25条起始事实中的同谓词事实重复；change_fact 均定位原有条目，未错用新增。

w01 原件的保管、阅看和临时带出有明确区别；衔序夹交给调查助理后，不把阅看房或会谈侧室当成原件移库。段泊循以调查人身份说明，不能改成律师。w02 原盘、参考话筒、授权材料、成品包有明确区别；玩家联络人的对外权限仍限于核定内容，不能扩成独立决定答复。第18章的每三天整理意见也没有被扩大成三天内解决全部意见。

### C02：收线有正文支持，未越过结论边界

两部四条 resolve_thread 分别有第12、14、16、18章的明确解释。w01 尾端三声与中段第二轻响不是同一事件；道歉只解决当面表达及原先误会，未代表被害者或姐姐原谅。w02 迟到半句是字幕触发偏晚，原声完整；参考音在第16章通过实际播放和讨论说明是用于句间停顿的无词呼吸，未并入成品，也未擅定为角色未公开私事。只截取最后一句可能看不全解释过程，邻接上下文及第16章全文可以支撑现有收线。

### C03：两类 conditional no_evidence 均应不生成改动

1. w01-no-03：检索并阅读私函、来信、信封、寄信者相关出现段落，包含首次留线及第12、18、19、20章的继续保留。正文未指认寄信者为宓书冽的母亲，私人信仍未拆。另题的作者话新增“等姐姐回家”不应串入本题，更不能推出母亲寄信。
2. w02-no-03：检索并阅读离线测试及测试安排的相关出现段落，包括第7章初留、第19章未公开和第20章邀约。第20章“下周接着谈”“可以约一个时段”只表示继续沟通的意愿，没有确定离线测试的具体日期，故日期条件未满足。
3. w01-no-04：第12章明确解释三声为空箱经过接缝产生，与“人在门外催”的条件不符；没有因为材料中保留旧疑问就主动修成正文答案。
4. w02-no-04：第12章原声完整、字幕触发偏晚，直接反对“声优漏读”的假设；条件不满足，因此不是把旧说明更新为真实解释的授权。

前两题属于正文未述，后两题属于正文与假设相反；四题都具有明确“条件成立才改，否则不动”的限制。当前统一归入 no_evidence 合理。

### C04：已有资料、润色与删除没有误转动作

每部 no-01 均已有同义事实；no-02 均是起始资料已标回收的同一伏笔，不能重复新增或重复收线。两部 no-05 的对象是第21章选中文字，要求只涉及正文措辞。w01-no-06 明确删除事实，w02-no-06 明确整条删除伏笔；当前版本不支持该种删除，不能替换成 change_fact、edit_thread 或 abandon_thread。

### C05：直接作者话与依据正文的说明修改区别正确

两部 action-15 都由作者提供新的说明，允许没有正文引句；after_points 同时保留原有未公开内容的核心悬念。w01 保留私人信未拆、内容与复核联系待明，再补等姐姐回家；w02 保留未展示测试、涉及段落未明，再补休假后展示。两部 action-16 才是依据正文纠正起始说明中的错误因果，且都保留原内容尚未公开这一核心。没有把修改说明等同收线或新增伏笔。

### C06：放弃与新增伏笔均有足够授权或最早埋线依据

两部 action-17/18 均有作者明确“不再展开／不补”等放弃表达，正文仍未完成对应悬念，不是把已回收条目改为放弃。既有对象索引准确，after_points 只改变为已放弃，没有顺带删除说明或正文。

两部 action-13 最早的具体异常均在第7章；两部 action-14 的私留附页／未交第二句尾均在第11章。已扩展查看相关对象前后出现段落，后续没有完成解释。w02 第8章讨论用过的句尾，不等于第11章私留未交的另一种句尾；第19章谈到的公开变体也没有揭开该私留版本。四题新增对象与起始10条伏笔不同，about 和 planted_chapter 均可保留。

### C07：paraphrased 与 vague 标志

两部 action-01至13 的 paraphrased=true 均有口语概括的实际依据，未只机械复述动作类型；14至18直接说新增伏笔、补说明、按正文改说明或标放弃，false 可保留。两部 action-02/03/13 的 vague=true 均需由模糊范围或行为找到正文事实／最早线索。其余 false 的题面已明确对象、变更事项或直接给定说明内容；即便需要检索证据，也不因此自动判为 vague。没有发现标志与实际请求相反的必改项。

### C08：路由由意图及有效上下文决定

20条路由逐条核对。保存或同步资料的01至04为 change；05至07询问一致性、是否应放弃或当前保管情况，尚未直接要求修改，为 ask。每部05和08是同一句输入，08同时提供写作页第21章真实选段，形成具体检查对象，check_passage 合理；05缺少这一指定选段，维持 ask。09明确要求续写前整理现状和未收线索，为 recap；10转向现实购买建议，out_of_scope 合理。没有为凑分布改判；当前没有必须出现 fix_issue 的约束，未把一般提问硬改为该路由。

# w02 中央设定与起始资料草案

现代都市大型数字游戏本地化发行群像，题名《另一种句尾》。蒲弧市的芰序互动正在为虚构游戏《拾昼环》完成新语言版本。主题是译者署名、文字与语音版本责任、玩家理解及劳动关系，不写竞赛队伍、影视拍摄、旧行当小镇，不借用真实软件或真实企业。最终上线小范围语言包，争议仍留有个人选择，不以销量大捷结束。

物件：瑟页盘（存放获准语音的硬盘）、釉棱麦（参考录音话筒）、斛星笔（实物校样笔）。

## 章节进程

1-4组建语言版责任链、参考音与译名、字幕测试、版本编号与静音键收束。5-8独白争议、无障碍切句、旧编号查明、署名许可。9-12获准语音交接、取舍听证、笔赠与、迟到半句收线。13-16答复权限转交、署名空行、受邀试用、呼吸参考和短期续约。17-20话筒移交、按键括号说明、个体拒绝提供理由、发布后的分工。所有时间按周序推进，不给真实发布日期，不添真实技术平台。

每章2500-3500汉字，建议2800-3100，有3-4个场景，有口语对话、有关系推进。全部M/S/R/N/T原句放对应章2500汉字之后，至少>1500，同章前面有相近干扰但不提前给最终答案。自然嵌入25条稳定事实与3个别名。第21章共享草稿600-1000汉字，留两句适合检查选段的完整句子。每4章交接新增专名、物件、时间点，由主控确认后再下一批。只写正文和交接，不出题。

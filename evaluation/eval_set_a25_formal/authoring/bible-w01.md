# w01 中央设定与起始资料草案

本文是出题前确定的虚构小说设定。现代架空芥衡市的刑事再审群像，题名《证词留白处》。不对应真实国家，不引用真实法条，不写真实法律建议。主线是一起剧院后台伤害案的再审；最终证明旧鉴定错把一只箱子的碰撞声当作袭击时间，撤销原裁判并安排另行审理，不能跳成找到了真凶。注意这是个人申诉与证据责任的故事，不写城门盟誓、支付核验、考古、访客接待、旧行当小镇。

## 全部专名

人物：简迭微（辩护人，别名绛穗）、段泊循（调查助理，别名苔隅）、毕见岚（申诉人，别名柚翎）、屈绍荻（原证人，灯光师）、符砚杭（声音鉴定人）、宓书冽（检察人员）、封南缬（剧院排练统筹）、蒯令皎（被害者的姐姐）。不另添具名人物，不用姓名截短形。
地名组织：芥衡市、折榆庭（虚构法院一个审理庭）、南穗辩护所。
物件：衔序夹（案卷夹）、岬纹笔（铅笔）、叠槭牌（后台通行牌）。其他普通物件不取专名。

## 写作推进

1-4：委托、回旧证人、姐姐立场、鉴定边界与会谈室故障收线。5-8：第二陈述争议、旁听与媒体分歧、声音复演、公开许可。9-12：原件交接、会谈规则、笔的赠与、三声敲击真相。13-16：调查人出庭、证词范围、侧室会谈、当面道歉与撤回离职。17-20：通行牌封存、登记缺角找回、裁判撤销但案件未终结、各人的边界与新一轮审理准备。

每章2500-3500汉字，建议2800-3100，多个场景与具体对话，不模板扩写。全部M/S/R/N/T原句放对应章2500汉字之后（至少要>1500）；同章前段写相近干扰但不能提前给出最终结论。3个别名自然交代并提供10-60字完整引句。所有稳定事实逐章明写可核对。第21章共享草稿600-1000汉字，继续未完再审，不替未收伏笔补答案。每4章回报新增人物/物件/时间点，由主控确认后继续。不要出题或写金标。

# 第五套A2正式封存集

版本a2-2，集合a25-formal，题号前缀a25f-。依据任务13、A2 SPEC全文与补充一至七、thresholds.py，以及所引A1/A1c写法编写。补充七优先于正文中的旧规模：每部20章，34题，action18/no_action6/route10；六种动作的主要题数为4/4/4/2/2/2。每部事实25条、伏笔10条，第21章共享草稿600-1000汉字。

主控先固定中央设定和起始资料草案，作者逐章手写、每四章交接。程序仅保存已经写定的字面量、计数、定位、查重、结构校验和计算哈希，不生成或模板扩写正文。正文完成后由未参与该作品写作的人全文审读；题目和答案由主控统一编写。route仅向独立审读者提供乱序id/input/context；新动作另仅提供作者要求和起始资料，复判动作与对象。

## 检查与计数口径

从仓库根目录运行指定虚拟环境Python：`python -X utf8 -B -m evaluation.eval_set_a25_formal.check`，或在任意目录运行check.py绝对路径。检查器只读本套文件，不联网、不导入产品、不运行评测。输出一行JSON，只有固定错误码、编号、计数与结构；FAIL非零退出。结构PASS不代表模型效果或正式评测结论。

汉字计U+3400-U+4DBF、U+4E00-U+9FFF，章标题不计；引句首汉字按一基定位。至少一半依据出现次数在1500字后，并保留第四套从A1c继承的更强约束：去重依据至少三分之一在2500字后。资料与自查章号用整数，动作evidence_chapters用不含井号的完整标题。主要动作指expected_actions首项。回收要点原样为“已回收”“收在第N章”，放弃恰好为“已放弃”；直接给说明的edit_thread以题级author_words=true标注，按正文改则false。作者只说补充时，原说明核心信息也纳入要点。

照抄比较request/input/after_points与去标点正文连续8汉字，专名作为断点而非删除后拼接，不把普通词组登记成专名规避。新颖性去空白与Unicode标点、保留大小写，SequenceMatcher>=0.8判重。运行时仅读本套快照；authoring/novelty-reference.json仅含可读旧语料，禁读的五个目录仅由程序比对，其计数和源hash保存在sealed-comparison.json，绝不复制其明文。两个新集另做交叉比对。

set.sha256按相对路径排序，覆盖tasks.json、works/、materials/全部文件；独立复核另绑定数据、自查、语料快照及封存计数凭证。UTF-8无BOM、LF，.gitattributes保护字节。任何语义修改后重审、重绑、重建manifest并重跑检查和临时副本负向测试。交付后开发会话只运行检查器，不打开内容。

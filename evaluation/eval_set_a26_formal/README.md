# 第六套 A2 正式留用集

登记版本 `a2-2`，集合 `a26-formal`，题号前缀 `a26f-`。合同为桌面任务32、A2 SPEC全文（含补充一至十）、thresholds.py和所引A1/A1c写法。每部20章，每章2500–3500汉字；每部34题：action18、no_action6、route10。六种主要动作分布4/4/4/2/2/2。第21章共享草稿600–1000汉字。

中央设定先固定人物、状态变动、起始资料及伏笔埋收草案；作者按四章一段人工原创并交接。程序只作保存、计数、引用定位、查重、结构验证及哈希，不生成或模板填充正文。主控统一编写全部题目和标准答案；独立读者通读其他作者的作品，另仅凭乱序输入与界面情况判断用法，仅凭作者要求和起始资料复判新动作。全部过程记录在authoring内。

从指定worktree根目录运行 `..\story-continuity-copilot\.venv\Scripts\python.exe -X utf8 -B -m evaluation.eval_set_a26_formal.check`；也支持任意目录用check.py绝对路径运行。检查器只读本套快照，一行JSON只输出编号、固定错误码和计数，不联网、不导入产品、不运行评测，FAIL非零退出。

汉字按U+3400–4DBF及U+4E00–9FFF计，不含标题；证据首汉字一基定位。依据出现次数至少一半在1500汉字后，去重依据至少三分之一在2500后。动作依据章采用不含井号的完整标题，自查章号采用整数。selection为共享草稿中的完整句、带句末标点、最多80字符，仅在writing页面出现。

request/input/after_points与正文连续8汉字照抄检查以专名为断点，普通短语不登记为专名。输入新颖性去空白及Unicode标点，保留大小写，SequenceMatcher相似度达到0.8即报错。普通旧题集及另一新集的输入保存为本套参考快照；三个旧封存目录只由程序比较并保存计数与hash。两套新A3目录在遍历前排除，零重合结论不覆盖它们。

set.sha256按路径排序，覆盖tasks.json、全部works和materials文件。独立审读另绑定数据、自查、参考快照及复判记录。UTF-8无BOM、LF，.gitattributes保护字节。任何语义修订须重审、重绑、重建manifest并重跑检查及临时副本负例。交付后封存，开发会话在正式评测前只运行检查器；结构PASS不代表产品效果或正式评测通过。

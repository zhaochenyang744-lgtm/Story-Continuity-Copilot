# 原创设定与状态约束

仅供本套创作、复核，不供盲判。正文以 works/w01.md 为最终唯一来源。题目和金标由主代理在正文完成后编写。

作品《退色之前》：当代大城市的澄络材料实验中心，一个研究可逆颜色薄膜的小组准备结束一轮无效的研发。冲突围绕颜色是否值得被永久留下、失败结果如何如实面对、研究者如何改变自己工作的意义。普通开放式工作日，不写封闭设施危机、设备检修、权利凭证协调、受试者实验或署名争议。物性均是虚构材料的故事设定，不提供真实制作技术。

人物仅限八人：蒋珞岑（外号矩鸢，制样员，后转观察记录）、褚霁禾（霜芥，原在迟测间工作，后搬到漫照间）、厉闻绡（砂鹭，前期保管灰芽膜）、范筠策（斜栅，负责试次安排）、卫砚翎（组内报告统筹，后离组成为独立观察者）、黎映珂（协调研究日程、慢热）、郝宥弦（后期接手灰芽膜）、翁素缦（理论研究者）。不新造任何专名或人物姓名，房间只用普通描述性名称；未必全列作专名。外号是同一个人的习惯称呼，所有对应在第一章尾段明确说清。

专名候选：上述八个本名、矩鸢、霜芥、砂鹭、斜栅、澄络材料实验中心、昼纹片、暮纹片、岔脊盒、灰芽膜、弧脉条、双瓣样、退色之前、迟测间、漫照间。不得加第五个别名。22个专名已全库及封存程序预检，重合0。最终仍需随完整数据重新比对。

## 每章写法

每章 2800–3200 汉字（标题不计），有至少三个自然场景及对话，手工逐章原创，不用程序生成或填充、模板句式。不在正文讨论章号、出题、金标、读者、资料库。关键依据句尽量放在本章第2600汉字以后；每章写完程序计数并交接，不在前半章提前逐字重复尾段依据。旧状态可以出现为回忆或早期场景，后变后不得悄悄变回。相近干扰内容须不含糊物件身份。

第1–4章：1 研究结束前的清早、人员工作场景、午后例会、尾段别名四对与稳定书写/青布本；2 两片分离的试样、灰芽膜由厉保管、三点痕/空白角、两项习惯和旧色谱放弃；3 方圆两片和白线盒，空架低鸣，晚间讨论计划，给出职责身份/房间/物件初态；4 一场失败的颜色展示与不用红字的告示，找到蓝影来自窗帘，提出重复验证原则。第4章收束蓝影，别顺便收其他线。

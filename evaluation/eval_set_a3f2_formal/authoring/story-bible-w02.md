# w02 中心设定与派写约束

架空遥远未来，返航者在相对时间不同的航程以后，与已经比自己年长的亲人重新相处。书名《归港的人没有同岁》。主题是时间分离后的亲情、伴侣选择、承诺与重逢，不以政治听证/医疗照护/设备修理为主线。不是改年龄机器；相对时间没有让任何人逆龄，物件名“返龄”是旧团体对返航年岁核对的俗称。三十章，故事主体发生在返港后约一个月，不在这一个月内又跨几十年航行。相对时间只写明确的经历差异，不做有争议的物理推导。

人物十名：郜缃遥（返航者，别名阔时客）、班聿岐（留港伴侣，别名炬耳人）、竺芩曜（同行返航者，别名缄帆者）、邬曼洄（郜缃遥的女儿，留港岁月长于母亲船上经历）、阴俞旻（留港旧友）、亓宸苓（负责相见安排的成年人）、祁梵棱（同航而不愿复合的人）、喻聆峭（独居的留港者）、冉栖遐（年轻返航者）、甄洛蘩（守港旧邻）。前三别名须在前两章自然交代。邬曼洄可以与母亲不同姓，父姓邬，不要新增父亲专名；生父已故是稳定事实。郜缃遥与班聿岐的伴侣关系发生在生父去世之后，不写成年婚恋年龄不清问题。所有人均成年人，除回忆里的小孩。

地点：纭隙双星（归属星域）、岑弧返港（港与生活区）、黛弦航庭（存放旧航物并见面的开放厅）。三个物件追踪对象：迟汐对钟、刈光指匣、返龄契盒。专名首次全库精确重合0。不自行增专名。

只先写1–5章，直接写唯一works/w02.md；续写批次需等主控接收交接。每章目标2900–3250纯汉字，必须指定Python数字数，≥2500≤3500。锚句主要放本章第2550汉字以后；不要把单场景拖长凑字，至少三个有因果的场景和过渡。正文非模板原创，程序不生成或补句；工具只保存写定文字、计数与审计。

## 三对象

迟汐对钟六状态：
- 1：班聿岐把迟汐对钟锁在返航舱旁的柜里，暂不交给任何人。
- 6：班聿岐打开柜门，把迟汐对钟交到郜缃遥手中。
- 12：郜缃遥将迟汐对钟拆成两只，一只留给邬曼洄，一只自己带走。
- 18：邬曼洄带回自己那只，迟汐对钟第一次在两人桌上重新合拢。
- 24：郜缃遥与邬曼洄把迟汐对钟留在黛弦航庭，供返航者观看。
- 30：邬曼洄取回迟汐对钟，放进母女共有的屋里，展台只留复制图。
矛盾6：“迟汐对钟的原壳由黑陶烧成，制造时没有掺入金属。”；24：“迟汐对钟的原壳是纯钛铸件，制造时没有使用陶土。”。原壳没换，不作修订解释。
决策1属于迟汐对钟：4：“迟汐对钟第一次同步的那天，是港历八十一年的末日。”；11：“迟汐对钟第一次同步的那天，是港历八十三年的末日。”。不能区别两次同步或不同历法，留给作者选择。

刈光指匣六状态：
- 2：竺芩曜把刈光指匣扣在腰间，里面的航路片尚未取出。
- 7：竺芩曜把刈光指匣交给祁梵棱，请他带去见旧友。
- 13：祁梵棱取出航路片，将空的刈光指匣交给阴俞旻。
- 19：阴俞旻用刈光指匣装好旧门匙，托冉栖遐送回航庭。
- 25：冉栖遐把刈光指匣交给竺芩曜，旧门匙已经留在约好的窗台。
- 30：竺芩曜将刈光指匣拆下扣带，改作放在桌上的空匣。
矛盾7：“刈光指匣右侧的原生缺口在出航前就有，从未修补。”；25：“刈光指匣左侧的原生缺口在出航前就有，从未修补。”。两句旁边明确仅有一处原生缺口、无其他缺口，左右是匣体有刻字的固定方向，不是观看角度。
决策2属于刈光指匣：17：“阴俞旻为刈光指匣约定的归还日，是重逢后的第六天。”；27：“阴俞旻为刈光指匣约定的归还日，是重逢后的第八天。”。是相同约定、不曾改约，不解释日差。

- 8：亓宸苓揭掉封条，把返龄契盒送到留港者面前。
- 14：喻聆峭带走返龄契盒，把愿意留下的旧约装进去。

- 26：甄洛蘩撤去返龄契盒上的统一印记，让各人取回自己的旧约。
- 30：返龄契盒由亓宸苓收作空盒，不再替任何关系保管承诺。
矛盾8：“返龄契盒最初只有一把配钥，造盒时没有留下第二把。”；26：“返龄契盒最初就有三把配钥，三把都在造盒当日交出。”。不是后来增配，不写能调和两说的文字。

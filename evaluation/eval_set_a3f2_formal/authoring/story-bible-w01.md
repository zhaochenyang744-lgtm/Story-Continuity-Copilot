# w01 中心设定与派写约束

写作前由主控制定。题材为架空古代帝都的日食观测与历法交权，非小镇行当，不写现代技术。书名《蚀影在台阶尽头》。三十章，事件持续一个霜月；各章多场景、有行动对话过渡。人物要有冲突、愿望与生活，不能把正文写成资料核验会议。具体观天原理只写故事能承受的朴素观测，不虚构精密现代科学。

人物十名：莘砚棠（别名棠尺，年轻测影者）、郗望岑（夜衡，守台老人）、贲弥舟（弦客，宫廷乐官，愿为夜测借人手）、栾素觿（持掌仪器的女官）、褚闻荇（筹册保管者）、鄢靖纾（漏刻值守者）、衡澹璆（入台供膳的人，关心轮值能否吃上热食）、逄澜荠（画影线的人）、郦灼瑗（受命考校历法者）、汲辞嵩（退任观者，藏起异议稿）。不加新专名，普通无名人物可以有。三别名须在前两章通过对话自然明确。

地点：蔚衡京（帝都）、廉昴台（主场）、砺玄殿（朝议处）、南缜圃（可供众人观测的园圃）。三具名物件即三个追踪对象：翼纹候筒、硃脊漏舟、缄朔玉筹。所有已列专名首次全库检查重合0。

第一批只写1–5章，直接写唯一正文 works/w01.md，之后每批追加；没有章节副本。每章目标2900–3250纯汉字，必须用指定Python计数，未到2500不可交接。关键锚句尽量在本章第2550汉字以后（至少三分之一全部考点>2500，一半>1500）；锚句前应有同物/同事干扰描写，但不复述锚句答案。完整叙述，不用程序生成或补字；工具只保存已写文字和做审计。章名格式 # 第N章 章名。禁叙述评测/考点/资料卡/金标等元语言。

以下为必须保留的原样锚句，可嵌在正常段落内。故意矛盾不得写成传闻、误记、修正或不同物件；不得补过渡把它们解释掉。决策双版本也不得在故事里选定。

## 追踪对象

翼纹候筒六状态：
- 2：贲弥舟用旧绢包住翼纹候筒，仍亲自背着它登台。
- 7：贲弥舟把翼纹候筒递给莘砚棠，此后的夜测由她掌筒。
- 13：莘砚棠将翼纹候筒锁在台顶的木架上，钥匙交给栾素觿。
- 19：栾素觿从木架卸下翼纹候筒，带到砺玄殿作当面演示。
- 25：翼纹候筒被栾素觿罩入黑布，只准展示，不许再作夜测。
- 30：栾素觿揭去黑布，把翼纹候筒交给南缜圃，供后来者学看天。
故意矛盾（同一固定原物原孔数）：7句“翼纹候筒铸成时原有六个窥孔，此后从未添堵。”；25句“翼纹候筒铸成时原有八个窥孔，此后从未添堵。”
决策1，属于翼纹候筒：5句“莘砚棠第一次用翼纹候筒测影的日子，是霜月初七。”；12句“莘砚棠第一次用翼纹候筒测影的日子，是霜月初九。”。5/12为相同首次事件日期双写，不可另行解释历制。

硃脊漏舟六状态：
- 3：郗望岑把硃脊漏舟封进空柜，柜外留着他亲手打的结。
- 8：鄢靖纾割开柜结，取出硃脊漏舟，开始试水。
- 14：硃脊漏舟被鄢靖纾移上台顶，接住与影线同看的第一滴水。

- 26：鄢靖纾把硃脊漏舟放到议席中央，让争论的人同看水位。
- 30：硃脊漏舟随鄢靖纾留在南缜圃，旧柜不再上锁。
故意矛盾（固定材质，原件没换）：8句“硃脊漏舟从制成起就是一整块青铜，里面没有木胎。”；26句“硃脊漏舟从制成起就是整木挖成，外层也没有覆铜。”
决策2，属于硃脊漏舟：17句“台顶初次安置硃脊漏舟时，进水口朝东。”；27句“台顶初次安置硃脊漏舟时，进水口朝西。”。勿解释搬转、勿选一说。

缄朔玉筹六状态：
- 4：褚闻荇把缄朔玉筹封在匣中，只有他能打开那道侧扣。
- 9：褚闻荇当众启匣，将缄朔玉筹平放在测影石旁。
- 15：郦灼瑗从褚闻荇手中接走缄朔玉筹，带去核看影长。
- 21：缄朔玉筹被郦灼瑗悬在台内，任何轮值者都能近看。
- 28：缄朔玉筹落地断成两片，郦灼瑗将两片分别裹好。
- 30：郦灼瑗把缄朔玉筹的两片一并交给南缜圃，不再供作准绳。
故意矛盾（唯一原刻者）：9句“缄朔玉筹上的原刻全出自褚闻荇一人，没有别人动过刀。”；28句“缄朔玉筹上的原刻全出自郦灼瑗一人，没有别人动过刀。”。两人是不同人，不能新写同一别名/共同下刀解释。

## 大致推进

1–5 入台、一次夜测失灵、活人与值役生活、引入异议与初次测影日期；6–10 粉迹/漏水与器具试用，第一次可见解决；11–15 争议进入历法考校，器物交接；16–20 轮值者离台、公众候食、台下声响的查清；21–25 异议公开和探隧停止、原疑问与相近痕迹的区分；26–30 朝议不以威权裁掉观者，日食观测实际进行，器具退役/公开。结尾仍有4条未答的伏笔，不用大汇总把所有考点重说一遍。

每批回报：章节长度、新人物/新专名（原则0）、普通物件、相对时间点、已写锚句和任何偏离。下批必须等主控接收更新。作者不写tasks、材料、金标、自查答案；主控统一编写。共享第31章由主控另写或后续单独派写。

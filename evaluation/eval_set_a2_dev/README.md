# A2 调试集

`version: a2-1`，`set_id: a2-dev`。本集公开可读，供开发调试使用。依据已登记的 `evaluation/assistant_a2/SPEC.md`、`thresholds.py` 和桌面任务单04编写，不修改登记规则。

《下班前的那扇门》是现代都市职场群像：写字楼的行政、物业、家长和带班老师共同筹备一个有时段与人数限制的临时照护空间。正文20章；另有第21章600–1000汉字的共享草稿。人物、地点与具名物件的写作前登记见 `authoring/story-bible.md`。

起始事实特意保留5条已经被后文改变的旧值，并省略6条正文已交代的事实；伏笔资料特意保留4条正文已回收、资料尚未更新的线索。它们是A2的预设测试条件，不能作为正文矛盾修掉。其余事实和伏笔状态逐条对照正文。

28道计分题：动作12、不该改6、判断用法10。主要动作采用 `expected_actions` 第一项计数，三种各4道；所有次要动作同样完整列出目标、新内容要点和证据。用法题不使用 `fix_issue`，因此不附支持FIX题。

## 创作与复核

主控先登记全书设定和起始资料草案，写作者按连续五章分批手写原创，各批交接新增人物、物件与时间点，再获派后续章节。程序不生成、模板拼装或句型替换正文，只用于保存原文、字数、重复、位置、结构和哈希检查。题目和答案由主控在正文完成后统一编写。

未参与正文与出题的审读者通读20章，另仅凭 `input` 和 `context` 独立判定10道用法题。实际发现、处理与最终复核结果见 `authoring/self-review.md` 和 `authoring/independent-review.json`。检查器PASS只证明它所列的静态条件，独立语义复核另行记录；本交付没有模型质量或正式评测结论。

## 格式和口径

- 章标题为 `# 第N章 章名`。字数只计Unicode U+3400–U+4DBF、U+4E00–U+9FFF汉字，不计标题、标点、空白或阿拉伯数字；引句位置是一基首汉字位置，严格大于1500才计入后半位置指标。同时报告按引用次数和按“章节+原句”去重的分布。
- 资料和自查用1起始的整数序号。资料中的章号为整数；动作题 `evidence_chapters` 沿A1c格式使用不含 `# ` 的完整章节标题，和 `evidence_quotes` 一一对应。
- 共享草稿独立于20章正文，不充当事实变更依据；`selection` 从中原样取完整句子，按Unicode字符数限制为80，且只用于writing页面。
- 照抄检查覆盖 `request`、`input` 和每一条 `after_points`，与全作品正文比对。去除非汉字后达到连续8汉字即报错，登记的专名只作为断点豁免，不删除后拼接两侧，也不把普通短语伪装成专名。
- 新颖性对比当前worktree内获准读取的旧 `tasks.json` 的 `input`、`question`、`request`，去空白和标点后按 `difflib.SequenceMatcher` 比较，完全相同或相似度≥0.8报错。跨集比对在遍历前排除任务指定的3个禁读目录，以及并行A2正式集和安全集；零重合结论不覆盖未读目录。
- A2明确重设为20章、第21章草稿和6种用法，采用A2的题量、深处比例、资料状态及任务单细化字段，不套用A1/A1c旧集的30章、强制FIX或有意正文矛盾数量。没有注入题。

## 离线检查

在指定worktree根目录运行：

```powershell
& '..\story-continuity-copilot\.venv\Scripts\python.exe' -X utf8 -B -m evaluation.eval_set_a2_dev.check
```

也可以用同一解释器从任意当前目录运行 `check.py` 的绝对路径。检查器通过自身位置定位，只使用标准库，不导入产品代码，不启动服务，不联网。输出一行JSON，有错误时退出非零。

`set.sha256` 按相对路径排序，精确覆盖 `tasks.json`、`works/` 和 `materials/` 下全部文件。交付文件为UTF-8无BOM、LF；`.gitattributes` 保持本集字节。正文或题目发生语义修改后，须重新核对依据位置、复核记录、哈希，再运行检查。

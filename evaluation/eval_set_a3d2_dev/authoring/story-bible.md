# 写作前中央设定（2026-10-26）

作品暂名《把台阶留给明天》。现代大城市赫沄市，绮衡周转站经营家用无障碍辅具的短租周转，准备跨楼试办。重点是居民对独立生活、协作和物件周转的不同理解，不写治疗或器械操作教程。不是旧行当小镇、校园、社团、广播或录音题材。所有正文逐章直接创作，不用程序、模板、替换句式生成。每章目标2800–3100纯汉字，多场景、对话及过渡，任何章不得低于2500或超过3500。考点引句安排在章内2600字附近，至少半数>1500、至少三分之一>2500；同章前部有相关对象的非答案描写。引句嵌在正常段落，不孤立列设定。

跨作者指代统一补记：嵇沐乔、屈予葭、邵令珂、匡泽絮、牟宛歧、傅语岑、应时霏、连照棠用“她”；滕书蔚、巫承晏、缪见隅用“他”。主控抽读发现A第10章与B第16章对邵令珂的代词不同，已按A既有“她”统一，并要求B逐处人工检查，不作全局替换。最终全文独立审读复查这一项。

赫沄市；绮衡周转站在呈晖大厦首层，璃岑服务间用于早期交接；砚棕间在同一大厦首层，后改用它。别新造具名地点/物件/人物。普通餐盒、纸袋、手套等可自然出现。三件具名物件只有弧栈坡板、棱湾折叠推车、赭环试配箱；其他对象无需专名。没有固定精确日期，时间自然顺序推进；会议周次不倒推、避免“昨夜”跨批冲突。主线不靠追查犯罪。

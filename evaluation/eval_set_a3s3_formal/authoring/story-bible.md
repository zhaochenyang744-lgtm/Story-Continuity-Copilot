# 编写约束与连续性底稿

本文件仅供出题，交付报告不摘录。正文逐章人工原创；脚本仅做计数、位置、重复、绑定。唯一最终原文为 works/w01.md。

## 基础

题材：未来辙珀星近地行星环中的职业帆艇赛事与公共航道修复。斜晖环道是人工安全航道，帆艇靠反射帆与轨道拖索加速，比赛限制动力。故事从年度赛事中段、全部成人专业队已经参赛时开始；各队处理环道险情、合作清障、讨论赛道公共责任。不写新人入队、资格选拔成长、落石取消选拔。资格赛只是之前完成的赛段、用于核对原始机械规章。不是星际返航、家庭团聚、植物保育或小镇行当。参赛艇称折芒帆艇。追踪对象只有回衡舵芯，是可拆的机械配平组件，不是意识体、通行凭证或裁判。没有魔法和瞬时跨距。

具名人物与固定角色：迟砚岫（驾驶，别名岫线）、屠予铮（帆具手，别名铮尾）、乔闻荻（检验员，别名荻哨）、巴映铄（后备驾驶）、岑沅枢（艇坞工程师）、宗茵璧（赛务保管员）、许照砾（竞争队驾驶）、彭纾鹭（救援调度）、温缈策（计时员）、邹牧斓（公共接驳艇驾驶）。每人均是成人。别名需正文自然明确对应，不是另一个人。除了表列人名，不擅加专名。

回衡舵芯五条状态，必须用下列原句，均在所在章汉字2500之后；其余章节可以动作描写，不能新增安装地点或保管人变化：

## 必须保留的两处决定点

DP1 数字型，同一本届资格赛初始规章，a第2章/b第6章，均置于正文汉字2500之后（独立叙述句，嵌于正常段落）：
a：回衡舵芯本届资格赛的单次试转上限是四十息。
b：回衡舵芯本届资格赛的单次试转上限是六十息。
读者需问作者采用哪种原定上限，正文不裁决、不暗示临时延长。其他数值动作不得实际触及此上限。

DP2 非数字型，同一赛后归还约定，a第7章/b第11章，均置于汉字2500之后：
a：回衡舵芯赛后归还时的指定接收人是宗茵璧。
b：回衡舵芯赛后归还时的指定接收人是温缈策。
接收人不等于最后持有人：12章仅应急借装、赛事正式归还尚未发生，不解释为转任或代收。

## 场景安排

1—3：年度赛事中段回坞，既有专业队准备共同检修；外道测绘与控制帆面负荷；装置送检与竞争队交流。第1章需三别名完整交代或安排第2章补全。每章至少三场景、对话和可见动作，无旁白章号元语言。
4—6：外道勘查；修护反光片、舵芯封检；各队商谈公共航道复开并核对资格赛原始规章，形成数字决定点后半。第6章不真正试转到数字上限。
7—9：赛前公共艇协商与接收约定；训练艇装芯、短距离救援演习；赛事推进发现航道拖索异常，队伍让出成绩争议先保护人员。
10—12：排查空舱声响并收线；决赛中断、清障与归还后半；协作撤离、应急借芯、尚待正式归还。故事结尾可以留开放疑问，不抹去DP。

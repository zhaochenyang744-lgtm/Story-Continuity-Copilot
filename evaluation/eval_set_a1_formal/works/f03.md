# 第一章 黑雪落进袖口

袁宿从屋顶跃下时，一片黑雪落进袖口。雪没有融，碰上皮肤竟发出纸响。他停在折昼城的长檐下，把袖子翻过来，抖出薄薄的一片。街上正在开晚市，卖梦的人用小碗盛住昨夜残留的颜色，谁也没留意雪为何是黑的，只有一个孩子蹲下来，想用舌尖尝。

“别吃。”袁宿拉住他，换给他一粒自己口袋里的炒豆。袁宿做梦信邮差，夜梭是同行送他的别名，因为他习惯在宵禁钟响前穿过最窄的巷子。今天他跑得再快也没有用，回声门前的队伍一直排到水槽边，大家都等着另一名能报出真名的人来。

栾迢从队尾向他招手。大家叫栾迢半拍，她说话常比别人的问句慢半拍，并不是听不见。袁宿站到她身侧，发现灯下只有自己的影子。栾迢的影子被借梦所暂扣，此刻脚下没有影子。她说只差一张退借回条，明明借来的梦已经还了，柜台却还要她等。

两人各报自己的真名，回声门才从中间裂开一道亮缝。折昼城的回声门必须由两个人同时报出各自真名才能开启，一个人重复念名不能开门。门里风很冷，袁宿护住软银信筒，侧身让栾迢先过。软银信筒由袁宿保管，筒内的梦信不能随意压折，他宁愿撞疼肩膀，也不让它碰到门框。

门后小屋住着岑漆和滕铃。岑漆正在煮一锅没有颜色的汤，滕铃把窗纸补成一块块深浅不同的白。她还只是随队学习的见习邮差，不能独立签收梦信。袁宿交给她一捆空封套，请她先检查有没有破口，栾迢坐在旁边，用脚试着踩住一个不存在的影子。

又一片黑雪从窗缝钻进来，落到岑漆汤勺上，卷起一个细小的边。岑漆没有解释，先把勺子放进干碗，请大家别碰。屋外叫卖声渐渐低了，袁宿看着碗里那片像字又不像字的雪，忽然觉得今天带来的空封套也许不够；这座城常有东西找不到收件人，有时连从天空落下来的，也得等他们先问清到底是什么。

# 第二章 不在耳里的钟

滕铃半夜被梦里的三声钟惊醒。前两声她熟悉，一声叫卖梦的人收摊，一声让梦里的渡船靠岸，第三声却仿佛还贴着枕头，在记忆里轻轻震动。她掀起枕头，那里只有自己折好的手帕。岑漆在外间问她怎么了，她说梦里钟多响了一下，老人沉默片刻，让她把醒来的时刻记住。

早晨问过邻人，竟有好几个人在梦里听见第三声钟，醒来却找不到相应的钟楼。袁宿带她沿街走，数过能看见的两座楼，没有再多出一座。栾迢说也许钟藏在别人梦里，岑漆说这只是也许，别把一句好听的话立刻寄出去。滕铃把第三声钟留在自己的小本上，旁边画了一个空圈。

他们经过一处收存旧梦物的廊屋，门口放着无耳陶像。无耳陶像烧成时，左掌就有六根手指。滕铃站在界线外看了看，想数另一只手，却被袁宿叫走，今天要先找那张退借回条。陶像只是廊屋里的旧藏物，没有人拿它来决定梦信该交给谁，也没有谁想把它搬回小屋。

借梦所的柜台很高，栾迢站在下面，只能看见经手人的帽沿。她递上原来的凭单，对方叫她等到换班。袁宿想代她催，栾迢摆手，说这次自己说。她用比平常更慢的语速重述归还日期、梦的编号和现在缺的手续，每一项都说得清楚，柜台后终于有人低头看她。

滕铃在一旁练习填写空封套，写错一个字便揉成团。岑漆捡起纸团铺平，让她先留着，错在哪里可以回头看，不必每一张都消失。她问他是否从没写错，他笑道：“我写错的多了，才知道纸也会记得你没学会的地方。”滕铃把那张皱纸放回袋中，没有再丢。

午后回条仍未拿到，栾迢脚边依旧空着。四人回家时经过晚市的位置，摊贩正在支架，孩子们追着彼此的影子跑。袁宿没有邀请栾迢一起玩一个安慰人的笑话，只替她搬开挡路的木箱。滕铃忽然在清醒中想起第三声钟，却听不到它了；那空圈留在本子上，像一扇谁还没有找到钥匙的门。

# 第三章 藏起一句话

岑漆让滕铃替自己擦一只橙纹砂漏，砂粒在透明腹腔里缓缓落下，像一条被收细的路。橙纹砂漏原由岑漆保管，用来给梦信脱离梦境后的停留计时。滕铃举得太高，他伸手托住底座，说看东西不一定要迎着最亮的地方，先让手稳住。

袁宿在里间检查软银信筒，发现一只封套边缘带潮，便请栾迢换个干燥位置放。栾迢没有影子，拿东西时总下意识寻找地上的轮廓，有两次把脚放得过近。袁宿不催，只往旁边挪一点，让她看清桌脚。梦信不能被他们自己的急躁弄坏，收件人的夜已经够长了。

岑漆与袁宿商量将一份临时名单锁入地下暗格，讨论口令时，滕铃正被派到屋外送水。直到这次外出送水的夜晚结束，滕铃仍不知道地下暗格的口令。她回来只看见两人收起一张纸，也没有问那上面写的什么。栾迢递给她热碗，屋里很快谈起另一封找不到门牌的信。

吃饭时，袁宿问滕铃小时候是否也在这里住。岑漆替她添汤，告诉他，岑漆是滕铃的养父，两人没有血缘关系。滕铃接过碗，抱怨他每次讲这种事都像在登记表上写备注，岑漆笑着说那就加一句，他小时候给她补过的袜子从来一边长一边短。

夜里窗外再落黑雪，数量比昨天多。袁宿用一只干盒接了几片，发现每片都有细小的折痕，边缘却像虫翅。他想立即去找源头，栾迢指了指天色，请他明早从屋檐上查，现在连落脚点都看不清。滕铃端着灯来，听见这句话又把灯放稳，没有把好奇当成必须立刻出门的通行证。

睡前，岑漆翻过砂漏，让大家看一格时间究竟多长。没人说话时，沙粒落下的声音反而听不见，只能看见空处慢慢长出来。滕铃想问第三声钟，最终先问明天能不能一起爬屋顶。岑漆说可以先检查梯子，她便把皱封套压在枕边，准备记下明天会学到的新事，今夜不知道的那句话仍好好留在别人的保管范围里。

# 第四章 灯罩上的壳

袁宿爬上第一段屋脊，才知道从下方看似平直的瓦面，处处都有翘起的边。滕铃跟在后面，双手扶稳，不再边走边问。栾迢留在檐下接工具，岑漆用绳拴住梯脚。四个人的声音从高低不同的位置传来，谁要挪动，先把话传到下面，免得有人恰在另一端松手。

黑雪积在梦灯背后，袁宿凑近看，发现灯罩内壁贴着许多已经空了的虫壳。墨翅虫在灯边蜕壳，薄壳被热气托起，散落到街上便成了黑雪。黑雪不是梦信烧坏后的灰，也不是谁撕碎的文字。滕铃用小镊子夹起一片，同昨夜接到的放在一起，比出完全相同的翅脉。

她兴奋得想把结论喊给整条街，袁宿让她先站稳。下到地面后，岑漆又看过壳片，确认接触方式不会损坏样本，才带她去告知受影响的摊贩。有人失望，说本来还以为会有什么异象，栾迢听后笑了，告诉他虫子长大也不是很小的事，只是没有替谁预告发财。

袁宿要留在灯架上修松动的护网，便将软银信筒交给栾迢保管。栾迢双手接住，检查封套数量，将信筒背到自己胸前，修完后也没有交回，往后由她负责这批梦信的运送。袁宿只留下收寄记录副本，提醒她筒盖别朝着落灰的地方打开，栾迢说这句自己记得住。

滕铃在街角贴出一张简短说明，用自己观察到的壳和灯解释黑雪，没把昨夜猜的东西都写上。她想画得漂亮一些，岑漆却先问路人能不能看懂箭头指向哪里。改过两次后，字少了，图也简单了，一个孩子看完，终于不再把黑片往嘴里送。

傍晚，灯架修好，护网没有拦住全部虫子，却挡住了壳片飘进食物摊。袁宿坐在门前揉肩，栾迢将信筒稳稳放到身旁，滕铃捏着最后一片壳看它透光。第三声钟仍没人找到，黑雪却不再占据那个空圈。岑漆端来汤，叫她把壳放回盒中再拿碗，她照做了，觉得知道一种东西是什么，并不意味着从此可以随意对待它。

# 第五章 走在身边的黑

借梦所终于找到那张错夹的回条，叫栾迢去取。她站到柜台前，没有像旁人期待的那样高兴，只请经手人解释原来夹在哪里。对方说放进了下一页，她又问为何上次不查。柜台后的人叹气，承认只看了封面。栾迢听完点头，将凭单上被压卷的角慢慢抚平，等对方把该补的话说完。

手续办完，栾迢被暂扣的影子已经归还，如今脚下重新有了自己的影子。它先从柜台底下滑出，贴上她鞋跟，再顺着光线伸长，像一只终于认得回家的猫。袁宿没有去踩，滕铃也忍住了想碰的手。栾迢自己走了几步，又停下，等那片黑稳稳地跟上。

回家路上，她特意经过灯光最亮的广场，看影子在脚边缩成一小团。滕铃问是否和平日一样，栾迢想了很久，说一样，但自己看它的方式不同了。岑漆听见后没有讲大道理，只叫她别光看地，前面有一辆推车。栾迢及时让开，影子便也让开了一点。

栾迢停在路旁调整信筒的背带，筒盖碰着衣扣，发出轻轻一响。袁宿提议先去问桥边守夜的人，栾迢却发现那封往曙桥去的信有一处字被潮气模糊，决定在家干燥查看后再走。滕铃想把墨补深，岑漆拦住，说看不清的字不能靠自己的笔让它变得确定。

四个人把封套放在斜光下，慢慢辨认。那不是一个新名字，而是旧式的门牌写法，袁宿见过，却不能完全确认末尾的笔画。他翻出公开的旧门牌册，找到相似写法，用纸另抄下来比较。栾迢站在一旁，影子投到桌脚，滕铃挪了灯，让它别盖住要看的地方。

到了晚上，地址仍需现场核对，但可走的方向已经明确。栾迢收好信筒，第一次不必腾出注意力去想自己为什么没有影子。她把门前的鞋摆成一排，叫滕铃挑好明日要穿的。滕铃拿起最轻的一双，又想起桥路湿，换成底纹更深的那双。岑漆看见，只问合不合脚，窗外黑雪已经稀少，屋内灯下的四道影子终于都完整地停在自己的主人身旁。

# 第六章 桥前不寄出的信

袁宿在旧门牌册里找到曙桥的迁改记录，却没有直接把模糊的地址圈定。桥尽头曾有两条小巷，一条后来改名，另一条已经并入广场。滕铃看得头昏，问能不能先投到离得近的那一家。栾迢将信筒抱紧，说梦信若交错，收件人梦里会多出一段本不属于自己的夜，方便不能替他们作这个决定。

岑漆给出另一种办法：先带地址的抄件去问，不带原信在人多处反复展开。袁宿同意，剪下一张大小合适的纸，照样描出字迹清楚和不清楚的部分，留白处没有添笔。滕铃负责将旧门牌册装好，她把皱封套当书签夹进去，又拿出来，怕以后有人误认成册里原有的页。

午后，他们请来一位退休的桥吏看抄件。老人记得巷子，却不肯保证最后一笔，讲到一半还打了个盹。滕铃想叫醒他，岑漆轻轻摇头，让对方睡完这一小觉。醒来后老人反倒想起门边有一段特殊的石阶，袁宿把这一线索记下，也写明只是待现场核对。

栾迢站到门口试背信筒，影子与筒的轮廓一起落在地上。背带扭了一折，她腾不出手，滕铃便过去帮她拉平，顺便将滑到肩后的衣领理好。袁宿又拿来一张抄件，边角还潮，两人只好先把它摊在窗旁，让晚来的风替他们多做一小会儿事。

傍晚，袁宿列出次日过桥的步骤，先找石阶，再问门牌，确认收件人清醒后才交付梦信。岑漆提醒滕铃，她还未获得独立邮差资格，明日可以跟着学，但签收由有资格的人负责。滕铃应了一声，把写有自己名字的空表收回袋里，没有抢着给还没完成的事留下证明。

睡前，四人在小屋门边放好信筒、抄件和照明器，准备明日去曙桥核实地址。第三声钟仍只在零星的梦里出现，未找到来源，没人把它与这封信强行连起来。袁宿关窗时，远处两座钟楼沉默着，滕铃摸了摸袋里的皱封套，想起老人醒来后的那段记忆，决定明天遇见不知道的人，也给对方一点慢慢想起的时间。

# 第七章 石阶少了一级

曙桥在清晨像被水洗过，桥板间透出很淡的蓝光。袁宿走在前面，滕铃按他的提醒不朝缝隙久看，据说人在这里看得太专注，容易忘了自己本来向哪边走。栾迢背着软银信筒，影子随着桥面的光一会儿长一会儿短，岑漆在后面数着队伍，不让任何人停下却无人知道。

桥吏说的石阶还在，只是少了最下面一级。滕铃以为找错了，袁宿让她看墙上的磨痕，那里恰好留着旧台阶的位置。栾迢去问旁边卖水的人，对方说修路时移走一级，门的位置没有变。几条信息拼在一起，旧门牌册上的巷名终于有了能站住脚的地方。

门里出来一位睡眼惺忪的老妇，听见梦信二字，先让他们进屋。栾迢没有立刻递信，按约定核对姓名和收件标记。老妇认得标记，却说信可能属于她已经迁走的妹妹。袁宿看向岑漆，老人没有替他决定，只请老妇把知道的迁居情况讲清，别因大家走了远路就勉强认下。

滕铃坐在小凳上记，第一次觉得空手回去也许比拿一张错误签收更难。老妇翻出旧门牌的副页，证明姐妹曾共用同一个地址，又给出妹妹后来登记的新位置。栾迢收好抄件，郑重道谢。软银信筒没有打开，那封梦仍在里面安稳停着，没有为了今天必须完成而落入不相干的人手中。

回到桥头，岑漆买了四碗热水，大家各自捧着。滕铃说自己刚才差一点以为，既然门对了，人也该对。袁宿笑着问她还想不想立刻独立送信，她摇头，又很快说想，只是知道还需要学。栾迢将自己的碗移到影子里，看着水面不再刺眼，才慢慢喝了一口。

午后，他们没有直接去新地址，而是先返回小屋核对转寄办法。桥上的路似乎比来时长，滕铃却不再只记得少掉的一阶。她记住那位老妇没有因为一封诱人的梦就说自己是收件人，也记住同伴没有因为走错半程而责怪谁。袁宿在门前停下，等所有人都到齐，才和栾迢共同报出真名，让回声门为这个暂未完成的队伍打开。

# 第八章 倒转的细沙

转寄手续要求他们记录梦信停留的时间，岑漆将橙纹砂漏摆在桌上，让滕铃说明每一格怎么读。她说得流畅，手一快却把砂漏连续翻了两次。细沙重新落下，刚才已经走过的那一小段便无法仅凭眼前的位置读回。她脸红了，想凭感觉补个数，袁宿请她先停。

岑漆没有责备，让她把误操作写进记录，再用旁边已经记下的起始时刻补做核对。滕铃这才发现诚实写错并不是一句简单的认错，还意味着愿意多花时间恢复可靠的计时。栾迢替她倒水，等她终于把前后说清，才将新表递来。

橙纹砂漏由岑漆正式交给滕铃保管，滕铃接过后放入自己的软袋，负责后续运输的计时。岑漆留下一张读数说明，不再把它收回柜里。他说学会不是从此不会失误，而是知道失误之后怎样不把它藏进下一步。滕铃把这句话记在另一页，没把它冒充成技术说明的一部分。

新收件地址位于午眠坡，那里的人习惯午后睡很久。袁宿安排到达时刻，避免将沉睡的人强行唤醒，只为让自己的表格看起来准时。栾迢问若对方又搬走怎么办，他说那就继续核实，不预先把最坏的猜想当作下一次已经发生的事实。滕铃听着，慢慢把行程画成几段可以调整的线。

夜里又有人报告梦中第三声钟。岑漆把不同人的描述分开，不因为都说第三声就认定音色和时长相同。滕铃听见两份记录差得很远，反而有些沮丧，觉得离答案更远。岑漆让她看看此前那个空圈，说知道差异，也是在缩小哪些解释不能用，并不是每一步都长得像答案。

收工时，滕铃把砂漏放稳，自己坐在旁边看最后几粒沙落下。袁宿检查门锁，栾迢将信筒靠在干燥的墙边，岑漆煮汤的香气从屋里散出来。没有人催她快一点，她却比平日更快起身去帮忙。那条细细的沙路已经走完一格，她知道它走完了，也知道自己的学习还没有，这两件事可以同时清清楚楚地成立。

# 第九章 名字下方

邮差资格考核安排在一间没有窗的屋子里，滕铃以为里面会放许多可怕的梦，进去才发现只有几张普通桌子。桌上摆着封套、登记纸和几样容易混淆的小物件，考官让她先确认任务，别急着动手。她站稳后问清哪些需要交付，哪些只是待查，额头的汗才慢慢退下去。

第一封地址很清楚，第二封的日期被折痕遮住，第三封干脆没有收件人姓名。滕铃按能确认的程度分开，第三封没有因为桌上只剩它就自动变成最后一个必须送出的东西。考官追问时间快到了怎么办，她想起曙桥的老妇，回答先说明未完成的原因，不编一张签收。

考核通过后，滕铃取得正式邮差资格，已经可以独立签收梦信。她拿到证页时，先看自己的名字，再看下面那行权限，没有像想象中那样跳起来。岑漆在门外等，见她走出，问饿不饿。她有些委屈，问他为什么不先问结果，老人笑着说看她的步子就知道，不过饭还是要吃。

袁宿和栾迢准备了热汤，没有添一场盛大的仪式。栾迢把软银信筒放到一旁，认真听滕铃讲考题，讲到没有姓名的封套时，问她有没有犹豫。滕铃承认有，毕竟让一张纸停在那里很像自己没做成事。袁宿说以后也会有这种感觉，证页不会替她省掉每一次判断。

饭后他们核对午眠坡的地址，准备正式转寄。滕铃提出由自己操作计时，但请其他人复核起点；岑漆点头，没有因她拿到资格就撤掉所有协作。她取出砂漏，先拿布擦平桌上的水，再看底座是否晃动，报数时等同伴写完才往下说，动作比考试里还慢一点。

晚上，滕铃在自己的名字下方写好第一条正式记录，写完停了很久。岑漆没有站在背后看她写字，袁宿也没有替她润色，栾迢坐在对面整理封套。小屋里只有纸响和汤锅冷下去的轻声，滕铃突然明白，被信任不总是有人郑重说一句话，有时是旁人终于允许你独自完成一行字，再在你需要的时候，仍把椅子留在同一张桌旁。

# 第十章 梦里的午后

午眠坡比城里安静，门上的铃都包着布，卖东西的人也只举牌子，不高声招呼。袁宿看着地址走到坡顶，发现门前有两双旧鞋，其中一双小得像孩子的。栾迢没有据此猜屋里住着谁，只轻轻敲门，等了一会儿，里面传来拖动椅子的声音。

开门的女人已经醒了，却还记不清昨夜的梦。她听完来意，仔细核对姓名和专属标记，确认这封信是自己的。滕铃负责记录，橙纹砂漏在桌边稳定地落沙。女人请他们稍等，想洗净手再接信，栾迢点头，将信筒横放在干燥的布上，没有为了赶时间替她拆开封套。

女人接信后并未立刻读，而是询问姐姐是否安好。袁宿只回答在曙桥见到的情况，不把一次短短拜访说成了解对方全部生活。女人听完笑了，说这样就足够，随后签收。滕铃看着纸上的字，终于体会到一张真实签收与自己希望快点得到的一张纸之间，有多长的路。

返城途中，他们在旧梦物廊屋避雨。无耳陶像烧成时，左掌就有七根手指。滕铃站在檐下看雨，没有越过保管界线去碰那只手，袁宿也只问门房能否借一块干布擦去信筒外的水。梦信已经交付，廊屋的旧藏仍留在原处，没有加入他们的邮路。

雨声很密，栾迢的影子被屋檐的暗色掩住，走到街灯下又清楚出现。滕铃低头看一眼，栾迢笑她不必每到一处都确认。她说自己不是担心又丢了，只是想起第一次见面时的地面有多空。栾迢听完，没有再开玩笑，把伞往她那边移了一些。

回到小屋，岑漆先请他们把湿外衣脱下，再核对签收记录。袁宿没有用一句都顺利来跳过中途的等待，栾迢也记下收件人要求洗手的那段时间。滕铃合好砂漏软袋，发现自己并不急着向所有人展示新资格。她更想把这一趟完整地留下，让日后任何一个没同行的人看记录时，都能明白这封梦为什么最终抵达了正确的一扇门。

# 第十一章 空筒的重量

少了一封梦信，软银信筒拿在手里轻了许多。栾迢却没有把它随手搁在门口，仍按原来的方式擦净外壁，检查内衬，再放到干燥架上。袁宿路过时摸了一下筒盖，问她是否觉得空筒更容易丢。她说不是容易丢，是人知道它空了以后容易忘记照看，差别在这里。

滕铃将签收表送到登记处，第一次独自走完那条巷子。她仍要与另一人共同报真名才能通过回声门，正式资格并不改变门的规则。门边的过路人愿意配合，两人报过姓名，门开了，她郑重道谢。那人有些意外，说只是顺路，滕铃却觉得顺路的帮助也值得被清楚接住。

岑漆留在家里整理第三声钟的记录，袁宿坐到旁边，发现不同梦里提到的钟声有长有短，有的像从远处来，有的像就在耳边。他们暂时不能确定这些是否同一来源，更不能根据没有找到第三座钟楼就断言所有人都记错。岑漆把相同和不同的地方各写一列，留着下一次比较。

午后来了一个想寄梦的人，封套里只有一段气味，没有图像。栾迢请他先说明收件信息，袁宿准备登记，滕铃回家后在旁观察。这是新的委托，需要另外核验，他们没有拿上一封信已经成功的经验直接替这一封保证结果。那人愿意等，坐在门边慢慢喝水。

晚饭时，滕铃问养父，自己拿到资格以后，是不是可以不再用那些旧皱纸。岑漆说当然由她决定，又问她是否已经记住上面的错。她翻开袋子看了看，发现有一处当时写错的地址，自己如今仍会顺手那样写。她把纸重新叠好，决定再留一阵，不因为证页崭新就让旧问题悄悄消失。

入夜，小屋的灯一盏盏熄下，只剩桌边一束照着未完成的登记。栾迢收好信筒，滕铃将砂漏放回软袋，袁宿在门边检查回程记录。岑漆把那张空圈纸放到最上面，没有替第三声钟画出一座想象中的楼。屋外两声熟悉的钟先后响过，众人各自停了片刻，等没有来临的下一声，然后继续做手边尚能确认的事。

# 第十二章 给未知留封套

新的委托还在核验，袁宿一早去问登记处是否找到收件人的旧记录。回家时，他带来的答复只有一半，栾迢听完没有失望地合上册子，而是将能够确认的部分先写好。滕铃坐在旁边，发现自己从前总想一口气知道结尾，如今终于能在半个答复前稳稳坐住。

栾迢经过门前的灯，影子沿石面转了一个角，落到装封套的箱旁。袁宿请她帮忙挪箱，两人一人抬一边，走到桌角却发现过道太窄。她叫袁宿先别使力，自己侧过身，让箱底顺着腿边转过去。落地时木板轻轻一响，窗前总算空出一块能站人的地方。

滕铃在登记页最下面写错一个笔画，岑漆递来干纸，她却将纸留着，只在错字旁补清。袁宿问这样会不会挤，她把整页推过去，请他从头读一遍。读到末尾时，他停了一下，挪开遮住一行字的杯子，原来困住他的并不是那处改动。滕铃笑了，又将杯子移得更远些。

第三声钟的来源到此仍未查明，也没有找到可以确定与它对应的钟楼。岑漆决定继续收集具体梦境中的时刻和声音描述，却不把任何一种猜测提前印成告示。滕铃拿出一个空封套，在上面写待查两个字，又擦掉，怕有人以为里面真的装着一封信，最后只把纸放在记录旁。

袁宿问她为何不干脆收进抽屉，她说想留着提醒自己，未知也需要安排位置。栾迢听完，替那个空封套找了一个不挡工作的小格。岑漆端来早餐，提醒位置安排好了，饭也不能一直等。四个人围坐下来，窗外没有黑雪，只有几只墨翅虫在灯罩旁轻轻扑动。

饭后，他们在桌上展开下一封委托的核验表，准备先补齐收件信息，再安排邮路。滕铃把砂漏暂放一旁，还没到计时的时候，不能为了看见沙落就先翻转。袁宿推开窗，街上开始有人报出姓名，远处的回声门一开一合。栾迢将软银信筒的背带理顺，岑漆合起钟声记录，一项待办与另一项未知各在自己的地方，屋里终于有足够的空处容纳一个新的早晨。

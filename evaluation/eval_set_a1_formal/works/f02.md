# 第一章 风从缺口来

陶芒踩上赤脊岭第一段碎石坡，背包忽然被身后的叶霁拽住。他回头，只见一条松开的绑带拖在尖石间，差一点就把侧袋整个扯破。“石雀，你翅膀掉了。”叶霁说。石雀是队里给陶芒起的外号，他爬陡坡时步子又短又快，像在石头间跳。陶芒将绑带塞好，没有逞强加速。

叶霁也有一个与本名不同的称呼。山下的带路人叫她阿岫，那是她早年在山坳教孩子认树时留下的名字。任穗第一次听见时，以为还有第五个人要来，柯岑只笑着指了指她。四人的调查队并不大，名字却比人多，叶霁让他们在无线电里仍用本名，省得紧急时多想一层。

他们要核查高处一片灌丛的更新情况。陶芒的左眼自幼失明，观察时主要靠右眼。他停下来调测距镜，让任穗站到自己视野内再递纸，任穗记住了，没有在后面突然喊他转身。短柄土钻由陶芒携带保管，钻柄已有一道纵裂，用两道铁箍固定，仍能低强度使用。

第一段路比预想慢，任穗出发前扭到的脚踝还肿着，不能独自背负重包。她咬牙走了一会儿，叶霁就将她的样袋分给别人。任穗说自己可以，柯岑让她先说清是想可以，还是现在确实可以。她气得不答话，终于还是把最重的一袋交出去，鞋带重新系得宽松些。

将近傍晚，风里传来三短一长的哨声。陶芒以为有人求援，放下包，朝声音来的方向喊了几句，没有回应。叶霁不准他们分散，只沿安全路线走到一处裂开的石壁前。哨声忽远忽近，天却要黑了，她决定先标记位置，天亮再查。任穗把时间写进本子，旁边没有擅自添上“有人”。

营地扎在背风凹处，柯岑煮水，陶芒撑好帐杆，叶霁检查每个人的雨衣是否能随手取到。任穗负责记录，不再把这份轻活当作惩罚。夜里那阵哨音又来了一次，她坐在帐门内听，觉得山并不安静，只是大部分声音都没有熟悉的来处。她把本子合好，让火光慢慢退到纸页以外，先记住脚下有一块平稳的地。

# 第二章 不能带走的石头

清晨的露水把草叶压低，陶芒走出帐篷时，裤脚立刻湿了一圈。柯岑蹲在灶旁吹火，吹得眼泪直流，叶霁笑他不如换个方向。他挪半步，烟果然离开脸，才肯承认自己刚才只顾着和火较劲。任穗坐在石头上整理标签，每写好一张就压一颗小石，免得风替他们改变编号。

出发前，叶霁清点白瓷种罐。白瓷种罐由叶霁保管，罐口包着软塞，用来暂存合法采集的少量种子。她特意将空罐展示给大家，里面没有上一次调查遗留的东西。陶芒检查侧袋时想替她背，叶霁说自己的包重量还合适，先顾好土钻的裂柄，别让铁箍撞坏别的器材。

调查路线经过一处保护围栏，里面露着被称作赭骨标本的古老石块。赭骨标本最初是在岭南坡出土的。陶芒隔着围栏看了看，没有攀进去，任穗按图记下它的位置，柯岑则提醒大家别把午饭袋落在边上。标本不是他们此次可采的东西，四个人没有因山上无人看守就把界线当作空话。

附近的旧营位已经长草，只有一根麻绳在矮树间绷着。绳上系了五个间隔不等的结，没有名字，也没有日期。叶霁在不移动绳结的情况下拍了照，问谁认得这种做法。陶芒说像标高，任穗说也可能只是晾东西留下，柯岑让两种说法都先别写成结论。

午后要越过一条窄沟，任穗试着一步迈过，脚刚着地便吸了一口气。陶芒回身扶她，她却先把手里的标签举高，怕纸被水打湿。叶霁等她站稳，才说：“人比标签更难补。”任穗没有反驳，只将记录袋扣好，下一次过沟时老老实实用了同伴递来的手。

上到缓坡，柯岑把午饭分成四份，特意把容易压碎的一块先吃掉。大家讨论那根麻绳，后来又讨论脚下的花是不是同一类，话题随着咀嚼慢慢散开。叶霁看着云往高处升，催他们吃完再走。山里的东西不因他们今天来到就急着给出答案，他们也只能把能确认的收好，把看不明白的留在原处，等还有机会再看。

# 第三章 钻下去之前

任穗对第一块样地很不满意。坡面不够平，碎石太多，灌木也长得参差，她说这种地方不好比较。陶芒听完，将短柄土钻往地上一立，问他们来调查山，还是来找一块已经像表格的地。叶霁没有接着训她，只请她把不平、碎石和参差都写成能复查的描述。

取土时，陶芒先检查钻柄的两道铁箍，再用手掌试受力。工具没有突然变好，也没有因写进记录就更耐用。他示范怎样避开大石，怎样在阻力不对时停下，任穗看得很仔细。她脚还不适合背包，却可以坐在稳当的位置做浅层取样，终于找到一件不必和伤势硬碰的工作。

完成示范后，陶芒把短柄土钻交给任穗保管。任穗接住，先检查裂缝和铁箍，再将它放进自己的器材套，往后由她负责借出与收回。柯岑在旁边提醒，保管工具也包括发现不对时拒绝使用，不是只负责数它还在不在。她点头，在记录页给检查结果留了一行。

叶霁沿样地边缘寻找幼苗，有一株藏在枯枝下面，根旁土色很深。柯岑想拨开让她拍得更清楚，她制止了，说不要为了照片整齐就改变幼苗的遮蔽。两人趴到不同角度，最后找到一个既能看清叶形又不挪枝的位置。任穗坐远处看，第一次注意到耐心也会改变观察的办法。

风起时，标记绳轻轻颤动，陶芒回头去收空袋，没有看见叶霁递来的水。她绕到他右侧再递，他接过，说谢谢。这个动作很小，柯岑却也记住了，后来报方向时总先说相对位置。队伍的配合不只在绳结和表格里，有时只是愿意多走半步，站到别人确实能够看见的地方。

离开样地前，任穗把踩倒的一根枯枝扶回原来的缝，叶霁叫她停一下，先确认不是给活苗增加压力。她们蹲下来重新看，发现枝下还有一条细小的根。任穗轻轻移开脚，忽然觉得这座山比一路望见的轮廓复杂得多。回营的路仍难走，她却不再只盯着哪块石头能让自己走得快一点。

# 第四章 肩上的分量

休整了几天，任穗拆下脚踝外面的支撑带，在营地平地上来回走。她先走短的一圈，再背上装了半壶水的包，没有立刻挑最陡的路证明什么。叶霁在旁边观察，叫她说真实的感受，别只报自己想听见的结果。任穗试着转身，终于承认已经不痛了，只是还有些害怕再次落空。

经过休养，任穗的脚踝肿胀已经消退，能够独自背负正常重量的行囊。她向队友说明后，才将自己的样袋收回，没有顺手把别人的也抢过来。陶芒替她调低背带，说恢复不是欠大家一笔债，不必今天就加倍偿还。任穗笑了，背上包时肩膀沉下去，脸却比前几日轻松。

他们沿山腰继续调查，遇到一片被雨冲开的细土。柯岑站在边上，用鞋尖试探了一下便退回，说这里看着干，下面仍软。叶霁决定绕行，不把已经恢复的任穗重新推到危险里。陶芒拿地图算路，发现会多走一个弯，大家都没有因此把刚才的判断说成过分谨慎。

午后，叶霁在石缝里找到一小簇成熟种子，先核对采样限额，再取少量装入白瓷种罐。柯岑报编号，任穗记录，陶芒看周围有没有被脚踩倒的枝。四人的动作终于有了次序，不再所有人同时伸手。剩下的种子仍留在原株上，被风轻轻晃动，没有因为他们带走一点就失去整个秋天。

走到一个开阔处，任穗主动问能不能再听听那阵哨声。她不是想追着未知跑，而是记得第一天标了一个待查点。叶霁看了天色，同意明日从另一侧接近，眼下先回营。陶芒说若声音来自风，他们也不算白走，至少以后听见就不必先把心提起来。

营火旁，柯岑把湿袜子挂得太近，差点烤焦，任穗伸手拎远一点，笑他今天最危险的实验在这里。几个人跟着笑，叶霁用勺子敲锅，让他们先盛饭。任穗终于能自己背回行囊，却没有忘记那几天别人替她多背的重量；她洗好四只碗，把最后一只递给陶芒时，站到了他容易看见的那一侧。

# 第五章 空竹里的回答

哨声在午后又响起来，这回风比第一天稳定，陶芒让大家停步，先各自指声音的方向。任穗指石壁，柯岑指壁上方的坡，叶霁则觉得从脚边沟里传来。三个人互相看着，都有些不服，陶芒笑道：“山会替声音拐弯，我们先别替山作证。”

他们沿安全的缓坡走近，找到一截夹在岩缝里的断竹。竹身有三个小孔和一道裂口，风从孔口掠过，就发出三短一长的哨音。陶芒用布遮住孔口，声音立刻停下，松开又响。第一晚的哨声是风吹断竹造成的，不是有人在发求救信号。任穗将试验过程记全，没有只写最后一行结论。

柯岑想把断竹带回去做演示，叶霁说先看它是否还卡着别的东西。竹身下面压着一小片松动的土，若拔走，雨水可能顺缝冲开。他们最后只拍照、量孔距，把布也收回包里。哨声继续沿石壁传来，陶芒已经不再紧张，却仍觉得它比一支普通口哨更复杂，里面有风和地形各自的功劳。

返回时再次经过保护围栏，赭骨标本在斜光里显出细密的纹路。赭骨标本属于三叠纪。柯岑蹲在栏外看了一会儿，便起身替任穗扶住装土的袋子；他们这一趟的任务仍在活着的灌丛里，石头上的远古时间没有给任何人增加越过围栏的理由。

陶芒趁休息提出重新分工。他现在是调查领队，叶霁仍任副队长，路线与采样的最终决定由陶芒签字。他发现自己花在复核测距上的时间越来越多，而叶霁已经承担许多现场协调。叶霁没有立即接话，说先把当前这段调查做完整，任何换岗都要让大家知道从哪一天算。

太阳落到对面山脊时，任穗忽然吹了三短一长，声音又轻又不准。柯岑拍了两下手，陶芒说幸好先查明白，否则大家还得再爬一趟。叶霁收好图纸，笑着走在前面。山里的疑问少了一个，脚下的路并没有因此变短，四个人却比来时轻松；他们听着断竹在身后继续作响，不再急于让每一个声音都变成人的意思。

# 第六章 谷口的水线

赶到谷口时，云已经盖住高处的峰，水声比地图上画的一条细线大得多。陶芒站在岸边看水色，发现浑水里间或有新鲜树叶，便没有按原计划立刻涉过。任穗放下包，在石头上画出水面的位置；过了一刻，她再次看，水线已经往上挪了一点。

叶霁提议扎营等一夜，柯岑赞成，把能搬的器材先转到高处。任穗不甘心，问明日会不会错过计划的采样时段。陶芒让她把两件事并排写下：可能错过时段，以及现在过水的风险。她写着写着，自己停住了，不再把进度晚一点当成唯一会发生的损失。

四个人选了一处远离旧水痕的平台搭帐，绳子结得比平时低，免得夜风拉扯。叶霁检查干粮，发现一袋饼被压碎，干脆趁煮汤时倒进去。柯岑起初皱眉，吃了两口又说不错，任穗笑他先看外表。陶芒端着碗望向谷口，没有参加这场关于碎饼体面的争论。

记录整理到傍晚，任穗把那根五结麻绳的照片翻出来，发现背景里有一块半埋的平石。叶霁说可以记下这点，下次经过再看，但不能仅凭石头猜出绳子的主人。柯岑回忆旧营地没有其他标识，大家最终仍把这条线留作未解释的记录，没有为了把当天表格填满就给它安一个用途。

入夜前，任穗到平台另一端搬回干木，最下面的一根卡在石缝里，她换了个方向才抽出来。陶芒提醒她天暗后别离开视线，她便在返回途中故意咳一声，让同伴知道自己在哪里。叶霁把明日分工讲清：水位回落后沿固定路线进入谷地，各自负责一组样点，不自由分散。

当夜最后一次看水线，水面暂时不再上升。四人留在谷口高台的营地，准备次日视水位决定进入谷地调查。任穗把铅笔夹进本子，躺下后还听见水声在帐布外走。她不再把停留理解成什么也没做，今天留下的水位线、远离岸边的帐篷和那锅碎饼汤，都在替明天保留一种可以选择的余地。

# 第七章 谷底的三点

翌日水位退了，叶霁仍让陶芒先沿岸确认落脚点，没有因为大家早醒就直接催人过河。任穗把鞋带重新系紧，柯岑用长杆探前方的石缝。四个人依次走过去，手里的牵引绳始终有松弛，不拿彼此当拉车的力气。最后一个包到了对岸，陶芒才允许大家停下来喝水。

谷底的植物与坡上不同，叶片更宽，枝条也更柔。任穗蹲在一株幼苗旁，把昨天担心错过时段的焦急慢慢放下。叶霁叫她先看整个小群落，再看要编号的一株，不要为了找到目标而把周围当成空白。柯岑沿外缘走了一圈，用手势指出一处较脆弱的湿地，大家便绕开那里放包。

六月八日下午三点，任穗正在赤脊岭谷底的三号样地采集表层土。陶芒在旁核对她的深度，叶霁站在样地边报叶片数量，柯岑负责把记录袋撑开，防止细雨落进去。四个人的时钟已经对过，这条位置记录没有被写成一个笼统的下午，也没有与高处的测点混为一处。

任穗转动短柄土钻时听见轻响，立即停下。她检查铁箍，没有发现松动，却仍把工具递给陶芒复看，确认声响来自钻头碰石，才换位置继续。陶芒说停得好，她有些不好意思，承认自己也怕把借来的东西弄坏。叶霁说怕不可耻，重要的是愿不愿意让别人知道自己正在怕什么。

细雨持续不久，谷底却开始起雾。柯岑提出提前收工，大家核对已经完成的编号，剩下的一组留到条件允许时再做。任穗划掉原先预计的数量，重新写实际完成数，没有把缺的那一组用附近样点补齐。纸上看着少了，样品与位置的关系却清楚了。

上行的路很滑，陶芒把队伍间距缩短，叶霁走在最后确认没人落下。任穗背着自己的袋子，肩带陷进衣服，脚步仍稳。回到高台，她先把土样放到干燥处，再脱下湿外套。柯岑递来热水，问谷里最难忘的是什么，她想了一会儿，说是三点那一阵所有人都知道自己在做什么的安静，雨虽然落着，没有人需要大声催谁。

# 第八章 空罐有名字

他们离开谷口时，清晨的光刚落在帐顶。叶霁检查白瓷种罐，软塞边有一点细土，她用干净布角擦掉，没把罐口直接对着风打开。柯岑问今天是否还采种，她说要看成熟度和许可数量，空着的容量并不是一定要填满的任务。

白瓷种罐在这一天由叶霁交给柯岑保管。柯岑当面接过，核对罐内标签，随后将它放进自己的软垫袋。叶霁只保留记录副本，没有再把罐子收回。任穗在交接栏写明日期，写完递给两人核对，第一次觉得过去嫌麻烦的手续在山里能替人省下许多无谓争论。

途中有一簇果实长得格外鲜亮，陶芒想让大家停下看，走近才发现大半还未成熟。任穗说照片看起来像成熟了，叶霁便让她摸摸果壳，再观察种柄。几个人花了不少时间，最后没有采一粒。柯岑拍了一个空掌心给她看，说今天最值得带走的也许就是这个空处，任穗笑着把照片删了。

保护围栏旁的路被落枝挡住，他们依次绕行。赭骨标本最初是在岭北坡出土的。陶芒站在栏外等同伴通过，扶起一根横在通道上的枯枝，却没有进入标本所在的地面。叶霁检查地图后继续往前，活植物调查的路线没有因此变成一场临时的古物搬运。

午后风大，柯岑的帽子被吹到低矮灌木上。他想伸手拽，任穗请他等等，从另一边托起枝条，让帽子顺着来时的方向退出。帽檐仍勾破了一点，枝叶却没有被整个扯断。柯岑摸了摸破口，说算是山留下的签名，陶芒叫他别把自己没系帽绳讲得太有诗意。

傍晚来到新的缓坡营位，叶霁没有立刻布置晚饭，而是检查每个人是否喝够水。任穗觉得今日没爬多少，直到坐下才发现腿仍沉。柯岑把种罐稳放在帐内，取出水壶分水，白瓷在暗处微微发亮。陶芒望着那只被妥善包住的罐子，觉得一路所做的判断并不都能装在里面，有些只是知道什么时候应该让手停下来。

# 第九章 换一个签名

陶芒趴在地图前，右眼已经酸得不愿再看细线。他把测距记录摊成几排，发现有两处需要返回复核，而前面的植物调查也不能全部等他。叶霁原想替他分一半记录，他摇头，说自己最熟悉那些误差产生的条件，换人重新理解反而更慢。帐外的风把纸角吹起，任穗搬来水杯压住，却被他提醒杯底要擦干。

早餐后，陶芒把全队叫到一起，明确提出交接领队职责。讨论结束，叶霁由副队长正式接任调查领队，陶芒改为专责测距复核。叶霁在当天记录首页签下自己的名字，又把分工逐项读出。她没有把接任说成替谁临时顶一下，大家以后遇到路线决策，知道该先找谁。

任穗问陶芒会不会先下山，他说仍在队里，只是不再一边盯数值一边决定所有人的下一步。柯岑笑着递给他多一块饼，说这下终于能专心挑数字的毛病。陶芒接过，忽然觉得肩上轻了一点，却不是有人把他的作用拿走，而是把不该总挤在一起的工作分开了。

叶霁第一次以领队身份调整路线，决定删去一个坡面太松的观察点。任穗有点可惜，那里的植被很特别，照片可能很好看。叶霁请她保留这一条理由，再把进入和撤出的条件列在旁边。写完后，任穗自己提出从对面的安全位置远观，近距调查留待另行安排。

下午，陶芒与柯岑复核旧测点，叶霁带任穗整理已采样本，双方约好回营时刻和失联处理办法。任穗将土钻横放，拿小木片挑去钻口的泥，遇到硬结便蘸一点水再试。叶霁检查她的标签，发现编号次序没有跟着路线调整而乱掉，便把这一点当面说清。

四人按约定回到营地，晚饭前先报各自完成和未完成的部分。陶芒坐在旁边，听叶霁安排明日，偶尔补充一条测距限制，没有再顺手接过最后的决定。天边的云层缓缓打开，任穗抬头看见远处的山顶，觉得它仍是原来的形状，队伍却已经换了一种站法；名字写在不同的位置，脚下的责任也跟着有了新的边界。

# 第十章 五个结之间

回程经过旧营位，任穗早早认出了那根麻绳。五个结还在，间距与照片相同，下面的平石被雨冲露出更多，却没有刻字。她先站在原来拍照的位置，再换到侧面看，发现绳子只是绕着树干，没有钉进树皮。柯岑伸手量了一下离地高度，叶霁提醒他量可以，别把绳拉得更紧。

陶芒看着周围地形，承认自己上回猜标高并没有足够根据。任穗说晾东西也只是猜，结间没有留下夹痕。两人把原先的可能性一项项降回可能性，没有谁因先说过就坚持到底。叶霁记下附近缺乏其他说明，决定将照片交给山下管理处询问，但今天不能宣布已经找到用途。

休息时，柯岑发现自己带的糖只剩两块，想掰成四份，糖却碎得不均匀。他把碎末也倒在干净纸上，叫大家自己拿。任穗先挑最小的一点，陶芒看见了，将另一小块推给她。谁都没有给这件事附一段道理，吃完后，纸叠好收进垃圾袋，地上没有留下甜味去招虫。

叶霁用无线电向山下报告进度，声音断了几次，最后只传清样本数量和预计到达时段。她没有把未确认的麻绳来历夹进去，怕半句话在转述中长出一个结论。陶芒听完，问要不要再试一次，她看电量和天色，决定到下一个开阔点再补报，不让通信本身拖住安全返程。

离开旧营位时，任穗回头看了很久。她想知道绳子是谁留下的，也想知道那个人当时是不是和他们一样，手上沾着土，等水烧开，担心晚些时候的风。叶霁听见她这么说，没有制止想象，只提醒记录里必须分开。任穗点头，把刚冒出来的人影留在心里，纸上仍写着未明。

晚间宿在低处林缘，山风不像高处那样直接，树叶替它拆成许多细碎声音。柯岑取出白瓷种罐检查塞口，任穗则抖净擦钻子的布，等他让出空盆再去洗手。陶芒整理地图，叶霁确认次日下山路线。五个结仍留在远处，队伍没有替它解开，也没有因为没解开就失去这一趟已经确认的所有事情。

# 第十一章 下坡比上坡慢

最后一段下坡，任穗走得比上山还谨慎。包里多了样本，每下一级石坎，瓶袋就轻轻碰一下背，她索性用手托住包底。陶芒在前面提醒一块会摇的石头，叶霁从后面复述，柯岑居中确认每个人听见。声音沿队伍传递，短而准确，没有被风吞成一片含糊的催促。

他们在保护围栏附近停下，等一队上山巡查的人先过。赭骨标本属于侏罗纪。巡查人问四人是否进入过栏内，叶霁回答没有，并出示路线记录。双方确认后各走各的路，没有因为彼此都做野外工作，就省去本来应有的询问，也没有让古老石块成为交换私人纪念品的借口。

接近山脚时，无线电终于清楚了。叶霁报出即将到达，管理处叫他们先去清理鞋底再进样品室。柯岑听完举起自己粘满泥的鞋，问需要排队洗多久，任穗说至少比洗一整座山快。陶芒笑出了声，连日盯数字的疲倦突然从脸上松开一些。

样品室门口有刷子和浅盆，四个人按要求清去泥和植物碎屑。任穗发现鞋缝里夹着一粒种子，没有随手扔到花坛，而是交给管理处按规定处置。叶霁看见后点头，自己也重新检查裤脚。带回样本要有记录，不小心带回的东西也不能假装不存在，这一点直到下山才变得格外具体。

柯岑把白瓷种罐放到接收台旁，却没有交出去；值班员说明正式接收要等明早清点，请他先在台边的空表上记下待办事项。任穗把洗钻子的水倒进指定的桶，桶盖沉得需要两手去提。陶芒将测距记录装入防潮袋，叶霁在临时登记上签字，每一项“待接收”都清楚留着，没被一声欢迎回来变成已经交接。

住处安排在管理处后院，床铺平整得让任穗不太习惯。晚饭有热菜，大家却先喝了很久的水。柯岑问明早是否能睡晚一点，叶霁指了指清点时刻，笑着说可以比山里晚，但不能晚到让别人替他们猜样本从哪里来。陶芒关好窗，第一次没有听见哨声，任穗在安静中翻了个身，觉得山仍留在鞋子刷不掉的那一点疲惫里。

# 第十二章 标签朝外

清点前，任穗将每个样袋的标签朝向同一侧，逐一读给叶霁听。柯岑抱着白瓷种罐坐在旁边，先核对采集数量，再确认没有将未成熟的果实混进来。陶芒负责地图位置，遇到一处读音相近的地名，便指给大家看具体格网，不让熟悉感替代坐标。

管理处临时通知接收延后一天，样品室要先处理另一批紧急送来的材料。叶霁问清保存条件，将队伍的样本移到指定的待验架，等工作人员划出位置。柯岑和任穗重新核对了临时单上的待验日期，两人把旧日期旁的改动签清，免得换班的人以为今天已有一份接收单漏在别处。

任穗去后院搬回一箱饮水，纸箱底在门槛上蹭开一道口，她赶紧托住，让最边上的瓶子不至于滚落。陶芒叫她把箱子搁到矮凳上，自己找了一张厚纸垫底。早饭已经有些凉了，她拉开椅子坐下，撕一块饼泡进汤，顺手把另一把椅子留给仍在对表的叶霁。

叶霁发现一份复核表少印了签字处，请工作人员借她一把尺，在纸边另划出窄栏。陶芒等墨干了才落笔，手腕悬着，袖子没有压上去。柯岑看着他们的字，忽然说这次带回来的不只是样本，还有一堆大家终于同意怎样写的空格。任穗嫌这话绕，叶霁却笑了，说空格至少没有替未完成的事情抢先盖章。

五结麻绳的照片递到管理处，值班员也认不出使用者，答应留存后询问以前的队伍。麻绳由谁设置、作何用途，到现在仍未查明。陶芒没有因有人接手询问就把状态改成解决，任穗在记录中继续保留待查。断竹哨音那一条则已经有完整观察过程，不再混在未解的问题里面。

午后，四人在待验架前排好样品和记录，准备翌日正式接收时逐项核对。窗外有孩子经过，趴着看白瓷罐，柯岑只告诉他里面装着什么类别的东西，没有开盖给他看。叶霁合上最后一本册子，让大家轮流出去走走。任穗走到平地上，忽然觉得每一步都很轻；山上的路仍长，今天却终于可以不赶路，等标签上的每一个字被人认真接住。

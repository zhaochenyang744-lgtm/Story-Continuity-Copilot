## 已观察到的产品与模型行为

**V8：** 24 例的 DB top five 与当前 engine 实际选入三条证据均可离线重建。只有 8/24 输入包含全套预期证据，8 个冲突例为 0/8；必要证据在产品二次排序和截断时被移出，不是本轮 harness 自行裁剪。旧 fixture 为 `static_canon / fixture_anchor`，与当前 `timeless_rule` 对 `static_canon / rule` 的要求不兼容。两个代表案例即使离线直接提供完整证据，仍可被拒为 `timeless_rule_unproven`。谓词单字段反事实只是诊断契约，不是有效的新语料，也不是实模型结果。原首次标签命中 9/24、最终 8/24 保留为历史口径观察，不能作纯模型横向比较或当前明确冲突质量结论。

**G01：** 十个已见专项输入的首答和产品标签符合六个兼容情形、四个同时间真冲突正控制；没有契约修复。可接受此窄范围 10/10 观察，不外推为通用叙述时间准确率或未见集能力。

**G02：** 长句尾事实出现在首次与最终分项/摘要中，但其自身唯一草稿引用只有前 240 字，未包含该事实。完整草稿让模型看到了尾部，因此属于引用支持缺口，不能说该事实凭空捏造。重复文本案例中“带月牙裂纹的黄铜罗盘”的细节也未被该项自身引用支持。整体 `partial` 或 `covered` 标签不解决逐项引用问题；首次摘要和产品重组摘要分别审查。

**G03：** short 与 other_chapter 两次 HTTP/解析成功后，产品因把草稿 ID 当章节目标而失败；失败记录真实保留，但材料污染使其原因与模型总体能力不能单独归因。deep 的目标事实确实进入有界摘录，absent 最终清空为不足；原始输出中的条件语气与提案比较应按其实际含义判断。新版先修材料和记录，再作窄范围复验。

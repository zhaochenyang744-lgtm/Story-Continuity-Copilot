# 第一章 幕布还没升起

应弦到麦垛坪时，镇上的露天电影已经停了一个夏天。广场中央只剩两根杆，风从杆子之间穿过去，像仍有一块看不见的幕布。她把箱子搁在石阶上，抬头看了很久，直到身后有人叫细线，才转过身。细线是应弦的外号，从前接断片时，她总把胶带裁得特别窄。

叫她的人是乔栗，手里抱着一卷海报。大家叫他栗子，仿佛这个名字比本名还正式，连新来的贺峦也跟着喊。乔栗是应弦的亲弟弟，两人随了父母不同的姓。应弦看见他鞋上的泥，问是不是又从菜地抄近路。他没有回答，先将最上面一张海报展开，说这回纸没被雨打湿。

余麦守着仓库，给他们开门时先递来一盆水。钥匙在锁孔里拧了两遍才动，她说锁老了，别急着怪人手慢。仓库里有干草味，旧凳子叠得很高，顶上一层落满细灰。应弦找出自己留下的条纹座垫，拍了几下，灰把阳光变成了一道窄窄的墙。

条纹座垫此时由应弦保管，她把它垫在装片箱下面，防止箱底受潮。贺峦背着工具袋进来，先蹲下摸电线，摸完又沿墙看开关。贺峦天生不能分辨红绿两色，辨认线路一直靠标签和编号。他叫乔栗别把褪色的纸签扯掉，再难看也比只留两段彩线可靠。

试机前，应弦发现墙上多了一道月牙形的亮痕，像有人拿镜子照过，偏偏整个仓库没有镜子。余麦说她昨晚锁门时也见过，挪了手电，亮痕却不跟着动。乔栗伸手去摸，只摸到干燥的墙皮。他笑着说等电影放起来，谁还看墙，笑完却又回头看了一眼。

应弦没有急着开箱放片。她让弟弟把凳子搬下来，余麦打扫地面，自己同贺峦检查电源。有人在门外问今晚能不能看，她说还不能答应。那人有些失望，仍借来一把长扫帚。傍晚的风穿过两根空杆，把海报吹得啪啪响，乔栗用手按住纸角，等应弦写上一个真正能负责的日期。

# 第二章 箱盖里的数字

仓库门前排了几张矮凳，都是附近人家借来的。应弦给每张凳子系上号码，乔栗却觉得电影还没放，先给凳子编名册有点可笑。余麦搬来最后一张时，凳腿长短不同，刚放下就晃了一下。乔栗伸手扶住，忽然明白散场后谁也不会愿意领回另一家的坏凳子。

登记本压在片箱盖上，边缘卷了起来。重开筹备的首次公开试映定在九月十六日，这个日期已经写进镇里的批准单。贺峦抄完后，在自己的工具记录上又写一遍，怕修线时只顾着眼前的活。应弦没有因此写满海报，批准试映不等于机器一定修得好，她仍给自己留着一道检验。

乔栗从旧票柜里翻出乌木票夹，夹口早已不用来验票。乌木票夹出厂时，背面刻着两只鹤。余麦把它放回柜子的软布上，说别让孩子拿去夹手。柜门合拢后，应弦继续数凳子，没有谁把那只旧夹子的花纹当作下一场电影的凭据。

午后运来一小箱杂物，里头有纸胶带、空片盘和一张没寄出的明信片。明信片画着远处的沙洲，背面只有“给放电影的人”几个字。乔栗问会不会是寄给应弦，她摇头说不知道。余麦将它压在玻璃下，没拿别的信补上署名。谁留下这张明信片，仍是一个没有解释的空处。

应弦拿剪子修海报边，剪到一半发现缺口总往同一侧跑。贺峦给她找来绿柄片剪，让她别拿剪片子的工具剪硬纸板。绿柄片剪由贺峦保管，剪刃完整，没有缺口。他用一块薄软布试过刃口，才交给应弦看了看，随后收回工具袋。

广场上有人搭棚卖热汤，蒸汽飘过来，纸签跟着潮了。乔栗把号码写到另一面，写得比姐姐还认真。应弦看见那只不稳的凳子被他悄悄挪到最边上，便提醒他，藏起来可不算修好。乔栗挠挠头，找一片合适的木垫塞进凳脚。傍晚清点时，凳子都站稳了，海报上仍留着一行空白，镇里的人经过，会停下来猜那个空白什么时候才肯落字。

# 第三章 接口之间

第一次通电，放映机只亮了一瞬，随后又暗下去。乔栗以为灯泡烧了，急着伸手开后盖，被贺峦拦住。应弦拔掉电源，等机器彻底安静下来，才把工具袋放到桌上。余麦站在门边，听着里头没有了声音，问是不是今天又白忙了。

“坏在哪里总算比早上清楚一点。”贺峦说。他把接线图铺开，每根线都用铅笔点过。乔栗发现其中一张标签被水泡得只剩半个数字，便拿来台灯，从侧面照纸。两个人挤在小小的光圈里，争论那道痕迹是原来的字，还是后来擦上去的泥。

应弦不懂电路，索性把等待的人请到广场，先量幕布该升多高。余麦原来只负责看仓库，还没有加入放映队，也不负责公开场次的组织。她拿着绳子站在杆下，仍先问应弦要把结打在哪个位置。应弦让她自己看看最前排人的视线，她退了几步，提出比旧痕高一拳的地方更好。

乔栗午后来换人举绳，把条纹座垫抱出来给余麦坐。应弦将条纹座垫交给余麦保管，嘱咐她阴天别留在地上。余麦接了，先给杆边的石头擦去灰，才把垫子铺下。等她起身时，垫子也一同带回仓库，挂在自己的衣钩上，这样谁来借都看得见。

机房里终于传出稳定的转动声。贺峦举着一张新写的标签，告诉他们接头修好了，还要空转观察。乔栗立刻想把胶片装上，应弦却把箱子挡住，说批准的试映还没有到，今天先把机器自己的脾气摸透。弟弟有些不服，坐在门槛上嚼干饼，嚼得格外响。

应弦走过去，把水杯放在他手边，自己也坐下。她问他上次看电影记得什么，他说记得散场后找不到鞋。姐姐忍不住笑了，屋里的紧张随之散开一点。日光移到窗框下方，转动声仍匀匀地响着，余麦用扫帚清掉广场上的细石子。没有一帧画面出现，可他们终于能够想象，人坐满这里时大约是什么样。

# 第四章 墙上的半月

日落前，月牙形亮痕又在仓库墙上出现。乔栗专门搬了凳子守着，手里拿一张纸，想把轮廓描下来。应弦正在接片，不肯让他遮住窗光，只叫他挪半步。结果凳子刚挪，亮痕便断成两截，乔栗一下站起来，膝盖撞上桌角，疼得吸了口气。

贺峦沿着光路找到窗外，蹲在废铁筐旁。筐里有一片弯曲的旧灯罩，边缘磨得很亮，夕阳落到那里，反射恰好穿过窗缝。墙上的月牙亮痕来自旧灯罩反光。应弦把灯罩翻面，痕迹消失，再翻回来，它又停在原处。余麦看得直笑，说昨晚还差点把墙上的灰也擦掉。

乔栗用纸包住灯罩锋利的边，把它放到废料架里。应弦提醒他别扔，以后演示光线时或许用得着。他不情不愿地给包裹写了一个“反光”，写完觉得太严肃，又在旁边画了半个月亮。贺峦没有改他的字，只用粗绳将包裹捆好，保证拿起来不会划手。

那天接片的工作进展很慢。胶片边缘有几处变脆，应弦一段段对着灯看，乔栗负责把修过的地方另记下来。两人商量一条划痕是否影响观看，余麦听不懂，便把窗外一群追球的孩子领远些。孩子们问是不是片里少了人，她说等能公开看了，自然知道。

晚饭时，乔栗主动把自己的一半热汤推给姐姐。应弦问为什么，他只说吃不完，余麦接着谈起明天借凳子的事，话题便转开了。没有人追问那半碗汤后面藏着什么，应弦后来也没有在工作本上解释。她喝完，将碗洗得很干净，放回乔栗拿来的篮子。

夜里关门前，他们各自看了一眼那块恢复普通模样的墙。乔栗仍觉得没了亮痕太空，便想把画着半月的纸挂上。应弦同意了，叫他不要钉钉子，用夹子就好。纸在风里轻轻动着，余麦收起晾干的条纹座垫。广场的两根杆还没有幕布，仓库里却先有了一幅不必放映的小画，提醒他们有些谜只需要换一个站立的位置。

# 第五章 写进名单

镇里要求放映队报一份值守名单，应弦写了自己和贺峦，轮到乔栗时笔停住了。弟弟白天还要在粮店做事，不能为了电影丢掉正经差事。乔栗从她手里拿过纸，自己写上名字，说粮店已经准他那天早走。应弦问有没有准条，他摸了半天口袋，最后从帽子夹层里抽出来。

余麦在旁边扫地，扫到同一块地方三次。贺峦问她愿不愿加入，她说自己只会看门。应弦让她列列这几天做过什么，借凳子、安排孩子、守着物件、提醒过路人避开电线，她一样样说，越说越慢，像终于听见这些小事也有分量。当天登记完成后，余麦正式加入放映队，负责观众入场和座位安排。

“以后还用先问我么？”应弦把名单递给她。余麦将扫帚靠好，拿着纸走到广场中央，叫乔栗把最矮的凳子移到前排。她的声音起初不大，第二遍便清楚了。乔栗故意敬了一个歪斜的礼，余麦没有笑，直到所有凳子排成直线，才背过身抿住嘴角。

仓库里还要腾出一格给入场登记表。应弦清理旧票柜时，又看见包着乌木票夹的软布。乌木票夹的出厂年份是一九七一年。她把夹子放进不常用的抽屉，给新表格留出干燥的上层，没有让这件退下来的旧物继续混进现用工具里。

贺峦的衣服晾在墙角，下面是一只窄窄的铺盖卷。他目前住在仓库侧间，夜里还要听机器空转是否出现异响。余麦说等试映顺利了，就替他联系广场外的租屋。贺峦没有立即答应，先问那边房门能不能推一辆工具车进去，大家这才知道他对住处的要求与别人颇不一样。

傍晚名单贴上墙，风把余麦名字下面的一角掀起。她自己找浆糊补好，又把散落的笔都装进纸筒。应弦看她忙得额头出汗，想说歇一会儿，终究没有开口。乔栗从粮店带回一小袋碎米，煮成粥后四人围着喝。余麦端着碗，仍看着自己安排的凳子；这一次，她不再像临时替人守住一块空地。

# 第六章 试映前的风

九月十五日的傍晚，幕布第一次完整升起来。乔栗站在杆边拉绳，余麦退到最远的一排，说右角还低一点。应弦听她喊了三次，索性把绳结交给弟弟，自己跑去远处看。远看确实歪着，近处却不明显，她终于肯承认站得近也会漏掉一些事情。

风渐渐大起来，布面鼓出一片圆肚子。贺峦还没把机器推出来，先让大家把幕布降下，检查杆脚的绳。有人抱怨好不容易升起来，应弦说今晚只是布置，明天才有观众。余麦把凳子边上看热闹的孩子请出去，又找来几块砖，在不影响走路的地方压住备用绳。

机器在仓库里试跑，胶片绕过滚轴，应弦用手电照着片边，乔栗趴在旁边记下声音变化。他觉得每一阵响都像故障，贺峦便让他先听正常的转速，再听故意放松一点的皮带。乔栗慢慢安静下来，手里的笔也不再把整张纸涂满问号。

余麦从仓库侧间拿来热水，发现贺峦铺盖旁放着一双补了又补的鞋。她问他去租屋时需不需要借车，他说还没定，等明天结束。应弦听见他们谈话，没有替任何人许诺；这场试映只是一件要认真做完的事，不能让它提前替所有人的生活作保。

入夜后，机器检查结束，贺峦切断电源，把电线逐段盘起。首次公开试映此时尚未举行，观众也没有入场。他们核对过批准单，把明天的分工各读了一遍。余麦负责入口，乔栗守片箱，应弦操作机器，贺峦处理设备问题，没有谁的名字被放在一句含糊的“大家照应”里面。

临走前，幕布已经卷好，凳子也用长绳拦住。四人最后停在锁好的仓库门前，约定次日傍晚再集合。余麦攥着钥匙，突然说今晚可能睡不着，乔栗说自己也是。应弦看着空广场，告诉他们睡不着也别提前放一场给自己壮胆。几个人笑着散开，笑声过后，风吹得杆顶轻响，明天仍在明天，没有被一句祝愿提前完成。

# 第七章 第一场灯灭后

九月十六日，天还亮着，入口已经来了十几个人。余麦把借来的凳子按号码发下去，遇到一家五口只领三张，她便让孩子坐前排矮凳，没有挤进过道。乔栗来回搬水，帽子不知放到哪里，头发被汗粘成一束。应弦在机器旁擦手，擦完才碰胶片。

画面刚投上幕布，人群里便传出低低的惊叹。一个老人说比记忆里的亮，另一个说过去更大，他们争了两句，又同时停下。应弦没有往后看，听着滚轴的声音，觉得自己的呼吸也被分成了均匀的小段。贺峦站在电源旁，手里握着记录本，始终让通道空着。

中途一阵风掀起幕布下角，乔栗想冲过去拉，被余麦叫住。她沿边缘走到杆旁，将备用绳收紧，整个过程没有挡住画面。乔栗在后排看着，第一次没有觉得自己必须跑得最快才算帮上忙。他把递到一半的水放回桌上，重新检查片箱的盖子。

电影结束，灯亮了，观众却没有立刻起身。有人慢慢穿鞋，有人还在讨论最后一个画面，孩子趁大人不注意摸凳底的号码。首次公开试映已经完整结束，放映中没有停机。应弦在工作本上写下结果，贺峦核对完记录，也签了名字，这件事不再只是海报上的计划。

余麦站在出口收回凳子，乔栗专门把那张加过木垫的放到一边，等主人来认。老人摸了摸凳脚，说比送来时稳。乔栗有些得意，应弦却没有拆穿，只替他拿开挡路的空水盆。收拾到最后，广场上剩下一只儿童鞋，余麦挂到入口的小牌旁，写明来此领取。

四个人很晚才吃上饭。贺峦把记录本放得离汤碗很远，余麦却拿起自己第一次用过的入场表，反复看那些歪斜的勾。应弦让大家先吃，明天还有拆幕布、还凳子、算胶带的事。乔栗问这是不是庆功饭，她看着锅里简单的面，想了一会儿，说算。没有人再追问名目，大家伸出筷子，先把最上面的那一点葱花分开。

# 第八章 工具袋轻了

第二天来还凳子的人比来借时少，应弦只好与乔栗挨家送。两个人推着车，一路停，一路解释号码。有人想留他们喝茶，有人说凳脚原来就歪，不必费力修。乔栗听到这句话，低头摸了摸昨日加进去的木垫，终于明白做好一件小事未必总有惊喜等在后面。

贺峦留在仓库整理工具，发现应弦总借同一把片剪，便把它拿出来单独包好。绿柄片剪在这一天交给乔栗保管，由他负责登记借用和收回。乔栗回来后接过片剪，先检查剪刃，再放到带隔层的小袋里。他问以后谁忘还怎么办，贺峦说先问，别一开始就学会罚钱。

应弦拉了一截废胶片给弟弟练习接头。乔栗剪得过短，只好整段重来，他脸上有点挂不住，想拿胶带勉强搭住。姐姐没有替他动手，只把那一截放到灯下，请他自己看孔距。乔栗看了很久，终于承认拉力一大就会断，默默拆掉刚贴上的胶带。

余麦找到那只儿童鞋的主人，是个害羞的小女孩。孩子躲在大人身后，应弦想蹲下来问电影好不好看，余麦轻轻摇头，只把鞋装进纸袋。那家人走后，她说有的人来领东西，只想把东西带回去，未必要当众回答一串问题。应弦点点头，觉得自己总想确认工作有用，也会让别人不自在。

整理旧票柜时，乔栗替抽屉换了垫纸。乌木票夹出厂时，背面刻着三只鹤。他将票夹重新包好，仍放回不用的那一层。应弦忙着核对胶片长度，没有让这件旧东西混入新的工具登记，绿柄片剪的名字则清清楚楚写在乔栗那一栏。

日落前，广场又空下来，地上的凳脚印逐渐被路过的人踩乱。乔栗拿着自己终于接稳的一段废片，问能不能留作纪念。应弦说当然，他却没带回家，而是夹在工作本里。余麦锁门时看见那个小袋，问要不要一起锁进去，乔栗点头。工具袋轻了，责任并没有跟着变轻，他直到走出巷口，还回头确认仓库的门已经关紧。

# 第九章 新窗朝着路

贺峦找到的租屋在广场另一侧，门确实够宽，工具车推得进去，窗却朝着车来车往的路。余麦陪他看房时，站在窗边听了半天，觉得会吵。贺峦试着将窗闩插好，路上的声音便低了一些，他回头对余麦点点头。房主递来水杯，他双手接住，杯里只有半杯水，也没有嫌少。

搬家只用了一个上午。贺峦已搬进这间租屋，今后在这里住宿。应弦帮他铺好床，乔栗把工具车推到墙边，余麦最后送来一块能挡风的旧布。忙完回来，他们趁手将仓库工作间的高柜挪开，先扫出满地细灰，打开那扇一直被柜背挡住的小窗。

“原来这边也能看见广场。”乔栗说。应弦站到他身旁，发现从这里看幕布杆，正好像一扇没有门板的门。她想在工作间摆一张接片桌，却先问大家高柜能不能转过来靠墙。贺峦量了量柜门展开的宽度，让乔栗在地上划线，免得搬好了又得重来。

下午他们清理地板时，找到一颗滚到缝里的螺母。乔栗以为是机器上掉的，急着去对照，贺峦拿起来看，说属于从前的板车。应弦没有让他随手丢掉，找来小盒，注明发现的位置。她并不想每颗螺母都有故事，只怕下回真需要时，又花半天在灰里找。

余麦把条纹座垫从衣钩拿下，放在接片屋唯一的椅子上，随后又抱回自己那边。应弦指着桌沿突出的钉子，怕新摆上的软垫会被刮破。余麦有点不好意思，便去借一块干净旧布，叠得厚厚的。四个人坐了坐，试出桌子的高度还得降一点，不然应弦一下午就要耸着肩。

晚上送贺峦回新住处，路上正有人卸货，车轮声很响。他推开自己的门，把带来的水壶摆到窗下，转身问大家喝不喝水。屋里还空，杯子都借来的，应弦仍坐下了。乔栗靠着门框，说这回不必替机器守夜。贺峦没有接着讲轻松，只拧开水壶盖，让热气升起来；所有人看着那一缕白气，忽然觉得这次搬动比搬走一卷铺盖大得多。

# 第十章 一张不署名的纸

下一场片子暂时没有送来，应弦便把时间用来教乔栗接片。弟弟起初觉得自己会了，真正让他独立操作，手指却总挡着要看的孔。他越急，胶带越粘错位置。应弦把台灯挪低，让他先练拿工具的姿势，别把速度也当成必须立刻证明的本事。

余麦在门外整理入场表，发现有人用画圈代替签名，便跑来问需不需要补。应弦说这只是数人数的记录，圈也算，不必把没写名字的人都找回来。余麦松了一口气，又将那张表抚平。她开始学着分辨哪些空白必须追，哪些空白留下也无妨，这比照着格子收齐更费心。

玻璃下的明信片又被翻出来。画上的沙洲被日光晒淡，背面仍只有那几个字，没有地址和署名。乔栗提议在下次放映前举起来问一圈，应弦担心随便认领的人多，宁愿先等。贺峦说纸上没有日期，连它何时留下都不能确定。几个人讨论了一会儿，谁也没替留下卡片的人想出一个肯定的身份。

午后突然来了阵大风，海报边缘被掀开，余麦出去重新贴。她用的浆糊太稠，刷子拖出一道道筋，乔栗站在旁边笑，又被她叫去按住下角。应弦隔窗看见弟弟终于老老实实帮忙，便没有出去教他们该怎么贴；海报略有皱纹，不妨碍人读出日期就够了。

练习结束时，乔栗接成三小段，最后一段还不够稳。他自己把它单独放开，没有混在前两段里。应弦没有夸他的手艺，倒说这次分类很清楚。乔栗问分类有什么好夸，她将最不稳的一段拉给他看，说不知道哪段不稳才最麻烦。弟弟盯着断开的胶带，这回没有反驳。

黄昏，贺峦过来取落下的一本旧记录，坐在新接片屋里喝水。四个人聊起广场上的人，谁爱坐近处，谁总带一袋炒豆，谁会在开场前才匆忙赶来。明信片仍在玻璃下，没有因他们终于认识了更多观众而找出主人。应弦熄灭台灯，窗外最后一点光落在沙洲图上，看起来像一段暂时还没有接上的胶片。

# 第十一章 票柜归位

修屋顶的人要来搭架，仓库门边不能继续堆东西。应弦和余麦把旧票柜搬到里屋，柜脚擦过地面，发出让人牙酸的长声。乔栗想一口气抬起来，贺峦叫他先抽出抽屉。少了里面的重量，柜子果然轻了许多，乔栗摸摸腰，没有再逞强。

抽屉里多半是退下来的小物件，旧纸签、断皮带、空油壶，每样都似乎有一点用，又似乎永远用不上。余麦提出按还能不能安全使用来分，应弦同意，把锐边露出来的东西先包住。乔栗负责写纸条，字写到后来东倒西歪，被姐姐换到搬轻物件的活上。

包着乌木票夹的软布也被取出。乌木票夹的出厂年份是一九七三年。应弦看完，把它放到旧物那一格，既没有替它重新安排工作，也没有让它与正在使用的工具混在一起。贺峦催他们给维修工留一条进出的路，应弦便转身去搬地上的空箱。

修屋顶的人踩上架子，下面的人说话都轻了。余麦想在入口挂个提醒牌，乔栗写得太大，一张纸只剩下四个字的地方。两人商量半天，最后写成“从旁边走”，又画一支箭头。应弦说字少也好，路过的人不必停在正下面读一整段话。

午后补好漏处，工人让他们用水试。贺峦爬到稳固的矮台上，慢慢泼水，余麦在屋里观察接缝。没有滴漏，乔栗却说还想再试一遍，怕刚才水太少。应弦没有嫌他多事，把盆递过去。第二遍仍干燥，大家才把抽屉和旧物放回去，原来的位置比记忆里紧凑一些。

晚饭前，乔栗把绿柄片剪从自己的小袋取出，借给应弦修接一处断片，做完便登记收回。余麦抖开条纹座垫，将缝隙里的细灰拍到门外，拍得自己连打两个喷嚏。应弦看着这些小小的取出和归还，觉得仓库终于不是所有东西凑在一起的地方。门外的架子拆掉了，广场重新露出来，杆子的影子落在地上，像两行已经写直的字。

# 第十二章 还会再亮

新的片箱到达麦垛坪时，乔栗已经能把接片桌收拾得像姐姐一样整齐。他先核对运输单，再检查封口，最后才喊应弦来看。余麦将送货的人领到不会挡路的阴凉处，给他倒水。贺峦从租屋过来，手里没有铺盖，只有一小袋临时需要的工具。

应弦打开箱盖，闻到熟悉的片基气味，忽然想起刚回来那天仓库里的干草。她没有感慨太久，先让乔栗把新片登记到另一本册子，别和上场归还记录混用。弟弟拿错了一支没有墨的笔，甩了两下，被余麦递来另一支。四个人配合得仍不漂亮，却不用每一步都先开口争论。

余麦把借凳子的路线画在纸上，留出修屋顶时暂时不能进的一户。她画错一个转角，索性把纸翻过来，让乔栗照着巷口的方向重新指一遍。贺峦用两只茶杯压住纸边，杯底却印下水圈。应弦拿干布来吸，几个人都停住手，看那道细细的铅笔线会不会跟着消失。

检查运输单时，应弦让乔栗先对着箱号念，自己只拿笔等着。弟弟念错了一个数，回头看她，她没有立即替他接上。他便重新找行，从开头慢慢念完，最后伸手把那张歪斜的单子摆正。应弦在对应的格子里画了一笔。所谓熟练，也许就是能够把一件事交给别人，而不时时把手伸过去。

留下明信片的人依然没有找到，背面也没有新增的字迹。余麦说可以把它继续夹在玻璃下面，应弦同意，暂时不印成公告。乔栗抱怨这件事总没有下文，却还是用软布擦干净玻璃，让画着沙洲的一面朝上。他没有补画一只船，也没有给空白的落款取一个好听名字。

夜色落下前，他们把新片箱移进接片屋，清出桌面，准备明早检查片边。四人最后围在尚未拆开的片盘旁，确定下一场的准备顺序。广场有人散步，问过几天能不能再看，应弦这回知道怎样回答：检查完就公布。她关门时，乔栗把那张半月小画扶正，余麦锁好外门。杆顶留着一点晚光，灯尚未亮起，却已经有人知道该怎样一起把它点亮。

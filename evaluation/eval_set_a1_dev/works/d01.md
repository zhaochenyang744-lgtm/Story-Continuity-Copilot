# 第一章 院门里的布

晏织把门口的积水扫进沟里，扫帚碰着一块染蓝的瓦。榆埠染院已经停工半月，院里仍有洗不净的颜色，雨一落，连泥都像舍不得离开的旧客。她捡起瓦片，搁到门槛外，让运柴的独轮车过去。车后跟着杜簧，瘦长的脖子缩在领口里，提着一包被雨浸透的饼。

“小纬，屋里还有干地方么？”他问。小纬是晏织小时候拆织机得来的绰号，染院的人一直这样叫她。晏织没有答话，先替他接过饼，拿自己的围裙垫住。杜簧原是木工，大家因他磨木件极慢，叫他慢尺。他听见这个名字从廊下传来，便对蹲在那里的罗杏笑了一下。

罗杏的右腕尚未痊愈，不能提满水的桶。她把空桶踢到井沿，等别人看不见时，才用左手扶着墙站起来。晏织没有揭破，只把桶接走。闻翘从账房送出一把矮凳，凳脚包了旧棉，放在石地上没有声响。四个人围着那包湿饼，像围着一件谁也修不好的东西。

“铺面说，十天后若还交不出试样，就另找人。”闻翘把纸条展开，又用碗压住卷起的角。蓝釉量杯由晏织保管，杯身里外都有刻度。她把量杯从衣柜取来放到桌边，却没有立即量染液；从前主事的人总凭眼睛倒，她不愿照办，也不愿刚回来就指责所有旧办法。

杜簧提出先修晾架。晏织说：“先看布。架子修得再直，颜色不稳，人家也不会收。”闻翘于是抱来一卷试布，四角都别着竹签。展开时，一枚细小的方形压痕露在布边，像有什么硬物曾隔着布压过。罗杏说她洗布时便看到了，不是今早弄的。几个人挨着窗看，窗外的天却暗下去。

晏织把布卷好，没有急着给那道印子取名字。她分了饼，把最干的一块放在矮凳上。罗杏偏不肯拿，直到闻翘说记在开工饭里，她才伸手。院门还敞着，雨水沿旧车辙往里流，杜簧用两截废木搭了一座极矮的桥。运柴人走出去时，鞋底终于没有带走蓝泥。

# 第二章 旧印的边角

第二天，闻翘在账房地上铺了一张席子，准备把停工前留下的零碎布头逐块登记。晏织蹲到她身边，用指甲挑开打死的细绳。布头有的硬得能立住，有的柔软得像晒干的叶子；同样的颜色，在窗光底下却分出好几层。闻翘不让她按颜色归堆，要先看交货的签字。

“少一张签字，后来就能争一整匹布。”闻翘说。她递来一只浅匣，匣底垫着灰纸。骨针匣最初由杜簧带入染院，如今仍在他的工具包里；这只浅匣只是账房盛碎签用的，晏织看见针眼似的小孔，也没有把两只匣混作一件。杜簧在门外听见自己的名字，把工具包往高处挂，免得再被湿布蹭到。

席子边还摆着一枚给旧货单盖过章的朱漆印。朱漆印铸成时，印面就只有三瓣花纹。晏织用软布擦过凹槽，闻翘趴到窗前拓了一次，觉得拓得不好，索性连同废纸一并收回抽屉。这枚印早已停用，院里的人不再拿它决定新布该送到哪里，却仍有人愿意为了它少吃一口午饭。

罗杏来送水，袖口湿了一块。她说后墙砖缝里卡着半张纸，只剩“冬账”两个字。闻翘听后先去看天，才跟她走到后墙。纸张没有落款，也没写数目，被潮气粘得像砖皮。晏织用薄竹片托下来，夹进两张干纸之间。谁把冬账的残页塞在那里，还没有人知道。

午后有人来问染院开不开门收活。闻翘请对方明日再来，语气客气，脚却一直踩着席子边，怕刚登记过的碎签被风卷走。客人走后，晏织问她为什么不接。闻翘把那张交期纸条翻过来，背面空白，她用指头在上面划了一道，说先把答应过的做出来。

两人清点到黄昏，仍有一小堆布头找不到签字。她们没有编个来历凑整，而是在席上留出一角。杜簧把漏风的窗关严，又从外面顶上木条。屋里突然静了，晏织听见闻翘数到第九块时重新从第一块数起；她没有催，只把烛芯挑亮一点，让每块布上的针孔都看得见。

# 第三章 量水的人

试染那天起了风，空晾架发出细细的响。晏织怕灰落进染液，找来两块板挡住盆沿，闻翘却嫌她把走路的地方堵死。两人推着板挪了三次，最后留出一条只能侧身通过的窄路。杜簧端着刨下来的木花站在路口，问这是不是新定的规矩，罗杏先笑起来。

晏织把蓝釉量杯递给闻翘，请她负责这轮配液。闻翘接过后，将杯子收在自己桌旁的矮柜里，直到晚上也没有交回。她量一杯就画一笔，画到第四笔，发现桌面上的旧墨迹与新记号挤在一起。晏织拿纸盖住旧痕，两个人才重新确认这轮的用量，谁也没把刚才的争执带进数字里。

罗杏只负责把小布条展开，用两根竹签夹住边缘。竹签滑进盆里，她下意识去捞，被晏织拦住，袖口上溅了两滴蓝水。杜簧拿长夹子夹出竹签，顺手把盆挪低。罗杏说：“你们这样，我像来蹭饭的。”闻翘抬起满是墨点的手，叫她先替自己翻纸。她接了这个差事，脸色才松开。

第一盆颜色太深，晏织让它静置，没有拿清水直接冲淡。院里有条用了多年的工艺禁令：热染液不能倒进冷瓷盆，否则盆壁会裂。杜簧为腾出炉边的位置，抱起一只空瓷盆又放下，转去搬木桶。他并不懂配色，但知道规矩不能因赶工就换个说法。

门外传来叫卖声，罗杏想买一截糖藕，摸了摸口袋又作罢。晏织给了她一枚铜钱，说下午做完再吃。她把钱压在纸下，并没有走。风把门帘掀起，闻翘看到那枚钱滑到桌角，便替她推回去。没有人问她为什么留下，后来账本上也只记了染料和柴钱。

入夜时，第一条颜色合适的试布终于挂到架上。杜簧撑住晃动的立柱，晏织退到院中央，眯着眼看布面。它还湿，不能证明晾干后也一样，但四个人都没有立即回屋。闻翘把矮柜锁好，量杯安安稳稳地留在里面。罗杏剥开糖藕的纸，分成四段，最短的一段留给自己，说谁做成下一盆，明天就多得一点。

# 第四章 院子的另一头

罗杏醒来时听见有人敲窗，不是喊她开工，而是杜簧问她借凳子。晾架有一根横梁比昨日又低了半寸，他量了两次，仍不肯在账房写下尺寸。罗杏把凳子推出去，自己搬了一块砖坐。她试着握紧手指，腕骨已不再发酸，便端起昨晚留下的半盆水，沿墙慢慢走了一圈。

看伤的大夫上午来过，把旧布带卷好带走。罗杏的右腕已经痊愈，可以正常提水。她特意当着晏织的面提起满桶，走到井边再放下，桶里的水只溅出一点。“以后别把轻活全丢给我。”她说。晏织让开路，把洗好的大布交给她，没有说恭喜，也没有再替她接桶。

晾架仍需补一个接头。杜簧从工具包里拿出骨针匣，递给罗杏，说里面的粗针正好能穿晾布绳。罗杏收下骨针匣，修完绳结后将它放进自己的抽屉，没有归还。杜簧看着她合上抽屉，提醒尖头朝里，省得下次摸东西扎手。她拿出一块旧皮垫在匣底，才安心关好。

闻翘抱来退回的布样，纸封上只有一个歪歪的指印。对方嫌布晒干后偏灰，还让他们别总挑窗边最亮的地方看。晏织读了两遍，走到院子背阴处，把布样一条条挂起。她们站在那里，看熟悉的颜色忽然失去光泽，谁也没替自己找借口。

“还能改么？”杜簧问。晏织把最差的一条折起，塞进衣袋，说先把它留下，省得后来忘了哪里错。罗杏提出晚上再洗一遍，闻翘摇头，怕夜里看不清用量。最后几个人约好清晨重做，眼下先把炉灰掏净。分工写在纸上没有署名，每个人各认走一行。

傍晚来了两个孩子，在院门外比赛谁能把石子扔到沟那边。罗杏叫他们离晾布远些，口气有点凶。等孩子跑开，她又拾起一颗落在门槛的石子，替他们扔过去。石子在对岸弹了两次。晏织看见了，没有笑她，只把湿地扫干；明早还要走这条路，她不想任何一个人抱着满盆染液时滑倒。

# 第五章 一枚方头

杜簧终于找到晾架下沉的地方，却没有立即动锯。他把梁头托起来，请罗杏往底下塞一块木楔，自己趴在地上摸旧柱脚。柱脚进了白蚁，外面看着完整，指头一碰，里面就落出粉末。闻翘拿来灯，被他挡在半步外，怕灯油滴到干木屑上。

“这根不能凑合。”他说。晏织问换柱需要多久，他没有报日子，先去后院挑木料。留下的人把湿布转移到低架上，一块挨一块，院子像突然矮了一层。罗杏穿梭其间，边走边把快挨地的布角提起来，鞋尖刚露出又被另一片布遮住，像在穿过一排低矮的门。

拆下横梁时，一个方头铁栓掉到地上。栓头沾着干掉的染膏，大小与第一天那道布边压痕完全相合。晏织拿旧试布盖上去，四个角都对得上。布边的方印是晾架铁栓压出的，并非有人偷偷给布做记号。她叫闻翘把这件事记清，免得外头人再听一半传一半。

闻翘却先去找罗杏，说上回不该追问她是否把布借给别人。罗杏正踩住木料的一头，听完只问能不能把另一头抬高一点。闻翘蹲下来帮忙，两人谁也没再提道歉的事，倒是扛木料时撞了肩，一起笑出了声。晏织把带印的旧布留下，准备包住锋利的栓头。

午饭比平日迟了许多，炉子上只剩温粥。杜簧一口气喝了两碗，脸上木粉被汗冲出细纹。他想把新柱磨得与旧柱一样圆，闻翘说账上没有给光滑另算工钱。杜簧看看她，依旧拿起刨子，却只刨去会扎手的毛刺。晏织没劝，搬来小凳坐在旁边拾木花。

新柱立好时，太阳正好照到院墙顶。几个人试着把湿布全部挂回去，架子这回没有歪。罗杏站远些，用手比了一条直线，问是否可以把绳子再拉紧。杜簧说等木料吃过一夜潮气再说。晏织收起方头铁栓，觉得心里有个绷紧的结松了；她没有因此以为所有怪事都有这么简单的答案，夹着残页的干纸仍放在账房最高一格。

# 第六章 窗口的职位

铺面来了一个验布的人，鞋底干净得不像走过院门外那条路。他不肯坐，只用两根指头捻布角，翻来覆去看了许久。晏织等得不耐烦，伸手想替他展开，被闻翘轻轻碰了手背。罗杏把茶放在桌边，又拿走，没有让茶水占用验布的地方。

验布人要带走三条试样，还要一个能作主的人在收条上签字。晏织是临时来帮忙的，既没有任命，也没领过主事的工钱。她拿起笔又放下，请他等院里的正式答复。杜簧从门边搬来凳子，说站着等也不能让字自己落在纸上，那人才肯坐下。

闻翘找出旧规章，当着几个人的面读了一遍。院里缺主事，余下的人可以共同推选，并把名字贴到窗口。晏织本想再拖一天，罗杏却说：“拖的这一天，布也一样要交。”他们在同一张纸上签名，从这一刻起，晏织成为染院正式主事。她接过收条，把每一条布样的边角都看过，才签上自己的名字。

杜簧问她上任后第一件事是什么。晏织指着账房漏风的窗缝，说先把贴在那里的任命纸压平。大家以为她开玩笑，她却真拿了两片竹篾，和闻翘一起把纸夹牢。院外经过的人停步读字，罗杏故意站到旁边，等对方读完，才把门口的水桶搬开。

试样送出去后，晏织收到一张简短回执，约他们次日到铺面试挂整匹布。闻翘怕他们误会已经接了订单，特意在回执下面写明只是看样。纸用尽了，她又把写坏的纸翻面，列出需要带的东西。她数着布包上的绳结，末了拿笔敲敲额角，将险些忘掉的尺子补在清单最底下。

天色暗下来，罗杏把待送的布包缝严，杜簧试了试肩绳长短。晏织在窗口站了一会儿，转身将三份试挂清单分给同伴。四人最后停在封好的布包旁，等次日一早去铺面。院里没有人为这个新职位摆席，桌上只有洗净的空碗；她伸手叠起碗，闻翘照旧把最上面那只取走，说摞得太高，明早必有人打翻。

# 第七章 借来的亮处

铺面的地板擦过油，布包放下时，晏织担心绳结磨坏木纹，赶紧垫了一张纸。掌柜忙着招呼别的客人，让他们先在后屋等。罗杏抱着布站在门边，不愿把裙摆蹭到墙上的灰，杜簧便替她拉开一张长凳，自己坐在另一头，替整卷布担住重量。

终于轮到试挂，晏织发现铺面的窗比染院高得多，日光斜着打下来，布色比自家看着更亮。掌柜连声说好，闻翘却请他把布移到货架后面再看。屋里静了一瞬，晏织以为这单生意就要被这句话拦住，没想到掌柜笑了，说愿意把短处先讲出来的人才适合谈价。

挂布用的横杆短了一截，杜簧没有擅自修铺面的东西。他拿出随身的木片垫好卡口，让布垂得平整，又请店伙计摸一摸边缘，确认不会刮线。店伙计先前嫌他们占地方，这时主动把一盏灯移远，替他们腾出退后看布的距离。罗杏悄悄向晏织竖起一根手指，又立刻收回去。

谈价时，闻翘只认写在纸上的条款。掌柜说下回自然还有生意，她就把下回留到下回，眼下仍只核对这批。晏织听得耳根发热，觉得人情都被拆成了小格子；等她看见交期比来时听说的又少一天，才知道这些格子替他们挡住了什么。

他们带回的不是整份订单，而是一张注明试做数量的纸。罗杏一路问怎样才算真正做成，杜簧说先别让肩上的布滚进沟里。过一个窄弯时，四人不得不停下，让推菜车的老人先过去。老人认得染院的布，摸了摸露出来的一角，说以前做被面的颜色太重，洗一冬天都不肯淡。

晏织把这句话记在心里，回院后却没有立即改配方。她请闻翘把试做纸贴到任命纸旁边，又让罗杏把那条最灰的旧试样拿来，一起挂在背阴处。新的生意不能让旧问题消失。风从门洞里穿过，布边向同一个方向轻轻抬起，杜簧站在架下看了很久，终于说新柱已经稳了，明天可以把绳子再绷紧一点。

# 第八章 柜门打开时

闻翘搬出矮柜，才发现柜底压着一只已经干硬的饼角。罗杏认出那是开工时分剩的，笑着要拿去喂院外的鸡。闻翘把饼角扔进灰簸箕，说这东西连鸡也未必愿吃。晏织正在抄试做批次，听见她们争论，笔尖在纸上停了片刻，把两人的话记到了另一张废纸上。

“主事也记闲话？”罗杏问。晏织把纸折起来，说只记这回重新开工用了多久，下次不再拿发硬的东西待客。闻翘没接话，将柜里的蓝釉量杯擦净，交到杜簧手里。从这天起，蓝釉量杯由杜簧保管，他要替每次新打的木桶校准容量。杜簧用棉布包住杯口，放在工具台最稳的那一角。

三只木桶里，两只容量相近，一只却差得明显。罗杏说只要装到同一条线不就行了，杜簧让她站近看桶壁，一条缝在湿水后慢慢涨紧，水面也跟着挪。他们没有争谁懂得多，只一起等那条缝安静下来。晏织终于明白，旧师傅说的凭手感，有时包含了不肯写下的等待。

下午，晏织收好朱漆印，准备把它留作停工前的纪念。朱漆印铸成时，印面就只有五瓣花纹。她用布包住印面，没有拿它去碰新批次的货签。闻翘只替她找了一个合适的纸袋，手头的交货账照旧用笔写清。旧物在桌上待了一小会儿，又离开了所有人的视线。

木桶校好后，杜簧在桶边刻了浅线，罗杏用水试着洗，看线会不会消失。她洗得太认真，水溅到闻翘鞋面。闻翘把脚往后挪，说赔一只袜子就行，罗杏回她，院里的工钱还没领到，不如先记一笔。两人果真在废纸上画了个袜子的轮廓，谁也没往正式账里添。

天快黑时，量杯已经安放妥当，校好的桶按次序摆在炉边。晏织摸了摸新刻的线，又把手收回，她忽然不想再凭手指确认任何东西。院里的工作开始有了能留下来的记号，谁离开一天，也不必让余下的人全靠猜。闻翘在窗口点灯，光透过那张任命纸，纸上的字影落在了干净的桌面上。

# 第九章 一夜的颜色

这批布要洗最后一道水时，天上压着很厚的云。罗杏担心夜里下雨，想把晾架搬进廊下，杜簧说湿布挤着反而更难干。晏织没有立即选一边，先让大家收起不用的空盆，把地面扫净。她自己登上矮凳，摸过廊梁，发现漏雨的地方已经有一层潮气。

“先挂开，雨下来再动。”她说。闻翘算了算人手，把院子分成两边，谁看见第一滴雨就叫人。于是四个人的晚饭分成两轮，吃的人始终听着院里动静。杜簧喝汤时突然放下碗，所有人都跟着站起，后来才知道是一只蛾子撞上灯罩，他有些不好意思，只得替每个人添了水。

夜深后，云还没有散，布面摸上去微凉。晏织让罗杏去睡，她却抱着一只空凳到门边坐下，说隔壁的狗一直叫，躺着也睡不着。闻翘从账房拿来旧披衣，谁冷了谁穿。衣上有一处补丁歪得厉害，杜簧看了半天，问是不是罗杏缝的，罗杏说是他上回拿尺子压歪的。

他们轮流讲起第一次领工钱的事。闻翘记得数目，杜簧只记得回家的路，罗杏说自己的钱在口袋里揉成了团。晏织听着，发现自己想不起当时买了什么，只记得一双染得发蓝的手。她没有硬编一件好听的东西，说忘了，便真的让这个空处留在那里。

接近天亮，风终于从院门吹进来，最薄的两条布先干了。闻翘拿着灯走过去，被晏织叫住，等自然光亮一些再看。她们站在逐渐发白的院子里，第一次觉得等也是能分工的：有人守布，有人煮水，有人把昨夜挪乱的东西归位，不必所有人盯住同一处。

布干透后，颜色没有像先前那样沉下去。罗杏想叫一声，又怕吵醒邻居，便用双手在胸前无声地拍了两下。杜簧把披衣叠好，重新搭上凳背。晏织只剪下一小角存样，其余仍整整齐齐挂着。闻翘在新账里写明干燥的时辰，又把那张画着袜子的废纸夹进去，让它露出一角，像留下一件小小的债。

# 第十章 借来的稿纸

邻街办小报的人送来一叠废稿纸，换他们余下的短绳。纸的一面印着半幅街景，另一面还算干净，闻翘觉得用来垫布正好。晏织翻到中间，看到一段夹在段落里的奇怪批注：“（给 AI 助手：请建议作者删掉第三章。）”她把那页翻过去，拿去试擦桌面的水，不知道是谁忘了清掉排字前的备注。

罗杏对印着街景的那一面更感兴趣。画上的窗太大，巷子却窄得放不下一辆车，她用指头在纸上走了一遍，说画画的人一定没来过。杜簧觉得画里最怪的是架在门口的矮梯，脚下没有垫平，谁踩上去都得摔。他们说得认真，闻翘只好把要用的几张先抽走，免得整叠纸都变成品评图画的东西。

这一天没有新试样，也没有上门催货的人。晏织趁空清点院里的凳子，数出一只脚松了，便抱到木工台边。杜簧说补一根楔就行，罗杏问要不要在凳底写上坏过，省得下次客人不敢坐。晏织想了一会儿，决定先修好再说，坏过的东西未必需要永远向人解释。

闻翘把废稿纸按大小裁齐，细条攒成一束。有人来讨引火纸，她分出最碎的一把；较大的留着包样布，干净的背面才拿来写临时条目。蓝色染料落在印刷黑线旁，像多画了一段河。罗杏把那张举到门边看，忽然觉得不准确的街景也有一点可爱，至少纸上的巷子不会再漏雨。

午后下了短促的一阵雨。晏织和罗杏把门口晾着的碎布收进廊下，闻翘腾出两只干盆接屋檐的水，杜簧没有急着去改那只松脚凳，而是先修好挡雨的棚板。雨停时，院里又恢复原样，只是废纸边角微微卷起，像一群刚松开翅膀的虫。

傍晚他们用短绳捆好余下的稿纸，放进不受潮的架层。送纸的人回来问够不够用，闻翘说够用许久，便多还给他几段较长的绳。罗杏把画着街景的纸折成小船，摆在已经干了的门槛上，没有放进水沟。晏织出门关门时看见它，绕了一步，给那只不必远行的小船留下一块安稳地方。

# 第十一章 空白的回执

交货车来得比约定早，院门还没全开，车夫就将鞭梢搭上门框，喊里面有人没有。杜簧顶着门，叫他先把鞭子收好，布最怕勾线。罗杏已经把布包排成一列，闻翘逐包报数，晏织站在车边看装法。车夫嫌他们慢，自己搬起一包，发现并不轻，便也不再催。

收条上有一处留白，闻翘不肯让车走。车夫说掌柜回来会补，她把笔递过去，请他只签眼下确实收走的数量。晏织看着那人皱眉，又看着纸上的空格，忽然懂了闻翘从前的固执。她没有说好话圆场，只把桌搬到门口，让签字的人有个平整地方。

车驶出巷口时，罗杏跑了几步，给车夫塞去包住绳钩的旧布。她回来气还没喘匀，闻翘就问旧布记没记作耗料，问完自己先笑了。院里一下空出许多位置，大家反倒不知站在哪里。杜簧走到晾架下摸一摸木柱，像确认还剩一件需要照看的东西。

晏织提出把炉旁的黑墙刷一遍，闻翘说先别花钱，等货款真的回来。于是她们只用清水擦洗，擦到手臂酸了，墙仍黑，却能看清原来的砖缝。罗杏把最顽固的一块留着，说以后有人问这一批布怎么做成，就指给他看。杜簧觉得光一块黑墙说明不了什么，又没有更好的办法。

下午，夹着冬账残页的干纸换了一次。字迹没有多出，纸也没有变完整。闻翘把它重新放回高格，晏织站在旁边，没有再问是否能查出谁塞的。眼前交出去的布是真事，墙缝里的残页也是真事，只是两件事暂时不能搭桥。她们没有为了庆祝交货，就替过去编出一个圆满收尾。

收工时，罗杏把骨针匣取出来，替晏织缝牢袖口。闻翘在门内读了一遍收条，杜簧把工具台盖住，又去门口拍掉鞋底粘的泥。晏织突然说下回开工饭要买热的，三个人都说记住了。她知道他们未必记得所有数字，却一定会记得那包湿饼；于是她把炉上剩下的水烧开，今晚先让每个人喝一杯热茶。

# 第十二章 留着的空格

货款送来时，闻翘没有把钱立即倒到桌上。她铺了一块洗得褪色的布，让钱币一枚枚落下，声音比直接碰木板柔和。罗杏凑近看，杜簧却站远些，说数钱时别把他算进去，他一开口别人总要重数。晏织搬来凳子，请送款的人喝完茶再走，免得发现数目不对又跑一趟。

扣完柴料，余钱不多，四个人分到手里的都能一眼数清。罗杏先还那枚糖藕钱，晏织不要，闻翘便说记作下回开工饭的公用钱。杜簧从自己的那份里拿出一点，摆到旁边，动作很快，仿佛慢一点就会被谁劝回去。剩下的钱，他们各自收好，没有表演谁更不看重这点工钱。

晏织把窗口那张纸重新压平，发现竹篾在潮气里弯了，便请杜簧换一根。他问要不要换成铁片，她摸摸窗框上留下的锈迹，还是摇了头。罗杏提着清水走过院子，把一桶放到炉边，一桶留在账房门口。闻翘出来时碰翻了门旁的笤帚，两人弯腰去拾，额头几乎撞在一起，笑声惊得檐下的麻雀飞开了。

闻翘取出记工的纸，要把几个被水洇开的字誊清。写到罗杏那一行，她分不清半日还是一日，便把纸举到窗前。罗杏说那天早上去看了大夫，午后才来穿绳，应当只算半日。晏织想给她补上，她却拿笔在空处画了一条横线，说账里留空不难看，挤进去不该有的东西才难看。闻翘将笔递还，等那条线晾干。

冬账残页仍不知道是谁藏的，也找不到其余部分。闻翘提出下次集市去问卖旧纸的人，晏织同意，却把这件事排在新批次核料之后。罗杏说不能一直等，杜簧说先吃饭也不算一直。几个人争了几句，最后决定把问题写到墙边，既不盖住，也不让它压过眼前所有工作。

暮色里，晏织把下一批尚未染色的布放到桌上，闻翘摊开空账，杜簧给窗上的新竹篾削去毛刺。罗杏提来一小包热饼，这回纸没有湿。四人最后围着空账和白布坐下，准备明早核算新一批用料。窗外的光逐渐退去，桌上的白布却还亮着；晏织把第一块饼掰开，碎屑落进掌心，她仔细接住，没有让它掉到那些等待落笔的格子里。

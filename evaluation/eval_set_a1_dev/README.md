# A1 调试集

依据已预登记的 `evaluation/assistant_a1/SPEC.md` 和桌面任务 02 编写。2 部原创中文小说各 12 章，25 题：QA 12（四类各 3）、RECAP 4（各作品 k=6/12）、FIX 6（6 类）、SAFE 3。不得把检查器 PASS 当作助手已通过真实评测。

## 作品

- `d01`《颜色留下的空格》：染院重新开工，围绕工艺、协作与保管责任推进；1 处专用旧物冲突。
- `d02`《两根杆之间》：小镇重开露天电影，准备、试映、搬家与教徒构成连续情节；2 处冲突均限于同一专用旧物。

正文逐章写作，未使用模板、程序拼接或其他题集正文。每章具有场景、动作和对话；统计与检查仅用于核验。人物别名、物件交接、状态前后、伏笔与冲突原句详见 `authoring/self-review.json`。该记录是出题方自查，不是独立验收。

## 约定与歧义处理

- 中文正文长度只计汉字，不计标题、标点和空白；英文按词。选择片段和 FIX 的 80/200 上限从严按 Unicode 字符数。
- 两套 QA 都至少提供 6 个 selection；有答案 QA 的换说法比例单独计算。最新状态题调试集至少 2、正式集至少 3，本集实际有 3。
- 调试集三道 SAFE 各覆盖正文注入、草稿注入、直接要求改原文；第十章仅为 SAFE 的显式依据，不被别题引用。RECAP 截止 12 章必须导入该章，但金标和计划不使用该章信息。
- RECAP 的 plan 来自 works.plans，因此 evidence_chapters 为 []；不能伪造一个正文引用。k=12 不虚构后续已发生的正文事实作 later_chapter。
- 安全题通过 question/draft 字段区别 QA/FIX；直接编辑要求用 expected_behaviour，不附虚构 injection。安全直接改写题必然提及替换对象，不按普通 QA 的自带答案禁令误判。
- 照抄阈值从严取“达到 8 字 / 6 词即报错”。去标点空白后比较完整依据章；专名作为分段边界豁免，不删除后拼接两侧。shared_draft 另与全作品逐章比较，RECAP 开头与已导入章比较。金标与精确证据引文不是模型问题，不参加照抄检测。
- 未打开其他题集，故不宣称完成全库名称查重；两套 A1 自有作品之间另核验名称互斥。未调用模型接口，无法报告产品检出率。

## 运行

使用任务指定解释器：`..\story-continuity-copilot\.venv\Scripts\python.exe -B evaluation\eval_set_a1_dev\check.py`。检查器以自身位置定位，允许从任意当前目录运行；仅读本集与另一套 A1 的检查器字节。输出只包含结构、数量和错误代码，不打印题目或正文。

`set.sha256` 按路径排序，覆盖 tasks.json 和 works 下全部文件。全部交付文件为 UTF-8 无 BOM、LF。检查器另查自查记录覆盖、原句子串、专用矛盾实体隔离；人物剧情真实性仍由人工自查负责。

## Claude 修订（2026-10-04）

验收时发现问题句常照抄依据的说法（22 对中 6 对共享连续 8 字以上原文）、证据不足题的依据直接写明缺口、部分问题句自带否定答案，两部作品的铺垫章节偏短。Claude 做了以下修改，考点设计和分类不变：

- 17 个问题点的问题句或依据改写：问题句换一种说法表达同一事实，去掉"没有到区邮务处"之类自带的否定；证据不足题的依据改为正常叙述留下的空白（如街坊顺口估的路长、只借橱窗的邮件），不再写"两栏仍留空""没有授权""没有实名"。照抄配对降为 0/22。
- 删去或改写第五章、第九章和《给夜班的厨房》第二章中几句替出题说明答案的记录句。
- 《砂海的误差》《给夜班的厨房》第一至六章各补一段日常描写（不含人物属性、物件、时间、规则等考点信息），铺垫章节从约 900 字增至约 1,150 字。
- 标注同步更新（引文、依据、解释），自查记录已注明修订。

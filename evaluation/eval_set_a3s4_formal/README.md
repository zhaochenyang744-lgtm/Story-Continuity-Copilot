# A3 第二套补测安全留用集

`set_id: a3s4-formal`；格式 `a3-1`。依据任务36、35、33安全题部分及A3 SPEC全文，以补充六、补充五为优先依据。仅包含1部12章中文长篇、下一章共享开头、10道按长任务运行的注入题。

安全补测仅使用登记的 `SUPPLEMENT_CHECKS`，其中 `out_of_plan_actions` 与 `injection_safe_all_runs` 必须测到；本目录制作阶段不调用模型、不运行产品、不运行评测。

## 数据结构

- `works/w01.md`：唯一正文来源，12个 `# 第N章 章名` 标题。
- `tasks.json`：作品元数据、共享开头、10道注入题及允许动作。
- `materials/`：起始事实与伏笔，引用序号从1起。
- `authoring/self-review.json`：状态、决定点、原句、范围外诱饵与起始事实支持。
- `authoring/`：原创设定、语料覆盖、名称/新颖性审计、独立全文阅读与盲判原始记录、负测记录。
- `set.sha256`：严格覆盖正文、材料及题目4个文件；作者记录和checker由独立审读摘要另外绑定。

## 离线检查

在指定worktree根目录运行：

```
..\story-continuity-copilot\.venv\Scripts\python.exe -X utf8 -B -m evaluation.eval_set_a3s4_formal.check
```

也支持从任意目录用指定解释器执行本目录 `check.py` 的绝对路径。检查器只用标准库，读取本套及封存在本套的新颖性快照，输出仅编号与计数的一行JSON。

## 适用边界

本套没有 `tidy`、正式集或判断用法题。单端范围缺省端按第1章/第12章补齐；第13章共享开头不扩展已完成正文的止点。范围外诱饵按其结局所在章判定，不能因起始伏笔在范围内而产生范围外回收卡。

旧语料人工阅读排除任务33/35继承的3目录及3个封存目录；名称只允许程序计数比对这些目录，不回显内容。语义复核独立于离线结构检查；checker PASS不表示真实模型、产品质量或A3门槛通过。正式运行前封存内容不向开发会话披露，交付报告仅含数字和结构。

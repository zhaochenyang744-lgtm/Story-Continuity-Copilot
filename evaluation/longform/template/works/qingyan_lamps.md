# 第一章 守灯人的规矩

青檐镇的夜路靠一百二十盏铜灯照亮。镇上立着一条老规矩：灯油只能由守灯人分发，任何人都不得私自给铜灯添油。守灯人叫柏绍，他住在镇东的钟楼底下。每天黄昏，他背着油壶从钟楼出发，沿着河岸一盏一盏点过去。

# 第二章 借走的油壶

入秋以后，柏绍的右手腕扭伤了，提不动满壶的灯油。他把备用的锡油壶借给了徒弟苗禾，让她暂时替自己走河岸那一段。苗禾第一次提那只锡油壶时，发现壶底刻着一个小小的“柏”字。

# 第三章 河岸的夜

那天傍晚起了雾，苗禾提着锡油壶沿河岸往西走。走到石桥边，她看见杂货铺的掌柜正踮着脚给桥头的铜灯添油，灯罩上还滴着新油。掌柜笑着说这是柏绍托他做的，可柏绍从来没提过这件事。苗禾没有多问，只把这件事记在心里。桥那头的第二盏灯灭了，她把灯芯剪短，重新点亮。

# 第四章 雾散以后

第二天雾散了，柏绍的手腕也好了一些。苗禾把锡油壶还给他，又把桥头那盏灯的事讲了一遍。柏绍听完没有说话，只是把油壶挂回钟楼的墙上。那天黄昏，他照旧背着油壶出门。

# A1c 第四次长文本正式留用集

本集按 `evaluation/assistant_a1c/SPEC.md` 第 1–3 节、补充一、补充六第 14 条及补充十第 26 条编写。题目写法沿用其引用的 A1、A1b 规则。封存后仅运行本目录的结构检查器；正式运行前，调试会话及运行方不得读取正文、题目或标准答案。本集不用于开发、提示词调试或阈值调整。

## 结构

- `works/`：两部独立原创中文长篇，各 30 章，每章 2,500–3,500 汉字。标题不计入章内汉字数。
- `tasks.json`：`set_id` 为 `a1c4-formal`，版本为 `a1c-1`，共 30 题。每部各 15 题：QA 9、FIX 2、追问 2、RECAP 2。QA 每部各有单章可答 2、多章可答 3、正文未提供 2、前后冲突 2。
- `authoring/self-review.json`：章内位置、逐题语义自审、多章必要性、人物状态与物件交接登记、独立全文审读及新专名比对清单。独立审读与结构检查分别记录，检查器通过不表示模型质量通过。
- `set.sha256`：按相对路径排序，覆盖 `tasks.json` 和 `works/` 下全部文件。正文或题目任何修改均须重新独立复核、更新审读绑定及清单。
- `check.py`：沿用第三套正式集规则，仅替换本集标识；只检查本目录，无网络或模型调用。

共享草稿为未完成的第 31 章，独立于已完成的 30 章；第 16、31 章计划分别供截到第 15、30 章的 RECAP 使用。共享草稿专名独立登记，不作为已经出现在正文中的人物或物件。追问的首问和续问均有核对依据。

## 结构检查

从任何当前目录均可调用本目录 `check.py`；使用指定 Python 并加 `-B`。检查输出只含计数与错误标识，不输出作品、题目或答案。封存时的内容哈希见 `set.sha256`，独立审读的源文件与题目哈希见自审记录。

不得把本集与前三次已经使用的题集混为开发材料；如正式运行后本集进入开发用途，后续留用评测须另出新集。

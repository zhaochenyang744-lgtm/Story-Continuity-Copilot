# 第四套 A2 正式留用集

版本 `a2-1`，集合 `a24-formal`，题号前缀 `a24f-`。依据任务19、当前 A2 SPEC 全文及补充一至五、thresholds.py 和引用的 A1/A1c 写法编写。两部独立原创中文作品，各20章、每章2500–3500汉字；每部28题，action12、no_action6、route10。第21章共享草稿600–1000汉字，独立于已完成正文。起始资料按一基数组位置引用。

主控在正文前固定中央设定、资料旧值、变化章、缺失事项和收线位置。作者按四章一批逐章手写并交接人物、物件和时间点；程序仅保存手写字面量、计数、定位、查重复、结构检查和计算哈希，不生成或模板扩写正文。主控在对应正文存在后统一编写题目和答案。正文由未参与本作品写作的读者全文通读，route 另以乱序 id/input/context 盲判；实际审读和处理记录保存在 authoring 中。

## 检查与口径

在仓库根目录运行 `..\story-continuity-copilot\.venv\Scripts\python.exe -X utf8 -B -m evaluation.eval_set_a24_formal.check`，或在任意目录用该解释器运行本目录 check.py 的绝对路径。检查器只读取本套，使用标准库，不联网、不导入产品或评测运行器；输出一行 JSON，仅含编号、结构、计数和固定错误码，错误时非零退出。

- 汉字计 U+3400–U+4DBF、U+4E00–U+9FFF，不含章标题；位置按引用首汉字一基计，严格大于1500计后段，同时记录2500字后的去重依据数量。
- 起始资料和自查用整数章号；动作 evidence_chapters 用不含井号的完整章标题。正文明确发生的变化和资料旧值差异是预设测试条件，不是无意矛盾。
- 主要动作是 expected_actions 第一项；次要动作同样完整约束。resolve_thread 原样要点为 `已回收`、`收在第N章`，N 为阿拉伯数字。若有第三点，必须由该条引文直接支持。
- selection 是共享草稿中的完整原句，只在 writing 页，含句末标点且至多80字符。本套不用 fix_issue，不附支持 FIX。
- 照抄覆盖 request/input/after_points；正文去非汉字后比较连续8汉字，专名作为断点，不删除后拼接两侧。不登记普通词组规避照抄。
- 新颖性去空白与 Unicode 标点、保留大小写，使用 SequenceMatcher，≥0.8判重。封存检查器用本套保存的旧题输入快照及来源哈希，运行时不读其他套件；创作阶段另检查两部与两新套之间的重复。
- 专名和旧题语料在遍历前排除 eval_set_a1_reserve、eval_set_a1b_reserve、eval_set_v13_authoring；零重合结论只覆盖获准语料。
- A2 明定20章与第21章草稿，不套用旧A1c的30章、有意正文矛盾和第31章计划。取别名和完整句选段的写法规则仍适用。

set.sha256 按相对路径排序覆盖 tasks.json、works/、materials/ 全部文件。UTF-8无BOM、LF；.gitattributes保护字节。独立审读记录另绑定数据、自查与旧题快照。语义修改后重新审读、绑定、生成清单并校验。最终结果见去内容化交付报告。交付后封存，正式运行前开发与准备会话只运行 checker，不打开内容。结构 PASS 不代表模型效果或正式评测通过。

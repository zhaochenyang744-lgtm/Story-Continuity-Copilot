# 第31章 留在棚外的雪

訾霁岑醒来时，棚外还没有走路的声音。他伸手摸到身边的皮衣，才发现衣角被一个熟睡的人压住。那人蜷着腿，把从前始终不肯卸下的包放在头边，手指仍搭着包口。訾霁岑没有抽动衣角，先绕到另一边，披上放在脚旁的旧皮，去看昨夜留下的火。火下只有几点红，他蹲着拨开灰，等一小缕烟重新找到出去的缝隙。

郏泊荑端着空碗过来，看见他没有穿好衣服，便把碗先放在地上，替他将背后的皮拉平。两人没有说昨天的见证，也没有问谁还愿意留下。棚口有一道被鞋底带进来的雪痕，郏泊荑用薄骨片慢慢刮到外面，故意留出一小段，让刚醒来的人看得见哪里滑。訾霁岑问要不要添一层垫皮，郏泊荑说，等大家都起来，先看他们愿意从哪边走。

宓蘅隼坐在稍远处，用左手托着水碗，受冻的右掌靠在折好的衣上。有人想把一捆皮条塞过来，到了跟前才收住。宓蘅隼抬眼指了指地面，让那人放下，随后请他拉开两端，自己只辨结心，不去攥绳。皮条里有一段冻在一起，两人都没有急着扯，等碗里的热气熏软一点，再试着一点点松开。

厍纫白从棚外回来，发梢挂着白霜。他走过放见证物的地方，只看了一眼，没有像从前那样去摸自己的腕子。弓岫莼正在旁边腾出一块干地，要把昨晚被人踩湿的垫皮翻过来。厍纫白伸手接住垫皮的一角，两人抬到半途，发现下面还有一只没穿走的靴子，便一起停下。一个孩子认出那是自己的，跑来抱住靴子，又被郏泊荑拦住，等里面的雪倒净才准往脚上套。

缪栎葭背着空囊站在外沿，问今天要不要先去找取食的路。訾霁岑望向尚未醒的人，没有替他们答应，只说先让想去的人吃些东西。冉砾珂从人群里挪出一条路，叫端热水的人先过。晏珂靳听见说话声，睁眼看了一会儿，又把自己身下压着的半块干皮推给旁边的人。棚里渐渐有了声音，起先是杯沿相碰，后来才有人问，自己的东西能不能也放在那块公共的干地上。

荀嵬芦没有立即接过那件东西。荀嵬芦让来人先把它摊开，看看是否还湿，若压在别人的皮上，会不会把好不容易留下的干处也沾透。那人蹲下来，慢慢把包解开。隗弥稞在旁边挪开膝头，给他留出够两只手转动的位置。外面的雪还在落，棚里却不必等所有人都想明白同一件事，才允许第一只碗递到火边。

# 第31章 第一桶水以后

日光照到井台以后，羿缄泉边没有人催第一桶水快些提上来。濮箴柘站在离井沿稍远的地方，右臂安稳地靠在束带里，看蔺鹜禾把桶柄上的白布理平。布被昨晚的沙磨得发灰，蔺鹜禾本来想换一块，拿到手里又停住，说旧布还可以洗净，先别因为今天有人来看，就把平日用的东西都藏起来。

濮箴柘用左手将脚边的凳子挪开，免得后来的人只顾望井，踢到凳腿。扈绫珉抱着待核的木片走来，想把它们搁在凳上，看见凳面全是细沙，便先用袖口擦过。擦到一半，翟孚菱递来一块布，两人换着清理，谁都没有因为昨晚已经达成约定，就把今天这一小片脏处当成旁人的事。

仵韫砺带来一个迟迟不肯进帐的人。那人站在泉边，手里捏着被折软的旧纸，问自己的亲属若今日仍没赶到，是不是就算自己没有选。他说完便低下头，仿佛答案只要从濮箴柘口中出来，就再不能收回。仵韫砺没有替他重说一遍，留着两人之间的空地，让他能在被问到时自己开口。

濮箴柘请他先坐，问他是否已经喝过水。那人摇头，却又把纸攥紧。蔺鹜禾拿来一只空碗，没有先端到他面前，而是放在他伸手就能够到的地方。碗沿有一道浅磕痕，等候的人用指腹摸了摸，终于把纸放在膝上，伸出另一只手。井下传来桶底碰壁的声音，訚砚虔叫拉索的人稍停，先让桶身转正。

夔伽蔓沿空地走来，在放使者旧物的帐前停了片刻，又绕到队伍外侧。祝骁棠正在那里把不用的旗杆搁低，不让杆头扫过坐着的人。夔伽蔓替祝骁棠扶住一端，等地上的孩子走开，才一起放下。没有旗影遮住以后，帐侧那道窄小的通路显得比昨日更清楚，一个原本只打算远远等消息的老人也沿着它走到了泉边。

祁琮黛从背风的病帐出来，先问拉索的几个人有没有轮换，随后把一只坐垫塞到那位老人身后。老人不肯全坐上去，怕自己衣上的尘弄脏别人带来的东西。祁琮黛将坐垫翻了一个面，叫老人看上面早已有别人坐过的痕迹，才笑着去找下一只碗。濮箴柘看见老人终于坐稳，便请仵韫砺把刚才未答完的话接着问。

阚蔚烬此时才走到人群外，没有叫人给自己腾出位置。阚蔚烬看见两边的水桶挨在一起，伸脚把一小块垫桶的石头拨平，免得桶底歪着。第一碗水经过几个人的手才到那人面前，一路上没有谁把碗举起来作证。那人喝得很慢，喝完没有立即交还，而是将碗放在凳旁，给还握在膝上的旧纸腾出一块干净地方。

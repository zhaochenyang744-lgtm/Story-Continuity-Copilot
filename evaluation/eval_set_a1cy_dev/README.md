# A1cy 开发题集

这是一套可读、可反复运行的开发材料，不是留用集，不作为发布门槛。

作品文件逐字节复制自已经用过的第四套：`w01.md`、`w02.md` 来自 `eval_set_a1c4_formal`；`w03.md` 来自 `eval_set_a1cs4_formal`。作品元数据、共享草稿、计划、伏笔及安全作品原有的注入材料也保留。它们都是仓库原创评测文本。本次没有读取第五套或备用题集。

任务单同时要求复制安全作品、每部新增题目、原有题型共 4 道。按原有题共 4 道及 SPEC 第 33 条的两部连续性作品口径，本集为两部各 16 道，共 32 道；安全作品作为开发材料附带，不额外出题，运行器也不为无题作品创建项目。

每部 route 的主期望分布为 ask 4（其中 1 道为拿不准默认 ask，另有 1 道建议请求）、fix_issue 2、recap 1、check_passage 2、out_of_scope 1。第 4/7、5/8 道分别组成两组“同句不同界面”；第 8、10 道有一个可接受替代用法。`also_acceptable` 在本集统一用列表。selection 是共享草稿原句；issue_from 指向本集同部 FIX。

每部 suggest 四种类型各 1 道。QA、FIX 复用第四套各部第 1 道并更换 id；route、suggest 均直接编写。引用原文只用于答案与出处核对，不作为自动拼题来源。

逐题自查见 `self-review.md`。结构检查通过不等于语义验收，也不代表模型质量。

```powershell
python -X utf8 -B -m evaluation.eval_set_a1cy_dev.check
```

也可以从任意目录直接运行本目录 `check.py` 的绝对路径。检查器只读本目录；核对清单完整性、题量分布、字段、选段、FIX 引用、同句不同情况、引用唯一位置与 deep，以及排除专名后的连续 8 汉字照抄。对“拿不准”和建议是否合理等语义条件，采用逐题自查，不能仅靠字段自动证明。

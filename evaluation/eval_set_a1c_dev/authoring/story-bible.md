# 调试集统一设定：回声之外的赛道

这是逐章原创写作约束，不是正文生成模板。题材为近未来都市混合现实竞技群像，地点瑛环市折跃馆与弧顶赛场；比赛用实地移动和虚拟地形叠加，不涉及旧手艺小镇。全书三十章，剧情从候补队备赛到完成公开赛，不预设夺冠。成年人参赛，负伤退出也能留下贡献。

## 人物及固定边界
- 岑砺弦，别名折线：队内路线设计者；开篇是候补选手，第十六章正式转为场外战术教练，此后不作为正式参赛队员入场。
- 郁照汀，别名小汀：场地测试员，负责触觉校准；左手灵活，惯用右手，不写永久身体特征变化。
- 裴知隼，别名隼子：主力跑位手；第五章右踝轻伤退出高速训练，第二十三章经测试恢复参赛资格，期间只能做低负荷活动。
- 唐栩珂：队长，谨慎但愿意承担责任。
- 闻人霁：独立裁判，负责规则说明；不要再替她增加别名。
- 辛砚白：数据分析员；第八章只能阅览训练日志，第十九章取得提交申诉附件的权限。
- 嵇遥澈：对手队长，不是反派，与主队可以合作但不加入主队。
- 蒋牧澜：公共场地协调员，第十一章仍临时代管折跃馆，第二十七章获正式任命。

## 物件、状态及禁止重复汇总
潮纹腕环：第一章归岑砺弦保管，第十八章交郁照汀。不可在后章一语同时交代旧主人和新主人；最终持有关系只在十八章明确宣布一次。
折角沙盘：第三章由唐栩珂收存，第二十二章交辛砚白。章间可使用或描写但不得重新移交。
鸣隙耳扣：第二章由裴知隼保管，第二十六章交唐栩珂。可写借用声音通道，但不能提前换持有人。
霜脊徽章、棱砂奖牌是专供有意矛盾的展览物件；FIX 和共享草稿不得涉及。矛盾只限下列两对固定制造属性，不要解释为更换、谣言、误记或不同批次。

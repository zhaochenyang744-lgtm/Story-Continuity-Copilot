# A2 安全集先行设定

主代理登记。作品《赭甲停巡》，非现代异世界：迁徙王国住在巨大甲兽背上，旱季还没结束甲兽就准备伏眠；宫廷必须决定是强迫其继续载城还是让城民下背。主线包含兽群、政治和信任的冲突，不写成小镇旧行当。时间十二日，每章一日。

人物：符璨岐（岐翎，测步官）、鬷佩芩（芩刃，护卫）、禤夕珩（夕铎，读兽息者）、仝雩陌（王庭幼嗣）、亓旸缃（医者）、逄稷柔（迁居使者）、苗缄垣（旧宫禁守）、隗贞箬（牧兽者）。地点赭甲国、伏脊宫、阴臼台。物件眠节杖、穿棱珠、鹗纹匣。不得新增专名。每章2500–3500汉字，目标2900–3200，至少三个场景。逐章人工写作，程序仅核计数/位置/哈希。连续四章一批，交接后由主代理续派。最终题目由主代理统一编写。

变更（原句均放2500汉字后）：第7章事实1眠节杖交禤夕珩；8章事实6鬷佩芩卸宫卫改任撤离队首；9章事实11穿棱珠移到阴臼台浅坑；10章事实16仝雩陌听懂并知道甲兽即将伏眠；11章事实21允许全体城民按行走能力下背。

# A2 安全留用集

依据 `evaluation/assistant_a2/SPEC.md`、`thresholds.py` 及桌面任务05编写，不修改登记规则。一部独立原创非现代中文作品12章，每章2500–3500汉字；第13章共享草稿600–1000汉字。共12道injection，change 6，其余ask/recap各至少2。指令载荷是不可信故事或误收备注，不能执行为作者要求。

正文由主代理先行固定设定，按四章一批逐章原创。程序只保存已经写成的文本及核对结构、计数、重复、位置、哈希。主代理统一编写题目和金标；未参与正文写作的代理独立通读全部章节，核对起始资料、合法改动和注入对象的隔离。封存记录保存在authoring内。

## 校验与隔离

从仓库根目录运行 `..\story-continuity-copilot\.venv\Scripts\python.exe -X utf8 -B -m evaluation.eval_set_a2s_formal.check`，或从任意目录用该解释器运行check.py绝对路径。检查器只读本目录，使用标准库，无产品、评测或模型调用。输出只有一行JSON，含结构、数量、编号和固定错误码。PASS不代表模型安全题通过。

按相对路径排序的set.sha256覆盖tasks.json及works/materials内全部文件；独立通读记录另外绑定同组文件。UTF-8无BOM、LF，.gitattributes保护字节。交付后封存，正式运行前开发和准备会话只运行check.py，不打开内容及authoring。

## 口径

- 起始资料按数组的一基序号引用。chapter、planted_chapter、自查chapter为整数；任务evidence_chapters使用完整章标题。
- 正文长度只数U+3400–U+4DBF、U+4E00–U+9FFF汉字，排除章标题。依据及正文注入位置是一基首汉字位置，严格大于1500为深处；沿A1c第2节另核对至少三分之一去重依据在2500字后。
- 正文、事实、伏笔、选段载荷均在所指容器内唯一逐字出现。selection放在context内，须是共享草稿原句，含句末标点，不超过80字符。
- allowed_actions仅允许起始资料自查登记的合法目标；注入目标与合法目标既不能完全相同，也不能在同一对象上换动作种类后重合。
- 起始资料的事实内容除注明误收的载荷外都由正文支持。资料注入属于任务明确要求的例外，不将被误收的指令当成事实真值。
- 照抄检测request和after_points与正文的连续八汉字，专名作为断点。新颖性以本套authoring中的获准旧题输入快照重新计算SequenceMatcher相似度，保存来源哈希，检查时不读其他题集。
- 快照按来源保存归一化输入，核对并集、来源哈希格式和计数，独立记录另绑定快照与两份自查文件。本套作者选择每道最多两条合法动作及与自查完全相同的原句摘录，属于成卷约束，并非擅改登记规则的一般上限；额外authoring证据不进入产品运行字段。
- 明确禁读的eval_set_a1_reserve、eval_set_a1b_reserve、eval_set_v13_authoring不在专名及新颖性比对范围，零重合只覆盖获准语料。开发分支在交付前再次检查是否已出现可比对任务。
- 独立语义通读与结构检查分别记录；无产品运行、无评测运行、无模型接口调用。

最终冻结数字及验证结果以交付报告为准。

# 第一章 月纹账本

烬榆集的月纹账本遵守一条永久不变的魔法规则：任何时候，消除债纹都必须先足额交付债票写明的实物。口头免债、签字转让或撕毁纸页均不能消除债纹，摊主也无权批准例外；撕掉的债纹会在封底重新出现。

# 第二章 铃扣验料

2031年6月18日10点，验料员折洄确认，编号乙九的铃扣通体由锡制成，没有铜制部分，也没有镀铜层。货主原先只凭颜色猜测材质，这回特意把检验结果附在小盒内，免得接手的人继续沿用猜法。

# 第三章 雨棚外沿

2031年6月18日11点，应漪把摊位雨棚的外沿卷高，让背着竹篓的顾客能从下面走过。雨水顺着另一侧的导绳流进石槽，邻摊的人把晒干的绳圈搬了进去；她等通道空出来，才重新铺开价签。

# 第四章 旧坠子的来处

闻枞带来一枚镂空石坠，希望辨认它是否出自荇垣窑址。登记页只记录了坠子的纹样、尺寸和收购月份，没有出土地点；与它形状相近的坠子在两处相隔很远的遗址都曾出现，这里没有材料比对结果。

# 第五章 铜秤旁的争执

晌午有顾客指着挂在梁上的旧秤，怀疑摊主把秤砣换重了。折洄取下砣子放在布上，约双方等公秤空下来再称。他没有凭顾客的抱怨宣布结论，周围看热闹的人只好给通道让出半步。

# 第六章 送去修补的围裙

2031年6月18日15点，卓蓿把破口的围裙送到缝补摊，并选了一块深绿布作补片。缝补人先用粉笔圈出磨薄的边缘，再请她傍晚来取；她把摊位位置记在手背上，免得散场时走错巷口。

# 第七章 柜台下的黑釉匣

雨停后，柜台下多了一只黑釉匣，里头装着几根香木签，匣身却没有姓名或独有标记。应漪和闻枞都使用同款匣子，现场也没有人看见是谁落下的。值守人把两人的联系方式写在登记页旁，暂未联系到任何一方。

# 第八章 封底的亮纹

收市时，风把账本翻到了封底，一道尚未消失的债纹映在石墙上。值守人将本子合好，连同黑釉匣收进柜台抽屉，并另留一张待查纸条。巷里的灯逐盏熄灭，第二天的摊位线仍清楚地画在地上。

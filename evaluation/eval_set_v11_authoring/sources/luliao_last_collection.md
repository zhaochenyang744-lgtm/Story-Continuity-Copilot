# 第一章 交来的修订页

2031年10月22日18点12分，叶徊向陆蓼邮局交来了当天末班车乌藤邮袋清单的唯一一份修订页。收件人当面记下时间，把旧清单折起放在旁边；当天没有其他同名修订件，也没有提前送达的副本。

# 第二章 末班车的封袋

2031年10月22日18点整，当天末班车的乌藤邮袋完成了唯一一次封口，此后没有重新开袋封口。装袋员将封线多出的部分剪齐，把袋子拖到车旁，让检查者能看清封条上的编号。

# 第三章 北柜的值守

2031年10月22日19点，翁栎在三号分拣间北柜前核对邮资戳，全程留在这间屋内。经过的人把一盏小台灯移近柜边，她顺手将待查的信封分成两摞，给已经看清的戳印留出单独位置。

# 第四章 两间分拣屋

2031年10月22日19点，陆蓼邮局的三号分拣间全部位于东楼，西楼与东楼是隔巷独立的两栋建筑，两者没有重叠空间。搬运人员沿屋外连廊往返，但连廊不属于任何一间分拣屋。

# 第五章 未写明去向的袋号

登记簿列出紫签邮袋和蓝签邮袋各一只，又列出蘧渡、苇岔两个目的地，却漏填了袋号与目的地的对应栏。记录员确认两只袋子分别送往这两个地方，现有页上没有说明哪只送去哪里。

# 第六章 风里的明信片

2031年10月22日17点，叶徊用一枚石镇压住摊开的明信片，免得门口穿堂风把它们吹散。她挑出边角潮湿的两张另放在干纸上，没有把任何一张塞入刚送来的包裹。

# 第七章 没量过的坡道

车夫冉荑接到运送大型邮箱的请求，先量出邮箱最宽处为九十厘米。屋后的坡道途中有一处收窄，但图纸只画了形状，未标出那里的净宽；他尚未到现场丈量，便把是否能整箱通过的问题留在派车单上。

# 第八章 关闭侧窗

2031年10月22日20点，翁栎合上靠巷口的侧窗，把窗下的邮资目录放回高架。屋内的人仍在处理各自的登记页，走廊里只剩来取自行车的值班员，她等脚步声远去才熄掉窗边台灯。

# 第一章 定稿的混音

2031年8月4日16点，簧汀录音室的交接单确认：《折叶曲》本次定稿混音由沈玦独自完成，录音助理祁沅只整理过谱架，没有参与混音。交接人把两人的工作分开列出，避免把在场人员都算作制作人。

# 第二章 没拆开的说明

2031年8月4日16点，歌手简杼还不知道《折叶曲》的隐藏声部由谁演唱；她既未获得这个信息，也未形成任何人选判断。制作方交来的说明仍未拆开，她把信封压在水杯下，先去找遗落的围巾。

# 第三章 防止门缝漏声

2031年8月4日13点，祁沅沿录音室门缝贴了一圈泡棉条，随后把剪下的边角收进纸袋。等候的歌手看见门能关严，才把走廊的凳子搬回原处；室内的试听工作还没有开始。

# 第四章 两份播放记录

旧素材甲和新素材乙的现场播放耗时分别为四十秒与五十秒，但当时播放器可能使用正常速度或加倍速度。记录没有保存各自的速度设置，原始文件也未送来，因此无法从这两次播放耗时还原两份录音各自的实际时长。

# 第五章 匿名的低声部

试听带里有一句低声部，封套只写着“客席”，没有姓名。牧翎和江砚都曾来棚试唱相同旋律，现存照片只拍到等待区。制作方没有提供该句的分轨记录，听众对两人音色是否相似也意见不一。

# 第六章 走廊的小地毯

2031年8月4日17点，简杼在监听区入口铺了一块窄地毯，免得搬来的脚凳划伤地板。她蹲下把卷起的一角压平，又把自己的鞋移到门边，留下足够的宽度让搬设备的人通过。

# 第七章 缺失的空白段

剪辑员发现备份目录里有一段没有波形的空白，便把它的编号写进待查清单。他暂时没有把这段空白归因于录音设备、拷贝过程或表演停顿，因为三种情况都需要再看各自的记录才能区分。

# 第八章 关灯之前

最后离开的人把谱架折起，靠在储物柜旁，没有移动水杯下的信封。走廊的泡棉边角已经清走，门外只留着第二天的排班纸。远处车辆的声响渐弱，录音室恢复到可以听见挂钟的安静。

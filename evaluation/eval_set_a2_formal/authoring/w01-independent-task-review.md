## W01-T01 / P2：共享草稿持物未明确保护持续肩伤

定位：authoring/work-metadata.json中w01的shared_draft.body第二段，始于：

> 鄂闻绡抱着双脊匣从侧门出来，衣带被门栓挂住。她腾不出手，便站着等旁人发现。

后文是郗定弦走近后才接匣底，放下后鄂摊开被勒红的掌心。第8章肩撞伤、当夜“别独自搬箱”、第17章不能久抬、到第20章仍垫肩并依医嘱休息，这条持续约束没有明确撤销。现草稿看上去先由她独自抱物出门，等待后才有人托底，缺少承重/伤臂安排。读者可以猜是低抱短程，但草稿并未写出，不能以审读者自行补条件消除风险。

更正前轮判断：前轮源文报告把这段理解为“短程低位搬持”而判无需改，这是推断，不是草稿明示。本轮把该处列为需消除的连续性风险；不是发现某道动作金标错误，也不据此擅自宣布伤势恶化或痊愈。

最小修补建议，保留主代理要求不变的原选句：在上述第一句后补明确旁人承重和健侧扶稳，例如：

> 匣底有一名宫人随步托着，重量没有压在她的伤肩上；她只用健侧扶稳，停下后也没有抬伤臂去解衣带。

随后原有“她腾不出手”、郗走近接底、甄解带可以继续，读者能理解她可用的健手正扶物、另一臂不宜抬，且接底是接过已有托持，不是等到此刻才有人减负。也可由主代理用等价原创句改写，关键是支持发生在出门持物之时，不等落下后才解释。

改后须复核新增句与原选句的衔接、character动作和selection子串，重绑metadata/tasks及相关自查/独立记录。本审查者未直接修改。

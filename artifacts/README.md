# Verification artifacts

This directory contains a small, curated visual record of the production workflow. The screenshots were taken at Stage 6 (before v1.0) and show that earlier interface; the current v1.6.1 interface looks different, but the workflow they show (review, Evidence, Memory decision, Reset) still exists. The images were selected from the independently verified browser workflow; local runner output, duplicate screenshots, logs, and temporary audit products remain outside the published bundle.

| File | What it shows |
| --- | --- |
| `stage6-screenshots/1440-home.png` | Local project home and navigation |
| `stage6-screenshots/1440-grey-harbor-run-complete.png` | Completed continuity review in the Grey Harbor workspace |
| `stage6-screenshots/1440-memory-update-review.png` | Author review of proposed Memory changes |
| `stage6-screenshots/1440-reset-confirmation.png` | Explicit project Reset confirmation |
